# Project Proposal — Bim Modeling

## Project Understanding
You need assistance with: 
**docs: upgrading from machines that have both 0.9.0 installer scopes**

*Project description:*
## Symptom

A machine that already has both 0.9.0 installer scopes installed (the 0.9.0 MSIs allowed that) cannot simply upgrade. The 0.9.1 MSIs refuse to install while the other scope is present. If one scope was uninstalled earlier, orphaned `.addin` manifests or add-in folders may be left behind and block the other scope.

## Repro

1. Install the 0.9.0 SingleUser and MultiUser MSIs together.
2. Uninstall one of them. Windows Installer leaves the shared components, and the per-user or per-machine add-in files stay.
3. Run a 0.9.1 MSI of either scope.

## Expected

The README install section says how to recover:

1. Uninstall both products (Apps > Installed apps).
2. Delete leftover `RevitModelMcp` folders and `.addin` manifests under `%APPDATA%\Autodesk\Revit\Addins\<year>` and `%ProgramData%\Autodesk\Revit\Addins\<year>`.
3. Install one scope.

## Evidence

README currently says only "Each refuses to install while the other is present, so uninstall the other first". It does not mention the 0.9.0 leftover case. On the bench, 0.9.0 to 0.9.1 upgrades within one scope worked in place, and a clean uninstall left nothing. The mixed 0.9.0 state is documented in the 0.9.0 review and was not re-tested with the 0.9.1 MSIs [inference for the leftover-manifest block].
## Where to start

- `README.md`, install section: the sentence "Each refuses to install while the other is present, so uninstall the other first". Add the recovery steps from Expected there.
- To test: `pip install -r docs/requirements.txt && mkdocs build --strict` and `pre-commit run --all-files` from the repository root. No Revit needed.
