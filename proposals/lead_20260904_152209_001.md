# Project Proposal — Bim Modeling

## Project Understanding
You need assistance with: 
**Author RevolutionElem: true spheres and revolved bodies instead of disc stacks**

*Project description:*
Refs #766, #591. Owner: *"we really need to stop not making circles out of smaller rectangle extrusion and make its true form"* — and asked for a true-sphere test file, which today's engine cannot produce.

## Where the line is now

#766 fits lying cylinders as TRUE cylinders (the Greenlee's 35 round parts). What remains disc/box approximations:

- **spheres/domes/cones** — `revolve.py` stacks discs, deliberately, and reports the volume ratio;
- **sculptural revolves and sweeps** — the Greenlee `shoe_casting` stays its prismatic envelope.

## Why this is expressible

The famdoc schema declares the full form family: **`RevolutionElem`** (`m_sketchId` — the same shape as `ExtrusionElem`), `RevolutionCurveData`, `SphereData`, plus `SweepElem`, `SweptBlendElem`, `BlendElem`. So a true sphere (a semicircle revolved about an axis) is a format-native body; the engine simply has no constructor.

## DONE
1. `famgen.geometry` (or a new module) authors a `RevolutionElem` form: profile sketch (arc + axis line), the revolve element, and the cached B-rep — #591 round 4 established the cached B-rep is what Revit draws, so the spherical/toroidal surface tokens must be authored, not hoped for. Read `SphereData`/`RevolutionCurveData` off the schema first, the way the driver tables were.
2. A `sphere` part shape switches from the disc stack to the true revolve; `revolve.py`'s stack remains as the fallback and the control.
3. Desktop verdict recorded per hard rule 4 before any surface calls spheres exact — the owner already holds `out/sphere/sphere_test_12in.rfa` (64-disc stack) as the before/after control.
4. `fit_solid` gains a sphere fit (round in plan AND in a side projection, fill ≈ 2/3 against the vertical-cylinder envelope) that emits the new shape.

## Territory
`src/rvt/famgen/geometry.py` (new form constructor) or a new `famgen/revolution.py`, `src/rvt/famgen/revolve.py` (fallback wiring), `src/rvt/ifc/assembly_parts.py` (sphere fit), tests, `docs/inbox/ifc-assembly-rfa.d/`.
