# Project Proposal — Bim Modeling

## Project Understanding
You need assistance with: 
**[BIM] Bim roof tool refactor or improvement**

*Project description:*
### Problem description

In BIM workbench, bim roof tool is probably the weakest aspect right now.One of the things I found is that Roof tool in Bim workbench constantly failed to build pitched hip roofs,in complex or asymmetrical shapes.

Example roof type:

<img width="783" height="391" alt="Image" src="https://github.com/user-attachments/assets/6dccbd8a-f57d-4f35-8042-bcf82f757aec" />

when tried to create roof with arch roof tool and set the desired roof angle and length,not only the roof tool doesn't cut the exceeded roof run properly,the roof geometry is also broken.

<img width="1920" height="1080" alt="Image" src="https://github.com/user-attachments/assets/494bc2b9-f6ad-40a5-b4d4-f81828bce1a9" />

The same operation can be done flawlessly in other BIM softwares like Archicad or Bonsai Bim.You can just set how much roof angle you want,30 or 45 degree or whatever, and the roof geometry adapts perfectly.

https://github.com/FreeCAD/FreeCAD/issues/21796
https://github.com/FreeCAD/FreeCAD/issues/21848

My Proposal?

Make the roof tool to be similar to Bonsai or other BIM softwares like ArchiCAD,Revit.You only need to type once to define the roof angle and overall roof height,and then the roof tool automatically fully generate the roof shape.

<img width="1920" height="1080" alt="Image" src="https://github.com/user-attachments/assets/fa851aee-9dd3-4efa-8b6f-b0836691fe97" />

It would also need to have these modification options.

<img width="1920" height="1080" alt="Image" src="https://github.com/user-attachments/assets/4267648a-8757-4461-8add-bbbd6deb6a64" />

1. You can change the roof pitch angle by sliding the node point along the path,to create gable roofs from hip.It is the same method used in Both Bonsai and Bim like Archicad.
2. You can also slide left and right from the top to create uneven,asymmetrical hip or gable roofs,where the roof run in opposite side is much larger.
3. You can lift along z-axis to rasie only a section of the roof.This could also solve this issue.
https://github.com/FreeCAD/FreeCAD/issues/23485

The roof tool should also need to be able to add and define different roof pitch angles and heights,so that we could also make roof like this.
