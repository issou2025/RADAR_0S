# Project Proposal — Bim Modeling

## Project Understanding
You need assistance with: 
**A prompt for a "2 tier slotted trapeze with threaded rod" builds the whole trapeze — rods, slotted strut tiers, nuts and washers — with every dimension as a family parameter**

*Project description:*
Refs #898

## Why
`route run --prompt "a 2 tier slotted strut trapeze hanger with threaded rod" --output rfa` today builds **one 10 ft strut channel** and drops `tier, slotted, trapeze, hanger, threaded, rod` as ignored words. The owner asked for the trapeze assembly with "all parameters needed to adjust the family".

## DONE
1. A `strut_trapeze` archetype in `src/rvt/famgen/archetypes.py`: N tiers (default 2) of slotted 1-5/8 strut, two vertical threaded rods, a square washer + hex nut above and below each tier at each rod; all sizes nominal and overridable by the prompt (`given`), nothing claimed as a manufacturer part.
2. The prompt above (and "2 tier trapeze", "strut trapeze", "unistrut trapeze") resolves to it, not to `strut_channel`; numbers like "3/8 rod", "36 in long", "3 tier" bind to the right dimension.
3. Every trapeze dimension is authored as a Revit family parameter with its value (Strut Length, Rod Spacing, Tier Spacing, Number of Tiers, Rod Diameter, rod lengths, channel section, slot pattern…).
4. The produced `.rfa` validates with 0 errors (2026 and 2025); stream-local tests + shard drop-in; `sync_plugin --check` clean.

Honest boundary: the parameters carry values; editing them in Revit does not yet move geometry (the drive chain has no desktop verdict, #372 / #787) — the report says so, and a different size is a re-generation.
