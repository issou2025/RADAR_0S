## Summary

`flutter_image_compress_common` 1.1.1 contains a partial Built-in Kotlin compatibility branch, but its Android build still hardcodes `compileSdkVersion 34` instead of using the consuming Flutter project's compile SDK through the modern DSL.

The latest published package is still 1.1.1. With Flutter 3.47.2, AGP 9.1.0, and Gradle 9.3.1, Flutter continues to flag this plugin during its Built-in Kotlin migration check because the build file retains a fallback `apply plugin: 'kotlin-android'` branch. The package should complete the migration using the built-in Kotlin extension and the current `compileSdk = flutter.compileSdkVersion` form, while preserving compatibility for supported pre-AGP-9 consumers if needed.

Relevant existing reports/prs include #362, #390, #400, and #401, but the published 1.1.1 Android build still contains the legacy `compileSdkVersion 34` declaration and KGP fallback.
