## Static release-readiness finding

The canonical branch contains substantial Dart/Flutter application logic for Patient, Doctor and Other Provider apps plus a shared `mobile_core`. However, each app root currently contains only `lib/` and `pubspec.yaml`; no `android/` or `ios/` runner project is present in the Release 1 repository tree.

The current CI resolves Flutter dependencies, runs `flutter analyze` for each application and `flutter analyze && flutter test` for `mobile_core`, but it does not produce Android APK/AAB or iOS archive/IPA artifacts.

The shared mobile core already includes `flutter_secure_storage`, `livekit_client`, `http` and `url_launcher`; Patient Mobile also includes `geolocator`. These are useful application-level foundations, but the native platform wiring needed for Keychain/Keystore, camera/microphone/location permissions, deep links, push, secure app lifecycle and store signing is not evidenced by the current app roots.

Status: **BLOCKED FOR PRODUCTION MOBILE RELEASE** until native runner projects and signed-build/device evidence exist.
