# Project Proposal — Structural Drawings

## Project Understanding
You need assistance with: 
**Revit 2027 structural model: 104 columns, beams, slabs, flights and footings on no storey (#1829)**

*Project description:*
Found by HWT-25's report (#1829) on a confidential Revit 2027 structural model (CHL), read with 0.18.0.

**What happens.** The storey matches Revit's export for 75% of the elements in common. 104 elements are reported as `unsupported_geometry_missing_level`:

| class | elements |
|---|---:|
| `IfcColumn` | 48 |
| `IfcBeam` | 25 |
| `IfcSlab` | 14 |
| `IfcStairFlight` | 14 |
| `IfcFooting` | 3 |

The diagnostics also say that 2,216 elements reached their storey through the partition Level references, with 15 storeys read.

**To find out:**
- Which reference the 104 lack. A structural column has a base level, a beam a reference level. Either the reader does not read the field for these classes on 2027, or the element names no level and Revit places it by elevation.
- Whether the same elements are on no storey in the measured models' exports. The Autodesk 2027 structural sample is one candidate.

**Done when** each of the 104 kinds is on Revit's storey where a record names the level, and the rest are reported.
