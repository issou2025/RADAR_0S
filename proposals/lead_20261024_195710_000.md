## Problem Statement

Fab's second technical review of the Unreal plugin came back as **changes needed** for one reason: the Source zip carried `LICENSE`. Fab refuses EULAs, licence files and policy files that sit beside the licence picked on the listing (the Fab Standard License), and its staff may delete them without warning. Every other row of the checklist passed, the per-file copyright header included. The packaging steps in the Unreal README copy `LICENSE` and `TRADEMARK.md` into the package on purpose, so every submission would fail the same way. `TRADEMARK.md` is a policy file and would be the next one flagged.

The listing is free under the Fab Standard License, with Apache 2.0 declared here on GitHub. Leaving the licence file out of the storefront package is lawful while every line of the plugin is Mantle Place's own: the redistribution conditions of Apache 2.0 bind people who redistribute someone else's work. That stops being true the day an outside contribution lands, because Mantle Place then receives it under Apache 2.0 like anyone else.

## Solution

The Source zip (the one asset uploaded to both the GitHub release and Fab) carries neither `LICENSE` nor `TRADEMARK.md`. The repository it is released from still carries both at its root, and the GitHub-only Win64 binary zip keeps both. Before any outside contribution lands, `CONTRIBUTING.md` asks contributors to agree, by signing off, that their work may ship through such a storefront while its source stays public here under Apache 2.0.

## Acceptance

1. The Unreal README's packaging steps build the Source zip without `LICENSE` or `TRADEMARK.md`, and still copy both into the Win64 binary zip. The steps say why in one sentence (the storefront refuses licence and policy files beside its own licence).
2. The plugin's `Config/FilterPlugin.ini` names no licence or policy file. Its comment says the plugin carries none and why, so nobody adds them back.
3. The README's **Fab pre-submit list** gains an item: the Source zip contains no licence, EULA, trademark, code-of-conduct or other policy file.
4. `tools/unreal-naming/check_third_party_layout.py` also fails when the plugin's `FilterPlugin.ini` lists a licence or policy file (`LICENSE*`, `COPYING*`, `NOTICE*`, `EULA*`, `TRADEMARK*`, `CODE_OF_CONDUCT*`), with unit tests for a passing and a failing `FilterPlugin.ini` beside the existing ones.
5. `CONTRIBUTING.md`, in **Sign your commits off (DCO)**, right after the paragraph that licenses contributions under Apache 2.0, carries this paragraph verbatim:

   > **Storefronts.** Some storefronts, Fab among them, refuse packages that carry a licence file. By signing off, you also agree that your contribution may be distributed through such a storefront without the `LICENSE` file, provided its source stays public in this repository under Apache 2.0. This grants no right to change the licence or to close the source.

6. Any other mention of the package carrying `LICENSE` or `TRADEMARK.md` (release notes template, `docs/releases.md`, `unreal/CLAUDE.md`, root README) agrees with the above.
7. **Verified live** (founder): the next `unreal-*` release's Source zip lists no `LICENSE` or `TRADEMARK.md` (`unzip -l`), and the Fab resubmission from that asset notes that the package no longer carries licence or policy files. That step is tracked in #277.

## Implementation Decisions

- **One Source zip for both channels.** The pre-submit list already requires the storefront upload to be the same asset as the GitHub release's. Keeping that rule beats a second, storefront-only zip that could drift; the GitHub release sits in a repository whose root carries both files.
- **The Win64 binary zip keeps both files.** It ships only on GitHub, so nothing refuses it.
- **Per-file headers stay unchanged.** Both Fab reviews passed `// Copyright 2026 Mantle Place LLC. Licensed under the Apache License, Version 2.0.` and the first quoted it by name.
- **The contributor clause is not a CLA and not a relicence.** It adds one permission to the DCO sign-off and grants no right to change the licence or close the source, so the statement that the project reserves no right to relicense stays true as written. It must land before the first outside contribution in `unreal/`, because it cannot reach back to code already contributed.
- **The gate extends the existing third-party layout check** rather than adding a new script: it already owns "no licence text in the plugin outside `Source/ThirdParty/`", and a `FilterPlugin.ini` entry that pulls one in is the same rule.

## Testing Decisions
