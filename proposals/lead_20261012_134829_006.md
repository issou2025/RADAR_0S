# Project Proposal — Bim Modeling

## Project Understanding
You need assistance with: 
**BIM_Trimex error when extending parallel with the current Z-axis**

*Project description:*
### Problem description

The `BIM_Trimex` tool shows error when extending a in a direction of Z-axis of the current working plane and inserting a value without cursor movement. Typical example might be height of a column.

I am able to reproduce with `Draft_Trimex` in FC 1.1.4



### Workbench affected?

BIM

### Steps to reproduce

- open new file
- create a column
- select the top face of the column
- run `BIM_Trimex`
- **make sure to not move the cursor after running the command** - there is `0` in the task panel `Distance` value
- type any number (e.g. `500`)

### Expected behavior

No error should happen.


--------------------------
I would expect this behavior (up for discussion):

- if positive value is entered, the object should be extended/trimmed in positive Z-axis value
- if negative value is entered, the object should be extended/trimmed in negative Z-axis value

This is not how the values are interpreted when cursor is moved before the value is entered (see video bellow). It is interpreted in reverse way. I think it would be best to switch directions in this case.
