# Project Proposal — Bim Modeling

## Project Understanding
You need assistance with: 
**Revit: command glyphs from reproducible sources, wired theme-aware to every ribbon button**

*Project description:*
**Host:** Revit

**The problem**

Once the mark exists, the remaining buttons still have no icons, and Revit since 2024 runs a light and a dark UI theme, so a single icon set reads badly on one of them. The Account face needs the mark; `Vault`, `Import Bundle`, `Probe Terrain` and `Open Logs` need command glyphs drawn in the flat monochrome style Autodesk's own buttons use, with the brand orange as the one accent, so the tab sits beside Autodesk's without looking like an advert.

**What you would like**

- Glyph sources: SVGs chosen from the MIT-licensed Tabler icon set, committed under `revit/src/MantlePlace.Revit.Addin/Resources/src/` with the licence text beside them, one per command. Recolour to Revit's light-theme and dark-theme foreground greys, with the orange accent where it earns its place.
- A render script (`revit/tools/Render-RibbonIcons.ps1`) that produces every PNG from the SVGs at 16 and 32 px per theme, so each binary is reproducible from a text source and the Binaries rule has a paper trail. Every generated PNG is committed; the script is how it is regenerated, not a build step.
- Wiring in `MantlePlaceApplication.cs`: set `Image` and `LargeImage` on every button, including the split button face and its dropdown items, from the retained references the Account issue introduces. Choose the set from `UIThemeManager.CurrentTheme` at startup, and subscribe to `UIThemeManager.ThemeChanged` to swap the set when the user changes theme. Both APIs exist from Revit 2024, so the 2025 floor covers all three gated versions with one code path.
- Images load as embedded resources via pack URI, not from loose files beside the DLL, so the packaging script does not grow a copy step.
- Verify by hand in Revit 2025, 2026 and 2027, both themes; the shim is not built in CI. Attach one screenshot per theme to the pull request.

Depends on the Account split button issue (retained references) and the logo render issue (the mark).
