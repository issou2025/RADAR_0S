## Recommendation (verbatim)
> Improve your app's performance with bitmap downsampling
>
> Your app is using BitmapFactory without downsampling. To reduce bitmap memory usage, consider using an image-loading library to automatically handle memory management and downsampling for you. Alternatively, use `inSampleSize` to downsample when decoding large bitmaps. This will make sure that you only load the resolution needed for your app's UI.

## Suggested direction
- Audit direct `BitmapFactory` / `decode*` usage (app + plugins)
- Prefer an image-loading library with automatic downsampling (e.g. Coil / Glide on Android, or Flutter equivalents if the call sites are Flutter-side)
- Or set `BitmapFactory.Options.inSampleSize` when decoding large bitmaps for UI
