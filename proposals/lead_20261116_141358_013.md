# Project Proposal — Bim Modeling

## Project Understanding
You need assistance with: 
**Snapshot producer gaps: types, CAD links and door From/To Room data**

*Project description:*
**Size:** L  |  **Priority:** P1

**Problem**
Two audits cannot rate a real model because the snapshot lacks data.
- `model_bloat_audit` says "not rated, not enough data": the live snapshot has no `types` list, no CAD records and no unused-type data.
- `schedule_consistency` returns `complete=false` on the real project: the door-to-room checks need From Room and To Room keys, and room level and location, none of which are saved.

**Evidence**
- `packages/mcp-server-revit/src/revit_mcp_server/modules/model_bloat/module.py:19-23`: "Today's live snapshots carry no `types` list and no CAD records"; `:74` reads `types` and `cad_scanned` from the file.
- `packages/mcp-server-revit/src/revit_mcp_server/modules/schedule_consistency/module.py:241-255` ("Not enough data for N door(s): both From Room and To Room keys must be captured"); `:266` `complete` is false when any check other than `door_mark_pattern_mismatch` was skipped.
- Producer: `packages/revit-bridge-addin/src/Bridge/BridgeCommandFactory.cs:5067-5083` (no `types`, no `cad_scanned`).
- Live results on Revit 2024: bloat "not rated"; schedule `complete=false`.

**Proposed change**
In the snapshot add (a) `types` (id, name, category, family, instance count), (b) `cad_scanned: true` plus ImportInstance / CAD link records (name, is_link, view-specific flag), (c) `From Room` / `To Room` keys on doors and room `level_uid` + location. Keep each block optional behind a `include` argument so the default snapshot stays inside the 20 s budget. Bump `schema` to `amb.snapshot/1` with new optional keys only (no break for old files).

**Done when**
- On the fixture model `model_bloat_audit` returns a rating, not "not enough data", and unused types are listed.
- `schedule_consistency` returns `complete=true` on the fixture model.
- Old snapshot files (without the new keys) still load and still say "not enough data".
- Snapshot time with the new blocks on the real project is recorded.

**Gate impact**
none
