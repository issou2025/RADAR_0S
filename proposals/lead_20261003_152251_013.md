# Project Proposal — Flutter App

## Project Understanding
You need assistance with: 
**[CLI] Remove Flutter requirement from CLI — enable dart pub global activate without Flutter**

*Project description:*
## Overview

The SATE AI CLI currently requires Flutter to be installed (`flutter pub global activate sate_ai`). This is a significant barrier for the primary use case of the CLI: running stress tests in CI/CD pipelines.

Most CI environments (GitHub Actions, GitLab CI, Jenkins, CircleCI) do not have Flutter installed by default. Setting up Flutter in CI just to run a testing CLI is unreasonable. The Dart SDK alone, however, is lightweight and commonly available.

This issue tracks making the CLI work with `dart pub global activate sate_ai` — no Flutter required.

---

## Current Behaviour

```bash
# Requires Flutter installed
flutter pub global activate sate_ai
sate_ai --model model.gguf --injectors memoryPressure
```

## Target Behaviour

```bash
# Works with only Dart SDK
dart pub global activate sate_ai
sate_ai --model model.gguf --injectors memoryPressure,malformedInput --output report.json
```

---

## Current State (Important Context)

The CLI already uses a pure-Dart barrel export (`lib/sate_ai_cli.dart`) that excludes the three Flutter-only adapters (`OnnxAdapter`, `TFLiteAdapter`, `FllamaAdapter`). The remaining work is to remove the `flutter` SDK requirement from the package that the CLI is installed from.

Once `sate_core` (#118) is extracted, the CLI can depend on `sate_core` directly and be published as a pure Dart package — no Flutter needed at install time.

---

## Why This Matters

Once this works, any developer — regardless of their language or framework — can add SATE AI to their pipeline with a single line:

```yaml
# .github/workflows/ai-test.yml
- name: Install SATE AI
  run: dart pub global activate sate_ai

- name: Run stress tests
  run: sate_ai --model models/model.gguf --injectors memoryPressure,malformedInput --output report.json

- name: Upload Report
  uses: actions/upload-artifact@v4
  with:
    name: sate-ai-report
    path: report.json
```

This works for Flutter devs, Android devs, web devs, Python devs — anyone who uses GitHub Actions. This is what "globally available" actually means in practice.
