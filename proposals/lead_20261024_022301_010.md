# Project Proposal — Flutter App

## Project Understanding
You need assistance with: 
**[iOS] SystemContextMenu asserts "Attempted to show while another instance was still visible" when the text toolbar is hidden and re-shown in one frame (e.g. a jump scroll)**

*Project description:*
### Steps to reproduce

On a device (iOS 16 or later, debug build), with the app in the code sample:

1. Double-tap a word in the text field, so the system context menu shows.
2. Wait. Every two seconds the app jumps its scroll view by one pixel (`ScrollController.jumpTo`).
3. The next jump throws the assertion. An animated scroll (`animateTo`) does not.

In our app the assertion fired twice on a screen of two text fields with the keyboard up. In a widget test of that screen, raising the keyboard under a field whose menu is up reproduces it, one assertion per frame of the rise, because `EditableText` scrolls the field into view with a zero duration (`showOnScreen(duration: Duration.zero)`).

Deterministically, with `flutter_test` only: the widget test in the code sample. It passes on 3.47.1, which means the assertion is thrown in the two cases that expect it:

- a zero-duration scroll of the enclosing `Scrollable` while the menu is up;
- the menu up in one `TextField`, then a double tap in another `TextField` whose two taps land with no frame between them (a janky frame on a device).

### Expected results

The new menu replaces the old one, as `SystemContextMenu`'s docs say: building one while another is visible hides the old one and shows the new one. `SystemContextMenuController.showWithItems` says the same: calling it while another menu is visible removes the old menu before showing the new one.

### Actual results

In debug, `SystemContextMenuController.showWithItems` throws:

```
Attempted to show while another instance was still visible.
'package:flutter/src/services/text_input.dart':
Failed assertion: line 3033 pos 7: '_lastShown == null || _lastShown == this || !_lastShown!.isVisible'
```

from `_SystemContextMenuState.build` of a newly mounted `SystemContextMenu`. The new menu never shows, and when the old `SystemContextMenu` is disposed later in the frame it sends `ContextMenu.hideSystemContextMenu`, so no menu is left.

Why, as far as we can tell: each `_SystemContextMenuState` owns its own `SystemContextMenuController`, and only `dispose()` → `hide()` clears `_lastShown`. When the toolbar is hidden and shown again in one frame, `ContextMenuController` removes its `OverlayEntry` and inserts a new one; the new `SystemContextMenu` mounts and builds in that frame's build phase, while the old state is disposed only in `finalizeTree`, after it. So the new controller finds the old one still `_lastShown` and visible. `EditableText._handleContextMenuOnScroll` does exactly this for a zero-duration scroll (hide on `ScrollStartNotification`, `showToolbar` from a frame callback on `ScrollEndNotification`), and a focus change plus `showToolbar` before the next frame does it across two fields.

This looks like the same race as #159259 (Scribble on iPad, closed as fixed in December 2024), reached by other paths. The assertion and the per-state controller are unchanged on master today.

In release the assert is stripped, so by our reading the new menu shows and the old controller's `hide()` is a no-op (it is no longer `_lastShown`); we have not checked that on a device.

import 'dart:async';

import 'package:flutter/material.dart';

// On an iPhone (iOS 16 or later), debug build: double-tap a word so the system context menu
// (Copy / Look Up / ...) shows, then wait. Every two seconds the scroll view jumps by one
// pixel, and with the menu up the next jump throws "Attempted to show while another instance
// was still visible." An animated scroll (animateTo) does not.
void main() => runApp(const MaterialApp(home: Repro()));

class Repro extends StatefulWidget {
  const Repro({super.key});

  @override
  State<Repro> createState() => _ReproState();
}

class _ReproState extends State<Repro> {
  final ScrollController _scroll = ScrollController();
  late final Timer _timer;

  @override
  void initState() {
    super.initState();
    _timer = Timer.periodic(const Duration(seconds: 2), (_) {
      _scroll.jumpTo(_scroll.offset == 0 ? 1 : 0);
    });
  }

  @override
  void dispose() {
    _timer.cancel();
    _scroll.dispose();
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      body: SafeArea(
        child: SingleChildScrollView(
          controller: _scroll,
          child: Column(
            children: <Widget>[
              TextField(
                controller: TextEditingController(text: 'one two three'),
              ),
              const SizedBox(height: 2000),
            ],
          ),
        ),
      ),
    );
  }
}

import 'package:flutter/material.dart';
import 'package:flutter/services.dart';
import 'package:flutter_test/flutter_test.dart';

const String assertion =
    'Attempted to show while another instance was still visible';

/// Two plain TextFields in a scroll view, with the iOS system context menu enabled.
Future<void> pumpFields(WidgetTester tester, ScrollController scroll) async {
  tester.platformDispatcher.supportsShowingSystemContextMenu = true;
  addTearDown(tester.platformDispatcher.resetSupportsShowingSystemContextMenu);
  tester.binding.defaultBinaryMessenger.setMockMethodCallHandler(
    SystemChannels.platform,
    (MethodCall call) async => null,
  );
  addTearDown(
    () => tester.binding.defaultBinaryMessenger.setMockMethodCallHandler(
      SystemChannels.platform,
      null,
    ),
  );
  await tester.pumpWidget(
    wrapWithView: false,
    View(
      view: tester.view,
      child: MaterialApp(
        home: Scaffold(
          body: SingleChildScrollView(
            controller: scroll,
            child: Column(
              children: <Widget>[
                TextField(
                  controller: TextEditingController(text: 'one two three'),
                ),
                TextField(
                  controller: TextEditingController(text: 'one two three'),
                ),
                const SizedBox(height: 2000),
              ],
            ),
          ),
        ),
      ),
    ),
  );
}

Offset inWord(WidgetTester tester, int field) =>
    tester.getTopLeft(find.byType(TextField).at(field)) + const Offset(30, 24);

/// Double-taps a word in [field], one frame between the taps, so its system menu shows.
Future<void> showMenuIn(WidgetTester tester, int field) async {
  await tester.tapAt(inWord(tester, field));
  await tester.pump(const Duration(milliseconds: 50));
  await tester.tapAt(inWord(tester, field));
  await tester.pump(const Duration(milliseconds: 400));
  expect(find.byType(SystemContextMenu), findsOneWidget);
  expect(tester.takeException(), isNull);
}

void main() {
  testWidgets(
    'a jump of the enclosing scroll view while the menu is up asserts',
    (WidgetTester tester) async {
      final ScrollController scroll = ScrollController();
      await pumpFields(tester, scroll);
      await showMenuIn(tester, 0);

      // A zero-duration scroll: ScrollStart and ScrollEnd in one frame. EditableText hides the
      // toolbar on start and shows it again from a frame callback on end, so the new
      // SystemContextMenu builds in the frame that disposes the old one, before it is disposed.
      // A rising keyboard does the same through showOnScreen(duration: Duration.zero).
      scroll.jumpTo(10);
      await tester.pump();
      await tester.pump(const Duration(milliseconds: 16));

      final Object? error = tester.takeException();
      expect(error.toString(), contains(assertion));
    },
    variant: TargetPlatformVariant.only(TargetPlatform.iOS),
  );

  testWidgets('the same scroll, animated, does not', (
    WidgetTester tester,
  ) async {
    final ScrollController scroll = ScrollController();
    await pumpFields(tester, scroll);
    await showMenuIn(tester, 0);

    scroll.animateTo(
      10,
      duration: const Duration(milliseconds: 250),
      curve: Curves.easeOut,
    );
    await tester.pump();
    await tester.pump(const Duration(seconds: 1));

    final Object? error = tester.takeException();
    expect(error, isNull);
  }, variant: TargetPlatformVariant.only(TargetPlatform.iOS));

  for (final bool frameBetweenTaps in <bool>[true, false]) {
    testWidgets('menu up in field 0, then a double tap in field 1; '
        'frameBetweenTaps: $frameBetweenTaps', (WidgetTester tester) async {
      final ScrollController scroll = ScrollController();
      await pumpFields(tester, scroll);
      await showMenuIn(tester, 0);

      // Tap 1 moves focus and hides field 0's menu; tap 2 selects a word in field 1 and shows
      // its menu. With no frame between them, field 1's SystemContextMenu builds before field
      // 0's is disposed.
      await tester.tapAt(inWord(tester, 1));
      if (frameBetweenTaps) {
        await tester.pump(const Duration(milliseconds: 50));
      }
      await tester.tapAt(inWord(tester, 1));
      await tester.pump(const Duration(milliseconds: 400));

      final Object? error = tester.takeException();
      if (frameBetweenTaps) {
        expect(error, isNull);
      } else {
        expect(error.toString(), contains(assertion));
      }
    }, variant: TargetPlatformVariant.only(TargetPlatform.iOS));
  }
}
