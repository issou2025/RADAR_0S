# Project Proposal — Bim Modeling

## Project Understanding
You need assistance with: 
**One failing route module stops every later module from registering**

*Project description:*
## What happens

`register_routes()` imports and registers all 22 route modules inside a single `try` ([`startup.py` L16-112](https://github.com/Demolinator/revit-mcp-server/blob/3de7db6a20637d15cf5e3d2b97e2fd8aae09c419/startup.py#L16-L112)). If one module fails to import, for example because a Revit API name is missing on one version, every module after it is skipped. The tools for those modules then all return 404, and the server's hint says the extension is "probably missing or a different version", which sends users looking in the wrong place.

## Expected

One broken module only disables its own tools, and its error is logged and easy to find.

## Suggested fix

- Replace the block with a list of `(module, register_function)` names, and register each in its own `try`, logging the module name and traceback on failure.
- Bonus: expose the failed modules in `/status/`, so `get_revit_status` can tell the user exactly what didn't load.

## How to check

Add `raise ImportError("test")` at the top of one module (e.g. `revit_mcp/tags.py`), reload pyRevit, and confirm that only that module's tools fail.
