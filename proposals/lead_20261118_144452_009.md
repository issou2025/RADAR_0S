# Project Proposal — Flutter App

## Project Understanding
You need assistance with: 
**Clarify minimum Xcode version needed for iOS builds**

*Project description:*
When I was setting up Loremark from my MacBook, I ran into a lot of build issues when trying to launch the app on an iPhone simulator
I was using Flutter 3.50.0 and Xcode 16.4, and the original connectivity_plus dependency (7.3.2) produced the following error:
Value of type 'NWPath' has no member 'isUltraConstrained'
After some time, I was eventually able to run Loremark after temporarily changing the dependency version in my local copy of pubspec.yaml
I think it would be helpful to specify the minimum required Xcode version in the developer setup instructions, especially since the README specifies a Flutter version already. This would make it easier for new developers to determine whether their device and environment actually  supports the project before trying to build it.
