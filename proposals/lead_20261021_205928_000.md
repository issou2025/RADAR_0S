# Project Proposal — Bim Modeling

## Project Understanding
You need assistance with: 
**The "Appearance per Face" tool under View deselects selected faces and isn't triggerable when there are no selected faces.**

*Project description:*
### Problem description

When I click `View > Appearance per Face` after having selected a face, it gets deselected again and I have to select it one more time. This seems weird to me, especially considering that I need to already have a selection prior to running the tool. It slows down the workflow and just doesn't make much sense.

Have a look at a recording to illustrate:

https://github.com/user-attachments/assets/54f55ff5-31b5-4087-a5ac-9546001cbc8f

### Workbench affected?

Core (App, Gui,...)

### Steps to reproduce

1. Have any object in Part or Part Design
2. (might be optional) Assign it a color or material
3. Observe that View > Appearance per Face is greyed out when there isn't a selected face
4. Select a face 
5. Observe that View > Appearance per Face is now triggerable. Click it.
6. Observe that, upon clicking, your selection disappeared.
7. Select your face (again) and continue with the usual procedure to change the appearance

### Expected behavior

Ideally, I can run the Appearance per Face tool whenever. And it wouldn't deselect my existing selection.
I could wonder: why do i need to have a face selected just for it to be deselected again?

### Actual behavior

Appearance per Face is greyed out when I currently don't have a face selected. After I have the selection and trigger the tool, my face gets deselected.
