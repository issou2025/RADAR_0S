# Project Proposal — Dwg To Revit

## Project Understanding
You need assistance with: 
**Support DWG entity handles as external IDs**

*Project description:*
### Description
Product issue: https://github.com/3drepo/3D-Repo-Product-Team/issues/388

In normal groups (i..e no rule based groups that is used in v4 groups, v4 views, issues, risks, and v5 tickets) and also clash detection, we are currently referencing objects with their external IDs. The purpose of this is to ensure we have cross revision support for the feature.

Currently we only support this for IFC Guids and Revit Element IDs. We would like to add support for DWG entity handles

 A link of all possible file types with entity handles can be found here: https://asitesol.sharepoint.com/:f:/s/3DRepoTeamFolder/IgBpHMbtn36GTLeXHwFmr19VARY-2ZvQAXqbWn4iA-0euO8?e=NfY1Ym

We need to ensure that we include all known possible metadata keys when we search for entity handles.
