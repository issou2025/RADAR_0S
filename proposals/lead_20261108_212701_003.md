## 3. Needs a different packaging approach

- [ ] **Open Infra Studio**: GIS and civil design in Open CAD Studio. [Open-Infra-Studio](https://github.com/OpenAEC-Foundation/Open-Infra-Studio) is GPL-3.0. Release v2026.45.4 ships a plugin `.so` plus a `linux-*.zip` (x86_64 and aarch64). It runs inside Open CAD Studio, so it probably needs to be an extension of `io.github.HakanSeven12.OpenCadStudio` rather than a standalone app. Check how Open CAD Studio loads plugins.
- [ ] **OpenAEC SuperCloud** desktop client: [openaec-cloud-desktop](https://github.com/OpenAEC-Foundation/openaec-cloud-desktop). No licence is shown. Release v2026.44.10 has a deb and an AppImage (amd64). It is a sync client for a self-hosted cloud, so it is only useful to people running that cloud.

## Before packaging

- **Licences.** The ⚠ rows have no recognised licence on GitHub. Before listing them, check the repo's LICENSE file or ask upstream.
- **Upstream contact.** Open PDF Studio and Open CAD Studio are already here. One message to the OpenAEC Foundation could cover the whole suite and an approval (#379).
- **Shared structure.** All of these come from the same Tauri release pipeline, with the same asset naming and signed AppImages. A single manifest template plus a single `resolve-update.sh` pattern would cover most of group 1. Use `org.openaec.OpenPdfStudio` as the reference.
