# Minimal DaVinci Adapter Scope

After the minimum Package Protocol spine is independently accepted, create a new bounded implementation branch from the accepted integration base.

Preferred branch name:

```text
feat/davinci-first-timeline-mvp
```

The adapter must consume only the compiled Normalized Timeline and resolved local asset data. It must not parse `AI_EDIT_PACKAGE.zip` independently.

Minimum supported timeline:

- one project;
- one timeline;
- one video track;
- one to three local video clips;
- explicit rational timeline frame rate;
- explicit clip order and `timeline_start_frame`;
- explicit source in/out ranges where the Resolve API supports them reliably;
- no source video audio (`discard`);
- no transitions, titles, effects, grading, music or voiceover;
- save the Resolve project after timeline creation.

The adapter may initially support only the exact Resolve version/API present on the owner's Windows computer. Record the detected version and limitations.
