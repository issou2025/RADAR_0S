## What to build

An Architect or Designer can click **Shadow Study** on the `Publish` panel of the Synthetic ribbon (across Revit 2022–2026) from an active shadow-capable graphical view, inspect the project's site place name, latitude/longitude, hemisphere, timezone offset, and Daylight Saving Time status, pick a single calendar date and destination folder in a Synthetic dark-themed modal dialog, and export a calibrated base-ratio Multiply **Shadow Composite** PNG (`<ViewLabel> - <yyMMdd> - Composite.png`) using sensible defaults (`1 hr` clock-aligned stepping, `5°` minimum sun altitude, `80%` maximum composite darkness, `3000 px` horizontal width, `Hidden Line` on a pure white background) while keeping the Revit model and Undo stack 100% untouched.

Confirming **Export** closes the modal dialog first, opens a responsive modeless **Progress State** window reporting current view, date, and frame progress with working **Cancel** and window-close cancellation (suppressing the **Export Completion Dialog** and cleaning up temporary files if cancelled), temporarily detaches any controlling View Template and applies a bundled per-view-family shadow-only View Template (`Cast Shadows = ON`, `Ambient Shadows = OFF`) inside an unconditionally rolled-back transaction group (hiding the 3D Sun Path widget and leaving Crop Boxes and Scope Boxes untouched), streams base-ratio Multiply blending against an unshaded (`ShadowIntensity = 0`) reference pass so black architectural linework stays visible against `RGB ~51` full-day shadows and sunlit halftones/hatches never self-darken, cleans up temporary frame files, and finishes with the shared **Export Completion Dialog**.

## Acceptance criteria

- [ ] A **Shadow Study** push button appears on the `Publish` ribbon panel across Revit 2022–2026 without version-conditional ribbon logic, opening a dark-themed modal dialog (including themed `DatePicker` and `Calendar` controls) when an eligible graphical view is active and showing a clear non-crashing notice if the active view is ineligible.
- [ ] All ViewModels, DTOs, headless orchestration, and the Revit adapter port exchange pure `string` identifiers (never leaking Revit `ElementId` or `Document` types), inject a dedicated folder-picker port (leaving existing file-dialog contracts untouched) plus `IProgress<ProgressState>` and `CancellationToken`, use built-in framework WPF imaging with zero new NuGet packages or `unsafe` blocks, and shape the adapter's raw-frame export request around a batch of `(views × dateSchedules)` (passing 1 view × 1 date in this slice) so multi-view and multi-date slices extend cleanly inside one rolled-back transaction group.
- [ ] The dialog displays the active project's site place name, latitude/longitude (converted from Revit radians to degrees), hemisphere, timezone offset, and Daylight Saving Time status, sanitizes illegal path characters in `<ViewLabel>`, and disables **Export** when the destination folder is blank or 0 valid daylight frames exist.
- [ ] Solar schedule calculation evaluates clock-aligned project-local timestamps across `[00:00..23:59]` (`1 hr` default), converts explicitly to UTC via `TimeZoneHours + (UsesDST ? 1.0 : 0.0)` (handling fractional timezones and UTC+ midnight crossings without calling Revit's sunrise/sunset methods), filters by NOAA solar altitude `>= 5.0°`, and computes power-law `ShadowIntensity` (`1..100`) targeting `80%` maximum composite darkness (`0.20` minimum brightness, `RGB ~51`, safely guarding `N == 0`).
- [ ] Streaming image compositing decodes PNGs sequentially without locking files or retaining multi-frame pixel buffers, validates matching `PixelWidth × PixelHeight`, normalizes each frame against the single `ShadowIntensity = 0` reference pass in straight-alpha 32-bit BGRA (guarding `0 / 0` black reference pixels as ratio `1.0` so `#000000` linework never yields `NaN`), and writes an opaque `<ViewLabel> - <yyMMdd> - Composite.png` (freezing bitmaps so both STA and MTA test runners succeed).
- [ ] All Revit model/view mutations execute inside a single outer transaction group that unconditionally rolls back in `finally` (per ADR 025), bundling version-matched shadow-only View Template assets across all 2022–2026 build outputs (copying from read-only install directories to temp when needed and suppressing sync-drift checks on template open), guarding pure-white gradient background assignment strictly to `ThreeD`, `Section`, and `Elevation` views, suppressing temporary-view export confirmation dialogs, applying targeted failure preprocessing, reporting view/date/frame **Progress State** updates, and leaving view properties, View Templates, Crop/Scope Boxes, document elements, and Undo history completely unchanged on completion, cancellation (via **Cancel** button or window close, suppressing the completion dialog), or error.
- [ ] Headless unit tests cover solar schedule math, site radian-to-degree metadata display, blank-folder / 0-frame `CanExport` gating, `<ViewLabel>` path sanitization, streaming Multiply compositing (white `#FFFFFF`, `#000000` black linework `0 / 0` guard inside `RGB ~51` shadow, halftone gray `RGB 190` preservation, monotonic darkening, unlocked handles, dimension-mismatch error), headless pipeline/ViewModel execution and mid-run cancellation via fake adapter/folder-picker ports, and ribbon command class resolution.
- [ ] Revit integration tests verify single-view export across `FloorPlan`, orthographic and perspective `View3D`, `Section`, and `Elevation` (including template-locked views), confirming darkened shadow pixels across distinct timestamps, untouched Crop/Scope Boxes, verified 2022–2026 template asset build deployment, and 100% clean document/Undo restoration across normal completion, cancellation, and simulated mid-batch exceptions, with clean compilation across Revit 2022–2026.
