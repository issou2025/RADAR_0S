**[Phase 1] Implement the secure OpenTopography USGS 1 m source**

*Project description:*
## Outcome

Fetch `USGS1m` terrain through OpenTopography as `AAIGrid` behind the pluggable source interface, with accurate error reporting and complete secret redaction.

## Scope

- Call `GET /API/usgsdem` with explicit dataset, format, and WGS 84 bounds.
- Read `OPENTOPOGRAPHY_API_KEY` from the process environment and keep request URLs, errors, and logs redacted.
- Surface authorization, quota, validation, network, and server failures without silently selecting a coarser dataset.
- Capture the authoritative response metadata needed to establish CRS and vertical provenance; fail rather than assume missing metadata.

## Acceptance criteria

- [ ] The HTTP client is injectable and testable offline with deterministic responses.
- [ ] Every request explicitly asks for `datasetName=USGS1m` and `outputFormat=AAIGrid`.
- [ ] No exception, diagnostic, fixture, or test output contains the API key or an unredacted authenticated URL.
- [ ] Authorization and source-metadata failures are distinguishable and actionable.
- [ ] The repository restore, build, and offline tests pass.
