## Strategic goal — S1 (owner-approved, 2026-10-23)
**Publish Arcade Poker as a real, publicly installable Android app on Google Play.** Start with the existing browser Poker, reuse authoritative WS/Poker engine, Netlify, Supabase, CH ledger and browser UI. The first Play release is **free-to-play social poker**, with virtual CH **nonredeemable for cash or prizes of real-world value**. Do not assume this alone settles law/store policy. Android first; iOS is a potential later M4 after Android release and separate owner GO.

**Owner decision:** ship a minimal compliant, stable mobile app first; add substantial game modes, social features and monetization iteratively. No release date promised. No Production or store submission GO is granted by creating this issue.

## Priorities and explicit exclusions
1. **Must have for first release:** policy/legal go/no-go, minimal functional Android package, login & existing account deletion, stable game/reconnect, data disclosures and Play Console/review/test readiness.
2. **Nice to have only if low-risk:** prettier default avatars, session-local hand history and a basic share link.
3. **NOT first-release prerequisites:** Facebook login, payments/cosmetics/VIP/CH packs, tournaments, World Tour/Seasons, Grand Entrance, AI MCP, full friends system, dealer/bot personality work.
