# Project Proposal — Flutter App

## Project Understanding
You need assistance with: 
**'node.built' assertion in flushSemantics when popping a route over a page that depends on ModalRoute**

*Project description:*
### Steps to reproduce

1. Save the test below as `node_built_test.dart` in any Flutter project's `test/` folder.
2. Run `flutter test test/node_built_test.dart`.

The page under the popped route depends on its `ModalRoute`, so it rebuilds as the route's status changes during the pop. Its tree holds a `LayoutBuilder` and a `Semantics(container)` → `Semantics(explicitChildNodes)` → labelled node, inside `GestureDetector`s.

### Expected results

The pop completes with no exception, and the semantics tree stays consistent.

### Actual results

At the end of the reverse transition (about 480 ms after the pop, in that single frame), `PipelineOwner.flushSemantics` fails its debug check:

```
'package:flutter/src/rendering/object.dart': Failed assertion: line 5732 pos 12: 'node.built': is not true.
```

The stack runs `_RenderObjectSemantics.debugCheckForBuilds` (recursing) ← `PipelineOwner.flushSemantics` ← `drawFrame`.

**Removing any one** of the seven marked ingredients makes the test pass, as does making only the *pushed* page depend on `ModalRoute`. `navigator.pop()` and the system back (`handlePopRoute`) both trigger it. Neither `Scaffold`, `Material` nor `AppBar` is needed.

In our app it surfaced when a reader page that depends on its `ModalRoute` (it reads it in `didChangeDependencies`) sits under a second page that's popped. It blocks us from giving a scrollable panel normal scroll semantics: every variant we tried trips this same check.

### Code sample

<details open><summary>Code sample</summary>

```dart
import 'package:flutter/material.dart';
import 'package:flutter_test/flutter_test.dart';

class Page extends StatelessWidget {
  const Page({super.key});

  @override
  Widget build(BuildContext context) {
    ModalRoute.of(context); // (1) rebuild on route status changes
    return GestureDetector(
      onVerticalDragUpdate: (_) {}, // (2) a semantics action handler above the Stack
      child: Stack(
        children: [
          LayoutBuilder(builder: (_, _) => const SizedBox()), // (3)
          Positioned.fill(
            child: GestureDetector(
              onTap: () {}, // (4)
              child: Semantics(
                container: true, // (5)
                child: Semantics(
                  explicitChildNodes: true, // (6)
                  child: Semantics(label: 'x', child: const SizedBox()), // (7)
                ),
              ),
            ),
          ),
        ],
      ),
    );
  }
}

void main() {
  testWidgets('popping a route over a page that depends on ModalRoute keeps the semantics tree built', (tester) async {
    await tester.pumpWidget(const MaterialApp(home: Page()));
    final NavigatorState navigator = tester.state<NavigatorState>(find.byType(Navigator));

    navigator.push(MaterialPageRoute<void>(builder: (_) => const Page()));
    await tester.pumpAndSettle();

    navigator.pop();
    await tester.pumpAndSettle(); // the assertion fires at the end of the pop transition

    expect(tester.takeException(), isNull);
  });
}
```
