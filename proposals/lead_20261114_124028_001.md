# Project Proposal — Bim Modeling

## Project Understanding
You need assistance with: 
**ai_element_filter message says "wallss"**

*Project description:*
## What happens

`ai_element_filter` builds its message as `"Found {} {}{} matching filters"`, adding an `s` to a label taken from the category name ([`revit_mcp/analysis.py` L162](https://github.com/Demolinator/revit-mcp-server/blob/437c47af3e23eda23c3485e8e086a6830e45751a/revit_mcp/analysis.py#L162)). Category names are already plural (`OST_Walls` becomes "walls"), so the message reads "Found 4 wallss matching filters". Only a count of exactly 1 gives "Found 1 walls".

## Expected

"Found 4 walls matching filters", and "Found 1 element" when no category is given.

## Suggested fix

Don't add an `s` to category labels. Only pluralise the no-category fallback ("element" / "elements").
