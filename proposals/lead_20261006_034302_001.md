# Project Proposal — Bim Modeling

## Project Understanding
You need assistance with: 
**fix(addin): shared coordinates throws on family documents**

*Project description:*
## Symptom

`revit_shared_coordinates` on an active family document fails with `Object reference not set to an instance of an object.` Severity P3.

## Repro

1. Open an `.rfa` file with `revit_open_document` and `activate=true`.
2. Call `revit_shared_coordinates`.

## Cause

`SharedCoordinatesReader.Read` calls `BasePoint.GetProjectBasePoint` and `BasePoint.GetSurveyPoint`, then dereferences the results (`basePoint.Position`, `ReadPoint`). Family documents have no project or survey base point, so both return null. `document.ActiveProjectLocation` and `ProjectLocations` need the same check.

## Expected

A family document returns a clear refusal such as "Shared coordinates are available only in project documents", not a `NullReferenceException`.

## Evidence

Found while running the 0.9.1 candidate on Revit 2026. The error appears in the add-in job log as a `NullReferenceException` from `SharedCoordinatesReader.Read`. The code is unchanged on current `main`. This is older than 0.9.0 [inference].
