# Project Proposal — Pdf To Revit

## Project Understanding
You need assistance with: 
**Roadmap: libraries for every file of Japanese construction, from drawings to BIM models**

*Project description:*
The plan of the zumenjs organization: libraries that read, show, check, write and draw the files that Japanese construction exchanges, the same in Rust, Python and browsers, under MIT. Each line below is tracked by its own issue, a sub-issue of this one.

## The files
| Field | Exchanged as | Where zumen stands | Issue |
| --- | --- | --- | --- |
| Drawings | DWG, DXF, JWW (JWC, JWS), SXF (SFC, P21, SFZ, P2Z) | Read, written, edited in place and drafted | #119 |
| Drawings for review and approval | PDF | Written; reading planned | #119 |
| Building models (Revit, Archicad, GLOOBE, Vectorworks …) | IFC | Not read; detected as SXF until #124 | #143 |
| Structural models (SS7, BUS-6 …) | ST-Bridge | Kept outside zumen, waiting for the terms | #140 |
| Timber houses and precut | CEDXM | Not read; terms unknown | #141 |
| Building services | BE-Bridge, Stem, IFC | Not read; terms unknown | #141, #143 |
| 3D design data of civil works | J-LandXML, IFC4.3 | Not read | #142 |
| City models and sites | PLATEAU (CityGML with i-UR) | Not read | Later |

The native files of programs without a public specification are read through what those programs export (#119).

## Repositories
- `zumenjs/zumen`: drawings and building models: reading, writing, editing in place, 2D and 3D views, checks and drafting.
- ST-Bridge stays outside zumen until #140 is settled.
- A repository for authoring building models, if #139 decides so.

## How the work is tracked
- Every piece of work has an issue under one of the issues above (as sub-issues), with the labels `bim`, `roadmap` and `decision` (needs a record in `docs/decisions/`).
- Formats whose publication needs a third party's permission, and dependencies whose license is not permissive, need a decision first ([decision 0013](https://github.com/zumenjs/zumen/blob/main/docs/decisions/0013-st-bridge-out-of-zumen.md)).
