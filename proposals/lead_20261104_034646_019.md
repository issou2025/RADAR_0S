## Handoff protocol

1. ChatGPT posts a bounded task comment here with objective, exact scope, acceptance criteria, allowed files, forbidden actions, budget, and expected evidence.
2. User starts or resumes Arena Agent Mode with this repository connected and asks it to read the latest **OPEN TASK** comment on this issue. No report needs to be copied into chat.
3. Arena posts its response, evidence, objections, and status as a comment here. For implementation, it creates one branch and one PR, linking this issue and the exact head SHA.
4. ChatGPT reads the comment/PR directly from GitHub, independently verifies claims, diff, exact-head CI and policy compliance, then posts a **REVIEW RESULT** comment here.
5. Arena reads that review from GitHub and may revise the same PR. Repeat until accepted or explicitly blocked.
6. The owner is contacted only for a true approval gate: secrets, spend, permissions, production changes, governance changes, merge when policy requires owner action, or unresolved ambiguity that cannot safely be inferred.
