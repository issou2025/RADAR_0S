- [ ] `create_dimensions`: `dimension_type` ("linear", "aligned", "angular") is read and never used ([`revit_mcp/annotation.py` L38](https://github.com/Demolinator/revit-mcp-server/blob/3de7db6a20637d15cf5e3d2b97e2fd8aae09c419/revit_mcp/annotation.py#L38)).
- [ ] `link_file`: `position` (offset in mm) is never applied ([`revit_mcp/interop.py` L153](https://github.com/Demolinator/revit-mcp-server/blob/3de7db6a20637d15cf5e3d2b97e2fd8aae09c419/revit_mcp/interop.py#L153)). RVT links land at the origin, and CAD imports are forced to `ImportPlacement.Origin`.
- [ ] `create_surface_based_element`: `offset` is applied to floors only ([`revit_mcp/building.py` L478-485](https://github.com/Demolinator/revit-mcp-server/blob/3de7db6a20637d15cf5e3d2b97e2fd8aae09c419/revit_mcp/building.py#L478-L485)). The roof branch ([`revit_mcp/building.py` L495](https://github.com/Demolinator/revit-mcp-server/blob/3de7db6a20637d15cf5e3d2b97e2fd8aae09c419/revit_mcp/building.py#L495)) never reads it.
- [ ] `get_element_properties`: `include_type_params` is a tool argument that is never sent to Revit ([`tools/parameter_tools.py` L14](https://github.com/Demolinator/revit-mcp-server/blob/3de7db6a20637d15cf5e3d2b97e2fd8aae09c419/tools/parameter_tools.py#L14)). **No Revit needed.**
- [ ] `set_parameter`: the response echoes the requested value rather than the stored one. `new_value` is read back and thrown away, and the result of `param.Set()` is ignored ([`revit_mcp/parameters.py` L290-300](https://github.com/Demolinator/revit-mcp-server/blob/3de7db6a20637d15cf5e3d2b97e2fd8aae09c419/revit_mcp/parameters.py#L290-L300)).

## Arguments that are silently replaced by a default

- [ ] `create_detail_line`: an unknown `line_style` silently uses the default style, with only a debug log ([`revit_mcp/detail.py` L107-127](https://github.com/Demolinator/revit-mcp-server/blob/3de7db6a20637d15cf5e3d2b97e2fd8aae09c419/revit_mcp/detail.py#L107-L127)).
- [ ] An unknown `type_name` or `level_name` falls back to the first match instead of returning a 404:
  - `create_structural_framing` ([`revit_mcp/structure.py` L207](https://github.com/Demolinator/revit-mcp-server/blob/3de7db6a20637d15cf5e3d2b97e2fd8aae09c419/revit_mcp/structure.py#L207) and [`revit_mcp/structure.py` L221](https://github.com/Demolinator/revit-mcp-server/blob/3de7db6a20637d15cf5e3d2b97e2fd8aae09c419/revit_mcp/structure.py#L221))
  - `tag_elements` ([`revit_mcp/tags.py` L110](https://github.com/Demolinator/revit-mcp-server/blob/3de7db6a20637d15cf5e3d2b97e2fd8aae09c419/revit_mcp/tags.py#L110))
  - `tag_walls` ([`revit_mcp/annotation.py` L260](https://github.com/Demolinator/revit-mcp-server/blob/3de7db6a20637d15cf5e3d2b97e2fd8aae09c419/revit_mcp/annotation.py#L260))
- [ ] `set_active_view`: with duplicate names, such as "Level 1" as both a floor plan and a ceiling plan, the last match wins ([`revit_mcp/view_management.py` L333-339](https://github.com/Demolinator/revit-mcp-server/blob/3de7db6a20637d15cf5e3d2b97e2fd8aae09c419/revit_mcp/view_management.py#L333-L339)). Prefer the floor plan, or return the candidates.
- [ ] `create_mep_system`: `element_ids` is documented as optional ([`tools/mep_tools.py` L106](https://github.com/Demolinator/revit-mcp-server/blob/3de7db6a20637d15cf5e3d2b97e2fd8aae09c419/tools/mep_tools.py#L106)) but required by the handler ([`revit_mcp/mep.py` L390-394](https://github.com/Demolinator/revit-mcp-server/blob/3de7db6a20637d15cf5e3d2b97e2fd8aae09c419/revit_mcp/mep.py#L390-L394)). For elements that already have a system, it only renames that system, falling back to the "Comments" parameter ([`revit_mcp/mep.py` L422-424](https://github.com/Demolinator/revit-mcp-server/blob/3de7db6a20637d15cf5e3d2b97e2fd8aae09c419/revit_mcp/mep.py#L422-L424)), and still says "Created".

**The rule for all of these:** if the caller asked for something the tool can't do, return an error, with the available names where that helps. Never silently do something else.
