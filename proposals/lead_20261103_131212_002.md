# Project Proposal — Bim Modeling

## Project Understanding
You need assistance with: 
**Decode workset visibility of 3D views**

*Project description:*
Revit 3D views can hide whole worksets (Visibility/Graphics › Worksets; per view, or through its template), and a workset's "Visible in all views" default decides what a view does when it sets nothing. The port does not apply any of this. `views_visibility[].hides` covers categories, hidden elements, view filters and phases (#7), but not worksets.

**What is known**
- The view record references `m_oWorksetVisibilityViewSettings`: a 6-byte reference right after `m_viewName` (RE log Stage 68).
- `WorksetVisibilitySettingsElem` (`m_invisibleWorksets`) is in the class roster.
- Each element's workset is decoded: `table_elements[].workset` (#37, RE log Stage 93). The workset table is `source.worksets` (`Global/PartitionTable`, Stage 82).

**Why it is blocked: no workshared sample file**
- None of the 9,536 corpus files is workshared. Each `Global/PartitionTable` holds a single workset.
- So no view in the corpus can hide a workset, and neither the workset-visibility body nor its link to the view can be measured.

**Needed**
- A workshared model, preferably as a pair that differs by one change: a workset set to hidden in one 3D view (like the single-change `Wand-1m-*` files). A second pair with a workset's "Visible in all views" turned off would also help.
- Then:
  1. Decode the view's workset settings, and the workset defaults stored in `Global/PartitionTable`.
  2. Add the elements of hidden worksets to `hides`.

Split out of #7.
