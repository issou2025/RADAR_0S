Gaps that remain in W7's column quantities:

1. **A joined column's `Length`.** The maintainer left it out (2026-10-26) because Revit's export draws 18 columns at permit as a cut mesh with no `Length` and nothing told them apart. RE-291 §2 finds what does: each of the 18 has a `CutPairGStep` slab whose span crosses its top, and none of the 327 extruded columns does. Writing it there would add 436 quantities, none Revit omits. This reverses the premise of the 2026-10-26 decision, so it is the maintainer's call; the code would be one more property in `export_content/column_quantities.rs`.
2. **The round column** (`Round Column:PI-6`, 3053209, one on each file). Its type holds a `Diameter` and no `b`, so the box rule leaves it out. Revit's `CrossSectionArea` is 0.01766 m² (the circle's) against the box's 0.0225; its `GrossVolume` and `NetVolume` differ from each other (0.105959 and 0.106005 m³), so the circle's formulas would need checking against the second. rvt-rs also draws it as a box (W6). Other families whose captions are not `b` and `h` stay out until a file with one is measured.
