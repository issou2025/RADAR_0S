## 3. Trend Signal Analysis

The dominant signal today is **harness and context engineering, not model capability**. The top of the trending list is Anthropic shipping `skills` and `claude-quickstarts`, Vercel shipping `agent-browser`, and third parties shipping `ECC` (300k stars) and `hermes-agent` (262k) — all tooling that sits *around* a model rather than being one. The community has clearly concluded that agent performance is now bottlenecked by skills, memory, tool access and token budget, not by raw weights. The RAG cluster corroborates this: `headroom`, `claude-mem`, `OpenViking` and `PageIndex` are all attacking context efficiency or memory persistence, and `caveman`'s viral 65%-token-cut pitch — however gimmicky — is a direct market read on how much teams will pay to shrink prompts.

A second signal is **stack diversification, particularly Rust**. `agent-browser`, `rig`, `Codewhale`, `DeepSeek-Reasonix` and `meilisearch`/`qdrant`/`lancedb` in retrieval all point to Rust consolidating its position in the performance-critical layers of the AI stack — CLI agents, inference plumbing, and embedded vector search. Go remains strong for local runners (`ollama`) and RAG engines (`ragflow`, `milvus`), while Python still owns training and scripting.

Third, **vendor-led standardization is accelerating**: Anthropic's Skills format, CopilotKit's AG-UI Protocol, and MCP integrations (`ha-mcp`) suggest the ecosystem is moving from ad-hoc glue to published interfaces. Notably absent from today's hot list are new frontier model weights — consistent with a period where releases are incremental and attention has shifted to the application and integration layer built on top of the last wave.
