# Project Proposal — Bim Modeling

## Project Understanding
You need assistance with: 
**Write actions execute against the active document, not the addressed one**

*Project description:*
## Severity: P0 (data safety — wrong-document mutation)

A queued write action records the target **PID** but not the target **document**, and the executor operates on the current `ActiveUIDocument` at the time the `ExternalEvent` fires — not the document the action was addressed to.

**Repro (single Revit, no multi-instance needed):**
1. Open models A and B in one Revit.
2. With A active, submit a write action (e.g. `move`/`delete`) addressed at A, referencing an `ElementId` that also exists in B.
3. Switch the active document to B before the `ExternalEvent` handler runs.
4. The mutation is applied to **B**, because `ElementId`s are per-document and the executor resolves against `ActiveUIDocument`.

**Impact:** silent modification/deletion of the wrong open model.

**Code:** `server/revit_model_mcp/actions.py:125`, `src/RevitModelMcp.Addin/Control/ActionCommandExecutor.cs:37`.

**Fix direction:** bind the queued action to the originating document (by title/path, captured at submit) and, in the executor, resolve/verify the target document instead of using `ActiveUIDocument`; fail if the addressed document is not open. Distinct from #50 (that is cross-process; this is one process).
