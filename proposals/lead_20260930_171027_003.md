# Project Proposal — Bim Modeling

## Project Understanding
You need assistance with: 
**Add an offline test suite that runs without Revit (tests currently can't be collected by pytest)**

*Project description:*
## Problem

The two files in `tests/` are **scripts**, not tests. They call `asyncio.run(main())` at module import. The result:

```
$ uv run --with pytest pytest -q
ERROR tests/test_init_latency.py - AssertionError('initialize too slow: 4.511...
ERROR tests/test_model_info_format.py - AssertionError("expected model data m...
no tests collected, 2 errors
```

`test_model_info_format.py` needs a live Revit with a model open, and `test_init_latency.py` is timing-sensitive. So there's no way for a contributor, or CI, to catch regressions in the CPython half without Revit.

## Proposal

1. Rename the existing live checks (e.g. `tests/live/check_*.py`) so pytest doesn't collect them, and document how to run them.
2. Add pytest tests that need **no Revit**:
   - `tools/utils.py::format_response`: success, error, status, and data-only dicts (the bug fixed in #2 is a perfect regression test)
   - `main._revit_call`: mock the Routes server with `httpx.MockTransport` / `respx` for 200, 4xx/5xx, and connection refused
   - Tool registration: spin up the server in-process, `list_tools()`, and assert **48** tools, each with a non-empty docstring
   - (stretch) Pure-logic helpers in `revit_mcp/` (e.g. color math) by stubbing the `pyrevit` module in `sys.modules`
3. Add `pytest` as a dev dependency (`[dependency-groups] dev = [...]` in `pyproject.toml`).

## Prior art

[ArturOPaes/arx-revit-mcp](https://github.com/ArturOPaes/arx-revit-mcp) built exactly this: *"a primeira suíte que roda sem Revit, e o pytest voltando a coletar"* (the first suite that runs without Revit, and pytest collecting again), including a `conftest.py` that stubs pyRevit. Worth borrowing from.
