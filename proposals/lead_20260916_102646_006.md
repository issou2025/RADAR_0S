# Project Proposal — Structural Drawings

## Project Understanding
You need assistance with: 
**Wayfinder Map — Indori Mart Platform**

*Project description:*
## Destination

A production-ready, city-as-tenant e-commerce platform for buying local Indore namkeens, comprising: a customer-facing web app (Next.js), Flutter mobile apps (iOS + Android), a vendor/supplier portal (Next.js), and an admin panel (React Admin) — all backed by a Java/Spring Boot monolith, PostgreSQL + Redis, hosted on AWS Mumbai. All products are stocked at a central platform-owned warehouse; the platform is the seller of record. The map is done when every architectural decision is locked and a developer can pick up any repo and start building without ambiguity.

## Notes

**Domain**: Hyperlocal food e-commerce (namkeens/snacks), Indore-first, multi-city-ready architecture.

**Standing preferences**:
- Backend: Java + Spring Boot (monolith-first, domain-packaged)
- Mobile: Flutter (iOS + Android)
- Customer web + Vendor portal: Next.js (React + TypeScript), polyrepo
- Admin panel: React Admin
- DB: PostgreSQL (primary) + Redis (cache/sessions/OTP)
- Payments: Razorpay (UPI only, v1)
- Delivery: Shadowfax (one booking per order, warehouse → customer)
- Auth: Phone OTP (MSG91) + optional Google Sign-in + Sign in with Apple (iOS mandatory)
- Hosting: AWS Mumbai (ap-south-1), Docker from day 1
- Notifications: FCM push + SMS (MSG91) + Email (SES/SendGrid)
- Repos: Polyrepo under github.com/indori-mart
- Cart: Multi-vendor per cart, single central warehouse fulfillment
- Fulfillment: Central warehouse (consignment model). Platform is seller of record.
- Vendor role: Supplier — submits stock, monitors sales/inventory. Does NOT confirm orders.
- Vendor payout: Platform collects all revenue; pays vendors on T+7/T+14 schedule via bank transfer
- Catalog: Vendor-created, admin-moderated
- Multi-city: city-as-tenant (city_id on every entity)

## Decisions so far

- **Delivery partner** (#2): Shadowfax for Indore hyperlocal. Delhivery as future intercity fallback. FSSAI license is a hard pre-condition.
- **Auth strategy** (#3): MSG91 OTP. Sign in with Apple mandatory on iOS. JWT 15-min access / 90-day refresh with full rotation. httpOnly cookies for Next.js. DLT registration must start immediately.
- **Razorpay UPI** (#4): UPI Intent only (Collect deprecated Feb 2026). Webhook payment.captured = source of truth. Java SDK: com.razorpay:razorpay-java:1.4.10.
- **Payment splits & delivery fee** (#16): No Razorpay Route needed (central warehouse = single merchant). Delivery fee: ₹35/order waived above ₹299 cart value + ₹8 platform fee. One Shadowfax booking per order.
