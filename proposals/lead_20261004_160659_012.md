# EXTERNAL ROOT CENSUS — Deep multilingual root discovery for MiniAndroid

## Mission

Create one authoritative, continuously updated census of generic Android compatibility/runtime root causes that can explain APK failure, white/black/partial screens, wrong UI, missing state, native failures, silent stalls, or false-positive execution.

This is NOT an APK-by-APK test list. Find root families already discovered by AOSP engineers, emulator projects, Waydroid/Anbox/Redroid/WSA, ART/Dalvik, graphics/runtime projects, AndroidX/Compose/WebView, app/framework issue trackers, academic work, Chinese/Russian/English/Japanese/Korean communities, GitHub issues/comments/PRs, source code, and technical forums — then map them to MiniAndroid.

CRITICAL: Do NOT make thousands of APKs rediscover the same root.

For every external finding:
SOURCE → mechanism → Android/AOSP semantic law → root family → MiniAndroid registry cross-match → NEW / DUPLICATE / ALREADY-FIXED / ENVIRONMENT-ONLY → representative probe/APK → A/B proof.

# ROUND-1 HIGH-VALUE EXTERNAL SIGNALS

1. AndroidGoLab/binder demonstrates about 1,500 Android Binder interfaces and version-aware transaction-code resolution; even firmware/API revisions can shift transaction mappings.
2. Waydroid issue #1148 demonstrates intermittent black screen when launching an app directly while full UI works: session/window/compositor setup can be causal.
3. Current Waydroid issues include graphics composer crashes, ARM/libndk translation, libhoudini/Vulkan deadlocks, zygote bootclasspath, ANativeWindow/AV1, camera and graphical corruption — high-value archaeology targets.
4. Redroid issue #934 demonstrates SurfaceFlinger/SwiftShader/AHardwareBuffer failure during shader-cache warmup before ordinary app rendering.
5. dotnet/android issue #12077 demonstrates API/system-image ↔ emulator-version contract failure: old emulator lacked required SurfaceFlinger AIDL and boot stalled/black-screened.
6. dotnet/android issue #12119 demonstrates system_server restart causing package Binder service disappearance during install.
7. Google Maps Compose issue #875 demonstrates missing ViewTreeLifecycleOwner can directly break ComposeView creation/measurement.
8. Android API semantic-drift research reports thousands of Android API incompatibilities across releases; semantic differences must be treated as a major root source.
