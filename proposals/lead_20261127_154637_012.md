### Three capability pillars (positioning)

| Pillar | OpenShip | Claude Ship |
|---|---|---|
| **1. Self-Review** | Lockfile-filtered diff, typed severity findings (`important`/`nit`/`pre_existing`), effort caps (`low`..`max`) | Built-in self-review |
| **2. PR Steward** | Fixes merge conflicts, failing CI, and review threads with a **3-attempt circuit breaker** | Built-in PR steward |
| **3. Declarative Approvals** | `.praisonai/approvals.yml` (`observe`/`enforce` modes, `protected_paths`, path-scoped rules) | Declarative approvals |
| **LLM support** | **Any LLM** incl. **100% local Ollama** | Anthropic Claude only |
| **License** | MIT Open Source | Proprietary |
| **CI automation** | Free GitHub Actions CI Steward (`workflows/steward.yml`) | Hosted / vendor-managed |

### CLI naming note

OpenShip intentionally uses `praisonai ship` / `praisonai steward` (plus the `praisonai-ship` / `praisonai-steward` script aliases from the meta-package) to avoid `$PATH` collisions with unrelated `openship` PaaS CLIs.
