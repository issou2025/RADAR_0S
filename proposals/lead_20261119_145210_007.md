# Project Proposal — Bim Modeling

## Project Understanding
You need assistance with: 
**Family instances that stay boxes: expose symbol geometry and instance placement**

*Project description:*
### Problem

A Revit 2024 project has a furniture family with 448 placed instances. The reader returns every instance as a box:

- 324 `partition_family_instance_turned_box`
- 124 `partition_element_record_bbox`
- geometry hash `unit-box-v1`
- no LOD2 or saved display mesh

The `family_extrusions` path only rewrites instances whose body is already a saved mesh (`BodySource == saved_graphics_mesh` with a triangulated face set). These instances never enter that path, so the family's authored geometry is unavailable even though the family document is in the file.

### Ask

1. A generic API that returns a family symbol's body/display geometry plus each instance's transform, so a consumer can draw N instances from one shared symbol. This must not be a per-family special case.
2. Saved display mesh access for family instances that have saved graphics but are currently returned as boxes or refused.
3. A no-geometry marker for elements whose source genuinely has no 3D geometry. A record box should not be the only way to express that.
4. Capability clarity: does `family_extrusions` cover only extrusions, or also sweeps, blends, revolutions, and nested families? Are instance transforms complete: rotation, reflection, translation, and scale?

### Constraints

- Preserve the existing export, saved-mesh selection, geometry, and property output.
- Keep the generic API stable enough for a thin adapter; no family-name branching in consumers.
- A consumer validates against the source inventory and a Revit IFC/FBX oracle where available.

### Minimal repro

The source model is customer-derived and is not public. I can provide element counts, a reduced `.rvt` fixture privately, or a synthetic artifact if that helps. The behavior reproduces on any model with a boxed family instance whose family has extrusions/forms but no saved display mesh.
