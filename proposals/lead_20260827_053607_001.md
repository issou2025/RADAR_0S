# Project Proposal — Dwg To Revit

## Project Understanding
You need assistance with: 
**Feature Request: AutoCAD / DWG Integration**

*Project description:*
It would be useful to have an AutoCAD integration similar to the existing Revit integration.

Many projects use a mixed-software workflow: some teams or scopes are developed in Revit, while others continue to work primarily in AutoCAD. Supporting AutoCAD would help maintain a more consistent dataflow across those environments. For example, a project may have a lower-LOD Revit model, with fully resolved details in AutoCAD. Having one platform where this data can come together can be very useful where both scopes ultimately need to participate in the same project information workflow.

**Proposed capability:**

Provide an integration for AutoCAD / DWG that allows project data and geometry to participate in the same general workflow currently supported for Revit.

**The initial scope could focus on:**

Reading geometry and relevant object/layer data from DWG.
Associating DWG objects with project data in Engine Services.
Supporting updates between AutoCAD and the shared project data environment.
Providing some form of stable object tracking where possible so unchanged and modified objects can be distinguished.
Enabling workflows where Revit and AutoCAD are both contributing to the same project.

Additionally: Linking a 2D DWG to a location in 3D space -- useful for understanding where on a project (in 3D) a 2D detail happens
