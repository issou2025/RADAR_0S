## Notes before starting

### This is one tab in the product but four services

The endpoints below share a docs tab, not a base path. Group them under one `client.files` namespace and keep four `BASE` constants. Check each endpoint page for its own path before writing the operation.

### It complements `client.data_management`, it does not replace it

Data Management already lists folders, items, and versions. This module adds only what Data Management lacks. Do not duplicate folder listing here.

### Seven endpoints are beta

The custom attribute and naming standard calls are beta. Mark them in the docstrings.

### Project IDs need the `b.` prefix removed

ACC endpoints take a bare project UUID. Data Management returns the same project as `b.<uuid>`. `client.account_admin` already documents this in `services/accountadmin/schemas.py`. Reuse that wording rather than writing a new note.

## How it fits the client

Follow the shape that `client.issues` already uses:

- `src/autodesk_platform_sdk/services/files/operations.py` holds one `Operation` per endpoint and a `BASE` constant.
- `schemas.py` holds the Pydantic request and response models.
- `__init__.py` holds the service class with a sync method and an async method for each operation.
- Mount `client.files` in both `client.py` and `async_client.py`.
- Add `cli/commands/files.py` and register it on the `aps` group.
- Add `tests/test_files.py` with mocked transports.
- Add the row to the services table in `README.md`.
