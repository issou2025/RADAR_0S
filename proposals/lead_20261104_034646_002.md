## Project Understanding
You need assistance with: 
**Agent runtime: warm the IronPython engine to avoid a ~2 s first-run delay**

*Project description:*
The first agent run in a Revit session spends about 2.2 s starting the IronPython engine before the script runs. Every agent session pays this on its first call.

Measured with the `timings_ms` breakdown from #3910 (Revit 2026, IronPython 3.4.2, trivial `result = doc.Title`):

| run | `engine` | sum of `script.*` |
|---|---|---|
| first | 2,421 ms | ~250 ms |
| later | ~50 ms | ~45 ms |

`engine` minus the runner's own phases is engine startup plus importing `pyrevit.agent._runner`.

Idea: warm the agent engine once after pyRevit finishes loading, for example on the first `Idling` event, by running a no-op entry script that imports the runner. CPython may need the same treatment.
