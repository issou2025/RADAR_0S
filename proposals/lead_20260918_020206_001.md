# Project Proposal — Bim Modeling

## Project Understanding
You need assistance with: 
**Revit: a per-layer checklist before the steps run**

*Project description:*
**Host:** Revit
**Parent:** #147. Phase A item 9. Needs the import window from item 3.

**The problem**

An import brings in every step the planner finds, and the only way to skip one is to not have it in the bundle. A curator who wants the terrain and the buildings, or the terrain alone, has no lever.

**The change**

- The import window opens with a per-layer checklist before the steps run, on both the vault path and the local path. All on by default. Prerequisites are enforced: subdivisions and the drape need the terrain; the IFC link (off by default once item 4 lands) needs nothing.
- The unattended path (`MANTLEPLACE_BUNDLE_ZIP`) means all on.
- No presets.
- The checklist's words are shared actions and go into the standard as an `HPS-51` row before the window uses them, since the Unreal plugin's own picker is on the roadmap.

**Done when**

- Each layer can be toggled and a disabled prerequisite explains why.
- Unchecked layers produce no elements and the log says they were skipped by choice.
- The unattended path imports everything.
