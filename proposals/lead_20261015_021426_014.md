## Developer Pain Points

The most frequent frustrations reported:

1. **Schema Validation Broken** — V2 configs flagged as invalid by editors due to outdated schema at `opencode.ai/config.json` (high-volume issue with 27 👍)
2. **Migration Failures** — V1→V2 migration leaves sessions invisible or causes Desktop crashes (#42170, #55253)
3. **Permission System Complexity** — Custom agents with restrictive policies incorrectly fail with free-tier errors; plugin permission requests not supported in-process
4. **Windows Integration Gaps** — PowerShell launch fails, SMB shares not supported, service port conflicts with Windows excluded ranges
5. **Free-tier Model Restrictions** — Custom primary agents rejected on free tier despite requests originating from within OpenCode
