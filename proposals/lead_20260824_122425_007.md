# Project Proposal — Flutter App

## Project Understanding

**🖥️ CLI Text Mode — Play Tubature in the Terminal (ASCII Art, 80s Retro)**

*Project description:*
## Summary

Add a standalone CLI/terminal text-mode for playing Tubature entirely in the terminal with ASCII art pipe rendering, ANSI color coding, and keyboard controls.

## Motivation

- **Developer fun**: Play the game during SSH sessions, in tmux, or while compiling
- **Retro aesthetic**: 80s ASCII art vibes 🕹️
- **Pure Dart**: Reuses game logic models (Tile, Grid, Level) without Flutter dependency
- **Testing**: Great for automated solver validation
- **Accessibility**: Works on any terminal, any OS, no GPU needed

## Proposed UX

```
┌──────────────────────────────────┐
│  TUBATURE CLI v2.5.0  Easy 6×6  │
│  Moves: 12  Connected: 24/36    │
├──────────────────────────────────┤
│  ═══  │    ║   ╔══  ───  ╗      │
│  ║   [╠══] ║   ║    ═══  ║      │
│  ╚══  ║    ╚══ ╠══  ║    ╝      │
│  ═══  ╔══  ║   ║    ╚══  ───    │
│  ║    ║    ╠══ ╚══  ═══  ║      │
│  🐉   ╚══  ║   ═══  ║   ╝      │
├──────────────────────────────────┤
│  ←↑↓→/WASD: Move  Space: Rotate │
│  R: Reset  Q: Quit              │
└──────────────────────────────────┘
```

- Focused tile shown with **ANSI reverse video** or **bright color highlight**
- Connected pipes shown in **green**, disconnected in **gray/white**
- Source shown as creature emoji (🐉/🧙/🚀)

## Technical Notes

- Pure Dart CLI app: `bin/tubature_cli.dart` or `tool/cli_play.dart`
- Reuses `lib/models/` and `lib/logic/` (Tile, Grid, Level, LevelGenerator, WinChecker)
- Terminal I/O via `dart:io` stdin raw mode
- ANSI escape codes for colors and cursor positioning
- No Flutter dependency — runs with `dart run`
