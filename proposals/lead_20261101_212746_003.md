# Project Proposal — Bim Modeling

## Project Understanding
You need assistance with: 
**Document increment table and latest partition disagree for 11 elements of the Revit 2021 basic architecture sample**

*Project description:*
In the Revit 2021 version of the Autodesk basic architecture sample project, 11 elements are stored in two or three partition streams, and the document increment table routes the element's last modification episode to an earlier partition than the latest one that holds a copy of the element.

For 10 of the 11 the routed copy and the latest copy have identical bytes, so the choice does not matter. For one element, id 708998 (an alignment element), the copies differ: the copy in partition 15 (named by the table) lacks one id in a list that the copy in partition 16 (the latest) has. The exported values of that element cannot tell the two copies apart, so it is undecided which copy Revit treats as current. The current-copy resolution keeps all copies of this element.

Needed: an independent check of which copy is current (for example reading the alignment through the Revit API, or a second sample with the same pattern), then either follow the table or the latest partition for this case.
