## 3. `client.model_derivative`, 3 missing

| Endpoint | Reference |
| --- | --- |
| `POST Specify References` | [doc](https://aps.autodesk.com/en/docs/model-derivative/v2/reference/http/urn-references-POST/) |
| `POST Fetch Specific Properties` | [doc](https://aps.autodesk.com/en/docs/model-derivative/v2/reference/http/urn-metadata-guid-properties-query-POST/) |
| `HEAD Check Derivative Details` | [doc](https://aps.autodesk.com/en/docs/model-derivative/v2/reference/http/urn-manifest-derivativeurn-HEAD/) |

- `POST Specify References` is needed for any Revit model with links, or any assembly. Translating one without
  it silently drops the linked geometry.
- `POST Fetch Specific Properties` queries properties by object ID. `get_all_properties` pulls the whole tree,
  which is slow on a large model.
- `HEAD Check Derivative Details` reads size and content type without downloading.

`GET Download Derivative` is deprecated. Leave it out.
