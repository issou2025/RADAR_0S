## Project Understanding
You need assistance with: 
**[FEATURE]: Streaming in the express compiler**

*Project description:*
The express compiler does not support streaming in any language. We want to support streaming to show developers our snappiest possible generation experience.

I'm not sure if this can reuse the existing generated Lexer etc, but either way, we should:
1) Define behavior, write a comprehensive suite of conformance tests which cover real use cases
2) Implement streaming to pass the tests.
3) Consider what it would take to make streaming usable in practice and create evals that show it work. This also affects prompting, because to stream, the agent needs to write the `root` node first, and build the tree breadth first from the root out. We should consider how to update prompts to support this, either by default, or with a flag, e.g. ExpressInferenceFormat could have some `streaming` flag which enables streaming parsing, and also sets a flag on the prompt generator which sets additional content suggesting the right order to create things. We should have a streaming eval suite which runs some streaming use cases and validates that the instructions are output in the expected order and are streamable.

There may be some flexibility around how we implement streaming. We do not necessarily need to output JSON for every line of express - we just want to output JSON as soon as we can, to show the end user valid UI.
