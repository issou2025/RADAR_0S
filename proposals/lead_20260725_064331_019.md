## Required implementation contracts

### Static contract registry

- Use immutable Python value objects.
- Registry keys are closed and source-specific.
- Freeze host, method, path, ordered/required query fields, selector/response schema versions, maximum 10-year window, timezone and source-document identity.
- Compute the contract fingerprint from canonical JSON rather than hard-coding an unexplained digest.
- No arbitrary URL, endpoint or mutable runtime override.

### Readiness

Closed statuses:

```text
confirmed
unsupported
not_entitled
unresolved
blocked
```

Required readiness dimensions include public contract, entitlement, retention, fixture, quota, completion, revision, credential lifecycle, historical membership and corporate actions.

For the initial golden path:

- public contract, entitlement, retention and fixture may be `confirmed`;
- quota, completion, revision and credential lifecycle remain `unresolved`;
- historical membership is `unsupported`;
- corporate action is `blocked` or `unresolved`.

The planner must return stable blocked reason codes and Chinese messages. It must always return `remote_executable=false`.

### Selector and request plan

- Selector accepts exactly one clearly synthetic `thscode`, explicit `start_ms` and `end_ms`.
- No current-time default.
- Require integer millisecond timestamps, `start_ms <= end_ms`, and a maximum elapsed window of 10 years.
- Reject real/live-looking selector namespaces in Stage C0.
- Ordered query items are exactly `thscode`, `interval`, `start`, `end` with interval `1d`.
- Fingerprint excludes credentials, account IDs, request IDs and runtime clocks.

### Schema validation

- Strictly validate the common envelope and one index-history data payload.
- Reject unknown fields, missing required fields, wrong types, invalid nulls and non-ascending `date_ms` order.
- Preserve source numeric text where the contract allows numeric strings; do not silently coerce arbitrary text.
- Fixtures carry `_aquantai_fixture_kind = synthetic`, but this repository-only marker must be removed before the Provider-envelope validator and may never be accepted as a Provider field.
- No real Provider code, index identity, date series, price, volume, turnover or request ID may appear.

### Network denial

- Production package must not import or reference `requests`, `httpx`, `urllib.request`, `socket`, `subprocess`, browser automation, Provider SDK or CLI transport.
- Tests must deny socket creation, DNS connection, HTTP client entry points, URL open and subprocess execution while importing and exercising all Stage C0 modules and the demo.
- No environment-secret read and no database call.

## Offline golden path

1. Import the package under network, subprocess, secret and database guards.
2. Load the frozen `a_share_index_daily_history` contract.
3. Build one clearly synthetic selector.
4. Build a readiness snapshot with live-contract dimensions unresolved.
5. Produce one deterministic plan with `synthetic_only=true` and `remote_executable=false`.
6. Confirm expected technical and Chinese blocked reasons.
7. Validate the synthetic success fixture.
8. Produce stable request and schema SHA-256 fingerprints across repeated runs and mapping-order changes.
9. Emit a redacted JSON demo summary without a URL containing secrets or any Provider-valued data.

## Primary failure path

The implementation must fail closed when:

- selector identity is not the reserved synthetic namespace;
- timestamps are reversed or exceed ten years;
- an arbitrary capability, host, path or query field is requested;
- a fixture includes an unknown Provider field or wrong type;
- rows are not ascending by `date_ms`;
- a required live readiness fact is unresolved;
- historical membership or corporate action readiness is requested as available;
- any network, subprocess, secret or database operation is attempted.

No failure path may send a request, select another Provider, persist data or publish a Today Market snapshot.
