## Upstream rules — mandatory
MeshCore Open CONTRIBUTING currently requires:
- search/use an existing issue first;
- do not start an unsolicited implementation/PR before discussion/plan acceptance;
- target latest `dev`;
- keep changes narrow and single-topic;
- one commit per PR (project may squash if needed);
- run `dart format .` and `flutter analyze` before commit;
- thoroughly review AI-generated code and understand the patch;
- tests under `test/` and `flutter test` for relevant changes;
- call out BLE protocol changes explicitly.

SmartAiPro must respect these rules. No upstream PR or issue comment is sent automatically; external submission remains explicit owner-authorized action.
