## Developer Pain Points

- **Plan mode safety violations** — Multiple reports of the agent ignoring plan mode and making edits; this is a core trust issue
- **Indefinite retry loops** — Permanent errors (404s, content filters) trigger endless retries, wasting resources
- **Quota exhaustion** — Free-tier users report near-instant quota depletion on BigPickle, and shared IP bucketting blocks first-time users
- **Shell hangs** — The timeout never starts when process creation stalls, leaving users with frozen sessions
- **Payment failures** — EU users (Italy specifically) cannot subscribe due to universal payment declines
- **Model/provider compatibility** — LM Studio, OpenAI-compatible gateways, and local models have protocol gaps causing failures
