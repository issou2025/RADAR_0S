## Project Understanding
You need assistance with: 
**Auto Review can lose a completed reviewer result and hide the handoff timeout**

*Project description:*
I reproduced this locally with the bundled `autoreview` tool on `f165544` and the canonical helper at `3cc834cec`. The helper starts its per-pass timer when it prints `native pass ready`. OpenClaw starts a second timer with the same budget when it launches `openclaw agent exec`. The helper can expire while the reviewer still has time left, or after the reviewer exits but before the submitter writes `1.ready`. [Helper deadline](https://github.com/openclaw/agent-skills/blob/3cc834cec/skills/autoreview/scripts/autoreview#L8856-L8872) · [Reviewer launch and cancellation](https://github.com/openclaw/openclaw/blob/f165544/extensions/autoreview/src/tool.ts#L390-L421)

I ran the real tool, process runner, and Python helper on a one-pass review with a four-second timeout and a controlled reviewer process. A short delay before launch let the helper cancel the reviewer about 2.2 seconds into its own runtime. In another run, the reviewer printed terminal JSON, but the helper timed out while OpenClaw was still waiting for process exit. When I let the reviewer exit successfully and delayed only submission, the helper removed the exchange and Auto Review returned `FileNotFoundError` in place of `OpenClaw execution result timed out`. [Wait for reviewer exit](https://github.com/openclaw/openclaw/blob/f165544/src/process/exec-runner.ts#L662-L676) · [Submission error handling](https://github.com/openclaw/openclaw/blob/f165544/extensions/autoreview/src/tool.ts#L449-L464)

I also passed the timeout through the Code Mode bridge. The wrapper reported `internal_error` with `failurePhase: "bridge"` and preserved the timeout text in its separate `error` field. In the late-submit case, the tool had already replaced the timeout with the file error before the bridge could report it. [Bridge error classification](https://github.com/openclaw/openclaw/blob/f165544/src/agents/code-mode-controller-source.ts#L369-L385) · [Result fields](https://github.com/openclaw/openclaw/blob/f165544/src/agents/code-mode-execution.ts#L585-L602)

I’d expect one coordinated deadline that accounts for result delivery. If it expires, Auto Review should report which stage timed out and preserve that error through cleanup.
