# 0. Locked product scope

DWG Viewer V1 is **not a CAD editor**.

Locked user flow:

> **Upload DWG → automatically derive vector PDF → cache → open very fast → measure reliable two-point distance.**

V1 has exactly two P0 product goals:

1. **Fast Viewer**
2. **Reliable Distance Measurement**

V1 explicitly does **not** include:

- DWG editing;
- drawing / markup;
- layer management;
- CAD entity editing;
- area measurement;
- quantity takeoff;
- DWG write-back/save;
- revision comparison;
- AI;
- field-record links;
- photo links;
- persistent measurement annotations;
- DXF editing;
- a custom full DWG renderer.

DWG remains the immutable source file.

The normal viewer artefact is a **derived vector PDF**.

---

# Target architecture

```text
Original DWG
    ↓
managed immutable source
    ↓
SHA-256 + source/revision identity
    ↓
DWG Conversion Port
    ↓
VECTOR PDF + conversion/measurement metadata
    ↓
derived cache
    ↓
fast native PDF renderer
    ↓
Pan / Zoom / Fit / Page
    ↓
Measurement overlay
```

Key rule:

- original DWG = durable source;
- derived PDF = reproducible/disposable cache;
- PDF bytes are not the source of truth;
- no raster-image-as-PDF fallback may silently masquerade as the normal vector result;
- measurement must never guess an unverified real-world scale.

**Codex reasoning:** max  
**Assistant recommendation:** Extra High

---

## DWG-013 — Measurement Trust Classification

Every measurable page/layout gets one explicit capability state.

### TRUSTED

PDF ↔ source/model coordinate relationship is verified. Real distance may be displayed directly.

### CALIBRATION_REQUIRED

Automatic scale cannot be proven. User must define one reference distance.

### UNAVAILABLE

Reliable measurement cannot be produced. Measurement is disabled instead of guessing.

Fundamental rule:

> **Never invent a scale. Never present an unverified value as metres.**

**Codex reasoning:** extra high  
**Assistant recommendation:** Extra High

# Governing performance principle

DWG Viewer success is **not measured by feature count**.

Priority order:

1. **Is the drawing shown correctly?**
2. **Does it open fast?**
3. **Are pan/zoom fluid?**
4. **Is distance measurement trustworthy?**

No additional viewer/CAD feature may take priority over these four questions in V1.
