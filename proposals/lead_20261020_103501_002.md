# Project Proposal — Pdf To Revit

## Project Understanding
You need assistance with: 
**Elevations and sections in sheets, for residential construction documents**

*Project description:*
### Problem or motivation

We're starting a residential architecture firm (custom homes) and evaluating Pascal for both design and documentation.

Pascal already covers a lot of a permit set: floor, foundation, reflected ceiling, roof and site plans, automatic dimension strings, door/window/room schedules, wall assemblies with layer poché, and multi-sheet PDF export with title blocks. What's missing for a residential construction set is **exterior/interior elevations and building/wall sections**. Every permit set we produce needs them, so today we'd have to export IFC and redraw those views in Revit or Archicad, which splits the documentation across two tools.

### Proposed solution

- New drawing types alongside `ConstructionDrawingType`: `exterior-elevation`, `interior-elevation`, `building-section`, `wall-section`.
- Views generated from the 3D model: a cut plane (sections) or view direction (elevations) with a depth range, cut elements drawn heavy with poché from their assembly layers, beyond elements drawn light.
- Level/datum lines with heights, opening marks matching the plan and schedules, material callouts taken from the assemblies (stucco, OSB, studs, drywall…).
- Section and elevation markers on plans that reference the sheet and view they land on.
- Placeable as sheet viewports at standard scales (1/4", 1/8", 3/4" = 1'-0" for wall sections). The `sheets` workspace mode is defined in the editor store but not used yet in the open-source editor; a sheet layout UI there would make this end to end.

### Alternatives considered

- IFC export, then elevations and sections in Revit, Archicad or Bonsai. It works for the model but means maintaining documents in a second tool.
- Screenshots of the 3D cut view. They aren't to scale and have no annotation, so they don't meet permit requirements.

### Additional context

Two smaller gaps we hit in the same test, in case they're useful:
- Room name/number tags don't appear on plan sheets; rooms only show up in the room schedule.
- No DXF/DWG export for structural and MEP consultants.
