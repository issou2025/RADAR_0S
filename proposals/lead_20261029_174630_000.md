# Project Proposal — Structural Drawings

## Project Understanding
You need assistance with: 
**fit_engineering_crs: place a model by matching it to a placed copy**

*Project description:*
Find where a model sits by matching it to a copy of the same model whose position is known, and return that as an Engineering CRS.

## Where this came from

`revit_instance_placement` in the Amsterdam Noord GeoBIM notebook (`nl_amsterdam/notebooks/amsterdam_noord_geobim.py` in bedrock-experiments), section "Where did the model go on the plot?":

- Someone placed the Revit structural model on the plot in Rhino. The original Revit model sits in Revit's internal coordinates.
- The notebook matches elements that occur once in both, by Revit element id: `properties.elementId` in the placed copy, the last eight hex digits of the UniqueId (`applicationId`) in the original.
- Per match it takes `placed_transform @ inv(revit_transform)` of the InstanceProxies, then the median over all matches. That is the transform from Revit's internal coordinates to RD New + NAP. It also reports the largest deviation of a single element from the median.
- Easting, northing, height and rotation of that transform then go into `derived_engineering_crs`.

The RVT Advanced Sample to R2 notebook (`speckle/rvt_advanced_sample_project_to_r2.py`) will need the same thing. Revit's geolocation is not reliable there: the MEP model sits at Revit's default location (Munich). Fitting it to the architecture or structure model on shared elements would place it.

## Why it is not in the first version

The plan keeps it in the Amsterdam notebook for now:

- It has one user so far.
- It matches on Speckle instance transforms, and a BimDataFrame expands instances. A packaged version has to match on something the BimDataFrame keeps: matched element ids plus mesh vertices or centroids (Kabsch), or a column with the instance transform.
- The id matching is source-specific (Revit element id against UniqueId).

## Sketch

`bimpolars.geobim.fit_engineering_crs(a, b, on=...) -> pyproj.CRS`: the Engineering CRS that puts BimDataFrame `a` where BimDataFrame `b` is, fitted on the rows matched by `on`, with the residuals per row. Tested against the Amsterdam Noord result.
