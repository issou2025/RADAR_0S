# Project Proposal — Scan To Bim

## Project Understanding
You need assistance with: 
**Drawings from more than IFC: point clouds, DXF and LandXML, glTF, IFCX, and connectors**

*Project description:*
IfcSheet should make drawings from more than IFC. The viewer it is built on already opens these formats (`apps/viewer/src/services/supported-model-files.ts`): IFC 2x3/4/4.3 and `.ifczip`, IFCX (IFC5), glTF/GLB, point clouds (LAS, LAZ, E57, PLY, PCD, PTS, XYZ), LandXML (`.xml`), DXF as a reference underlay, and models from connectors (Autodesk ACC/BIM 360, Dalux, Dropbox, OneDrive/SharePoint). The drawing set, however, is built on IFC structure (storeys, classes, properties), so opening a file is not the same as getting drawings from it.

## Step 1: audit (do first)
For each format, on a real sample file, record: does it open in the IfcSheet edition, does the Wall produce a drawing set, which views work (plan, section, elevation), what is missing (levels, element names, title-block fields), and what breaks. Result: a table in this issue and one follow-up issue per format.

## Candidates, in order of value
1. **Point clouds → survey drawings of existing buildings.** Plans and sections sliced from a scan at chosen heights and lines, with outlines usable on sheets and in DXF. Renovation permits need drawings of the existing state.
2. **DXF and LandXML → the site plan.** Place the surveyor's DXF situation plan under the site plan (georeferenced or aligned by two points) and terrain contours from LandXML.
3. **glTF/GLB → drawings without BIM.** Plans and sections cut from geometry for people working in SketchUp, Rhino or Blender, with levels defined by the user and title-block fields typed in.
4. **IFCX (IFC5)** gets the same drawing set as IFC.
5. **Autodesk connector:** open a Revit model from ACC/BIM 360 without exporting (whether an IFC derivative can be requested through Autodesk's cloud is to be verified).

Done when: the audit table is here, and each candidate has its own issue with a clear "done when".
