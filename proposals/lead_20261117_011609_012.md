## Context

Developers run the project lint checks before submitting changes. The filesystem tests share in-process WebDAV fixtures, including a method that makes the fixture reject writes.

## Problem

**Expected:** the fixture compiles cleanly under the project lint checks and supported newer Clippy versions.

**Actual:** `WebDavFixture::reject_writes` has the same `allow(dead_code)` attribute twice. Clippy 1.100 was reported to reject this as `duplicated_attributes`. Whether the pinned toolchains report it has not been checked here.

**Confirmed on:** code reading on current `master` (`3b35b344`); the duplicate is present. The reported Clippy failure has not been independently reproduced.

Internal references: LO-CLIPPY-DUPLICATED-ATTRIBUTES.

## Where to start

- `fsio/src/test_fixtures.rs`, `WebDavFixture::reject_writes`, has two consecutive identical attributes. Other fixture methods in the same implementation use a single attribute where needed.
- `fsio/src/lib.rs` exposes the fixtures behind `test-fixtures`; filesystem integration tests also include that file directly. `Justfile` runs Clippy with warnings denied. `nix/devshells/default.devshell.nix` pins Rust 1.98.1, while `nix/platforms/windows/rust.nix` specifies 1.99.0.
