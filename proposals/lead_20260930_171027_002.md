# Project Proposal — Bim Modeling

## Project Understanding
You need assistance with: 
**Slash commands don't pre-approve 17 of the 48 tools (save_document, create_room, check_clashes…)**

*Project description:*
## Problem

Each command's `allowed-tools` frontmatter lists the `mcp__revit__*` tools it may call. Tools added to the server since the commands were written were never added to any command. These 17 tools appear in **no** command:

```
check_clashes create_detail_line create_duct create_mep_system create_pipe create_room
create_room_separation create_view export_ifc get_element_properties link_file load_family
save_document set_active_view set_parameter tag_elements transform_elements
```

So `/revit-bim:design-building` can't save the model, create rooms, or route MEP without permission prompts. `/revit-bim:analyze-model` can't run clash detection, and `/revit-bim:modify-model` can't move or copy (`transform_elements`) or `set_parameter`.

## Suggested mapping (adjust as you see fit)

|---|---|
| `design-building` | `create_room`, `create_room_separation`, `create_view`, `create_duct`, `create_pipe`, `create_mep_system`, `load_family`, `save_document` |
| `create-element` | `create_room`, `create_room_separation`, `create_duct`, `create_pipe`, `create_mep_system`, `create_detail_line`, `create_view`, `load_family` |

| `query-model` | `get_element_properties` |
| `analyze-model` | `check_clashes`, `get_element_properties` |
| (any) | `export_ifc`, `link_file` where they fit |

Also update the command bodies so Claude knows when to use them (e.g. "offer to `save_document` at the end").
