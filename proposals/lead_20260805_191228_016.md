## Project Understanding

**Two bash hooks are syntactically invalid and therefore never run**

*Project description:*
## The measured defect

`coordinator-pretooluse.sh` and `session-mcp-readiness.sh` do not parse. Bash
refuses them before executing a single statement, so both hooks are inert on
every Unix host and every Git-for-Windows invocation — not degraded, not
fail-open with a warning, simply absent.

`coordinator-pretooluse` is the hook that enforces the coordinator's hard
gates (commit message shape, worktree preconditions, protected-branch rules).
Nothing has been enforcing them.

## Evidence

Run against the *committed* content, so this is not a working-tree artefact:

```
$ bash -n coordinator-pretooluse.sh ; echo $?
coordinator-pretooluse.sh: line 106: syntax error near unexpected token `)'
coordinator-pretooluse.sh: line 106: `                printf '%s\n' '{"hookSpecificOutput":{ ... "permissionDecisionReason":"Main repository is not healthy (\'git status\' failed). Fix repository state before creating a worktree."}}''
2

$ bash -n session-mcp-readiness.sh ; echo $?
session-mcp-readiness.sh: line 127: unexpected EOF while looking for matching `"'
2
```

All other `.sh` hooks return 0.

- **`coordinator-pretooluse.sh:106`** — `\'` inside a single-quoted string.
  POSIX shells have no escape inside `'…'`; the quote closes at the backslash
  and the rest of the line is parsed as code.
- **`session-mcp-readiness.sh:127`** — an unterminated double quote.

## Why it went unnoticed

The hook suite exercises behaviour through the hooks it can run and never
asserts that every shipped `.sh` file *parses*. A file that dies at parse time
produces no output, and a hook that produces no output is indistinguishable
from a hook that had no objection — the same "empty result reads as consent"
failure mode as #54.

## Scope

1. Fix both quoting errors.
2. Add a static gate that runs `bash -n` over every `hooks/scripts/*.sh` and
   `[System.Management.Automation.PSParser]::Tokenize` over every `*.ps1`, so a
   non-parsing hook fails the suite instead of silently disarming a gate.
3. Check what `coordinator-pretooluse.sh` should have been blocking while it
   was inert, and whether any of it needs a regression test.
