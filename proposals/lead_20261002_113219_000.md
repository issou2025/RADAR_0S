## Performance contract

C owns most heavy engines, so these are mandatory.

1. No engineering viewer/engine initializes at normal Concord startup.
2. Viewer code must remain behind existing lazy boundaries.
3. Parse source once and reuse derived artifacts.
4. Derived cache keys include source hash + engine/version.
5. IFC must not be reparsed every time Model opens.
6. PDF/CAD diff runs outside the main interaction thread/path.
7. OCR is not loaded until required.
8. IfcClash supports restricted/targeted runs.
9. ReCheck must not require full-model clash by default.
10. Leaving a viewer disposes:
   - workers;
   - WebGL resources;
   - textures;
   - canvases;
   - large model state where supported.
11. Do not mount all Drawing/CAD/BIM viewers hidden in the DOM.
12. Report measurable import/diff/clash timings for Golden Project qualification.
13. Missing/failed engine state must be explicit to B, never silently downgraded into fake success.

## Acceptance criteria

- PDF drawing opens through the mature Drawing donor integration.
- Drawing viewer remains inside C's viewer boundary.
- PDF R1/R2 can be compared using `pdf-diff-viewer`.
- PDF diff produces normalized A-compatible Changes.
- DXF opens with mlightcad.
- DXF revisions compare using `cad-diff-viewer`.
- DWG obeys the explicit licensing/connector boundary.
- DOCX/XLSX/PDF/images can enter Docling ingestion.
- XLSX retains usable table structure.
- scanned PDF/image can run through RapidOCR.
- document results preserve source revision and page/location provenance.
- IFC Viewer Online or the pinned final donor opens a Concord model revision.
- BIM ViewerTarget selects/fits the requested GlobalIds.
- user selection can map back to stable Concord BIM references.
- IFC revision comparison continues through the existing IfcDiff adapter.
- IfcDiff output normalizes into shared Changes.
- IfcClash supports targeted clash runs.
- clash results normalize into structured Evidence.
- IDS validation runs through IfcTester.
- IDS violations normalize into Evidence.
- BCF viewpoint can be saved/reopened/exported without a proprietary Concord viewpoint format.
- Revit/AutoCAD/Navisworks integration boundary is based on mature connector architecture.
- native connector input cannot bypass `ProjectSourceRevision`.
- no raw donor type enters `backend/app/domain`.
- heavy engines are absent from cold application startup.
- unchanged source hashes reuse derived artifacts.
- inactive viewers release large resources.
- exact upstream revisions and licenses are recorded in `THIRD_PARTY_NOTICES.md`.
