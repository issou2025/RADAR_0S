# Project Proposal — Bim Modeling

## Project Understanding
You need assistance with: 
**Snowdon: 6 slabs in the Legends phase are not in Revit's export (phase filtering)**

*Project description:*
## Measured

On Snowdon Towers Architectural (Revit 2024, local only), Revit's own IFC4 export omits 6 slabs, 2287679 to 2287714, that carry no design option (RE-35 §5, RE-40 §3). They are the only elements rvt-rs exports outside Revit's export that the #309 type omissions do not explain.

Each exported element's frame reference list names exactly one `OST_Phases` (−2000112) record:

| phase record | name (phase name entry) | elements rvt-rs exports that name it | in Revit's IFC4 export |
|---|---|---:|---:|
| 32440 | Existing | 0 | – |
| 118390 | New Construction | 5,839 | 5,769 (the other 70 are the #309 type omissions) |
| 2287613 | Legends | **6** | **0** |

The phase names come from name entries shaped like RE-40's design-option entries: `u64 id · u32 · u32 size · u32 0x0c82 · … · 0xff run · u32 n · UTF-16 name`. The Legends phase's description reads "Phase used for creating legends".

## What is missing

Revit's IFC exporter exports one phase: by default the phase of the view it exports from, and an element created in a later phase is not shown in it. rvt-rs does not know:
- which phase the export uses;
- the phase sequence (the ids are not in sequence order, and the phase records carry no obvious ordinal).

Leaving out "the last phase" or "a phase named Legends" would be a guess, so nothing is filtered yet.

## To do

- Find the phase sequence, for example a phase-order list in `Global/Latest` or in the phase records' chain bodies.
- Find the phase an export would use, for example the default 3D view's phase parameter.
- Then leave out elements created after the export phase (and demolished at or before it, once a demolished-phase reference is found), report them as a skipped item, and require zero exported elements dropped on the files that have Revit exports.

Refs #309.
