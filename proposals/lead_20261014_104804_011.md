### Summary / Description
At the top of every desktop DM conversation, next to the call button, there is a bell icon left over from development. Clicking it shows "Notification will fire in 5 seconds. Minimize the app now!" and, five seconds later, sends a fake notification reading "Hello! This is a test DM notification." that appears to come from the person you're chatting with. This ticket removes the debug button from the DM header.

### Why is this ticket needed? (Required)
- **It looks broken to users:** a bell in a chat header suggests notification settings for that chat. Instead it shows a developer message telling the user to minimize the app.
- **It creates fake messages:** the test notification appears to come from the real person in the conversation, saying something they never sent.
- **Debug code shouldn't ship:** CONTRIBUTING.md's self-review checklist asks contributors to make sure "debug code is gone".

**Proof:** the code below, and the recording in Links / Screenshots.

### Details
- [dm_chat_area.dart, lines 308–337](https://github.com/zeduchat/zedu-desktop/blob/3b51d6c02b78797197520ae6a62677fffc94b3f7/lib/features/dms/presentation/components/dm_chat_area.dart#L308-L337): an `IconButton` with tooltip `'Test Notification (Delayed 5s)'` shows a snackbar, then calls `notificationServiceProvider.handleIncomingMessage(...)` with hardcoded content and `forceShow: true` after a 5-second delay.

**The fix:** remove this button (and the `SizedBox` spacer next to it) from `_DmChatHeader`. The call button and the rest of the header stay unchanged.

**Not part of this ticket:** the separate test notification fired by the **sidebar** bell in `app_sidebar_rail.dart`. That is already tracked in #9. This issue is only about the button in the DM conversation header.

Expected change: `dm_chat_area.dart` plus a widget test.

### Steps to reproduce
1. Open the Zedu desktop app, log in, and open any DM conversation.
2. Click the bell icon at the top right of the conversation, next to the headphones (call) button.
3. Wait 5 seconds.

**Expected:** the chat header has no debug controls.

**What happened:** a snackbar says "Notification will fire in 5 seconds. Minimize the app now!", and then a notification appears saying "Hello! This is a test DM notification.", shown as coming from the other person.
