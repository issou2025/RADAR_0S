# Project Proposal — Flutter App

## Project Understanding
You need assistance with: 
**support macOS in the Nix flake and build releases through it**

*Project description:*
## Goal

CI and development now run through the flake (#106), but `release.yml` still installs Flutter with `subosito/flutter-action` pinned to a literal 3.47.4 in its Android jobs and in `build_ios` (which runs on `macos-latest`). The pin can drift from `flake.lock`, and macOS developers cannot rely on the flake for iOS work. Make the flake work on macOS and build the release through it, so there is one toolchain source.

## Current state

- `flake.nix` already lists `x86_64-darwin` and `aarch64-darwin`, but nixpkgs dropped `x86_64-darwin` (so `nix flake check --all-systems` already fails on `main`), and the default dev shell's Android SDK, NDK and iOS tooling have not been verified on darwin (#83 verified x86_64-linux only).
- Xcode itself cannot come from Nix; the iOS build needs the host's Xcode (`xcode-select`) plus CocoaPods.

## Scope

- Decide the supported systems and drop the ones nixpkgs no longer builds (`x86_64-darwin`)
- Make the dev shell usable on `aarch64-darwin`: Flutter, CocoaPods, the Android SDK and NDK where applicable, and a documented way to use the host Xcode
- Verify `flutter build ios --release --no-codesign` and `flutter build apk` inside `nix develop` on a macOS runner
- Convert `release.yml` (Android jobs on Ubuntu, `build_ios` on macOS) to run through `nix develop`, and remove the literal Flutter pins so the version comes from `flake.lock`
- Keep the lean `devShells.ci` for analyze and tests; decide if a release shell is needed
- Update `CONTRIBUTING.md` (where the Flutter version comes from, macOS setup)

## Acceptance criteria

- [ ] `nix develop` works on `aarch64-darwin` and the iOS build passes with the host Xcode
- [ ] `release.yml` builds the APK, AAB and iOS artifacts through the flake with no literal Flutter version
- [ ] The release validation checklist still passes
- [ ] `nix flake check` passes for every system the flake declares
