# Project Proposal — Bim Modeling

## Project Understanding
You need assistance with: 
**3D model viewer linked to drawings with two-way overlay**

*Project description:*
## Summary
Add a 3D model viewer that is linked to the project's drawings. The user should be able to overlay a drawing onto the model, and overlay the model onto a drawing, so the two can be checked against each other.

## Expected behavior
- Open a 3D model in a viewer within the app.
- Open a drawing and overlay it on the model in the viewer, positioned and scaled to match.
- From the model, overlay or show the related drawing(s) on top of it.
- Adjust overlay opacity and toggle each overlay on and off.
- Selecting an element in the model can open the drawing it appears on, and selecting an element on a drawing can highlight it in the model.
- Overlay alignment can be adjusted manually if the automatic alignment is off.

## Acceptance criteria
- [ ] A 3D model can be displayed and navigated (orbit, pan, zoom)
- [ ] A drawing can be overlaid on the model with adjustable opacity
- [ ] The model can be overlaid on a drawing
- [ ] Overlays can be toggled on and off
- [ ] Links between model elements and drawings work in both directions
- [ ] Overlay alignment can be adjusted manually

## Open questions
- Which 3D formats need to be supported (for example IFC, glTF, or Revit exports)?
- How are drawings and model elements linked: manually by the user, or derived from the file metadata?
- How is alignment set up: by matching reference points, or by the user adjusting it by hand?
