## Detailed Notes & Tradeoffs

### A. Instant No-Card Cloud Real Devices (No OSS Application Needed)
1. **Firebase Test Lab (Spark Plan)**
   - **Why it fits:** Already wired in `.github/workflows/firebase-test-lab-daily.yml` (#573) and being expanded in #656. On the **Spark plan**, no Google Cloud billing account is linked, so overage charges are **impossible**—runs simply stop after **5 physical + 10 virtual runs/day** (resets midnight PT).
   - **Important Billing Firewall Tip:** If the main `belongonthespectrum` Firebase project is ever upgraded to Blaze for production Cloud Functions/Firestore scale, keep a **separate dedicated Spark-only Firebase QA project** (e.g., `belong-qa-ftl`) exclusively for Test Lab APK uploads so Test Lab retains a hard $0/no-card ceiling forever.
2. **Samsung Remote Test Lab (`developer.samsung.com/remote-test-lab`)**
   - **Why it fits:** Zero credit card—just a free Samsung account. Gives **20 free credits every day** (~5 hours/day) on real physical Galaxy S phones, Z Fold/Flip foldables, and Galaxy Tabs in the browser, including APK install and remote ADB bridge support. Great for verifying sensory/high-contrast themes and wide/foldable responsive layouts.
3. **Xiaomi / OPPO / Huawei Cloud Debugging**
   - Free OEM developer portals offering real non-Pixel Android hardware in the browser. Useful for tiny spot-checks on FCM background delivery (#624) where Chinese/OEM skins behave differently from stock Pixel Android.

### B. Free Open-Source Sponsorships for Real iPhones & Safari PWA (No Credit Card)
> **Repo Prerequisite Callout:** `neiljaywarner/refuge` is already **public**, which satisfies requirement #1 for OSS device-farm grants. However, **there is currently no root `LICENSE` file in `refuge`**. Adding an OSI-approved license (e.g. `MIT`, `Apache-2.0`, or `MPL-2.0`) unlocks free real-iOS/Android sponsorships from:

4. **BrowserStack Open Source Program (`browserstack.com/open-source`)**
   - **Why it fits:** Directly solves **#43** (verifying iOS Safari *"Add to Home Screen"* PWA install, standalone splash/icons, and real iPhone/iPad rendering) with **no credit card required**. Also offers a tiny one-time ~30-minute no-card trial on standard signup for immediate testing before an OSS grant is approved.
5. **Sauce Labs Open Source Program & LambdaTest (TestMu AI) Open Source Program**
   - Both provide zero-card grant licenses for public repos with an OSI-approved `LICENSE`, giving real iOS + Android interactive and automated Appium/Espresso/XCUITest minutes. LambdaTest also includes a tiny free-forever starter tier with no card required.

### C. Zero-Card Cloud Simulators / Emulators for Automated CI
6. **GitHub Actions `macos-latest` (iOS Simulator) + `ubuntu-latest` (KVM Android Emulator)**
   - Since `neiljaywarner/refuge` is public, GitHub Actions hosted runners are **100% free with no credit card**. Booting an iOS Simulator on `macos-latest` lets us run `.maestro/` YAML flows and Flutter integration tests on iOS Safari/Simulator without consuming any external device farm quota.
7. **Appetize.io Free Tier & Codemagic Free Tier**
   - **Appetize.io** gives ~30 min/month of browser-streamed iOS Simulator / Android Emulator sessions with no card (handy for quick interactive checks or embedding live demos).
   - **Codemagic** gives 500 free `mac_mini_m2` minutes/month on personal accounts with no card.
