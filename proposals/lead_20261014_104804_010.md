*Project description:*
## Vision

`imaji_install_attribution` is the platform-only, privacy-first answer to "where did this install come from, and where was the user going?" for Flutter — every first-party signal Android and iOS offer (Play referrer, AdServices, store/installer, Google Ads and Meta referrers) behind one typed, never-throwing API. It replaces Firebase Dynamic Links' deferred half without an SDK vendor, fingerprinting, or a Kotlin Gradle Plugin line.

**What makes this package the clear choice:** the only Flutter plugin that combines the Play referrer *and* AdServices *and* installer detection behind one sealed result, built on AGP Built-in Kotlin, with typed failures, a timeout, an allowlisted deep-link helper and consume-once. The roadmap closes the remaining gaps: iOS install source (vs `flutter_install_referrer`), the iOS server half (vs `*_asa_attribution`), Google Ads and Meta referrers (vs MMP SDKs), and a self-hosted FDL replacement (vs hosted link vendors).

## Problems this solves

## Considered and not filed

- **Galaxy Store / AppGallery referrer APIs** — real (Adjust ships a [Samsung referrer plugin](https://dev.adjust.com/en/sdk/android/plugins/samsung-referrer-plugin); Huawei's lives in the HMS Ads Kit SDK), but both need vendor AARs, Samsung's distributed on request. Revisit as optional companion packages if users ask; `InstallSource` already identifies those stores.
- **iOS deferred deep link without the pasteboard** — Apple provides no install payload; the only sanctioned paths are App Clip → full app handoff via a shared App Group, and AdServices for Apple Ads. Clipboard and IP matching conflict with the Non-goals. Documented in the cookbook/FAQ rather than built.
- **Web support** — there is no install on the web; reading UTM parameters from `Uri.base` needs no plugin. `read()` already returns `Unavailable(notSupported)`.
- **`flutter create` template / migration CLI** — the integration is ~15 lines and the README migration guides cover the three source packages; a code-mod tool would cost more to maintain than it saves.
