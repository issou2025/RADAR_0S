## 1. Decision: wrap the existing PWA with Capacitor

One codebase, both stores. The curation client (`app.js` 723 lines, `search-engine.js` 464, the semantic layer, the 1.3 MB runtime data) ships unchanged.

**Rejected alternatives:**

- **Finish the SwiftUI app + write a Kotlin Android app.** Two codebases, and the dev machine is Windows so half of it cannot even be compiled locally. `ios/` has never been through a compiler — its README says so and lists 9 `// AUDIT:` items. It is a design document, not a head start (though #33 and #28 harvest its logic).
- **React Native / Flutter.** Rewrites the entire curation client and destroys the no-build property the nightly pipeline depends on.

**iOS can be built without a Mac.** GitHub Actions macOS runners + fastlane produce signed TestFlight builds. The repo is public, so runner minutes are free. This fits the Actions-based operating model the org already runs.

## 2. The App Store 4.2 constraint

Guideline 4.2 rejects apps that are "a repackaged website." Foray wrapped *as it exists today* — a webview showing four cards that link out to Apple Podcasts — is close to a guaranteed rejection.

**#20 is the answer, not a workaround.** The in-app player, offline downloads, lock-screen controls, and seek-to-timestamp are the M3 milestone from `docs/brief/06_ROADMAP.md`. They are also, coincidentally, exactly the native-value features 4.2 asks for.

**Sequencing consequence: Google Play first.** Play is materially more lenient about webviews, and Android builds on Windows today. iOS submission gates on #20 landing.

## 3. Architecture changes the shell forces

Reviewed the existing client against Capacitor's requirements. Seven changes, three of them non-trivial.

### 3.1 🔴 The no-build repo needs a build step

Capacitor requires a `webDir` containing exactly the files to bundle. Foray's web root **is the repo root**, which also holds `data/` at ~40 MB (`catalog-breadth.json` 12 MB, two `.gz` archives 26 MB) — pipeline inputs, not client assets. The client actually fetches only ~1.3 MB.

So a prepare step must assemble a clean `webDir` from the repo root plus the runtime data subset. **This introduces a build step to a deliberately no-build repo** (`CLAUDE.md`: "Root: static site"). That tension is real and worth an explicit decision: the web deploy stays no-build and Pages-served; only the *native bundle* is assembled. Keep the prepare script dumb, committed, and dependency-free.

### 3.2 🔴 `ios/` collides

Capacitor generates its iOS project at `ios/`. That path holds the SwiftUI scaffold, which #28 and #33 still reference as the design source. Move it to `ios-native-reference/` (updating the references in #28, #33, `CLAUDE.md`, and `ios/README.md`) or point Capacitor elsewhere via `ios.path`. Decide once, early — it touches several issues.

### 3.3 🔴 Bundled data goes stale immediately

The nightly pipeline refreshes `data/*.json` on Pages every night. An app reading only bundled data would need a store release per content update. The app must **bundle a snapshot as offline fallback and fetch fresh data from the live Pages origin** at launch. Requires `connect-src https://jw-incorporated.github.io` and an explicit freshness/TTL policy. See MP6.

### 3.4 🟠 The service worker must not register in the shell

`sw.js` caches the shell cache-first and `data/` network-first. Inside Capacitor the assets are already local; a service worker adds a stale-cache layer in front of local files — a well-known "the app won't update" failure — for no benefit. Register it only on the web origin.

### 3.5 🟠 localStorage is evictable on iOS

All user state uses the `cp_` prefix in `localStorage`: interests, seen-window, playback prefs, and — once #26 lands — **playback positions**, plus the Supabase anonymous session token. WKWebView can clear localStorage under storage pressure. Losing the anon token orphans a user's entire event history, since `auth.uid()` is the only identity (ADR-0005).

Migrate durable keys to the Capacitor Preferences plugin (native `UserDefaults`/`SharedPreferences`) behind a small storage shim so the web build keeps using `localStorage` unchanged. Do **not** rename the keys — `CLAUDE.md` warns that renaming wipes user state.

### 3.6 🟡 CSP needs shell origins

`index.html` ships a strict `<meta>` CSP: `default-src 'none'`, `connect-src 'self' https://qjdllvqdcgacvujhclny.supabase.co`. Under Capacitor the origin becomes `capacitor://localhost` (iOS) / `https://localhost` (Android). Needs: `media-src https:` (already required by #24 — media currently falls back to `default-src 'none'` and is blocked), the Pages origin in `connect-src` (3.3), and the Capacitor scheme. Keep it strict; do not reach for `unsafe-inline`.

### 3.7 🟡 `app.js` is a classic script

Not an ES module. #23/#33 introduce `player/*.js` modules. Either convert (module scripts are deferred and change execution order) or expose the player on a global. Decide in #24; note it here because the shell makes it visible.

## 4. Store accounts — the long pole

**Both stores' organization accounts require a D-U-N-S number. Free, up to 5 business days.** Nothing else can complete until it lands, so it goes first.

It buys two things beyond branding:
1. Apple seller name reads "JW Incorporated" rather than a personal legal name.
2. **Play organization accounts are exempt from the 12-testers-for-14-consecutive-days closed-testing requirement** that applies to personal accounts created after Nov 2023. That exemption alone is worth the wait.

Costs: Apple Developer Program **$99/yr**, Google Play Console **$25 one-time**.

**Open decision:** is JW Incorporated a registered legal entity with a business address? If not, the fallback is Apple Individual + a personal Play account, eating the 12-tester rule. Converting Individual → Organization later is a support ticket. See MP9.

## 5. First move

**MP1 is a throwaway spike and it gates everything else's estimate.** Does `<audio>` inside a Capacitor WebView survive lock and backgrounding on both platforms? If yes, #28 (native audio backend) is a later optimisation. If no, it is mandatory and on the critical path. `06_ROADMAP.md` M0 had exactly this instinct — retire the audio risk before building on top of it.

## 6. Out of scope

Voice / hold-to-talk, Siri App Intents, CarPlay / Android Auto, widgets. Each is its own epic once the app exists.
