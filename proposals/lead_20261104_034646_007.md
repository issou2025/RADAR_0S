# Project Proposal — Flutter App

## Project Understanding
You need assistance with: 
**Request for API access: Faisal Hasan (Namaz Near Me)**

*Project description:*
Assalamu alaikum,

* **Please tell us about yourself (include an email address):**
  Faisal Hasan, developer of Namaz Near Me (by Taqniva), a free Islamic app for Android and iOS used in India. It shows prayer times, nearby mosque jamaat times, Qibla, and a daily "Dars" (one Quran ayah + one hadith a day). Email: faysal.inmbd@gmail.com

* **Your purpose in using this API:**
  To show one "Hadith of the day" inside the app, chosen from Sahih al-Bukhari and Sahih Muslim. Each hadith is shown with its Arabic text, English (and Urdu, if available) translation, grading, collection name and hadith number, plus a link back to its page on sunnah.com, with "Source: sunnah.com" credited on screen and on the share image. Users can share that one hadith as an image card with the same citation. The app is free and has no ads.
  The API key stays on our server, not in the app: a Firebase Cloud Function fetches the day's hadith once and caches it, and the app reads from that cache. We will not mirror or republish collections.

* **API rate limits:**
   * **Maximum requests per second:** 1
   * **Maximum requests per day:** 100 (normally only a few: one daily fetch plus occasional retries)

* **Is your use case better served by having an offline dump of hadith data or programmatic API access?**
  Programmatic API access. We only need one hadith per day, so a full dump is not needed.

* **What are the languages in which would you like hadith data?**
  Arabic and English, and Urdu if available.

* **What programming language will your API client be in?**
  JavaScript / Node.js (Firebase Cloud Functions); the app itself is Flutter (Dart) and does not call the API directly.

JazakumAllahu khayran.
