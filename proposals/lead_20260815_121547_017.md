## Question

How does Archiver get onto a user's machine, and how are new versions shipped?

Settle:

- `install.sh` behind `curl -fsSL <url> | sh`: arch detection, checksum verification, install location on PATH with a fallback and a PATH hint, an uninstall path, and idempotent reinstall/upgrade.
- Whether a Homebrew tap replaces or supplements the one-liner for a public open source project.
- **Code signing / notarization**: `curl` does not set `com.apple.quarantine`, so an unsigned binary installed this way generally runs — confirm that, and decide whether signing is needed anyway (and whether it becomes needed if a `.dmg` or browser-downloaded archive is ever offered).
- Versioning and release cadence, given that extractor breakage forces releases on someone else's schedule.
- If gallery-dl ships inside the binary, the GPL-2.0 redistribution obligations land here — licence notice, written offer, source availability.

---

## [#5](https://github.com/luojiahai/archiver/issues/5)'s reversal deleted most of this ticket's hard parts

The constraints previously handed here — payload placement, ad-hoc versus Developer-ID signing, notary visibility, SHA-256 cache verification, per-architecture payload builds, and GPLv2 §3 corresponding source spanning CPython, OpenSSL and Cryptodome — are **all void**. Archiver ships no Python payload and no GPL binary.

What remains, and what changed:

- **The artifact is now a single self-contained binary of Archiver's own code**, roughly the ~1.6 MiB Go floor plus the frontend, rather than ~18–32 MiB. Re-price the distribution options against that.
- **The licence is now [MIT](https://github.com/luojiahai/archiver/issues/4)**, not GPL-2.0-only. The licence-notice, written-offer, and source-availability bullet above is void as written — MIT's obligation is attribution only.
- **Cross-compilation is no longer constrained.** PyInstaller was the reason a macOS runner per architecture was required. Go and Rust cross-compile freely, which is also why [#13](https://github.com/luojiahai/archiver/issues/13) is now nearly trivial.
- **Signing and notarization survive on their own merits** — the `curl`-does-not-quarantine question is unchanged, and still worth confirming.
- **Release cadence gets worse, not better.** The existing bullet notes extractor breakage forces releases on someone else's schedule. That schedule is now X's and Instagram's *directly*, with no upstream absorbing it. See [#18](https://github.com/luojiahai/archiver/issues/18).
