# Project Proposal — Flutter App

## Project Understanding
You need assistance with: 
**[Linux][Wayland] 3.50: content drawn at wrong size after moving window to a monitor with a different scale**

*Project description:*
### Steps to reproduce

1. Use Flutter 3.50.0 (3.47.9 does not have this issue)
2. Use a Wayland session with two monitors of different integer scale, e.g. a 4K monitor at 200% and a 1080p monitor at 100% (tested on KDE Plasma 6.8.2).
3. `flutter create repro && cd repro && flutter run -d linux`
4. The window opens on the 200% monitor and renders correctly.
5. Move the window to the 100% monitor.

I could also reproduce this issue only on the 4k monitor by changing its scale factor from 200% to 100% while the app was running.

### Expected results

The content fills the whole window at the correct scale.

### Actual results

The content is drawn at half size in the top left corner of the window. The rest of the
view is black background. Mouse interactions do not align with the rendered content.
