## Goal (user story)
As a new user who installed MaybeSitter from the store, I sign in (Apple, Google or email), finish onboarding, and land in the app. I'm never asked to paste a pilot token. As a developer, I can still run a development build against my local backend without signing in.

## Implementation steps
1. **Packages:** `npx expo install @react-native-firebase/app @react-native-firebase/auth expo-build-properties expo-splash-screen`.
   - In `app.config.ts` `plugins`, add `'@react-native-firebase/app'`, `'@react-native-firebase/auth'` and `['expo-build-properties', { ios: { useFrameworks: 'static' } }]`. React Native Firebase needs static frameworks on Expo.
   - If the Firebase Apple SDK's minimum iOS version is above SDK 57's default, set `ios.deploymentTarget` there too.
2. **Firebase apps:** register the iOS and Android apps `com.maybesitter.app` in `maybesitter-app` (UC-1.0a (#140) scripts, or `firebase apps:create`).
   - Save `mobile-rn/firebase/GoogleService-Info.plist` and `mobile-rn/firebase/google-services.json`, and reference them as `ios.googleServicesFile` and `android.googleServicesFile`.
   - **Decision:** commit both files; they identify the project but authorize nothing. Restrict the API keys immediately:
     - the iOS key to `com.maybesitter.app`
     - the Android key to `com.maybesitter.app` plus UC-1.2 (#146)'s SHA-1s
     - allowed APIs: Identity Toolkit, Token Service and Firebase Installations (UC-3.0b (#184) and UC-4.4 (#180) add FCM and Crashlytics later)
   - **Decision:** one Firebase project serves staging and prod in S1.
3. **Auth layer** in `mobile-rn/src/auth/`:
   - `types.ts`: `AuthUser { uid, email, emailVerified, displayName, providerIds }` and `interface AuthRepository { onChange(cb): Unsubscribe; currentUser(): AuthUser | null; getIdToken(force?: boolean): Promise<string | null>; reloadUser(): Promise<void>; signOut(opts?: { reason?: 'user' | 'session_expired' | 'revoked' | 'deleted' }): Promise<void> }`
   - `firebaseAuthRepository.ts` (modular API) and `fakeAuthRepository.ts` (Jest)
   - `AuthProvider.tsx` and `useAuth()`, returning `{ status: 'loading' | 'signedOut' | 'signedIn', user, lastSignOutReason }`, with the reason held in memory only
   - UC-1.1 (#145)–1.3 add the provider methods. UC-1.R4 (#157)'s `src/api/auth.ts` calls `authRepository.getIdToken`.
4. **Routing gate** in `app/_layout.tsx`:
   - Hold the splash (`SplashScreen.preventAutoHideAsync()`) while `status === 'loading'`.
   - Protected groups:
     - `<Stack.Protected guard={status === 'signedOut'}>` around `(auth)`
     - `guard={signedIn && !onboardingCompleted}` around `(onboarding)` (UC-2.R1 (#171))
     - `guard={signedIn && onboardingCompleted}` around `(tabs)`, `capture`, `commitments` and `settings`
   - A deep link opened while signed out lands on sign-in, and its href resumes after sign-in (held in memory only).
5. **Sign-in screen** `app/(auth)/sign-in.tsx`, with slots in order: Apple (UC-1.1 (#145)), Google (UC-1.2 (#146)), "Continue with email" → `app/(auth)/email.tsx` (UC-1.3 (#147)). Below them, Privacy and Terms links from `EXPO_PUBLIC_PRIVACY_URL` / `EXPO_PUBLIC_TERMS_URL` (OWNER-A1 (#137)), opened with `expo-web-browser`.
6. **Decision: dev-only override.**
   - `EXPO_PUBLIC_DEV_BEARER_TOKEN` is honoured only when `__DEV__ && env.appEnv === 'development'` and the API host is `localhost`, `127.0.0.1` or `10.0.2.2`.
   - `useAuth()` then reports a synthetic `dev` user, and UC-1.R4 (#157) sends the token.
   - Store builds have `__DEV__` false, and UC-0.2a (#139)'s guard fails any staging or production build that sets the variable.
7. **No pilot code in RN.** Don't port `PilotAccessScreen` or the token store. The ported `pilotAccess*` strings serve only 403 states (UC-2.R1 (#171) step 6). Trust `revoke`/`delete` responses call `signOut({ reason })` (UC-2.R4 (#174)).
8. **Account rows** in Settings (the screen is UC-2.R4 (#174)'s): "Signed in as {email}" (or "Apple ID (private email)") and Sign out. Sign-out runs in this order:
   1. `Notifications.cancelAllScheduledNotificationsAsync()`, once `expo-notifications` exists (S3)
   2. `queryClient.clear()`
   3. the provider sign-out (Google, UC-1.2 (#146))
   4. `signOut()`
9. **Strings:** add `auth.*` keys to `src/i18n/locales/{en,ar,he}.json` (UC-1.R3 (#156)).
