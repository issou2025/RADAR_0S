# Project Proposal — Flutter App

## Project Understanding
You need assistance with: 
**Flutter 3.44+: plugin applies deprecated Kotlin Gradle Plugin (Built-in Kotlin migration needed)**

*Project description:*
Starting with Flutter 3.44, apps using `blurhash` 1.2.0 see this warning on `flutter build appbundle --release`:

```
WARNING: Your app uses the following plugins that apply Kotlin Gradle Plugin (KGP): blurhash
Your app will fail to build in future versions of Flutter.
```

**Cause** — `android/build.gradle` applies KGP the legacy way:

- `ext.kotlin_version = '1.7.10'` + `classpath "org.jetbrains.kotlin:kotlin-gradle-plugin:$kotlin_version"` in the `buildscript` block
- `apply plugin: 'kotlin-android'`
- explicit `implementation "org.jetbrains.kotlin:kotlin-stdlib-jdk7:$kotlin_version"`

**Fix** — per the official plugin-author migration guide, remove the plugin-applied KGP and let Flutter provide it:

1. Delete `ext.kotlin_version`, the `kotlin-gradle-plugin` classpath and the `kotlin-android` apply.
2. Replace the `kotlinOptions { jvmTarget = '1.8' }` block with:

```groovy
kotlin {
    compilerOptions {
        jvmTarget = org.jetbrains.kotlin.gradle.dsl.JvmTarget.JVM_1_8
    }
}
```

3. Drop the explicit `kotlin-stdlib-jdk7` dependency (KGP applies the stdlib automatically).
4. Bump `environment` in `pubspec.yaml` to `sdk: ^3.12.0` / `flutter: ">=3.44.0"` (requires KGP >= 2.0).

References:
- https://docs.flutter.dev/release/breaking-changes/migrate-to-built-in-kotlin/for-plugin-authors
- https://docs.flutter.dev/release/breaking-changes/migrate-to-built-in-kotlin/for-app-developers#report-incompatible-kotlin-gradle-plugin-usage-to-plugin-authors

Environment: Flutter 3.44.8 stable, macOS 27 arm64, blurhash 1.2.0 (latest on pub.dev). Thanks!
