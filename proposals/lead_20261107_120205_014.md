## Description

**목표**: Flutter 앱 `Twin-Fang/passQL` 의 "앱 정보" 화면을 `pro-launch` render 흐름(snapshot > 임시 golden 테스트 > `render run --collect`)으로 라이트·다크 캡처하고, 여백을 고친 뒤 같은 테스트로 다시 캡처해 비교하려 했다.
