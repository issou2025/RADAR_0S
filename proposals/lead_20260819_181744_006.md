# Project Proposal — Flutter App

## Project Understanding
You need assistance with: 
**Set the Flutter API base URL per environment instead of commenting lines in and out**

*Project description:*
The Flutter app's API base URL is switched by **commenting one line out and another in**. That is a release hazard: ship with the wrong line uncommented and the APK in the store talks to a dev host that is unreachable from users' phones.

### Current state

`flutter/fn.giwu/lib/api/client.dart:3-4`:

```dart
const kDefaultBaseUrl = 'https://giwu.co.za/api/';  // live server
// const kDefaultBaseUrl = 'http://giwubible.test/api/'; // dev server
```

Nothing enforces which is active. `flutter build apk` has no idea which environment it just built for, and CI cannot tell either — `flutter analyze` and `flutter test` both pass whichever line is live.

### Fix: compile-time environment, no source edit

```dart
const kDefaultBaseUrl = String.fromEnvironment(
  'GIWU_API_URL',
  defaultValue: 'https://giwu.co.za/api/',   // live is the safe default
);
```

Then:

```bash
flutter run --dart-define=GIWU_API_URL=http://giwubible.test/api/
flutter build apk                            # live, no flag, no edit
```

**Live as the default is deliberate**: the failure mode of forgetting the flag becomes "a developer hits production from their laptop", not "every user gets a build pointing at a `.test` domain".

`setApiBaseUrl()` at line 17 already allows runtime override, so a debug-only settings field can still point a test build at staging without a rebuild.

### Web client is already correct — leave it

`laravel/resources/js/api/client.js:4` reads `import.meta.env.VITE_API_URL ?? '/api'`. Since the merge into one Laravel app the web reader is same-origin, so the `/api` relative default is right in every environment. No change needed.

### Stale documentation to fix at the same time

`CLAUDE.md` states the Flutter base URL default is `https://api.giwu.test/` — twice. The code says `https://giwu.co.za/api/`. One of them has been wrong for a while.
