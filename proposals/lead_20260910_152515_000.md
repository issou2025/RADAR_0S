## Why

The owner has decided the repository stays **public on purpose** (#774), superseding CLAUDE.md hard rule 6. The instruction files still say the opposite, in three auto-loaded places:

- `CLAUDE.md` §1 rule 6 — *"**Keep this repo private.** … Nothing here goes to a public remote."*
- `docs/PROGRAM.md` "Not goals" — *"No public remote (rule 6)."*
- `docs/STEERING.md` — no row for the steer.

All three load into **every** session. Until they are corrected, the next session reads rule 6 as an absolute hard rule, finds the repo public, and does exactly what this one did: stops, files a `needs-decision`, and holds every push and merge. That cost 10 days of held work (#763, 2026-08-31 → 2026-09-10) and one session's #762 branch is still stranded locally because of it.

This is a documentation-only correction of a stale hard rule, not a change of posture.

## DONE

1. `CLAUDE.md` §1 rule 6 states the repository is public by owner decision, cites #774, and keeps the parts of the old rule that visibility never governed: the counsel-review material is still sensitive, `PRODUCT_AUTHOR_PLACEHOLDER = "rvt-writer"` stays, and "Autodesk Revit" is never echoed as *our* author string.

3. `docs/PROGRAM.md`'s "No public remote (rule 6)" not-goal is corrected.
4. `docs/STEERING.md` gains the standing row for #774, newest last, no existing row rewritten.
5. No session reading these three files can conclude the repo must be private.
