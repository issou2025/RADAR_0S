# Project Proposal — Structural Drawings

## Project Understanding
You need assistance with: 
**Complete nested extensible-storage decoding in schema-driven records**

*Project description:*
### Problem

The schema-driven field walker cannot interpret all extensible-storage payload layouts. Encountering one can leave later fields in the record unavailable, including data used by reinforcement shape definitions and data-storage elements in newer files.

### Expected behavior

Use the file metadata needed to decode supported nested payloads and continue reading the remaining record fields within their declared boundaries.

Use the Revit 2027 file to investigate partial field walks involving reinforcement shapes and data-storage records. Inspect diagnostics and the fields following nested extensible-storage payloads. A reduced fixture isolating an unsupported payload remains part of this issue.
