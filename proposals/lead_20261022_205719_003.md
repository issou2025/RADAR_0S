*Project description:*
## Context

Raised by the review of the publication series (project *Publikacje GIS*, `output/Publications/Series_review.md`, 2026-10-22), task T12. Papers 06, 10 and 11 will cite DiGi repositories and their wikis. Several wiki home pages describe a different library than the repository, and most ecosystem links still point to the former owner.

## Findings

| Wiki home | Says | Repository actually is |
|---|---|---|
| DiGi.BDL | parser for the Building Description Language (BDL) for EDSL Tas | client of the GUS Bank Danych Lokalnych API |
| DiGi.Communication | shared networking and IPC protocols | radio propagation (multi-ellipsoidal model) |
| DiGi.OSM | OSM downloader and parser | seed/placeholder project |
| DiGi.Typology | structural typologies for simulation setups | generic multi-level classification engine |
| DiGi.SAM | "Simple Architectural Model" (repo description: "System Advisor Model") | converters to SAM (Sustainable Analytical Model, SAM-BIM) |

Stale links: the "DiGi Ecosystem" sections of many homes (e.g. DiGi.Test, DiGi.GIS, DiGi.BDOT10k, DiGi.EPW, DiGi.BDL, DiGi.OSM, DiGi.Typology) link to `https://github.com/ZiolkowskiJakub/<repo>/wiki` — some also to non-existent `DiGi.BDOT`.

## Scope

1. Fix the five descriptions above (and the repository description of DiGi.SAM).
2. Replace `ZiolkowskiJakub/` with `DiGi-Organization/` in all wiki homes; fix `DiGi.BDOT` → `DiGi.BDOT10k`.
3. Add a check (script in this repo) that flags wiki links to other owners.
4. Tag releases of the libraries cited by the papers (at least DiGi.Solar, DiGi.GIS, DiGi.GIS.ML, DiGi.YOLO, DiGi.Typology, DiGi.GIS.Analytical, DiGi.GIS.PostgreSQL) and connect Zenodo for DOIs.
