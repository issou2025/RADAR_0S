### Context

### The Corrected Plan (Execution & Reflection Loop)

To execute the remainder of #2927 correctly, the agent must follow this exact mechanical loop. Memory is worthless; rely strictly on these written phases. To prevent drift, the autonomous loop enforces a strict "Execution -> Evaluation" (Actor-Critic) pattern.

**Phase 1: Onboarding and Rollback (Run Once)**
1. **MANDATORY READ:** Read `docs/standards/0031-gemini-actor-critic-loop.md` in full using your file tools. You are governed by this ADR.
2. Revert `data/scratch-2026-09-06-gemini-audit/ledger.md` to remove the falsely closed Checks 12 and 13.
3. Delete the unauthorized Python scanner scripts left in the audit directory.
4. Restore the audit state to exactly where it was at the end of Batch 714.

**Phase 2: The Autonomous Execution & Reflection Loop**
The operator will not babysit the agent. The agent must chain tool calls continuously, but it must strictly evaluate its own work between every batch per ADR 0031.

**Node A: Execution**
1. Target the next batch of files.
2. Execute `cat` (or `sed`) to pull the raw text into the context window.
3. Read the text semantically, looking for raw HTTP requests, environment manipulations, dynamic imports, and bypassed `retry_gate` patterns.

**Node B: Self-Reflection (The Critic)**
Before updating the ledger, the agent MUST explicitly evaluate its execution against these failure conditions:
- *Did I use `grep`, write a Python script, or use any automation to find the findings?*
- *Did I fail to use `cat`/`sed` to ingest the actual text?*
- *Am I guessing line counts instead of using `wc -l`?*
If the agent fails any of these checks, it must discard its findings, halt the loop, and restart Node A for the current batch using the correct manual protocol.

**Node C: Commit and Chain**
1. If Node B passes, write the exact line count and findings to `ledger.md`.
2. Ask the Mechanical Question: Has the operator typed since the last tool call?
3. If NO: Do not end the turn. Immediately make the next tool call to fetch the next batch. Chain tool calls indefinitely.

**Phase 3: Hard Halts & Handoffs**
The agent may only break the loop and stop if:
1. The context window begins to degrade (run `/handoff`).
2. A banned command is the only way forward.
3. Unrecoverable state would be destroyed.
4. The entire remaining audit is 100% complete.
