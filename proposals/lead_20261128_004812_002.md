# Project Proposal — Flutter App

## Project Understanding
You need assistance with: 
**[P1] Play Store readiness: target API 36, 16 KB pages, edge-to-edge, health declaration**

*Project description:*
## Problem
- **Target SDK:** Play has required updates to target API 36 since 31 Aug 2026. `android/app/build.gradle.kts` uses `flutter.targetSdkVersion`, so the value depends on the installed Flutter SDK and is unverified.
- **16 KB page size:** from 1 Feb 2027, updates without 16 KB page support can't be released (developer.android.com). Native libraries are the risk, especially `sqlite3_flutter_libs`.
- **Edge-to-edge:** on API 36 apps can no longer opt out. Settings and onboarding screens are where hidden UI typically shows up.
- **Predictive back:** API 36 enables it by default. `WillPopScope` should become `PopScope`.
- **Play forms:** the Health apps declaration and Data safety form are required for an app that reads training and wellness data.

## Proposal
- Check the release AAB's target SDK, and pin it if needed.
- Run `zipalign -c -P 16` or APK Analyzer on the release AAB, and update or replace native plugins that fail.
- Audit insets on every screen (Today, Settings, onboarding, sheets, Chat input), and replace any remaining `WillPopScope`.
- Draft the Health apps declaration and Data safety answers in `docs/privacy.md`.

## Acceptance criteria
- [ ] The release build targets API 36. Verified, not assumed.
- [ ] The 16 KB alignment check passes.
- [ ] No content under the system bars on a 360 dp Android 16 device or emulator.
- [ ] Play form answers are documented.
