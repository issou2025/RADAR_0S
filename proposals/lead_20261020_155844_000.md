### ♻️ To Reproduce

Install Bluebeam Revu 21 (21.11) with its Revit 2025 plugin, and pyRevit 7.0.0.26278+2233.
Start Revit 2025.5 (25.5.0.57) without pyRevit, open a project, and make sure the Bluebeam Connected Sessions pane is open/docked. Exit Revit.
Enable pyRevit and start Revit 2025.5.
Create a new blank project, or open any model.
Revit crashes about 2 seconds later.

### ⏲️ Expected behavior

Opening a document doesn't crash Revit. pyRevit's WebView2 assemblies shouldn't replace the versions other add-ins resolve in Revit's shared load context. Ideally pyRevit would load them in an isolated AssemblyLoadContext, or load them lazily only when the pyRevit output window first needs them.

### Additional context

A colleague with the same Revit, pyRevit and Bluebeam versions doesn't crash. As far as we can tell, their Connected Sessions pane isn't open.
Workaround: close the Bluebeam Connected Sessions pane (open a project with pyRevit off, close the pane, exit Revit), then re-enable pyRevit.
