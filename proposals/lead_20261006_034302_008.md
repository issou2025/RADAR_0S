## Detection contract

Selected project root resolves to `react-native` only when both are true:

- valid selected-root `package.json` has a non-empty string `dependencies["react-native"]`;
- at least one real selected-root application marker exists:
  - `android/`
  - `ios/`
  - `app.json`
  - `app.config.js`
  - `app.config.cjs`
  - `app.config.mjs`
  - `app.config.ts`.

Symlinks are not markers. Peer/dev dependencies, lockfile/transitive entries, `node_modules`, README/name text, or one side of the evidence conjunction are insufficient.

Precedence:

```text
go -> python -> react-native -> typescript -> javascript -> generic
```

## First-party profile / verification

The built-in React Native profile:

- emits first-party mobile engineering/security guidance into managed `AGENTS.md`;
- maps only selected-root package-manager/scripts already configured by the project;
- keeps TypeScript/build/E2E applicability explicit when scripts are missing;
- never invents Gradle/Xcode/Expo/React-Native/simulator/device/signing/deploy commands;
- conservatively refuses to auto-import visibly sensitive-effect scripts into general verification;
- treats repository configuration as evidence, not authorization.

Sensitive signing/publication/deployment/store/device-farm actions remain separate HUMAN DECISION/manual execution surfaces.

## Lifecycle contract

Only auto-selected profiles may transition automatically.

Approved Stage 11 specialization family:

```text
generic    -> react-native
javascript -> react-native
typescript -> react-native
```

Required:

- `install.requestedStack == "auto"`;
- current exact selected-root detection == `react-native`;
- normal conflict/ownership/backup/rollback/idempotence controls remain active.

Explicit selectors, legacy missing provenance, Go, and Python remain preserved.

## Plugin coexistence
