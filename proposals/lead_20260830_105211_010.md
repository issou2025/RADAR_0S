# Problem Statement

JustUI currently ships two visual presets (`default_` and `neobrutalism`) via the `JustThemePreset` enum and `JustPresetTokens` polymorphic contract. However, the modern UI landscape — particularly iOS/macOS system UI, Web3 dashboards, and premium SaaS applications — heavily employs **frosted glass (glassmorphism)** aesthetics. Developers using JustUI cannot achieve this look without manually wrapping every component in `BackdropFilter` + `ClipRRect`, breaking the zero-configuration preset workflow.

# Rationale & Motivation

- **Market demand**: Glassmorphism is the #1 requested aesthetic alongside neobrutalism in design systems (shadcn/ui, Radix UI themes).
- **Architectural fit**: The `JustPresetTokens` abstract contract (`preset_tokens.dart:20-74`) was explicitly designed to be extensible — adding `GlassmorphismPresetTokens implements JustPresetTokens` requires zero changes to existing component code.
- **Zero-dependency guarantee**: Flutter's built-in `BackdropFilter` + `ImageFilter.blur` + `ClipRRect` achieve the frosted glass effect natively without external packages.
- **Existing infrastructure**: `JustThemeData.fromSeed` (L116-233 of `theme_data.dart`) already branches on preset for background color, shadow scheme, and motion profile selection — adding a third branch is architecturally trivial.

## 2. Core Layer (`packages/just_ui_core`)

### New file: `src/theme/presets/glassmorphism_preset_tokens.dart`
```dart
class GlassmorphismPresetTokens extends JustPresetTokens {
  const GlassmorphismPresetTokens();

  @override
  double get borderWidth => 1.0; // Subtle luminous border

  @override
  bool get showsDefaultBorder => true; // Always show translucent glow border

  @override
  List<BoxShadow> resolveShadow(
    JustShadowScheme shadows,
    JustShadowLevel level, {
    required bool isPressed,
  }) {
    // Glassmorphism uses no traditional shadows — depth comes from blur layers
    return const [];
  }

  @override
  Widget buildPressEffect({
    required Widget child,
    required bool isPressed,
    required JustMotionProfile animations,
    Offset? customOffset,
    double? customScale,
  }) {
    // Subtle scale-down on press (same as default preset)
    return AnimatedScale(
      scale: isPressed ? (customScale ?? 0.97) : 1.0,
      duration: animations.instant,
      curve: animations.defaultCurve,
      child: child,
    );
  }
}
```

### New file: `src/theme/schemes/glass_shadow_scheme.dart`
- `GlassShadowScheme implements JustShadowScheme` — returns empty shadow lists since depth is conveyed through transparency layers, not drop shadows

### Modified file: `src/theme/theme_data.dart`
- `fromSeed` factory: add `JustThemePreset.glassmorphism` branch
  - Light bg: `Color(0xFFF0F4FF)` (very subtle blue-tinted white)
  - Dark bg: `JustDynamicSurfaces.generateDarkSurface(seed, lightness: 0.08)` 
  - Shadow scheme: `GlassShadowScheme`
  - Motion profile: `JustMotionProfile.standard` (smooth, not snappy)

### New shared component: `_shared_glass_container.dart`
```dart
class JustGlassContainer extends StatelessWidget {
  final Widget child;
  final double blurSigma;
  final BorderRadius? borderRadius;

  @override
  Widget build(BuildContext context) {
    final colors = context.justColors;
    final radius = context.justRadius;
    final resolvedRadius = borderRadius ?? .all(radius.lg);

    return ClipRRect(
      borderRadius: resolvedRadius,
      child: BackdropFilter(
        filter: ImageFilter.blur(sigmaX: blurSigma, sigmaY: blurSigma),
        child: DecoratedBox(
          decoration: BoxDecoration(
            color: colors.card, // Resolved to translucent by preset
            borderRadius: resolvedRadius,
            border: Border.all(
              color: Colors.white.withOpacity(0.2),
              width: 1.0,
            ),
          ),
          child: child,
        ),
      ),
    );
  }
}
```

# Proof of Concept

The following PoC demonstrates the core glass container rendering using only Flutter built-in APIs:

```dart
// Standalone PoC — requires no external packages
Widget build(BuildContext context) {
  final colors = context.justColors;
  final radius = context.justRadius;
  final blur = JustBlur.lg; // 16.0 sigma

  return ClipRRect(
    borderRadius: .all(radius.lg),
    child: BackdropFilter(
      filter: ImageFilter.blur(sigmaX: blur, sigmaY: blur),
      child: Container(
        padding: .all(context.justSpacing.lg),
        decoration: BoxDecoration(
          color: colors.card, // Translucent under glassmorphism
          borderRadius: .all(radius.lg),
          border: Border.all(
            color: Colors.white.withOpacity(0.2),
            width: 1.0,
          ),
        ),
        child: Text(
          'Frosted Glass Card',
          style: context.justTypo.headingMd.copyWith(
            color: colors.textPrimary,
          ),
        ),
      ),
    ),
  );
}
```
