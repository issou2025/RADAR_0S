# Project Proposal — Bim Modeling

## Project Understanding
You need assistance with: 
**BIM: Space 'Elevation With Flooring' property provides wrong value**

*Project description:*
### Problem description

Space `Elevation With Flooring` property provides wrong value - it is not according to IFC schema.

According to IFC schema, the provided value is "elevation of the space", which is actually not an attribute or a property.

The correct information in `Elevation With Flooring` should be: `.Shape.BoundBox.ZMin` + `height of the flooring (IfcCovering object)` . I don't think there is currently a simple way for FreeCAD to calculate this value automatically. Flooring height of the space would need to be detected for this value to be filled in correctly.


Even though it may prove useful, I don't think the value should be auto populated, as it does not provide correct value. The best way to solve this issue is to not autopopulate this property at all.

I am able to reproduce in FC 1.1.3

### Workbench affected?

BIM

### Steps to reproduce

- open sample file (remove the .txt extension)

[FC-space-attribute.FCStd.txt](https://github.com/user-attachments/files/30907258/FC-space-attribute.FCStd.txt)

- select the `Space_volume` object
- run `Arch_Space`
- the space is created
- look at the value of `Elevation With Flooring` property - there is strange value there (this is another issue)
- write something into the `Description` to see the value

### Expected behavior

The value of `Elevation With Flooring` property should be 100mm, because that is the elevation of the flooring in the Space has that value.

Note: even if the `Covering - floor` object is added to the Space, the value does not change.

### Actual behavior

The value of `Elevation With Flooring` property is 0 mm, which is not correct.

See behavior in the video:

https://github.com/user-attachments/assets/f171f9fa-4816-426d-8694-1defde794a71
