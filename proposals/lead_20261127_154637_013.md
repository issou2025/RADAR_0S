## Findings

### 1. capture-runtime-context-sources-pr-tree-script-on-early-failure

- Category: `A08:2021-Software and Data Integrity Failures / STRIDE Elevation of Privilege`
- Severity: `high`
- Confidence: `8/10`
- Location: `.github/workflows/review_autofix.yml:3331`

**Exploit scenario**

The 'Capture runtime context' step runs under if: always(). It looks for its script under ${SUPPORT_SCRIPTS_DIR:-}. If that file is missing, it falls back to ${GITHUB_WORKSPACE}/.codex-workflow-src/scripts/review_autofix_step_capture_runtime_context.sh and sources it (line 3336). SUPPORT_SCRIPTS_DIR is only set by 'Stage workflow support files' (line 2454), and the trusted support repo is only checked out into .codex-workflow-src at line 2420. Both run after 'Checkout repo' (line 2332), which checks out the PR head with token secrets.GH_PAT and leaves persist-credentials at its default. Someone who can push a same-repo PR branch, or an injected AI implement agent that writes PR files, can commit two things: a `.opencode` path, so the 'Reject project OpenCode configuration' step (line 2371) fails on purpose before staging, and a file at `.codex-workflow-src/scripts/review_autofix_step_capture_runtime_context.sh`. Every later step is skipped, but the always() step still finds the PR-planted script in the workspace and sources it. That runs attacker code, which can read the GH_PAT persisted in .git/config (http extraheader) and use it to push, merge or dispatch across the repos that token reaches.

**Recommendation**

Remove the workspace fallback, or make it fail closed. Before sourcing, require that steps.checkout_support_source succeeded and that `git -C .codex-workflow-src rev-parse HEAD` equals SCRIPT_REF. Otherwise skip the step with a warning. Better still, only source from ${RUNNER_TEMP}/coding-workflows-runtime-* (outside the PR tree) and skip when SUPPORT_SCRIPTS_DIR is unset. Also set persist-credentials: false on the PR-head checkout so PR-controlled code cannot read GH_PAT from .git/config. Apply the same guard to every other always() step that uses the REVIEW_AUTOFIX_STEP_SCRIPT fallback pattern.
