## 1. Deeper, curvier entry

The lead-in is currently a **straight line** carrying the main curve's start
tangent. That is why every attempt to deepen it has fallen flat: a straight line
cannot both enter steeply and arrive flat. Turning it into a **cubic** whose
second control point sits on the tangent at x=0 gives a steep start and a
kink-free join.

The main curve gets more curvature at the same time — its control polygon drops
6 / 46 / 76 instead of 22 / 46 / 46, so the gaps between stations go from
35 / 43 to **31.5 / 54.8**: clearly accelerating rather than nearly even.

## 2. Centre the two paths, move the docs link right

The action row becomes a three-column grid `1fr auto 1fr`. The two pills sit in
the middle column and are therefore **genuinely centred**, independent of how
wide the link on the right is — a flexbox `space-between` would have shifted them
by that width.

"Wie genau funktioniert das?" loses its border, padding and radius and becomes a
plain link with the GitHub mark and arrow, right-aligned in the third column.

```html
<div class="actions">
    <div class="actions-main">…two pills…</div>
    <a class="actions-link" …>…GitHub mark… Wie genau funktioniert das? →</a>
</div>
```

The selector that reveals the stack line is bound to `.action.muted` and has to
move to the new class in **both CSS and script**. `.action.muted` then goes away.

Below 769px the grid collapses to one column and everything returns to the left.

Accepted trade-off: headline left, paths centred, meta link right means three
alignments on one page. Readable as a separation of roles, but it may read as
restless — that is the call to make when looking at it.
