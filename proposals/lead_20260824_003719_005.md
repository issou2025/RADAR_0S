## Infrastructure & conventions in place

- **CI** (`.github/workflows/ci.yml`): PRs + non-main pushes — Flutter
  analyze/test/build (app + `parlour_theme`) and the legacy node engine tests.
- **Deploy** (`.github/workflows/deploy.yml`): on `main` — builds Flutter to
  `app/` beside the legacy site; single hand-written `sw.js`; cache hash folds
  the Flutter output. Toolchain pinned in `flutter_app/.fvmrc` (3.47.1).
- **Design system**: `flutter_app/packages/parlour_theme`. Demo gallery at `/demo`.
- **Cutover**: `scripts/cutover-game.mjs` + `docs/cutover-shim.template.html`;
  `docs/porting-recipe.md` + `docs/parity-checklist.md` are the Phase 1 authority.
  The recipe supersedes the "update the sw.js precache entry" line in the older
  game-issue drafts — the shim keeps the URL, so no `sw.js` edit is needed.
- Build flags: `flutter build web --release --wasm --no-web-resources-cdn --pwa-strategy=none --base-href /game-hub/app/`
