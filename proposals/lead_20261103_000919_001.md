# Project Proposal — Bim Modeling

## Project Understanding

*Project description:*
## Context

A session cleaned up filled region types against area plan color schemes in a workshared Revit 2026 project model. No `am-*` skill covers this work, so the agent wrote raw `run_query` / `run_modify` scripts. It read only the pyRevit `revit-scripting` skill.

## What happened

Four IronPython / Revit 2026 errors cost a retry each:

1. `ElementId.IntegerValue` raised `AttributeError`. The runtime hint pointed to `.Value`. The pyRevit `revit-scripting` skill does not say it.
2. `DB.Int64` does not exist, so the first attempt to build an `ElementId` from an int failed. The fix is `import System`, then `DB.ElementId(System.Int64(n))`.
3. `json.dump` failed on .NET integers, for example `Color.Red`. Each value needed `int()` first.
4. `FilledRegionType.Name` raised `AttributeError: Name`. Read worked with `t.get_Parameter(DB.BuiltInParameter.SYMBOL_NAME_PARAM).AsString()`. Write worked with `DB.Element.Name.__set__(t, new_name)`.

Points 1 and 2 are already in the archi-magic README troubleshooting table and in "Revit 2026 differences" in `am-revit-api-docs` (from #29). Part of point 4 (read with `GetValue`) is in `am-import-from-manufacturer-rvt`. But the agent did not load those, because the task did not match any `am-*` skill. So the fixes exist, but they do not reach a raw MCP session.

## Proposed change

- Put a short "IronPython + Revit 2026 gotchas" list where every Revit session sees it. For example, the archi-magic session-start rules, or one line there that says "read 'Revit 2026 differences' in `am-revit-api-docs` before the first script".
- Add points 3 and 4 to "Revit 2026 differences":
  - convert .NET numbers with `int()` / `float()` before `json.dump` or a result dict;
  - for type names (filled region types, floor types and others), read with `SYMBOL_NAME_PARAM` and write with `DB.Element.Name.__set__(t, name)`.
- Optional: offer the same list upstream to the pyRevit `revit-scripting` skill.

## Acceptance ideas

- A session with no matching `am-*` skill gets the gotcha list before its first `run_query`.
- A script that renames a filled region type works on the first try when it follows the list.

Not verified: whether `json.dump` fails on every .NET numeric type, or only on some (for example `Byte` from `Color.Red`).

Related: #29, #76, #77.
