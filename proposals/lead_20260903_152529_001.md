# Project Proposal — Bim Modeling

## Project Understanding
You need assistance with: 
**Make DWG entity handles consistent across file formats**

*Project description:*
### Description
Product issue: https://github.com/3drepo/3D-Repo-Product-Team/issues/388

We would like to support DWG Entity Handles as External Ids. To do this, we need to ensure they are consistent when imported via NWDs as well as Native Imports, while also not breaking existing functionality.

The main challenge here is NWDs, as the NWD tree will often include composite parts in a more detailed breakdown than is presented in the 3DR tree. We need to ensure then that metadata (i.e. unique Ids) for DWGs, RVT and IFC files is attached to the correct node. Currently, the importer inherits parent metadata for NWD nodes, which works for RVT and IFC files, but not for DWGs.
