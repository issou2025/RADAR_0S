# Project Proposal — Bim Modeling

## Project Understanding
You need assistance with: 
**BIM: Section view hides isolated faces**

*Project description:*
### Problem description

When rendering some roofs with BIM section planes and BIM views, I noticed that in solid rendering mode, some roofs were seemingly randomly not rendered. Further investigation into the code shows that for solid rendering sorts the faces it needs to render, but that sorting algorithm would drop faces that cannot be related vertically to any other face.

I have a rough fix that fixes my direct issue in the sorting code, but I also think that the sorting code might be unnecessarily complex and could maybe be improved. I'll reply with a comment about this in a minute (or maybe later today).

The file contains four slabs (based on wires), which overlap when viewed from above. I also added a bit of vertical difference, but that is not needed to trigger this bug. The file also has two section planes (positioned above the slabs), with associated BIM views  on the techdraw page.

<img width="725" height="450" alt="Image" src="https://github.com/user-attachments/assets/75eac19f-9cef-4bec-bc47-5ac113e446c7" />

One section cuts all four slabs. When rendered, this shows all four slabs as expected.
The other section omits one slab, which leaves one slab "disconnected" from the others (when viewed from above). When rendered, only two slabs are shown. The "disconnected" slab is not shown, even though it should be.

Note that when there is just one visible slab/face in the section, then the sorting is skipped entirely, so the slab *is* rendered, which was a bit confusing trying to debug this.
