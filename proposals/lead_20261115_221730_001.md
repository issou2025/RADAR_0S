# Project Proposal — Bim Modeling

## Project Understanding
You need assistance with: 
**[Bug]: pyRevit loads Roslyn 4.11 into Revit's default load context and breaks add-ins that need a newer Roslyn**

*Project description:*
On Revit 2025-2027 (.NET Core), `pyRevitAssemblyBuilder` loads `Microsoft.CodeAnalysis` / `.CSharp` 4.11 from `bin/netcore` into the default AssemblyLoadContext at start-up. Another add-in compiled against Microsoft.CodeAnalysis 4.12 then fails with `FileLoadException: The located assembly's manifest definition does not match the assembly reference` (reproduced with a C# eval add-in).

Same in v7.0.1. Suggested: load Roslyn in pyRevit's own (isolated) AssemblyLoadContext, as already done for WebView2.

Found during the 7.1.0 RC qualification (#3969) on candidate 14af9ddb8 (7.1.0.26319). Not a release blocker. Evidence files are in the QA folder of that run.
