# Project Proposal — Bim Modeling

## Project Understanding
You need assistance with: 
**Design: unattended execution policy for actions**

*Project description:*
## Context

Actions are gated by `REVIT_MCP_ALLOW_WRITE=1` and the workstation `allow-write` file, and every mutating action supports `dry_run` and returns `verification`. What does not exist yet is a policy for unattended use: once both gates are on, any prompt can mutate the model without a per-action confirmation.

## Discussion needed

Before implementation, agree on the model. Options on the table:

1. **Confirmation tokens.** A mutating call without a token returns a preview plus a one-time token; the client repeats the call with the token to commit. Works with any MCP client, adds one round trip.
2. **Allow-list per session.** The workstation file lists which actions are allowed (`move,set_parameter`) instead of a blanket switch.
3. **Rate and scope limits.** Maximum elements per action, maximum actions per minute, refusal outside the active view.

These are not exclusive. The outcome of this issue is a short design note in `docs/actions.md` and follow-up issues per accepted item.
