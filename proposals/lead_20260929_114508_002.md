# Project Proposal — Bim Modeling

## Project Understanding
You need assistance with: 
**feat: out-of-band confirmation for irreversible and bulk actions**

*Project description:*
Actions are enabled by default, and tool results return model-authored text (element, family, link and workset names, parameter values, warnings) verbatim to the MCP client.
Content in a linked model, family or shared central model can therefore steer an agent into actions.
`revit_remove_links` cannot be undone and runs in a single call.
Bulk deletes and `edit-families` with purge or parameter removal also run without a human checkpoint.
The document-lifecycle confirmation token is returned to the agent, so it does not prove human consent.

## Proposal to discuss

- Show a Revit TaskDialog on the workstation before irreversible operations and before bulk operations above a threshold.
- The agent never sees an approval token.
- A workstation setting can relax the prompt for trusted setups.
- A declined prompt returns a clear error and changes nothing.
