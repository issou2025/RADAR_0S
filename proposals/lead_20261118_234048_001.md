# Project Proposal — Structural Drawings

## Project Understanding
You need assistance with: 
**Hot-swap ribbon: remove empty panels on sync without restarting Revit**

*Project description:*
## Summary
Support "hot swapping" the Relay ribbon: a user swaps which graphs are in the Relay folder (for example, a Dynamo graph copies a chosen subset of tools from a master directory into the Relay folder with the desired panel structure), runs **Sync**, and the ribbon matches, without restarting Revit.

## Current behavior
- Adding buttons on sync works.
- Removing buttons on sync works.
- **Ribbon panels (sections) are never removed until Revit restarts.** If a folder/panel goes away, its empty panel stays on the tab for the rest of the session.

The root cause is that Revit registers ribbon panel/tab IDs for the whole session, and the API has no supported way to delete a `RibbonPanel` once created.

## Desired behavior
After a sync, panels with no backing folder are no longer visible, and panels that come back (same name) are reused and repopulated, all within the same Revit session.

## Possible approach
- Since panels can't be unregistered, hide them instead: set `RibbonPanel.Visible = false` for orphaned panels (and the AdWindows `Autodesk.Windows.RibbonPanel`/`RibbonTab` if needed), and set it back to `true` when a matching folder reappears.
- Keep a session map of panel name to panel so a re-added panel is reused instead of re-created (re-creating with the same name throws).
- Same idea for a tab that ends up with no visible panels.

## Use case
Keep the complete tool list in a referenced directory, and use another DYN to copy the desired tools/structure into the Relay folder, then sync, so different teams/projects can swap ribbon layouts on the fly.
