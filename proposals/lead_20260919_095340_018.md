## What exists today (facts for the concept's Notes)

- **tmux-herd** (`docs/design/TMUX-HERD.DESIGN.md`, DRAFT, no code;
  task-020 waits on APPROVED and on task-021 / issue #307). Its discovery +
  git adapter already computes the forward half of the map -- session ->
  agent cwd -> `git-common-dir` -> `origin` owner/repo + branch -- and
  bakes it into the session name `<agent>@<owner/repo>=<branch>+<slug>`
  (L219-249). Data model says "Nothing persisted" (L328); Rejections
  refuse a persistent state file because "state that drifts from the tmux
  server is worse than no state" (L425). Todd's daemon idea sits in
  tension with that rejection: record it, resolve it in phase 2.
- **The PR page carries the other half.** Head repo + head branch are in
  the DOM, so the lookup key is (owner/repo, branch), which tmux-herd
  already derives. PR number -> branch is the page or `gh pr view`.
- **Branch -> PR exists once:** `bin/branch-merged-check` `query_gh()`
  (L64-70) runs `gh pr list --head <branch> --json state,number,url`, with
  a fake seam `TDS_BRANCHGUARD_QUERY` (L52-56). The pre-commit branchguard
  caches per-worktree verdicts under `<git-dir>/tds-branchguard/`
  (`docs/branch-guard.md:142-159`).
- **goldfish** `running_agents()` (`goldfish/shell.py:553-570`) maps agent
  PID -> enclosing clone, but collapses worktrees of one repo and has no
  tmux awareness. Not reusable as-is.
- **Stable session identity** is task-021's deliverable (`#{session_id}`);
  a reverse map wants that more than the mutable name.
- **Mac surfaces:** rumps menu-bar apps (`bin/chores-monitor`,
  `bin/skills-drift-monitor`, `bin/lmde-sync-monitor`) with launchd plists
  in `macos/launchd/`; Dock tiles via `macos/apps/mkmacapp`. Chores set the
  dashboard mould: one `status()` query, four surfaces (CLI `--json`,
  Textual TUI, rumps, Dock; `CHORES.DESIGN.md:284-291`) and rejected a
  Swift `NSStatusItem` app and any web/windowed dashboard (L566-568).
  `MACOS-APPS.DESIGN.md` defers menu-bar agents (L44-47, L200-204).
  rumps is un-radared (issue #288).
- **Terminal.app** is the terminal (`TODO_PLAN.md:1171`, AppleScript
  branding). Shell <-> app IPC today is subprocess + JSON stdout.
- **Transport precedents:** log-hoarder's `log-hoarderd` is the localhost
  HTTP+JSON daemon mould (`LOG-HOARDER.DESIGN.md:139-141, 445-451`; bind
  address is the auth; UNIX sockets rejected L387-389). NATS KV
  `agent.<agent>.<session>.state` on 127.0.0.1:4222 is the other
  (`AGENT-NOTIFICATIONS.DESIGN.md:165, 331`; NATS is Adopt); chores
  rejected NATS for itself (`CHORES.DESIGN.md:558-560`). No URL-scheme
  handler (`CFBundleURLTypes`) exists in either repo.
- **Browser:** no extension or userscript exists in tds-utils or
  template-tools. orgmarks chose CLI over extension
  (`docs/concepts/orgmarks/README.md:19-28`;
  `BOOKMARK-ORGANIZER.DESIGN.md:60, 806`). `lmde/TECH_RADAR.md:118-123`:
  Chrome 142+ silently disabled `--load-extension` for branded Chrome
  under automation; manual "Load unpacked" is untested here.
- **Radar** (`lmde/TECH_RADAR.md`, human-maintained): no row for browser
  extensions / MV3, Swift, Electron, Tauri, Rust, plain sqlite. Any of
  those is a proposal, never a silent add.
- **Hole by construction:** PRs from claude.ai/code sessions (branches
  `claude/...`) have no tmux session at all.
