Affected users on Windows CLI v2.1.1 tried `opencode/glm-5.3-flash-free` and `opencode/beam-free` with no success. Suggests a backend quota tracking or IP-based limit miscalculation.

### 3. First-Time Users Hitting Free Limit Immediately (5 comments)
[#58550](https://github​.com/anomalyco/opencode/issues/58550) — A new user reports installing OpenCode and writing their first message with a free model, only to immediately receive "Free usage exceeded, subscribe to Go." This is a critical onboarding blocker.

### 4. All Free Models Stopped Working in Desktop 1.19.4 (5 comments, 5 👍)
[#58781](https://github​.com/anomalyco/opencode/issues/58781) — The highest-voted issue reports that all free models in OpenCode Desktop suddenly return "Free Usage Exceeded, Subscribe to Go"—even for users who haven't reached any visible limit. Indicates a possible service-side quota calculation issue.

### 5. CLI "api get" Truncates Output When Piped (5 comments)
[#52925](https://github​.com/anomalyco/opencode/issues/52925) — `opencode api get` returns complete JSON to files but truncates stdout when piped, producing invalid JSON and breaking standard patterns like `opencode api get ... | jq`. A ~580 KB response consistently fails.

### 6. Provider Discovery Hard-Coded 1s Timeout Too Short (4 comments)
[#58558](https://github​.com/anomalyco/opencode/issues/58558) — Model discovery for Ollama, LM Studio, and vLLM silently fails with zero models returned when endpoints take several seconds to respond. The hard-coded 1-second timeout in the shared discovery helper needs to be configurable.

### 7. OpenCode Crashes with Custom %TEMP% Path on Windows (3 comments)
[#58559](https://github​.com/anomalyco/opencode/issues/58559) — Changing the Windows `%TEMP%` path to a custom location causes OpenCode to crash entirely on startup. A significant Windows compatibility issue.

### 8. Expired Free Model Breaks Client Catalog Access (3 comments)
[#57931](https://github​.com/anomalyco/opencode/issues/57931) — When a previously active free model (e.g., glm-5.4-free) expires or is removed, the OpenCode client enters a validation/session lock that blocks access to *other* valid free models instead of gracefully skipping the expired one.

### 9. DeepSeek V4.1 Flash Free Infinite Loop (3 comments)
