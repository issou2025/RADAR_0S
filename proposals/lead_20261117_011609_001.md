*Project description:*
## Gap

The canonical scene now has `kind:"extrusion"` (walls, slabs, footings and generic extruded shapes: a frame, 1..8 items of outline rings with up to 64 holes, extruded along the frame normal; optional `class` wall/slab/footing, IFC4 `predefinedType`, `axis` (a wall's or strip footing's centreline), `loadBearing`, a one-layer `material` (`{layers:[{name, thicknessMm, grade?}]}`), `quantities` (weights included), and the member label channel). `ifc.write` writes it as IfcWall/IfcSlab/IfcFooting and `viewer-3d` draws it. The Revit bake does **not** create one: it receipts every `extrusion` as `unsupported` (`unsupported-kind`, naming the kind) and creates nothing in its place. That was deliberate for this slice (FloLess add-ons S3, pawellisowski/floless.app#3296: "leave out / IFC instead").

## What a native Revit bake would need

- **Wall** (`class:"wall"` with an `axis`): `Wall.Create` on the centreline from `axis.u0`..`axis.u1` along the frame's `uDir`, `WallLocationLine.WallCenterline`, a wall type whose width equals the ring's thickness, base offset from `fromMm`, unconnected height `depthMm`. A banded wall (several items) or a non-rectangular profile needs an edited profile (`Wall.Create` with a curve profile) or one wall per band; openings → `Opening`/`NewOpening` cuts.
- **Slab** (`class:"slab"`): `Floor.Create` from `CurveLoop`s (the outer ring plus one loop per hole) at the frame's level and offset, with a floor type whose thickness is `depthMm`.
- **Footing** (`class:"footing"`): pad → an isolated foundation family instance sized from the ring (or an in-place/DirectShape where no family fits); strip → `WallFoundation` under a wall, or a `Floor`/DirectShape where it stands alone. Say which is used in the receipt.
- `predefinedType`/`objectType` → the element's IFC export parameters; `material.layers[0].name` (and `grade`) → the type's structural material; `loadBearing` → the structural flag; `meta.properties` → shared parameters through the same label path members use.
- Receipt: one `emitted` row per element with the created ElementIds; a shape Revit cannot express exactly fails per element with the reason, never a silent approximation.
- Clash/placement proof per the house rule: assert the created solid's volume and face positions against the scene's rings and depth.
