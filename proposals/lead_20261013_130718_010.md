# Research iOS development and synchronization

## Description

AirPx needs an iOS client alongside the Android app and the web app. The team has no Mac available, so we chose [[xtool](https://github.com/xtool-org/xtool)](https://github.com/xtool-org/xtool) (open source) as the build toolchain. This issue covers the research needed before implementation starts: which technology stack fits, how automatic photo sync can work on iOS, and how we develop and test without a Mac.

## Tasks

### 1. Compare iOS development technologies
- [ ] Evaluate native Swift/SwiftUI built with xtool (SwiftPM-based)
- [ ] Evaluate cross-platform options (Kotlin Multiplatform, Flutter, React Native) and whether they work with xtool or without a Mac
- [ ] Compare them on effort, code sharing with the Android app, performance, and library availability
- [ ] Document xtool's limitations (e.g. no Interface Builder/storyboards, Xcode SDK setup, supported frameworks)
- [ ] Recommend a stack and record the decision

### 2. Investigate automatic photo synchronization
- [x] Research the Photos framework (PhotoKit) for accessing the camera roll and the permissions required (full vs. limited access)
- [ ] Research background execution limits on iOS (background tasks, background URLSession uploads, photo library change observers)
- [ ] Clarify what is possible without a Mac and what is limited by Apple (e.g. app expiry with free signing)
- [ ] Define the sync strategy: detecting new and changed photos, upload queue, retry, conflict handling (local edit → cloud update)
- [ ] Compare with the Android auto-backup design so both clients behave consistently via the same API

### 3. Research development options without a Mac
- [ ] Set up xtool on Linux/Windows (WSL) and build a "Hello World" app
- [ ] Document how to install and run on a physical iPhone (Apple ID, signing, 7-day limit with a free account)
- [ ] Check simulator alternatives (xtool has none, so testing needs a real device)
- [ ] Evaluate cloud Mac options (e.g. CI runners, rented Macs) as a fallback
- [ ] Clarify what is needed for TestFlight/App Store distribution (Apple Developer Program, cost)
