*Project description:*

How to implement repository mirroring for `github.com` to provide a reliable alternative source and mitigate user rate-limiting and connectivity issues.

The following **west** commands currently access `github.com`:

### 1. `west init`

- Mirroring can be implemented using Git's `insteadOf` feature. For example:

```gitconfig
[url "https://example.com/mirrors/"]
    insteadOf = https://github.com/
```

From: @marc-hb ( in the comments below ) :
- ... always `git clone mirror` + `west init -l`
- In fact, you should always do this in CI and in automation/scripts so when one step fails (due to some rate-limit or any other reason) then you instantly see which one did without even looking at the logs.

### 2. `west update`

- Mirroring can be implemented using Git's `insteadOf` feature. For example:

```gitconfig
[url "https://example.com/mirrors/"]
    insteadOf = https://github.com/
```

### 3. `west blobs fetch`

- Git's `insteadOf` feature cannot be used because blob downloads do not go through Git repository URLs.
