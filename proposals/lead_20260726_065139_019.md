# Task Assignment

## Task ID

`ARCH-CANONICAL-EVENT-ADMISSION-001`

## Purpose

GitHub上のIssue／PR／review／comment／CI由来イベントを、Automatic Gate Progression Evaluatorへ渡す前に正規化・検証し、受理可能なcanonical eventだけを通すAdmission Contractを設計・Freezeする。

## Background

- Pure Automatic Gate Progression Evaluator: PR #180でMerge済み
- Canonical V2 fixture corpus: `docs/automation/phase1-v2-normative-fixture-corpus.json`
- 次工程: Canonical Event Admission
- 後続: Gate Status Publisher、Role Routing、Approval Detection、Protected Action Executor、Continuous Orchestration

## Required Scope

### Canonical Event Envelope

最低限、以下をFreezeする。

- provider／repository／event type
- source object identity
- actor identity
- occurred_at／observed_at
- delivery／event identity
- immutable source references
- raw payload binding
- normalized payload
- schema／contract version

### Admission Pipeline

```text
raw event
→ structural admission
→ source admission
→ identity validation
→ ordering / duplicate handling
→ canonicalization
→ accepted | rejected | failed
```

### Required Decisions

- 対象GitHub event種別
- canonical event identityと重複判定
- redelivery／out-of-order処理
- current-state再取得の要否と境界
- raw payloadとnormalized payloadのbinding
- source precedence
- unknown／unsupported eventの扱い
- malformed payload時のsafe result
- timestamp／actor／repository identity検証
- evaluator入力への変換境界
- fail-closed条件
- telemetry／secret redaction
- versioningとmigration

## Required Outcomes

```text
accepted
rejected
failed
```

`rejected`は決定的なAdmission結果、`failed`は内部処理失敗として分離する。

## Required Test Scenarios

- valid Issue event accepted
- valid PR event accepted
- unsupported event rejected
- malformed envelope rejected
- duplicate delivery rejected or deduplicated deterministically
- same source object with newer event accepted
- out-of-order event handled deterministically
- repository／actor identity mismatch rejected
- missing immutable source reference rejected
- input-external evidence is never synthesized
- unknown fields follow closed-schema policy
- internal failure does not masquerade as rejection
- no event triggers Ready／Approve／Merge or other protected action

## Deliverables

- Architecture Contract
- canonical schemas／types
- precedence and failure tables
- normative fixture plan
- implementation boundary
- Architecture Review decision

## Boundaries

- Architecture first。実装はFreezeとArchitecture Review PASS後
- Pure Evaluator Contractを変更しない
- Gate Status Publisher以降を実装しない
- Runtime GitHub writeを行わない
- Ready、Approve、Merge、protected actionを行わない
- SD Prompt Studio固有依存は局所化し、Core Contractへ直接埋め込まない

## Completion Definition

Canonical Event Envelope、Admission pipeline、identity／ordering／duplicate policy、source precedence、failure boundary、evaluator binding、normative test matrixが推測不要な完全literal ContractとしてFreezeされ、Architecture ReviewでPASSしていること。
