## Project Understanding
You need assistance with: 
**Historical Press development: PR records and issue transfers**

*Project description:*
This migration record preserves the development rationale and qualification context from Press after reusable software moved to GuavaJam. It is historical evidence, not a supported-format specification or a backlog of work to restore.

Current ownership: [core](https://github.com/nashspence/guavajam/tree/main/projects/core) owns source/signature, capture, assets, discovery and preservation; [view](https://github.com/nashspence/guavajam/tree/main/projects/view) owns optional presentation. The single current protocol is v1, core never depends on view, and Press consumes the pinned core package. See GuavaJam PRs #8 and #11. Historical HTML issuance, release receipts, old profiles, dated-v2 declarations and migration helpers are superseded. No retired implementation or compatibility path is introduced by this discussion migration.

The snapshots below preserve all 58 closed PR descriptions and all 34 conversation comments, plus authorship, dates, state and commit provenance. Empty descriptions are recorded explicitly; there were no submitted reviews or inline review threads. Original Markdown is fenced to preserve source references and prevent accidental mentions. Machine-specific paths and private deployment references are omitted. Merged software history remains reachable in GuavaJam Git history. Publisher-only PR #7 is recorded as provenance only.

All 34 closed issues have moved natively to GuavaJam, with authorship, dates, closure reasons and discussions preserved; source issue URLs redirect to the destination.

GitHub has no PR-deletion operation, and its archive mutation rejects merged PRs (`Cannot archive a merged pull request`). The two closed, unmerged PRs (#9 and #79) are archived and return HTTP 404 to unauthenticated readers. For the 56 merged PRs, migrated descriptions are replaced with forwarding links, original conversation comments are deleted after payload verification, and conversations are locked. Their merged records, diffs, edit histories and managed Git references remain in Press.

**Remaining blocker:** permanent removal of those 56 merged PR records is not available through GitHub's supported API. This issue tracks that unresolved cleanup decision. Repository deletion/recreation and support contact have not been performed. The content migration does not claim physical erasure from GitHub storage.

Active qualification stays in [GuavaJam #9](https://github.com/nashspence/guavajam/issues/9) and [Press #85](https://github.com/nashspence/press/issues/85). The first real publisher edition remains Press-owned. Completed and superseded records stay closed.

PR snapshots were captured before native issue transfers. GitHub rewrites references during a transfer, including quoted Markdown; the preserved snapshots are checked and restored to their captured, sanitized text afterward. The transfer table below supplies current issue destinations.
