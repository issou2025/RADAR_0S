# Project Proposal — Bim Modeling

## Project Understanding
You need assistance with: 
**A storefront curtain wall door loses its quantity set.**

*Project description:*
In the Revit 2025 architecture sample the door of the family "Door-Curtain-Wall-Single-Storefront" has BaseQuantities Height 8.0 in 0.1.0 and none in the current main. The reference writes Height 8.0, Width 3.0 and Area 24.0. OverallHeight 8.0 and OverallWidth 3.1458 are written in both builds.

Probable cause, not verified for this door: the height and width of a door are taken from the parameters or the frame extent before the bounding box, and the bounding box is no longer used when those give nothing.

The curtain wall door of the Revit 2024 school sample has no geometry, no parameter and is not exported by the reference; this one is exported, so a value exists to match.

Needed: decide how the Height, Width and Area of a door without a parameter or frame extent are measured, with this door as the fixture.
