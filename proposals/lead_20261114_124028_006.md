# Project Proposal — Bim Modeling

## Project Understanding
You need assistance with: 
**export_ifc exports the whole model when view_name doesn't match a view**

*Project description:*
## What happens

`FilterViewId` is only set when a view with that name is found ([`revit_mcp/interop.py` L84-89](https://github.com/Demolinator/revit-mcp-server/blob/3de7db6a20637d15cf5e3d2b97e2fd8aae09c419/revit_mcp/interop.py#L84-L89)). A misspelt or unknown `view_name` silently exports the entire model, and the response doesn't mention that the view wasn't found.

## Expected

An unknown `view_name` returns a 404 with the names of available views, as `set_active_view` already does.

## Suggested fix

After the lookup loop, if `view_name` was given and `target_view` is `None`, return the 404 before starting the export.

## How to check

Code review is enough for the logic. In Revit, call `export_ifc` with `view_name="does not exist"` and confirm you get an error and no file.
