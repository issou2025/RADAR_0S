# Project Proposal — Bim Modeling

## Project Understanding
You need assistance with: 
**Accept dashboard API tokens in Authorization: Bearer, and let users set token expiry**

*Project description:*
**Context:**
I had today conversation with Antonio on possibility to integrate ThatOpenPlatform with external applications people develop using ThatOpenEngine. They could potentially integrate platform CDE and allow their developed apps to read .frag files form CDE or put some files there too.
I did small, local and private test using platform's dashboard API key and such integration is rather easy, as it allows to pull files from CDE. I am now aware that such integrations will be subject of separate terms of use and rules how to allow them, but my test has revealed potential improvement for API:

**Current state:**
1. Dashboard API tokens only work as a ?accessToken= query parameter. The same token sent as Authorization: Bearer gets 401. For example, on GET /api/built-in/<uuid>/bundle: no auth returns 401, ?accessToken= returns 200, and Bearer returns 401.
2. These tokens also don't expire: the tokens I have tested carry no exp claim, platform also does not allow to set it. 

**Why this matters for potential 3rd party integrations**
- No tokens in URLs: 3rd party apps run on servers with access logs, reverse proxies, monitoring and error trackers, and URLs end up in all of them (query param will be treated as part of URL and logged)
- Standard: HTTP clients, API gateways and server frameworks expect the token in the header as a standard. The query form needs custom handling everywhere.

**Proposal:**
a) non-breaking:
Accept dashboard tokens in Authorization: Bearer in addition to ?accessToken=. Nothing breaks: the CLI, the Revit/Rhino plug-ins and published cloud components keep using the query parameter until they update.

b) switch to bearer token (breaking, if all of these Revit plugins integration and others uses api key in query param).

PS: I also propose to set up some private channel for reporting security related questions or issues. Thanks!
