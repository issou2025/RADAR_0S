## What this builds

Defines the design and implementation scope for expanding `skills/pr-review/SKILL.md` to include deep code quality, complexity, duplication, language/runtime-specific audit checks, and Playwright e2e test suggestions across WebJamApps repositories.

**Core Operational Rule**: `pr-review` is a strictly read-only code review pipeline — it **never** modifies, edits, creates, or updates the code/test files it is reviewing. It only provides formatted code review results and actionable feedback.

Design work for this issue runs through `/issue-design web-jam-tools`.

## Proposed Audit Expansion Scope

1. **Code Quality, Complexity & Duplication Audits**:
   - **Exported Contract Drift**: Verify public function signatures or exported contracts update all callers across the repo.
   - **Test Suppression Audit**: Ensure no existing unit tests were deleted, commented out, or had assertions softened ("No Superficial Symptom Patches").
   - **Backward Compatibility**: Enforce expand-contract rules (e.g. backend contract changes must be additive before frontend deployments).
   - **Duplicate Utilities**: Detect custom helper re-implementations when existing helpers are available ("Audit Before Re-inventing").
   - **Silent Error Swallowing**: Flag empty `catch` blocks or dummy fallback returns masking fatal failures.
   - **Dynamic Bounds vs Magic Numbers**: Enforce dynamic layout math over arbitrary static offsets.

2. **Language & Runtime-Specific Review Guidelines**:
   - **Deno & TypeScript (`web-jam-tools`)**:
     - Verify `deno task fmt:check` clean pass.
     - Enforce `deno deploy .` positional root argument and `entrypoint` in `deno.json`.
     - Verify `import.meta.main` guards on dynamic `Deno.serve` entrypoints.
     - Standardize Deno/TypeScript over Python for workspace helpers and hooks.
   - **React & Node.js (`JaMmusic`, `web-jam-back`, `CollegeLutheran`, etc.)**:
     - Audit Vitest timer sequences (`vi.useRealTimers()` initialization before `vi.useFakeTimers()`).
     - Audit MUI `<Autocomplete>` mock event mapping (`onChange` propagation back to parent state).
     - Verify `package-lock.json` engine lock alignment via `npm install --package-lock-only --ignore-scripts`.
   - **Bash / Shell Scripts (`scripts/`, `hooks/`)**:
     - Enforce `set -euo pipefail` and proper variable double-quoting in shell scripts.
     - Enforce `gio trash` over `rm` for local file and checkpoint deletions.
     - Verify anchored regex matching and compound command injection safety in PreToolUse guards.

3. **Playwright & End-to-End Test Automation Suggestions (Suggest Only)**:
   - **Coverage Gap Detection**: Inspect PR diffs for new user-facing components, routes, or workflows (e.g. Gigs/Venues CRUD, authentication, forms) that lack end-to-end test coverage.
   - **Suggest-Only Rule**: Instruct `pr-review` to **suggest** when a Playwright test could or should be added based on the code review — `pr-review` **never** creates, adds, or updates test files or code files itself.
   - **Local & CI Runnable Guidance**: Ensure any suggested Playwright test guidance specifies that tests must be runnable locally as well as in automated CI pipelines.
