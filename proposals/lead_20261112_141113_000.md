# Project Proposal — Structural Drawings

## Project Understanding
You need assistance with: 
**Support walls with custom elevation profiles (irregular base and top edges) for HBIM and sloping-terrain cases**

*Project description:*
### Problem

### Problem / Use case

In renovation and HBIM projects (especially existing buildings on sloping ground or with partial basements) it is common to need walls whose base or top is **not horizontal**.

Typical example:
- A basement / lower wall whose top edge follows the external ground slope.
- An upper wall (or insulation/cappotto layer) that sits on top of it, only covering the above-ground portion, and has a regular horizontal top.

Currently ConstructCraft walls are rectangular extrusions constrained to levels. This forces workarounds (multiple walls, voids, or post-processing) that break parametric behaviour, joins, openings and schedules.


### Proposed solution

### Requested feature
(with help by Grok)

Allow walls to have a **custom elevation profile** (frontal/elevation sketch), so that:
- The bottom edge can be irregular / sloped / stepped.
- The top edge can be irregular / sloped / stepped.
- Individual layers in a compound wall can have different vertical extents (base offset + height per layer).

This matches the behaviour found in ArchLine.XP (and other BIM tools): you can edit the frontal profile of a wall or draw a wall from a free elevation profile, and layers can have independent vertical offsets.


1. **Elevation profile editing**
   - Select a wall → “Edit Elevation Profile” (or equivalent).
   - Sketch mode in the wall’s elevation plane (similar to existing sketch tools or roof profiles).
   - Closed outline defines the wall solid. Default remains the current rectangular profile.
   - Support straight segments and arcs for the profile edges.

2. **Per-layer vertical extents** (compound walls)
   - In the wall type layer editor, allow each layer a base offset and independent height (or “extend to wall top / bottom”).
   - Useful for insulation that starts only above ground level while the structural core goes deeper.

3. **Constraints and interaction**
   - Keep existing base/top level constraints as the overall bounding box.
   - Profile operates inside those constraints (or can override them when edited).
   - Joins, openings (doors/windows), room bounding and IFC export should still work (export as IfcWall with a more complex solid or IfcExtrudedAreaSolid + clipping / IfcBooleanClippingResult).

4. **Optional future**
   - Ability to pick a terrain/surface and project the bottom edge onto it (nice-to-have, not required for the first version).

### Why this matters

- Essential for realistic HBIM of existing buildings and renovations on slopes.
- Enables correct material take-offs (insulation only where needed, structural wall full height).
- Aligns ConstructCraft with common BIM practice (ArchLine.XP frontal profile, Revit/ArchiCAD wall profile editing, etc.).
- Reduces the need for destructive workarounds.

### Alternatives considered

- Stacking two separate walls (lower structural + upper insulated): works but is cumbersome for joins, openings and scheduling.
- Using voids / boolean cuts: fragile and non-parametric.
- Waiting for full site/terrain tools: useful later, but the elevation profile already solves the majority of real-world cases.
