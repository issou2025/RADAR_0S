# Project Proposal — Bim Modeling

## Project Understanding
You need assistance with: 
**Free geometry (SketchUp-like) as its own geometry kind: select, edit, push/pull, split face — state and gaps**

*Project description:*
Remark from the maintainer's review of dev build `19cdda7` (31 October 2026), index #87.

**What:** the Sketch functionality is its own **geometry type**: free SketchUp-like geometry beside the four families (#105). In it the user can **select** faces, edges and points, **edit** them, **pull** a face up (push/pull) and **split a face**. The maintainer mentions a SketchUp clone somewhere that is worth examining for how it does this.

**What exists today** (read from the code and tests on main `19cdda7`):
- **Sketch tab** (`ui/panels/bim_ui.dl`, tab 2):
  - Draw: Line, Rectangle, Text.
  - Shape: Push/Pull (P), Split face, Offset.
  - Transform, and Components: Make, Place, Edit, Explode, Detail.
  - Solids: Box and others, as B-rep parts of a component.
- **Push/Pull:** a rectangle is pushed into a mass, and a mesh face is pushed by a distance (`push bim editor mesh face by …`). A wall or plate side is pushed too (`push bim editor side by …`). Tests: `sketch`, `push_pick`, `side_push`.
- **Split face:** a line across a mass splits it in two (`split bim editor faces along …`, `split bim editor mesh … face …`, `split bim editor sketch mesh …`). Test: `sketch_split`.
- **Edit mode,** Blender-like with SketchUp's picking: Tab on a face, pick points and edges, grab with G along X, Y or Z by typed distances. Self-crossing faces are refused, and Esc returns. Test: `edit_mode`.
- **Components:** made from the masses and placed several times. Editing one updates every instance, the model writes and reads back, and an instance can be exploded (test `sketch`).
- **IFC:** a mesh is exported as `IfcBuildingElementProxy`.

So the core of a SketchUp-like mode exists. What the review should find out is where it falls short in use: picking faces in 3D, push/pull directly in the 3D view, inference (on-axis, parallel, perpendicular, midpoint), and sticky versus grouped geometry.

**Proposal:**
1. Make it explicit as a fifth geometry kind, **"Free geometry"** (meshes and masses), in the family buttons of #105.
2. Its floating toolbar (#101): Select, Push/Pull, Split face, Edit (Tab), Make component.
3. Converting free geometry into a family element: a mass to a wall, floor or roof. This is how SketchUp-style massing turns into BIM.
4. Compare with the SketchUp clone the maintainer means (inference engine, face splitting on drawing, push/pull feedback) and with `docs/research/prior-art/sketchup.md` (inference as the transferable mechanism).

**Open question for the maintainer:** which SketchUp clone? It is not in the OpenAEC-Foundation organisation (searched: open-3d-studio is a component-template modeller, and skp-reader only reads SKP files).
