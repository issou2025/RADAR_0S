# Project Proposal — Flutter App

## Project Understanding
You need assistance with: 
**M10 · Android release, App Links for invites, first beta**

*Project description:*
## Goal
Ship a first beta to friends: a signed Android APK and the web app on the Pi, with invite links that open the Android app directly (App Links). iOS stays compile-only until there is a Mac and an Apple Developer account (see {{later-extras}}).

## Tasks

### Decisions (owner)
- [ ] Confirm the app ID **`io.github.urdaraluca.friends`**. It can't change once the app is in a store.
- [ ] Choose the public hostname, and set `API_BASE_URL` in `app/env/prod.json` for **mobile** builds. The web build keeps `""`, meaning same origin.
- [ ] Write a privacy-policy page (needed for the Play Store later; a static page on the Pi is enough).

### Android signing
- [ ] Generate an upload/release keystore. **Never commit it** (`*.jks` and `key.properties` are gitignored), and back it up outside the repo, e.g. in a password manager.
- [ ] `android/app/build.gradle.kts`: add a `release` signing config that reads `key.properties` (local) or environment variables (CI).
- [ ] CI (optional): a manual `release-android` job that decodes the keystore from a repository secret and builds `flutter build apk --release --dart-define-from-file=env/prod.json`. Secrets are added by the owner.

### App Links (invite links open the app)
- [ ] `AndroidManifest.xml`: an intent-filter with `android:autoVerify="true"` for `https://<host>/join/` (the path prefix `/join/`).
- [ ] Backend: set `ANDROID_CERT_SHA256` in the Pi's `.env` to the release fingerprint (and the debug one if wanted). `/.well-known/assetlinks.json` is served by the backend ({{web-hosting}}).
- [ ] go_router handles the incoming `/join/:code` deep link and opens the JoinScreen ({{app-groups}}).
- [ ] Check `adb shell pm get-app-links io.github.urdaraluca.friends` shows **verified**.

### Release
- [ ] Tag `backend-v0.x.0` (the image with the web build) and deploy to the Pi with `update.sh`.
- [ ] Tag `app-v0.1.0`. Create a GitHub Release with the APK attached and short "how to install" notes (allow unknown sources).
- [ ] Beta checklist on real devices:
  - register via an invite link;
  - create a group; add movies with IMDb ratings;
  - spin the wheel; vote in a poll; schedule a weekly event;
  - see the calendar and birthdays;
  - log out everywhere; delete a test account.
- [ ] Collect feedback in new issues.

### Polish before the beta
- [ ] App icon and name everywhere (Android label, web manifest/title, iOS display name), plus a splash screen.
- [ ] Empty states and friendly error messages for every screen.
- [ ] Basic accessibility: semantics labels, contrast, text scaling.

## Acceptance
- Tapping an invite link on Android opens JoinScreen in the installed app.
- The web app works fully from the Pi URL with no CORS configured.
- The APK is on a GitHub Release, and at least 3 friends use the beta for a week.
