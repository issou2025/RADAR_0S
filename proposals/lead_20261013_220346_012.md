Use the `http` package, or `dart:io`'s `HttpClient` to need no package. Keep it short, like the others, and run it once to check it prints `Oran`.

**Done when:** the block is in `docs/api.md`, it prints `Oran` when you run it, and you say in the pull request how you ran it. Title it `docs: add a Dart example to docs/api.md`.
