**Title:** Migrate Android build to AGP 9 and built-in Kotlin

**Background**
Flutter 3.47 moves Android builds to Android Gradle Plugin (AGP) 9, where Kotlin support is built in and the separate `kotlin-android` plugin is no longer used. Our project still uses AGP 8.11.1 with `id "kotlin-android"`, and only builds thanks to two temporary flags the Flutter migrator added to `android/gradle.properties`:

```properties
android.builtInKotlin=false
android.newDsl=false
```

These flags are a bridge, and future Flutter/AGP versions will drop them. We should migrate before an upgrade forces us to.

Flutter guide: https://docs.flutter.dev/release/breaking-changes/migrate-to-built-in-kotlin/for-app-developers

**Scope**
1. Check that **all plugins** we depend on support built-in Kotlin and AGP 9 (mapbox_maps_flutter, flutter_blue_plus, sentry_flutter, isar_community, flutter_local_notifications, share_plus, etc.). If one doesn't yet, document it and pause the task.
2. In `android/settings.gradle`, raise AGP from `8.11.1` to the current AGP 9.x, and remove `org.jetbrains.kotlin.android` if the guide says to.
3. In `android/app/build.gradle`, remove `id "kotlin-android"` and move the `kotlinOptions` / `jvmTarget` settings to the form AGP 9 expects.
4. In `android/gradle/wrapper/gradle-wrapper.properties`, raise Gradle to the version AGP 9 requires (see the AGP release notes).
5. In `android/gradle.properties`, set `android.builtInKotlin=true` (or remove the flag) and remove `android.newDsl=false`, adjusting the build files to the new DSL if needed.
6. Check our own Kotlin code in `android/app/src/main/kotlin/` still compiles.

**Acceptance criteria**
- [ ] `flutter build apk --debug` and `flutter build apk --release` succeed after `flutter clean`
- [ ] `flutter build appbundle --release` succeeds, and signing still works with the keystore config
- [ ] The CI workflows (`tests.yml`, `build-apk.yml`) are green
- [ ] Smoke test on a real Android device: app start, BLE connection to the senseBox, recording a track, map, upload, notifications, CSV share
- [ ] No more temporary migration flags in `gradle.properties`
- [ ] No AGP/Kotlin deprecation warnings from Flutter during the build

**Notes**
- This is Android only; the iOS app is not affected.
- Expect it to touch only the `android/` folder, with no Dart code changes.
