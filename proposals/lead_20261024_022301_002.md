# Project Proposal — Pdf To Revit

## Project Understanding
You need assistance with: 
**Domain gap: output — export sheets and views to PDF, DWG, IFC and NWC with company file naming and delivery check**

*Project description:*
## Goal

The connector can check a delivery folder against the sheets (`delivery_*`, `company.delivery.check`) but cannot **produce** the delivery: there is no PDF, DWG, IFC or NWC export anywhere (`ExportViewImageTool` is the only native export). Add an export tool family that names files by the company convention so the existing delivery check passes on its own output.

| Tool | Permission | Purpose |
|---|---|---|
| `revit_list_export_setups` | ReadOnly | Named DWG/DXF export setups in the document, IFC exporter availability and version, Navisworks exporter availability, printable sheet count |
| `revit_preview_export` / `revit_export` | ReadOnly / RequiresApproval | Export sheets or views: `pdf`, `dwg`, `dxf`, `ifc`, `nwc`, `image`; one file per sheet or combined; company naming; target folder under policy |
| `revit_export_and_check` | RequiresApproval | `revit_export` followed by `delivery_check_against_revit_sheets` on the target folder, returning both results |

## Why

An unattended "prepare the TP delivery" job (#100) ends with files on the share. Today the agent can only tell the user to print. Revit 2022+ has a native PDF export (`PDFExportOptions`), DWG export is a one-call API with named setups, IFC and NWC depend on installed exporters that can be detected. The delivery check already defines the file name grammar (`DeliveryFileNameParser`: `{projectNumber}_{stage}_{discipline}-{group}-{sequence}_{description}[_{revision}].{ext}`), so the export must emit exactly that.

## Design

### Selection

`sheets[]` (ids or sheet numbers, supports `RevitSheetNumberParser` short and full forms), `views[]`, or `sheetSet` (a `ViewSheetSet` name from `FilteredElementCollector.OfClass(typeof(ViewSheetSet))`), or `filter {discipline, stage, group, nameContains, revisionOnly}` evaluated on the sheet parameters the company skill uses (`Projekti osa`, `Grupi tähis`, `Järjekorra tähis`, see `ListSheetsTool`). Max 500 sheets per call. Sheets without a title block or marked `Appears In Sheet List = No` are skipped with a note unless `includeUnlisted=true`.

### Naming

`naming` = `company` (default) | `sheetNumber` | `revit` | `pattern:<tokens>`. `company` builds `{SheetNumber}_{SheetName sanitized}` where `SheetNumber` is already the company pattern written by `company.lehed.nimetamine` (`1626_TP_EL-5-01`), optionally `_{revision}` from the sheet's current revision (`ViewSheet.GetCurrentRevision` → `Revision.RevisionNumber`, as `r02`), with the file extension; the pure `ExportFileNamer` reuses `DeliveryFileNameParser` to **verify** that the produced name parses back (round trip) and warns when the sheet number does not follow the pattern. Note the known mismatch: the delivery regex accepts only digit groups (`\d{1,3}`) while the naming skill tests use a letter group (`EL-A-001`); fix `DeliveryFileNameParser` and `RevitSheetNumberParser` to accept `[A-Z0-9]{1,3}` in the same PR and add the test case. Sanitizing: `ExportPathService.ResolveFilePath`'s character rule, Estonian letters kept (UTF-8 file names are fine on NTFS), max 120 characters. Collisions within a batch get `_2`, `_3`; existing files are overwritten only with `overwrite=true`, else the file gets a timestamp suffix as `ExportPathService` does and the result flags it.

### Formats

- `pdf`: `PDFExportOptions { Combine = combine (default false → one file per sheet), FileName (combined), PaperFormat = Default (sheet size), ZoomType = Zoom 100 %, HideCropBoundaries, HideScopeBoxes, HideReferencePlane, HideUnreferencedViewTags = true, ColorDepth, RasterQuality, ExportQuality, AlwaysUseRaster = false, ViewLinksInBlue = false, ReplaceHalftoneWithThinLines }`, naming through `SetNamingRule` when one file per sheet (a `TableCellCombinedParameterData` list: Sheet Number, `_`, Sheet Name) **or** export one sheet per call with `FileName` set — choose the latter: it gives the exact company name without fighting the naming-rule API, and 100 sheets × one call is fine. `doc.Export(folder, new List<ElementId>{sheetId}, options)`.
- `dwg` / `dxf`: `DWGExportOptions.GetPredefinedOptions(doc, setupName)` (setup from `revit_list_export_setups`; default the document's current setup, `BaseExportOptions.GetPredefinedSetupNames`), `MergedViews = true`, `SharedCoords?`, `ExportingAreas = false`; `doc.Export(folder, name, viewIds, options)` per sheet, name without extension. Revit appends the view name to the file for multi-view exports; export one sheet per call and rename to the company name afterwards when Revit decorated it (same post-step pattern as `ExportViewImageTool`'s `Directory.GetFiles(baseName+"*")`).
- `ifc`: requires the IFC exporter; detect with `IFCExportOptions` constructor + a test `doc.Export` is too heavy, so check for the add-in assembly (`Autodesk.IFC.Export.UI` loaded, or the `IFCExporterUIOverride` registered) and report `ifc_exporter_missing` otherwise. Options: `ifcVersion` (`IFC2x3CV2` default | `IFC4RV` | `IFC4DTV`), `spaceBoundaries` (0–2), `exportBaseQuantities`, `viewId` for element filtering (`FilterViewId`), `setup` (named `IFCExportConfiguration` is UI-side and not readable; document that only API options apply). `doc.Export(folder, name, new IFCExportOptions{...})`. Whole model, so `views[]` picks the filter view, `sheets[]` is invalid.
- `nwc`: `OptionalFunctionalityUtils.IsNavisworksExporterAvailable()` else `nwc_exporter_missing`; `NavisworksExportOptions { ExportScope = View | Model, ViewId, ExportLinks, Coordinates = Shared|Internal, ConvertElementProperties = true, ExportRoomGeometry }`; `doc.Export(folder, name, options)`.
- `image`: delegate to the existing `ExportViewImageTool` logic, extended to accept the folder and naming (refactor its body into `ImageExportService`).

Folder: `FilePathPolicy.ValidateWrite` (network delivery shares need `AllowNetworkPaths`; the result says so when refused). Export is long-running (a 50-sheet PDF can take minutes): add `revit_export` and `revit_export_and_check` to `LongRunningTools.Names`; the tool checks the cancellation token between sheets, and a cancelled call reports which files were written. Export must run **outside** a transaction (`DocumentToolSupport.CheckNoOpenTransaction`); a sheet that fails (`doc.Export` returns false or throws) is recorded and the loop continues.

Preview: resolves sheets, computes every file name (with round-trip check and collision suffixes), reports which files already exist, exporter availability, estimated count, and the exact options that will be used. The result is also what `revit_export_and_check` feeds into the delivery comparer.

Result per file: `{sheetId, sheetNumber, fileName, path, bytes, status: written | overwritten | renamed | skipped | failed, reason}` plus totals, elapsed, and `deliveryCheck` when requested (the comparer's issue list: missing, orphan, duplicates).

### Status codes

`exporter_missing` (data: `format`, hint), `export_folder_denied`, `nothing_to_export`, `sheet_number_not_company_pattern` (warning only).

## Implementation order

1. Namer, planner, parser fix + tests.
2. `revit_list_export_setups`, availability detection.
3. PDF (per sheet), then DWG/DXF with setups, then image refactor.
4. IFC and NWC behind availability checks.
5. `revit_export_and_check`, skill task, long-running names, summaries, bridge, docs, benchmark.
6. Manual test (2026 and 2024): export 5 EL sheets to PDF and DWG into a test folder, run `delivery_check_against_revit_sheets` → no missing/orphans; re-run without `overwrite` → timestamp suffixes flagged; IFC on a machine without the exporter → `exporter_missing`; NWC with the exporter installed → file opens in Navisworks Freedom; cancel a 50-sheet export mid-way → partial list reported.

## Acceptance criteria

- Files produced with `naming=company` parse with `DeliveryFileNameParser` and the delivery check reports zero issues for the exported set.
- PDF per sheet uses the sheet's paper size and hides crop boundaries and scope boxes; DWG uses the named setup; IFC/NWC fail fast with a clear message when the exporter is absent.
- The policy decides where files may go; network shares are refused with the config key named until allowed.
- Long exports do not time out and can be cancelled with a truthful partial report.
- Unit tests green, both targets build, benchmark report committed.

## Out of scope

Printing to physical printers or non-PDF print drivers; publishing to ACC/BIM 360; DWF/DGN/SAT/FBX; per-sheet PDF naming rules through `SetNamingRule` (replaced by one-sheet-per-call); exporter installation.
