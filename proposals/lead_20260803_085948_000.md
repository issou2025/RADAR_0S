## Bug Report: "Failed to create command instance" error for all commands (Revit 2025, v1.0.0)

### Environment
- Revit version: 2025
- Plugin version: v1.0.0
- OS: Windows

### Summary
After installing the plugin, all commands fail with the error `Failed to create command instance` in the log, even after fully unblocking every DLL/addin file.

### Steps already taken
1. Confirmed all required files are present, including `RevitMCPCommandSet.dll` and the Roslyn dependencies (`Microsoft.CodeAnalysis`, `Microsoft.CodeAnalysis.CSharp`) needed for `send_code_to_revit`.
2. Suspected Windows was blocking the DLLs (since they were extracted from a downloaded zip). Ran the following PowerShell command to unblock every file recursively:
   ```powershell
   Get-ChildItem -Path "$env:AppData\Autodesk\Revit\Addins\2025" -Recurse -Include *.dll,*.addin | Unblock-File
   ```
   Command completed with no errors, confirming all files were successfully unblocked.
3. Restarted Revit completely and re-enabled the Revit MCP Switch.
4. **The error persisted identically** — log timestamp `2026-08-03 09:32:31` still shows `Failed to create command instance` for every command, after the unblock step.

### Suspected root cause
This appears to be a **dependency version mismatch** rather than a file-blocking issue. The plugin ships two separate copies of the same dependency DLLs in different folders:
- `revit_mcp_plugin\` (root)
- `revit_mcp_plugin\Commands\RevitMCPCommandSet\2025\`

Both folders contain their own copies of `RevitMCPSDK.dll` and `Newtonsoft.Json.dll`. If these two copies were built from slightly different versions, .NET may fail to recognize matching interface types across the two assemblies, which would produce exactly this "Failed to create command instance" error when the plugin tries to instantiate a command.

### Relevant log excerpt
```
2026-08-03 09:03:53 [Info] 当前 Revit 版本: 2025 Current Revit version: 2025
2026-08-03 09:03:53 [Info] 已加载配置文件: C:\Users\vahnguyen\AppData\Roaming\Autodesk\Revit\Addins\2025\revit_mcp_plugin\Commands\commandRegistry.json Configuration file loaded: ...
...
[Failed to create command instance] (repeated for all registered commands, including after 09:32:31 post-unblock retest)
```

### Suggested fix
Please verify that `RevitMCPSDK.dll` and `Newtonsoft.Json.dll` are built from the **same version** and are either deduplicated (single shared copy) or explicitly version-pinned across both the root plugin folder and the `Commands\RevitMCPCommandSet\2025` folder in the v1.0.0 release package.
