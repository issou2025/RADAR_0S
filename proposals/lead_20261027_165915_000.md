# Project Proposal — Bim Modeling

## Project Understanding
You need assistance with: 
**New recipe in `am-safe-change`: material color changes with a live panel**

*Project description:*
**Problem**
The user wanted to choose target colors by eye, then write them to Revit. The session did this by hand: it built an HTML panel in chat with RGB inputs, swatch previews, and an "Apply to Revit" button that sends the changed rows back as a prompt. It worked well.

**Proposal**
- Add a recipe "material-colors" to `am-safe-change`:
  1. Read the current Shading and Surface Pattern colors.
  2. Open an interactive panel (color picker plus RGB boxes, preview swatch, reset per row and for all, count of changed rows).
  3. Offer a palette helper: "give me N light greys that stay readable". Compute the contrast of text and of the pattern foreground on each grey. State the WCAG ratio.
  4. On "Apply", run a dry run, show a before/after table, then commit only after the user's yes.
- Keep the panel in the Browser pane or the chat widget. It must not need a server.

**Done when**
The user can tune colors for a material group and apply them in one flow.
