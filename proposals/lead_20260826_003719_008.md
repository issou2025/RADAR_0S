# Project Proposal — Flutter App

**Wayfinder: Chess Habits App**

*Project description:*
## Destination

A cross-platform chess app — **mobile and web, fully offline** — with an **embedded AI opponent** (no online AI) that plays correct chess and is adjustable down to genuine **sub-700 strength**. The plain chess app is built and playable first. The **ChessBrah "Building Habits"** ruleset (GM Aman Hambleton) is layered on afterwards: elo-banded habit rules, drills, in-game coaching, and missed-rule detection, starting at the sub-700 band and building up.

## Decisions so far

- [Research: embedded chess engine for sub-700 offline AI (#2)](https://github.com/jtstothard/chess-habits-app/issues/2): Stockfish WASM cannot go below ~1320 Elo (Skill Level 0 floor). Hybrid recommended: js-chess-engine (MIT) for weak levels (~400–900), Stockfish WASM lite single-threaded (~7MB, GPL-3.0) for stronger levels. Exact sub-700 calibration needs real-world tuning.
- [Research: cross-platform framework for mobile + web offline (#3)](https://github.com/jtstothard/chess-habits-app/issues/3): **Capacitor wrapping a React web app** — single React/TS codebase, offline via bundled assets (no service worker needed), WASM + Web Workers work in WKWebView/Android WebView. RN+Expo blocked by Hermes lacking Web Workers; Flutter = Dart + preview-tier web WASM; Tauri mobile experimental; PWA-only = no App Store presence.
- [Research: chess board UI library (#4)](https://github.com/jtstothard/chess-habits-app/issues/4): **react-chessboard** (MIT, actively maintained Aug 2026, mobile-first, chess.js integration) recommended. @mirasen/chessboard is a strong runner-up (framework-agnostic, active) but small community. chessground is GPL-3.0 + stale React wrapper.

- Gamification/streak model (Duolingo-style streaks/XP was flagged as a design reference)

- Rule licensing/attribution: series is free on YouTube; how we represent the rules (summaries vs. embedded content)
