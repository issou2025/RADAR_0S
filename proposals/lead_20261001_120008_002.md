# Project Proposal — Structural Drawings

## Project Understanding
You need assistance with: 
**BUG: Closed square profiles (hollow sections) displaced in IFC2x3 and corrupt in IFC4 (Revit 2027.3)**

*Project description:*
### BUG Description

When exporting a model containing closed square structural columns (hollow sections) to IFC, the elements suffer severe geometric and coordinate corruption. This seems directly related to the application of Steel Connections (like base plates).

IFC 2x3: The columns are exported but completely displaced from their original coordinates (X/Y offset), appearing as "phantom" elements floating outside the main structure.

IFC 4: The exported file becomes corrupted and cannot even be opened by standard IFC viewers such as BIM Vision.

To Reproduce
Steps to reproduce the behavior:

Open Revit 2027.3.

Place structural columns using a closed square profile family (Hollow Section).

Apply a steel connection (e.g., base plate) to the columns.

Export the model to IFC 2x3. Open in an IFC viewer -> The columns are displaced from the grid.

Export the model to IFC 4. Open in an IFC viewer -> The software fails to open the file due to corruption.

Expected behavior
The closed square columns should maintain their original XYZ coordinates upon export, and IFC4 files should generate a valid, readable schema. (Note: As a workaround, modifying the family to create a longitudinal slit—turning it into an "open" profile—fixes the coordinate displacement, confirming the bug is exclusive to closed hollow topology).

IFC Viewer used: BIM Vision
