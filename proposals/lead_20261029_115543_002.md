# Project Proposal — Structural Drawings

## Project Understanding
You need assistance with: 
**`send_code_to_revit` always fails on Revit 2021 with "The type initializer for 'PerTypeValues`1' threw an exception"**

*Project description:*
## Summary

On Revit 2021, `send_code_to_revit` fails for every input, including the minimal snippet `return document.Title;`. All other commands I tried work normally, so the connection between the MCP server, the plugin, and Revit is fine. The failure seems specific to the dynamic C# compilation/execution path.

## Environment

- Revit 2021 (.NET Framework 4.8) — exact build: [21.0.0.383]
- Revit 2021 First Customer Ship, build 21.0.0.383 (no 2021.1.x updates installed; perpetual license, updates are not available to me)
- Windows: [e.g. Windows 11, version26H2]
- Release used: `mcp-servers-for-revit-v1.0.0-Revit2021.zip`
- MCP client: Claude (Desktop)
- MCP server: `mcp-server-for-revit` npm package, installed globally (`"command": "mcp-server-for-revit"`)
- Other add-ins:
  - `%AppData%\Autodesk\Revit\Addins\2021\`: only `mcp-servers-for-revit.addin` and `revit_mcp_plugin`
  - `C:\ProgramData\Autodesk\Revit\Addins\2021\`: Autodesk add-ins (BatchPrint, Collaborate, eTransmit, Worksharing Monitor, FormIt Converter, GenerativeDesign, ExportViewSelector, nwexport) and Rhino.Inside.Revit

## Steps to reproduce

1. Start Revit 2021 and open a project.
2. Turn on the MCP server from the ribbon.
3. From the MCP client, call `send_code_to_revit` with:
   ```csharp
   return document.Title;
   ```

## Actual result

```
Code execution successful!
Result: {
  "success": false,
  "result": null,
  "errorMessage": "执行失败: 'PerTypeValues`1' のタイプ初期化子が例外をスローしました。"
}
```

(The Japanese part means: "The type initializer for 'PerTypeValues`1' threw an exception.")

Other snippets fail with the same error, e.g. one that creates a `Transaction` and calls `ElementTransformUtils.MoveElement`, and one that uses `List<ElementId>`. So it does not look like it depends on the code content.

## Expected result

The code runs and returns the document title.

## What works (same session)

`say_hello`, `get_current_view_info`, `get_current_view_elements`, `get_available_family_types`, `get_selected_elements`, `analyze_model_statistics`, `export_room_data`, `get_material_quantities`, `ai_element_filter`, `create_line_based_element`, `create_surface_based_element`, `create_point_based_element`, `create_room`, `create_grid`, `create_level`, `create_structural_framing_system`, `create_dimensions`, `tag_all_walls`, `tag_all_rooms`, `color_elements`, `operate_element`.

## What I tried

- Restarted Revit and re-enabled the MCP server several times.
- Moved `RhinoInside.Revit.addin` out of the ProgramData add-in folder and restarted Revit: same error.
- Checked the files in `revit_mcp_plugin\Commands\RevitMCPCommandSet\2021\`. All 16 DLLs are present:
  `JetBrains.Annotations`, `Microsoft.CodeAnalysis.CSharp`, `Microsoft.CodeAnalysis`, `Newtonsoft.Json`, `Nice3point.Revit.Extensions`, `Nice3point.Revit.Toolkit`, `RevitMCPCommandSet`, `RevitMCPSDK`, `System.Buffers`, `System.Collections.Immutable`, `System.Memory`, `System.Numerics.Vectors`, `System.Reflection.Metadata`, `System.Runtime.CompilerServices.Unsafe`, `System.Text.Encoding.CodePages`, `System.Threading.Tasks.Extensions`.

## Suspicion (not confirmed)

The Roslyn compilation path needs several System.* assemblies (`System.Collections.Immutable`, `System.Memory`, `System.Reflection.Metadata`, `System.Runtime.CompilerServices.Unsafe`, etc.). A version conflict with assemblies that Revit 2021 or another component has already loaded could make a type initializer fail. I could not verify this.

2. Is there a log or setting that would show the inner exception of the type initializer error? (I searched the latest Revit journal for "PerTypeValues" and found nothing.)
