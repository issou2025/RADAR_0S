*Project description:*
## Idea

Open the model that was just changed in Revit as a 3D page in the browser on localhost,
without saving the file and without a cloud service. A click on an object in the page
selects the same element in Revit, and query results can be highlighted in 3D.

Possible uses:
- show a result to someone who has no Revit;
- link 3D views from the issue register next to the PNG snapshots;
- compare the model before and after a batch action.

This issue is for deciding whether the feature is worth building. Nothing is planned yet.

## Rough shape

1. A new tool such as `revit_export_gltf`: the add-in walks the model with
   `CustomExporter` and `IExportContext` and writes a GLB, with the ElementId,
   category and level stored in each node's extras.
2. The file reaches the MCP client the same way `revit_export_view` delivers PNG files,
   so it also works when Revit runs on another machine.
3. A static page served on localhost renders the GLB with three.js or xeokit.
4. Clicking an object returns its ElementId, and `revit_show` or `revit_select` takes it from there.

## Why not APS Viewer

APS Viewer v8 (preview since October 2026) only displays models translated by
Model Derivative. That means uploading the model to Autodesk's cloud, paying for
translation above the free monthly limit, and setting up an APS app for every user.
It also sees only the saved file. That conflicts with the local-first design of this
project. A separate, optional "publish to APS" tool could be considered later.

## Open questions

- Is there real demand, or are PNG snapshots enough?
- How much of the model to export: active view, visible elements, or the whole model?
- Materials and textures: flat colours first, or full appearance?
- Linked models: skip, or export them as separate files?
- Should the viewer page live in this repo or in a separate package?
- How big does the GLB get on a large model, and does that need streaming?

## Acceptance (if we build it)

A wall and room model changed through MCP opens in the browser without saving,
and a click on a wall selects it in Revit.
