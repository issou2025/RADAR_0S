*Project description:*
Hello, I'm Diego. 
CreaBim developer was interested in my humble opinion about this and I thought it would be worth to share here too. I hope it helps something!
I will explain my work's demands and workflows after, so you can understand my user profile. Sorry for the big text.

### **ArchiCAD Pros**

1. Solid Elements Operations. This is a really powerful tool, super versatile and I use a lot, especially the "subtraction with upward extrusion" and "subtraction with downward extrusion". The extrusion modes are incredible and a use it 90% of the time.
2. Marquee Tool and (stretch). Another amazing powerful and versatile tool. You can use like Autocad stretch to modify many element types at once, to select elements inside the area, to box cut the 3D view and probably more. May be worth to see Archicad's documentation to learn more about it.
3. Fluid 3D modeling. I enjoy designing in 3D a lot,
4. The tools are versatile. You can make ramps with stair tool or roof tool
5. Same co-planar materials are joined in 3D too, which is nice for lower LODs when I create slabs faces co-planar to walls, its nice for elevations or 3d view to not show lines separating.
6. Trace and Reference for almost all things and more options, like move, rotate, colour, alpha, swap the reference as active view.
7. Find tool, good for a more deep search, has two buttons to quickly copy the element type it is selected and its parameters like every door with 90 cm width.
8. Quick trim using Ctrl + click. This is nice, can trim many elements like walls, lines, beams very quick and easily.
9. Good default library of objects and customization.
10. If an element is selected, manage tools like hatches, materials, surfaces, profiles will preselected and show it first
11. Attributes manager has nice things, like open another project file or template, to quickly compare and transfer all attributes (hatches, lines, surfaces, materials, profiles etc).
12. When you select multiple objects that shares parameters and change just one parameter, the other objects will change only that one.

### **Revit Pros**

1. Graphics overrides and hide from view.
2. Big third party objects "families", specially from manufactures. 
3. The families are easier to create from scratch, I created my last template from a completely empty file.
4. Bit better terrain modeling than archicad. I really want a better worflow for this. 
5. When moving a wall it also updates the room boundaries and its area. In archicad you need to click update zones or manually edit then. In archicad, however, you can use the marquee tool to stretch both wall and zones.
6. DWGs or similars imported can be seen in 3D, a minor thing, but useful when building the model from someones dwg plan.
7. 2D Views seems to be more connected from the 3D, specially for site plans, reflected ceiling plans. A mat put under a table will showup as behind the table. 
8. Dynamo.

### **Archicad Cons**

1. Layer System, it is the old "CAD" way of doing, I really hate it. It's time consuming, have to manage lots of layers combinations, and is really frustrating to create another layer and layer combination to only hide one object from the view.
2. 3D model feels disconnected from 2D views sometimes. For example: reflected ceiling plans seems to be just a normal plan view but hiding (filling) the doors and windows voids; site views same thing, each element (walls, slabs, pillars, beams, etc) need configure it's settings to be visible or not for each level. This with the layer system turns to a mess really quickly and super tedious to set up. Many other problems are caused by this, for example, the constantly need of "send to back" or "bring to front" menu to change the view order and terrain not being cut in plan.
3. Creating new custom objects is almost impossible to the common folk, old GDL language. This makes manufacturer companies avoid creating objects for their products resulting huge deficit in the availability of objects.
4. Pen linework configurations, another old CAD way of doing. I don't like it, it uses the same pen table to handle both colour and lineweight, which brings some problems.
5. The spreadsheets are a bit limited, would be nice to perform some excel operations that interact with parameters from de model. (I see you already did this for Lapim)
6. Depth representation is really annoying to do. Need create a new custom propriety, mark to use with the elements, create a graphic override and configure one by one element to be thick/medium/light/gray linework. It has a feature to do that by dividing the sections and elevations draw distance in two, anything pass the middle range will change the graphics, but its not great when it suddenly changes to a different graphics, like on the middle of a roof. (CreaBIM does this in a interesting way)
7. Tags in Archicad for doors, windows etc. not a fan. I prefer Revit way.
8. Hidden elements are confusing to set up, like walls behind a slab or roofs.
9. The section and elevation tag are annoying because it is not possible to adjust the symbol different positions for different views and plans. In revit is possible.
10. Terrain modeling is really bad and doesn't update or generate terrain contours lines. Revit is a bit better, but another new workflow would be really cool. The solid elements operations makes it less worse, like performing boolean operations with upward extrusion from a slab, for example. (Edit: I like how you are doing with site and terrain modeling)
11. Can't rotate objects on the X and Y axis, only on Z. This one always amazes me.

### **Revit Cons**

1. Very "stiff" modeling, too many constraints automatically. Really not enjoyable in design phase, especially in 3D. Some elements after you move them will also move other things you don't want, it is frustrating sometimes. I'm not sure what would be a good balance. Walls interconnected 
2. I don't like the "edit sketch" workflow, it contributes to the "stiffness" feeling. In Archicad you don't need to check and fix the sketch contour all the time to be closed to accept the changes. I think it's secret is all modifications you can do to the contour are "area shape based" boolean, you only modify edges and vertices. When it would break like creating two "islands", it will just divide the element in two separates parts. 
3. Underlay is very limited.
4. I don't enjoy the families types system for design phase, it breaks the "flow". For example, when you are in 3D testing some doors or windows, you need go edit type, duplicate the type, change its dimensions, save, you don't like, repeat... I think your way with Lapin is better, a good mix of both, I like it!

### **Blender**

1. In Blender, I heavily use "Shift + ~" shortcut on blender to enter "gamemode". WASD fly easily through the model, Q and E goes up and down and pressing TAB enables gravity, exactly like a fps game. I even bound the same shortcut on Archicad and I can't go without it anymore. Very fast way and fun way to navigate.
2. Modular interface is really nice.
3. Geometric Nodes. This is more advanced, but can do really nice things.
4. Tab goes Edit mode. This gives me an idea it could be a nice way of mixing Revit and Archicad. Maybe pressing Tab activates the element contour (a slab or a roof for example) and a context floating toolbar like Archicad shows. (picture)

### **Some Thoughts**

- I think a good and easy method for creating new custom objects or families probably will be a decisive factor for people choosing a software.
- Project time tracking. A simple add-on or built-in time tracking feature would be nice. I made a simple one last year with AI, that tracks: 1) How much time an  window was active in foreground (focus time), 2) How much time the window was opened but not active in foreground (work time), 3) Idle time (window opened but no mouse or keyboard input in 5 minutes.
- I like when most of keyboard shortcuts can be done with the left hand, so my right hand never leaves the mouse. This is very try hard. I see your keyboard preferences menu seems to allow such customization.
- Archicad and Revit are the result of decades of development. While, on the one hand, they have been refining their products, on the other, they remain tethered to outdated paradigms and old code. So it is a good chance for new upcoming software to bring improvements.

### **My user profile.**
**Note:** Probably I had more to say about Archicad because it is what I'm using more for the last 6 years, but I remember the pros and cons being 50/50%, between the two. 

**Work:**
I work in a small architecture studio, three persons here in Brazil. Our workflow is the most common one here, a person who develops the project's concept in Autocad and build the 3D model and rendering in other software, most commonly Sketchup, rendering with Vray or Lumion. In our case, the plan is designed by one person in Autocad, but I bring it to Archicad to develop more the design in 3D and create documentation in general (drawings, quantities, details, etc). I also take advantage of the 3D model from Archicad to bring it in Blender for photorealistic renderings. 
We are far from using all the BIM's capabilities, LOD 200 to 300 I guess. I have the impression that a good workflow, with better tools and greater ease of use, is what's missing for greater adoption of those software in most offices here, specially in design phase.

**Me**
I enjoy learning new software and improve my workflow. I'm a open source enthusiast.
A started using Revit in 2012 at architecture school until around 2020. 
I start using ArchiCAD after that, mostly because how nice it is to model and design with it.
My dream software is a evolution of them, mixing the best qualities with new paradigms. Something fun, quick and easy to model and document.
