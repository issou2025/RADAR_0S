# Project Proposal — Flutter App

## Project Understanding
You need assistance with: 
**MIDI prototype: program change to a Nord Stage 3 on all platforms (ADR-0039)**

*Project description:*
## Goal

First implementation step of ADR-0039: a prototype that proves setDING can switch a **Nord Stage 3** by MIDI over USB on every target platform, before the feature itself is built.

## Scope

- Add `flutter_midi_command` (newest version, BSD-3-Clause, licence notice shipped) behind a small `MidiOutput` interface (list devices, connect, send bytes, connection state) with a fake for tests.
- A minimal developer screen (or debug-only entry) that lists the USB MIDI devices, connects to one, and sends on a chosen channel: bank select MSB (CC 0), bank select LSB (CC 32), program change, via `sendData` / `sendDataAwaitingDelivery`.
- Try it with a real Nord Stage 3 on:
  - [ ] Android (USB host, USB-C/OTG)
  - [ ] Windows
  - [ ] Linux
  - [ ] Chrome (Web MIDI, `app.setding.app` or `make web`)
- On the Nord, test:
  - [ ] Programs: CC 0 = 0, CC 32 = 0–7 (bank A–H), PC 0–49
  - [ ] Live memories: PC 50–54
  - [ ] Nord songs: addressing with CC 0 = 1 (forum report, no official chart), find out what actually selects a song and a song part
  - [ ] Result independent of the Nord's current panel mode when the full bank select is sent

## Results to record (in this issue and in ADR-0039's decision log)

- Nord Stage 3 OS version used
- Per platform: works / does not work, and any permission or setup needed (e.g. Android USB host feature, browser prompt)
- The working addressing for Nord songs, or the decision to leave the Songs mode out (ADR-0039)
- If the library fails on a platform: which alternative from ADR-0039 is chosen

## Acceptance criteria

- Results recorded as above; ADR-0039 and the architecture README updated.
- The prototype code is either kept as the base for the feature (with tests for `MidiOutput` and the message bytes) or removed; no hard-coded UI texts (ARB files in de and en if any UI stays).

## Needs

A real Nord Stage 3 and the owner's Android/Windows devices: the hardware tests are done by the owner or with them.
