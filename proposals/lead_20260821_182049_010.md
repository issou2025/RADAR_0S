# Project Proposal — Flutter App

## Project Understanding
You need assistance with: 
**flutter doctor reports Android license status unknown with Android SDK Command-line Tools 23.0**

*Project description:*
### Steps to reproduce

1. Install Android SDK Command-line Tools version 23.0.
2. Verify the installed command-line tools version:
cat /Users/<username>/Library/Android/sdk/cmdline-tools/latest/source.properties

**Output**:
```
Pkg.Revision=23.0
Pkg.Path=cmdline-tools;23.0
Pkg.Desc=Android SDK Command-line Tools
```
3. Run:
```flutter doctor -v```
4. Observe:
```
[!] Android toolchain - develop for Android devices
     ✗ Android license status unknown.
```
5. Run `flutter doctor --android-licenses` to accept the SDK licenses.
6. Run the command suggested by Flutter:
```flutter doctor --android-licenses```
7. Observe that no licenses are displayed for acceptance. Instead, the following output is shown:
```WARNING: The SDK Manager CLI tool (sdkmanager) is deprecated. Android CLI will be used instead.

The 'android' binary can also be found in the cmdline-tools directory, and 'android sdk' is the replacement for 'sdkmanager'.

To learn more about the Android CLI and how to use it, see the documentation:
https://d.android.com/tools/agents/android-cli

Warning: The --licenses option is no longer needed.
```

8.The same behavior occurs when directly running:

/Users/<username>/Library/Android/sdk/cmdline-tools/latest/bin/sdkmanager --licenses

### Expected results

flutter doctor should correctly determine the Android SDK license status and report:

✓ All Android licenses accepted.

Alternatively, if Android SDK Command-line Tools 23.0 has changed the license workflow and --licenses is no longer required, Flutter should support the new Android CLI behavior instead of reporting the license status as unknown.

flutter doctor --android-licenses should also not direct users into a workflow that the installed Android SDK tools no longer support.

### Actual results

flutter doctor -v reports:
✗ Android license status unknown.
Running the recommended command:

```flutter doctor --android-licenses```
does not provide an option to accept licenses and instead returns:
```
The SDK Manager CLI tool (sdkmanager) is deprecated. Android CLI will be used instead.
Warning: The --licenses option is no longer needed.
```
