The copilot service timeout configuration bundle that manages execution time limits for LLM integrations including OpenRouter and visiting language models, extending the current 10-minute maximum to 60-90 minutes for all copilot operations.

### Definition of Done

The copilot timeout configuration is updated to 60 minutes (or 90 minutes if determined necessary) for all LLM providers including visiting LLMs and OpenRouter. The job execution no longer fails with the "maximum execution time of 10m0s" error. All copilot sessions can run for the full extended duration without timeout interruptions, and the configuration change is deployed to production successfully.

This timeout constraint is artificially limiting the system's capability to handle legitimate long-running AI tasks that users expect to complete successfully. Without addressing the underlying timeout architecture and monitoring systems, simply increasing the limit could mask other performance issues or create resource contention problems.
