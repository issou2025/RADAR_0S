# Project Proposal — Bim Modeling

## Project Understanding
You need assistance with: 
**Core/Expressions/Property View: Improving expression handling via the right-click context menu.**

*Project description:*
### Problem description

We often need to reset, modify, or disable expressions. Until recently, the only way to do this was to open the expression menu (and then click "Reset").

Recently, the ability to disable an expression with a double-click—and immediately enter new data (non-expression data)—was introduced. This is convenient.
However, there is another scenario that needs addressing: "applying" the current data. Essentially, this refers to the "Reset" button inside the Expression Editor. Currently, accessing this function still requires opening the editor.

Overall, there are three ways to interact with the expression input field:
1) Create/Modify (the current "=" or "fx" option)
2) Replace the expression with new static data (Double-click)
3) "Apply" the expression (convert it to static data while retaining the calculated result).

The third option is currently completely unavailable outside the Expression Editor.  Implementing it would make the Property View input fields much more user-friendly when working with expressions.
