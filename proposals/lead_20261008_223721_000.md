# Project Proposal — Bim Modeling

## Project Understanding
You need assistance with: 
**Void extrusions that cut a solid: the back box as one solid with an open front, and round mounting holes**

*Project description:*
## Why
We never write a void. `geometry.new_extrusion` always sets `m_cutting = False`.

The owner's reference panelboard (steer #1046) is built from:
- one box solid;
- a void that hollows it into an open-front can with wall thickness `t`;
- a second void of four circles: the mounting holes, labelled by radial dimensions.

Revit records the cut as a `FamilyGeomCombination`. Its `AddGeomToCombinationGStep` per member carries face / edge history tables, and the connectors are hosted on that combination's faces.

Building the can from five plates looks the same, but it is not built the same way. A user who edits the family sees plates where the library has a solid and a void.

1. **Format law, from a private census of the reference library (counts only):**

   - which elements reference the combination (connectors, labels).
2. **Writing it.** `geometry` writes a void extrusion and the combination for a box minus a box and minus N cylinders.
   - The combined B-rep is our own (`solid_box_brep` lineage).
   - The 0x0f3f / cap / lock laws hold.
3. **Using it.** #1047's can uses it, behind a flag until a desktop verdict (hard rule 4). Plates remain the default until then.
4. **Tests and record.** Validator 0 errors; tests; a record. A viewer / desktop batch is STAGED only, never uploaded by a session.
