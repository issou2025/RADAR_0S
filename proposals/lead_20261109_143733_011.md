# Project Proposal — Flutter App

## Project Understanding
You need assistance with: 
**[camera_avfoundation] Front camera preview rotated 90° and stretched on iPhone 17 Pro Max since 0.11.0+2**

*Project description:*
### Steps to reproduce

1. Create a new app with `camera: 0.12.2` (resolves `camera_avfoundation: 0.11.1`), add `NSCameraUsageDescription` to Info.plist and use the code sample below.
2. Run it on an iPhone 17 Pro Max (iOS 27) and hold the phone upright.
3. Look at the front camera preview.
4. Change `CameraLensDirection.front` to `.back` and run again, or run on an older iPhone.
5. Add `camera_avfoundation: 0.11.0+1` under `dependency_overrides` and run again on the iPhone 17 Pro Max.

### Expected results

The front camera preview is upright and keeps its aspect ratio while the phone is held in portrait, like the back camera, like on older iPhones, and like with camera_avfoundation 0.11.0+1.

### Actual results

On iPhone 17 Pro Max the front camera preview is rotated by 90° and stretched while the phone is held in portrait. The back camera on the same device is fine, older iPhones are fine, and pinning `camera_avfoundation` to `0.11.0+1` fixes it.

This started with 0.11.0+2 (flutter/packages#13247), which replaced the deprecated `videoOrientation` with `videoRotationAngle` on iOS 17+. `DefaultCamera.videoRotationAngle(forDeviceOrientation:)` maps portrait to 90°, landscapeLeft to 0°, landscapeRight to 180° and portraitUpsideDown to 270°. These fixed angles assume the sensor is mounted like on earlier iPhones. The iPhone 17 Pro / Pro Max front camera sensor is mounted differently: on that camera `AVCaptureDevice.RotationCoordinator.videoRotationAngleForHorizonLevelCapture` returns 0° in portrait instead of 90°, and an Apple engineer confirmed this is expected (https://developer.apple.com/forums/thread/813548). Setting 90° therefore rotates the frames by an extra 90°. The deprecated `videoOrientation` lets AVFoundation pick the right angle for the device, which is why 0.11.0+1 works.

`updateOrientation` applies the same angle to `captureVideoOutput` (preview texture and recordings) and `capturePhotoOutput`, so recordings and photos are likely affected as well; we observed it in the preview.

Possible fix: add the connection's default `videoRotationAngle` (read before the plugin first changes it) to the current mapping, i.e. `(defaultAngle + mappedAngle) % 360`, or use `AVCaptureDevice.RotationCoordinator` as suggested in #170438. Other models with the new Center Stage front camera (iPhone 17, iPhone Air) are probably affected too.

### Code sample

<details open><summary>Code sample</summary>

```dart
import 'package:camera/camera.dart';
import 'package:flutter/material.dart';
import 'package:flutter/services.dart';

Future<void> main() async {
  WidgetsFlutterBinding.ensureInitialized();
  await SystemChrome.setPreferredOrientations([DeviceOrientation.portraitUp]);
  final List<CameraDescription> cameras = await availableCameras();
  final CameraDescription front = cameras.firstWhere(
    (CameraDescription camera) =>
        camera.lensDirection == CameraLensDirection.front,
  );
  runApp(MaterialApp(home: CameraPage(camera: front)));
}

class CameraPage extends StatefulWidget {
  const CameraPage({super.key, required this.camera});

  final CameraDescription camera;

  @override
  State<CameraPage> createState() => _CameraPageState();
}

class _CameraPageState extends State<CameraPage> {
  late final CameraController _controller = CameraController(
    widget.camera,
    ResolutionPreset.high,
    enableAudio: false,
  );

  @override
  void initState() {
    super.initState();
    _controller.initialize().then((_) {
      if (mounted) setState(() {});
    });
  }

  @override
  void dispose() {
    _controller.dispose();
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      backgroundColor: Colors.black,
      body: Center(
        child: _controller.value.isInitialized
            ? CameraPreview(_controller)
            : const CircularProgressIndicator(),
      ),
    );
  }
}
```
