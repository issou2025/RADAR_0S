=== TITLE ===
Aligned/Linear dimension cannot reference structural columns – only grid lines can be picked

=== DESCRIPTION ===
**Summary**
In a floor plan, the dimension tools (Annotate tab -> Dimension panel -> Aligned / Linear) only pick up grid lines.
Structural columns cannot be used as dimension references (neither their faces nor their centre lines),
so it is not possible to dimension the distance between two columns.

**Steps to reproduce**
1. Create grids and place structural columns on the grid intersections (e.g. K1, K2, K3, rectangular 25/70 cm).
2. Open the floor plan view "Кота 0.00" (scale 1:50, detail level Fine).
3. Annotate tab -> Dimension -> Aligned (also tried Linear).
4. Hover over / click a column face or the column centre.

**Expected**
The column face (and the column centre line) highlights as a reference, the same way grids do,
so a dimension can be placed between two columns (face-to-face, centre-to-centre or face-to-grid),
like Revit's Aligned Dimension.

**Actual**
Only the grid lines are picked. The column is ignored; the cursor jumps to the grid that passes through it.
Dimensions 500 / 500 / 405 in the screenshot were placed between grids only.
The red arrow in the screenshot marks the dimension I need: between column K2 and column K3.

**Notes**
- The README lists wall faces, centre lines, grids and door/window jambs as dimension references,
  and columns as snap points – but columns do not seem to work as dimension references.
- Could Tab cycling between references (face / centre) also be supported, as in Revit?
