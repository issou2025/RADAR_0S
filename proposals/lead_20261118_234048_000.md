# Project Proposal — Bim Modeling

## Project Understanding
You need assistance with: 
**Onboarding: no place to record where the office template lives, so the agent scanned a network drive for 8 minutes**

*Project description:*
**Sessions read:** 1 local Claude Code session on 2026-11-18 (Windows 11, Revit 2026).

## Context

A markup said that a typical accessibility sheet should come from the office Revit template. The user asked what the template is, then said they could not find it. No am-* skill covers finding office standard files. The agent used the pyRevit `revit-files` skill. That skill points only to `app.DefaultProjectTemplate`, `app.FamilyTemplatePath` and the Autodesk default `.rte` folder.

## What happened

- The Revit settings on that computer listed only the Autodesk default templates.
- A Grep over the working folder for `.rte` hit its time limit after about 20 s.
- The agent then listed the mapped drives and scanned an archive drive: one scan of about 20 s, one of about 3 min, and one of about 4 min that the agent stopped.
- The office template was not an `.rte` file. It is a Revit model (`.rvt`). On the archive drive the agent found only a personal detached backup copy, about a year old. The agent guessed that the live master is in the cloud document platform. It did not check this.
- cost: about 8.5 minutes of waiting for the user, and the result was an old personal copy, not the master. Reading that copy then needed a large file copy, a sync of the open model first, and an upgrade on open (see #276).

## Proposed change

- Add a short hint for "the office template" requests, in `am-welcome` or a shared hints file: office templates are often `.rvt` models in a document platform or a standards folder, not `.rte` files in the Revit template folder. Ask the user (or the BIM lead) where it lives before a broad search.
- Optional: a local, never-committed file such as `%LOCALAPPDATA%\archi-magic\office-paths.json` with the project template, detail library and standards folder. It is filled once from the user's answer, and skills read it first.
- House rules: a recursive search on a network drive needs a depth limit and a time limit, and a short note to the user before it starts.

## Acceptance ideas

- "Where is our template?" leads to one question to the user, or a read of the local paths file, before any network scan.
- No file search runs longer than about a minute without the user knowing.

## Not verified

- Where the live master template is kept.
- Whether the same search happens in other sessions. This was seen once.
