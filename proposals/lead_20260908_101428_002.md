# Project Proposal — Bim Modeling

## Project Understanding
You need assistance with: 
**BIM: Walls made up of multiple collinear segments create null shapes depending on width**

*Project description:*
### Problem description

When you spawn a BIM wall from a draft line that is composed of multiple collinear segments, the wall has a chance of creating a null shape depending on what width you set it to. You can test it yourself in the attached file. If you set "ErrorWall" width to 4.75 in, it creates a null shape, but almost every other width I tested worked.

### Workbench affected?

BIM

### Steps to reproduce

[BrokenWall.zip](https://github.com/user-attachments/files/31918710/BrokenWall.zip)

Change ErrorWall's width to 4.75" and you'll get a message that it's an invalid null shape. Almost every other width I tested worked fine.

### Expected behavior

Changing the wall width should not generate a null shape error.

### Actual behavior

When I change ErrorWall's width to 4.75", I get a message that it's an invalid null shape.
