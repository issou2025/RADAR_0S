# Project Proposal — Bim Modeling

## Project Understanding
You need assistance with: 
**Contextual tab with Finish and Cancel, and an options bar**

*Project description:*
As a Revit user, I want a contextual tab with Finish and Cancel, and an options bar with the tool's values, so that I can place and finish elements by clicking instead of typing on the command line.

Found while testing wave 4: there was no visible way to finish a slab (only typing the first point again), and no way to set a slab's offset or a column's height while placing.

### Acceptance criteria
- [ ] While a placement tool runs, a contextual *Modify | Place …* tab (*Modify | Create Floor Boundary* for slab sketches) shows ✓ Finish and ✗ Cancel. Enter finishes and Esc cancels.
- [ ] Sketch tools (slab, vertical opening) finish with Finish. They no longer need the first point typed again, though that keeps working.
- [ ] An options bar under the ribbon shows the running tool's key values, edited by clicking: slab offset from level; column top level or height; wall height or top level, and location line; beam offset.
- [ ] The command line keeps working as an extra way in, but no tool needs it.
- [ ] Window tests cover Finish, Cancel and editing an option.

Not in this story: the Properties panel (#26), and showing the element being placed in it.
