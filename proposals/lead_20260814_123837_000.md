# Project Proposal — Bim Modeling

## Project Understanding
You need assistance with: 
**MCP: no way to cancel an in-flight call, though the CancellationToken is already threaded end to end**

*Project description:*
Part of #107. On the official MCP best-practice list next to progress: *"Allow clients to cancel
in-flight requests that are no longer needed or taking too long."*

## The plumbing is already there

- `CommandRequest.CancellationToken` is on the envelope — `Core/Common/Dispatch/CommandQueue.cs:18`
- `CommandQueue.ExecuteAsync` passes it into `DispatchAsync` — `CommandQueue.cs:116`
- `IRevitTask.ExecuteAsync(IRevitContext ctx, CancellationToken ct)` — every command already receives it
- `McpWire.Codes.Cancelled` already exists and is already documented as "the call was cancelled — by
  the caller or by shutdown"

So the token reaches every command, and the error code for the outcome is already minted. What has
no path is the *request* to cancel: `McpWire` has two verbs, `invoke` and `list`
(`McpWire.cs:40-41`), and neither of them is "stop the call with this id".

## What to do

- [ ] A `cancel` request type on the wire, carrying the `id` of the call to stop
- [ ] The bridge holding the `CancellationTokenSource` per in-flight id and cancelling it
- [ ] `AnalyseTool.Mcp` wiring MCP's cancellation to it (the SDK owns the client-facing side)
- [ ] Confirm the result comes back as `Codes.Cancelled`, not `Codes.CommandFailed` — the distinction
      already exists in the code and should survive the round trip

## Why it is worth doing early

Today the only way out of a call into a stuck Revit is the 10-minute `InvokeAsync` timeout added in
#88 — deliberately generous, because a timeout that fires on legitimate work is worse than none.
That trade only exists because there is no cancel. With one, the timeout stops being the sole escape
hatch, and the agent gets a way to abandon work it no longer wants without waiting out the bound.

Pairs naturally with the progress work: same correlation by `id`, same in-flight bookkeeping.
