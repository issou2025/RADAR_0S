# Project Proposal — Bim Modeling

## Project Understanding
You need assistance with: 
**Agent runtime: edits to pyrevit/agent/_runner.py need a Revit restart**

*Project description:*
pyrevitlib is meant to be live: an edit takes effect without restarting Revit. `pyrevit/agent/_runner.py` is an exception. Both agent engines keep the imported runner between runs, so an edit to it is ignored until Revit restarts.

- CPython keeps it in the interpreter for the whole session.
- IronPython reuses the cached agent engine (`clean: false`), which keeps it too.
- Popping `sys.modules["pyrevit.agent._runner"]` is not enough: the entry script's `from pyrevit.agent import _runner` reads the attribute cached on the `pyrevit.agent` package.

Found while benchmarking #3910: the old and new runners were silently the same code until the cache was purged on both engines.

Idea: have the entry script reload the runner when its file's modification time changes, or at least document the purge in `docs/agent-runtime.md`.
