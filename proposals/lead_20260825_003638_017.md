## Summary

<!-- A clear and concise description of the feature you'd like to see. -->
Need a resource module to configure BGP per routing-instance. We are looking for a module similar to `junos_bgp_global` - which configures BGP under `protocols bgp`, but in this case we need that support extended to configure BGP per routing-instance under `routing-instance protocols bgp` heirarchy.

The requested module would allow user to configure BGP under each routing-instances as shown but not limited to below Junos statements.
```shell
set routing-instances GI routing-options autonomous-system 65101
set routing-instances GI protocols bgp group TEST type external
set routing-instances GI protocols bgp group TEST neighbor 1.1.1.1 peer-as 65102
set routing-instances GI protocols bgp hold-time 9

# Corresponding XML rpc-reply
<configuration junos:changed-seconds="" junos:changed-localtime="">
            <routing-instances>
                <instance>
                    <name>GI</name>
                    <routing-options>
                        <autonomous-system>
                            <as-number>65101</as-number>
                        </autonomous-system>
                    </routing-options>
                    <protocols>
                        <bgp>
                            <group>
                                <name>TEST</name>
                                <type>external</type>
                                <neighbor>
                                    <name>1.1.1.1</name>
                                    <peer-as>65102</peer-as>
                                </neighbor>
                            </group>
                            <hold-time>9</hold-time>
                        </bgp>
                    </protocols>
                </instance>
            </routing-instances>
    </configuration>
```

## Motivation

<!-- Describe the problem or use case this feature would solve.
     Why is this important? Who else might benefit? -->

Users provisioning BGP using resource module, might need to configure BGP per routing-instance/VRF. Its a common use-case in a Data-center VXLAN setup.

## Proposed Playbook / Task Usage

<!-- Show how you would expect to use the new feature in a playbook.
     This helps clarify the desired interface. -->

```yaml
---
- name: Example using the proposed feature
  hosts: dut
  gather_facts: no
  collections:
    - juniper.device        # or junipernetworks.junos

  vars:
    config:
      vrf_name: GI                           ## new parameter - Routing-instance name
      as_number: 65100                 ## VRF ASN
      groups:
        - name: ANSIBLE_TEST
           neighbors:
             - neighbor_address: 1.1.1.1
                peer-as: 65102
    state: merged

  tasks:
    - name: Invoke BGP resource module
       juniper.device.junos_bgp_vrf:                 ## new module
         config: "{{ config }}"
         state: "{{ state }}"
       register: result

    - name: Debug output
      ansible.builtin.debug:
        var: result
```
