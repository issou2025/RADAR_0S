The backend supports Gemini for both RSS summarization and analyzer, but these are **separate flags**: `NEWS_SUMMARIZATION_ENABLED` and `NEWS_ANALYSIS_PROVIDER=GEMINI` with the existing `GEMINI_API_KEY`; `NEWS_ANALYSIS_PROVIDER` defaults to NONE. `NEWS_INGESTION_ENABLED`, `NEWS_ANALYZER_BRIDGE_ENABLED`, `NEWS_ANALYSIS_SCHEDULER_ENABLED` and `NEWS_MIND_CONTEXT_ENABLED` all default to false. A key in SSM alone is NOT evidence that news analysis is on. Inspect only existence/key mapping and sanitized runtime status; never print secret values.
5. Source discovery currently has only Moneycontrol and Economic Times selected by default (SEBI supported). These are feeds, not proof of licensed use or real successful ingestion. Source approval must remain fail-closed.
