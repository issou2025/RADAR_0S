# Project Proposal — Bim Modeling

## Project Understanding
You need assistance with: 
**install.ps1: say what it is downloading (126 MB) instead of sitting silent after "checking for the latest release"**

*Project description:*
On a clean install of v0.1.5 the one-liner showed `Installing Revit MCP Bridge -- checking for the latest release...` and nothing else for several minutes. It was not stuck: `$ProgressPreference = 'SilentlyContinue'` (needed, PS 5.1's progress bar throttles downloads) plus a single `Invoke-WebRequest ... -OutFile` of the 126 MB `mcpbridge-release.zip` on a slow GitHub CDN night. The user reasonably read it as a hang.

Proposed: after the release lookup, print one line before the download, e.g. `Downloading Revit MCP Bridge v0.1.5 (126 MB) from GitHub...`, and one after (`downloaded in 4m12s, verifying checksum`). Optionally, for interactive runs, use `System.Net.Http.HttpClient` with a stream copy and print a percentage every 10 % — cheap, and unlike `Write-Progress` it does not slow the transfer.
