## 6. 趋势信号

1. **MCP 作为一级集成层** — 每个工具都在大力投入 MCP 服务器生命周期、OAuth 和进程管理。这标志着 MCP 已成为 CLI 扩展性的事实标准。

2. **进程泄漏/资源管理是普遍问题** — 从 Codex 的 MCP 服务器泄漏到 Copilot 的语音服务器段错误，再到 Gemini 的内存增长问题，多个工具都面临资源清理挑战，需要系统性解决方案。

3. **企业级功能趋同** — 多账户切换、权限提升控制和审计日志等功能在多个工具中出现，表明市场对团队/企业用例的压力。

4. **上下文极限的性能** — 深度会话处理（800+ 消息、6000+ 条目）在多个工具中导致栈溢出和渲染卡顿，表明"长时间运行的代理"用例正在生产环境中被测试。

5. **终端 UI 投入增加** — 所有工具都在改进滚动条、路径处理和搜索功能，表明 TUI 作为竞争差异化的成熟。

6. **安全模型演进** — Claude Code 的权限层级模型和 Copilot 的钩子绕过发现表明，行业仍在学习如何在代理自主性和安全性之间取得平衡。
