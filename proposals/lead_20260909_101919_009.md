## Steps to reproduce

1. Use the attached Flutter-only project, or create a web project and replace `lib/main.dart` with the code below.
2. Keep/add `<meta name="viewport" content="width=device-width, initial-scale=1.0">` in the HTML head before Flutter bootstrap, as in the attached `web/index.html`.
3. Run `flutter pub get`, then `flutter build web --release`.
4. Serve `build/web`, for example with `python3 -m http.server 4387 --bind 127.0.0.1 --directory build/web`.
5. Open `http://127.0.0.1:4387/` in Safari on an iPhone 14 simulator, portrait, at 100% zoom. The tested layout viewport is 390 × 699 CSS pixels.
6. Tap the centre of the visible blue LOWER button once. No scrolling or text-field focus is needed.

Tested with Flutter 3.47.1 stable, framework `6655482ec0`, engine `5d53178869`, Dart 3.13.1, CanvasKit, Safari 26.4 on iOS simulator runtime 26.4.1 (23E254a), Xcode 26.4.1. Semantics are explicitly enabled with `ensureSemantics()`; VoiceOver is not needed. The semantics handle is retained for the app lifetime.

## Expected results

Only LOWER's callback runs: `UPPER callbacks: 0`, `LOWER callbacks: 1`, `Last callback: LOWER`.

## Actual results

UPPER's callback runs instead: `UPPER callbacks: 1`, `LOWER callbacks: 0`, `Last callback: UPPER`.

Repeated native taps on the lower control continue incrementing UPPER. It also reproduces after reloading, without any Inspector diagnostics installed. The app uses only Flutter widgets and has no custom scaling, fonts, CSS, backend, authentication, or third-party runtime packages.

## Controls and browser measurements

Using the same build and native lower-button tap:

| Configuration | Result |
|---|---|
| Default: long label, semantics enabled, separate SliverToBoxAdapters | UPPER callback (incorrect) |
| `?label=short`: only change label to “Upper” | LOWER callback |
| `?semantics=off`: omit explicit semantics activation | LOWER callback; zero `flt-semantics` DOM elements verified |
| `?layout=column`: long label, semantics enabled, Column | LOWER callback |

The short-label case retains 13 semantic DOM elements. These are diagnostic comparisons, not suggested accessibility workarounds.

In the failing case, an optional passive `pointerdown` listener recorded client coordinates `(340,307)` with target `flt-semantic-node-9` (UPPER), outside that element's box and inside LOWER's box:

| Measurement | UPPER | LOWER |
|---|---|---|
| Element rectangle (x, y, width, height) | 314, 129, 52, 52 | 314, 281, 52, 52 |
| Text Range rectangle | 314, 129, 75.515625, 459 | 314, 281, 41.7578125, 19 |
| z-index | 5 | 3 |
| overflow | visible | visible |

`document.elementsFromPoint(340,307)` returns UPPER before LOWER. Viewport scale is 1, with zero viewport offsets and window scroll. The upper accessible label is invisible but its wrapped text overflows far below the upper element and participates in Safari's hit test. Flutter then invokes that node's tap callback.

In the Column comparison, UPPER/LOWER z-indices are 4/6 and the correct lower callback runs. These observations point to Flutter web semantics text overflow and stacking, rather than a visual/pointer scale mismatch. They do not establish which engine or browser change is the best remedy.

## Code sample

The complete `lib/main.dart` follows. The HTML viewport meta tag above is also included in the attached project.

<details open><summary>main.dart</summary>

```dart
import 'package:flutter/foundation.dart';
import 'package:flutter/material.dart';
import 'package:flutter/semantics.dart';

const String longLabel =
    'Upper control with a deliberately long accessible description. '
    'This entire description belongs only to the upper control. '
    'It must never intercept a tap on the separate lower control.';

SemanticsHandle? semanticsHandle;

void main() {
  WidgetsFlutterBinding.ensureInitialized();
  final Map<String, String> parameters = Uri.base.queryParameters;
  final bool enableSemantics = parameters['semantics'] != 'off';
  final bool useLongLabel = parameters['label'] != 'short';
  if (kIsWeb && enableSemantics) {
    semanticsHandle = SemanticsBinding.instance.ensureSemantics();
  }
  runApp(
    ReproducerApp(
      enableSemantics: enableSemantics,
      useLongLabel: useLongLabel,
      layout: parameters['layout'] ?? 'slivers',
    ),
  );
}

class ReproducerApp extends StatelessWidget {
  const ReproducerApp({
    super.key,
    required this.enableSemantics,
    required this.useLongLabel,
    required this.layout,
  });

  final bool enableSemantics;
  final bool useLongLabel;
  final String layout;

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      debugShowCheckedModeBanner: false,
      home: ReproducerScreen(
        enableSemantics: enableSemantics,
        useLongLabel: useLongLabel,
        layout: layout,
      ),
    );
  }
}

class ReproducerScreen extends StatefulWidget {
  const ReproducerScreen({
    super.key,
    required this.enableSemantics,
    required this.useLongLabel,
    required this.layout,
  });

  final bool enableSemantics;
  final bool useLongLabel;
  final String layout;

  @override
  State<ReproducerScreen> createState() => _ReproducerScreenState();
}

class _ReproducerScreenState extends State<ReproducerScreen> {
  int upperCount = 0;
  int lowerCount = 0;
  String lastCallback = 'none';

  void recordTap(String control) {
    setState(() {
      lastCallback = control;
      if (control == 'UPPER') {
        upperCount++;
      } else {
        lowerCount++;
      }
    });
    debugPrint('CALLBACK $control upper=$upperCount lower=$lowerCount');
  }

  Widget buildControl(String name, String accessibleLabel, Color color) {
    return Row(
      mainAxisAlignment: MainAxisAlignment.spaceBetween,
      children: <Widget>[
        Text(name),
        Semantics(
          container: true,
          button: true,
          label: accessibleLabel,
          child: Material(
            color: color,
            child: InkWell(
              key: ValueKey<String>(name),
              onTap: () => recordTap(name),
              child: SizedBox(
                width: 52,
                height: 52,
                child: ExcludeSemantics(
                  child: Center(
                    child: Text(
                      name.substring(0, 1),
                      style: const TextStyle(color: Colors.white, fontSize: 24),
                    ),
                  ),
                ),
              ),
            ),
          ),
        ),
      ],
    );
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      body: SafeArea(
        child: Padding(
          padding: const EdgeInsets.all(24),
          child: buildLayout(<Widget>[
            const Text(
              'Tap the blue LOWER button',
              style: TextStyle(fontSize: 20),
            ),
            const SizedBox(height: 12),
            Text(
              'Semantics: ${widget.enableSemantics ? 'on' : 'off'}; '
              'label: ${widget.useLongLabel ? 'long' : 'short'}\n'
              'Layout: ${widget.layout}',
            ),
            const SizedBox(height: 24),
            buildControl(
              'UPPER',
              widget.useLongLabel ? longLabel : 'Upper',
              Colors.teal,
            ),
            const SizedBox(height: 100),
            buildControl('LOWER', 'Lower', Colors.blue),
            const SizedBox(height: 32),
            Text(
              'UPPER callbacks: $upperCount\n'
              'LOWER callbacks: $lowerCount\n'
              'Last callback: $lastCallback',
              style: const TextStyle(fontSize: 20),
            ),
          ]),
        ),
      ),
    );
  }

  Widget buildLayout(List<Widget> children) {
    return switch (widget.layout) {
      'column' => Column(
        crossAxisAlignment: CrossAxisAlignment.stretch,
        children: children,
      ),
      'list' => ListView(children: children),
      _ => CustomScrollView(
        slivers: children
            .map((Widget child) => SliverToBoxAdapter(child: child))
            .toList(),
      ),
    };
  }
}
```
