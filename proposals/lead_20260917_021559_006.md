### What happened?

TITLE

iOS: plugin registration blocks the main thread at launch (App Hang) for all
users, including those who never use location


DESCRIPTION

Registering the plugin unconditionally constructs it, and constructing it
touches CoreLocation synchronously on the main thread. Because registration
happens through GeneratedPluginRegistrant inside UIApplicationMain, this runs
on every launch of every app that installs the plugin, including the roughly
99% of our users who never open the one screen that uses location.

TSLocationManager links CLLocationManager and calls locationServicesEnabled.
Apple documents that call as a synchronous XPC round-trip to locationd which
"may take a long time to return" and should not be made on the main thread.
When locationd is slow to answer, the launch blocks past two seconds and iOS
reports an App Hang.

We see about 220 App Hang events over 30 days, 100% of them on iOS, spread
across app versions 6.06.12 through 6.07.07 and several different bundle IDs.
This is not a regression from a recent release; it has been chronic since at
least 6.06.12.

Nothing in our integration requires the plugin to be live at launch. We use
stopOnTerminate: true and startOnBoot: false, and we register no headless
task, so the plugin is only ever needed after the user deliberately opens the
screen that starts a trip.

We confirmed the same code is present in 5.7.0, so upgrading does not change
this behaviour.


REPRODUCTION

Not reproducible on demand. It depends on locationd being slow to answer,
which in our captured event coincided with the device having 90 MB free out
of 5.9 GB. The code path itself runs on every launch regardless; the hang is
the tail of that distribution rather than a separate condition.


REQUEST

Make initialization lazy: keep it free of CoreLocation and resolve the
TSLocationManager instance on the first method call instead of at
construction. Alternatively, expose a documented way to defer plugin
registration. Either way, apps that never call into the plugin would never
touch locationd.
