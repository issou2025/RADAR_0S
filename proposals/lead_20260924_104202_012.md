*Project description:*
Act as a Lead Mobile App Architect and Full-Stack Developer. I want you to step-by-step guide me in building a cross-platform mobile application named "Janice" — an AI-powered personal voice assistant. 

Here is the core vision, feature set, and technical requirements for the application:

---
### 1. APP OVERVIEW & NAME
* App Name: Janice
* Default Assistant Name: Janice
* Primary Core Purpose: Act as an intelligent personal assistant that ingests screenshots/images (of emails, WhatsApp chats, messages), extracts structured calendar events and notes, manages an in-app calendar with home screen widgets, and responds using custom voice cloning technology.

---
### 2. CORE FEATURES & SPECIFICATIONS

1. Image & Screenshot Ingestion (OCR & Parsing):
   * Users can upload or share images/screenshots directly into Janice (e.g., via system share sheet or in-app picker).
   * The app extracts text using Optical Character Recognition (OCR).
   * Janice uses an LLM pipeline to analyze the extracted text, auto-detect event dates, times, locations, and context, and present confirmation cards before saving to the calendar.

2. In-App Calendar & Local Storage:
   * Built-in local calendar and task/note manager.
   * Capability to create, edit, delete, and categorize events and notes.
   * Full offline support for basic CRUD operations.

3. Home Screen Widget:
   * Android (AppWidget / Glance) and iOS (WidgetKit) widget support.
   * Displays upcoming calendar events directly on the user's home screen, real-time synced with the in-app database.

4. Custom Voice Synthesis (Text-To-Speech):
   * Users can record/upload audio clips of their own voice to train or clone a custom voice model.
   * Janice uses this custom voice profile for voice responses and verbal event/note summaries.

---
### 3. PREFERRED TECH STACK
* Frontend: Flutter (Dart) for iOS and Android.
* Database: SQLite / Isar for fast local offline storage.
* OCR Engine: Google ML Kit Text Recognition.
* AI Parsing: OpenAI API (e.g., gpt-4o-mini with Structured Outputs / JSON mode).
* Voice Cloning / TTS: ElevenLabs API (or similar voice cloning service).
* Home Widgets: home_widget Flutter package.
