# Project Proposal — Bim Modeling

## Project Understanding
You need assistance with: 
**Revisit A34: 135 degree hooks are the deformed-bar convention, but stirrups are assigned plain round mild steel**

*Project description:*
Opened at the project owner's request when deciding #31 (A45): the stirrup
hook angle moved from 180° to **135°**, and 135° is the convention for
**deformed** stirrups, while **A34** assigns stirrups **mild St 24/35 —
plain round**.

Both may be right, but they pull in opposite directions, so the pairing is
worth a deliberate look rather than being left as an accident of two
decisions taken a day apart.

## The tension

- A **plain round** bar has no ribs. It develops anchorage by bearing and
  friction, which is the classical reason codes call for a **semicircular
  (180°) hook** on plain bars. That is the strongest argument for A33's
  original 180°, and it is why A45 does **not** touch A34 on its own
  authority.
- **135°** is the convention for **deformed** stirrups and for
  ductile/seismic detailing, where the ribs carry the bond and the shorter
  hook is easier to place around the main bars. It is also the only thing
  the Revit library ships for Stirrup/Tie hooks.

So the coherent pairings are roughly *plain round + 180°* or *deformed +
135°*. The tool now details **plain round + 135°**, which is the one
combination neither convention argues for directly.

## Where A34 came from

A34's assignment is not an inference — it is a direct instruction from the
project owner: high tensile for every bar **except** stirrups, mild for
stirrups. That is why nothing here is being changed unilaterally, and why
`rft.core.grades.ROLE_GRADE` carries an explicit comment against
"correcting" the mapping.

## What is actually affected

Less than it might appear. Under **A42** the grade is no longer a selection
axis: it is the **label** on each role's bar-type picker plus a line in the
report, and the actual bar comes from the `RebarBarType` the engineer
selects. So this decision changes what the tool *tells* the engineer, and
the mapping in `ROLE_GRADE`, but not which element gets placed.

That is also the risk: a report line naming "mild St 24/35 (plain round)"
next to a 135° hook is a statement the drawing carries, and if the stirrups
actually placed are deformed bars, the report is wrong while the geometry
is right.

## The options

**A — Keep A34 as instructed (mild St 24/35, plain round), with 135°.**
Nothing changes. The pairing is recorded here as a known, accepted
position rather than an oversight.

**B — Amend A34 so stirrups are deformed**, making the grade consistent
with A45's 135°. Changes the label and report line only, not the placement.

**C — Make the stirrup grade label follow the selected bar type** rather
than a fixed mapping. Rejected once already under A35/A42 — grade cannot be
inferred from a `RebarBarType` — so this would need a different mechanism,
such as an explicit per-project grade setting alongside the type.

No code is blocked: A45's guard (`REBAR_HOOK_STYLE = 1` and 135° ± 1°) is
fully specified and #25 can proceed either way. This ticket only decides
what the tool *says* about the steel.
