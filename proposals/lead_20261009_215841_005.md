# Project Proposal — Structural Drawings

## Project Understanding
You need assistance with: 
**Spike: text -> LLM -> draft event in a Supabase Edge Function**

*Project description:*
## Goal
Prove that the backend can turn a parent's typed (or dictated) text into a structured draft event, using an LLM inside a Supabase Edge Function that acts as that parent so RLS still applies. If Supabase can't host this, we need a separate backend app, which the Flutter app would use too, and that changes how the rest gets built.

This is a throwaway spike. Write down what you find; don't keep the code.

## Architecture this is checking
Every consumer goes through the same tools and the same Postgres functions (#50). Business rules live in the database, not in any one client.

```
Text / voice ──> Edge Function `quick_add` ──> LLM (tool use + structured output)
                        │                          │
                        │        tools: list_members, list_templates, find_events
                        ▼                          ▼
                 draft event (JSON) ──> #3 form, prefilled ──> user confirms ──> create_event (#50)

Later: ChatGPT / Claude ──MCP──> Edge Function `mcp` ──> same tools ──> same Postgres functions
```

The tools are written once, as thin TypeScript wrappers over Postgres, and shared by `quick_add` and a future MCP server.

## Tasks
- [ ] Edge Function `quick_add`, called from a local client with the parent's JWT. It reads with that JWT, never the service role key.
- [ ] One LLM call that has tool use (`list_members`, `list_templates`) and returns a draft event matching the `events` columns, its members and its template id. Any provider will do for the spike; the provider decision is recorded in #16.
- [ ] Try 5–10 real prompts (e.g. "Swimming Tuesdays 4pm, Ella, bring goggles", "Bins out Thursday night"). Note which ones fail and why: the model, the tools, or the schema can't express it (e.g. #14 skip weeks, #15 roles).
- [ ] Check that a parent in another family gets nothing back from the tools.
- [ ] Note latency and cost per request, plus any Edge Function limits we hit (timeouts, request size).
- [ ] The LLM API key lives in Edge Function secrets (`supabase secrets` / local `.env`), never in `app/` or git.
