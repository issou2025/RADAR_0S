## Purpose

Persistent intake queue for **gathered but not-yet-implemented scientific/data enrichment**. This queue is deliberately separate from implementation WIP: research can be collected, verified, deduplicated, and ranked here even when the sprint has no legal implementation slot.

This is **not** a second scientific authority and does not bypass the enrichment governor, source registry, workbook/normalized-data contracts, provenance requirements, or merge gates. Canonical mutation still requires the normal governed implementation path and a legal WIP slot.

## Queue lifecycle

Each candidate moves through:

`DISCOVERED → VERIFIED → DEDUPED → READY_FOR_GOVERNED_IMPLEMENTATION → IMPLEMENTING → MERGED`

Other terminal/holding states:

- `REJECTED` — source/entity/claim is unsuitable or misleading.
- `BLOCKED_TOOLING` — evidence is good but current ingestion tooling cannot represent it safely.
- `BLOCKED_SEMANTIC` — identity/claim boundary needs resolution.
- `STALE_REVALIDATE` — evidence or external assumption needs freshness review before promotion.

## Required fields per queue item

- target entity / slug
- candidate source identity: PMID / DOI / canonical URL / title
- study class and population
- formulation / preparation / species boundary
- exact claim or field the source can support
- important null findings / limitations / uncertainty
- safety / interaction boundaries when relevant
- funding / conflict / supplier provenance when relevant
- repository dedup result
- current-site defect or missing field addressed
- proposed normalized destination
- status
- confidence
- priority rationale
- dependency / blocker
- discovered date / last verified date

## Ranking guidance

Highest priority generally goes to:

1. published factual/source integrity defects;
2. held profiles that can be safely unlocked with human evidence;
3. missing human evidence on already-indexed profiles;
4. high-value safety/interaction evidence;
5. recent systematic reviews/meta-analyses/RCTs that materially change certainty;
6. entity-resolution fixes that prevent a class of bad enrichment;
7. depth-only enrichment for already well-covered profiles.

Safety/scientific integrity overrides numeric convenience. Negative/null evidence is first-class and must not be discarded merely because it does not support a positive claim.
