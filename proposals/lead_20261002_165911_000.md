# Project Proposal — Bim Modeling

## Project Understanding
You need assistance with: 
**Feature request: Settings option to disable the built-in Claude chat panel (MCP Panel button + Dockable Pane)**

*Project description:*
Hi! Separate request from the image-capture one.

I (and I suspect many other users) use revit-mcp-server with an external
MCP client (LM Studio, Cursor, Claude Desktop). In that setup, the
built-in Claude chat panel inside Revit is not needed — it just takes up
ribbon space and adds a dockable pane.

Problem
-------
There is currently no way to disable it from Settings. OnStartup always
does:
  - ClaudeDesktopConfigurator.EnsureConfigured()
  - registers the Dockable Pane for the built-in chat
  - creates the "MCP Panel" button on the ribbon

The only way to remove it is to edit RevitMCPPlugin.dll manually with
dnSpyEx and NOP out those calls — which is not something a regular user
should have to do, and it breaks on every plugin update.

Suggested implementation
------------------------
A checkbox in Settings (MCP → Settings), e.g.:
  [ ] Enable built-in Claude chat panel
      (shows the MCP Panel button and the dockable chat pane)

Default: checked (current behavior preserved). When unchecked, skip:
  - ClaudeDesktopConfigurator.EnsureConfigured()
  - Dockable Pane registration
  - MCP Panel ribbon button creation

Ideally two separate toggles (one for the ribbon button, one for the
dockable pane), but a single one would already solve the problem.

Note: the MCP server itself, Revit MCP Switch and Settings should keep
working regardless of this option — only the built-in chat UI is disabled.

Environment
-----------
Revit 2026, revit-mcp-server v2.2.1.

Thanks!
