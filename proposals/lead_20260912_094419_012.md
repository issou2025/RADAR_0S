*Project description:*
## Objective

Add sound support for quantum adversaries and the quantum random-oracle model (QROM), with foundational proofs that validate the abstractions and conservative adapters that preserve VCVio's classical infrastructure.

The proposed foundation is finite-dimensional CP/subinstrument semantics with explicit quantum input/output, register operations, and strategies with declared access and resources. Fixed-memory `QComp` and ordinary sequential `FreeM` form one initial frontend, not the universal interface for quantum cryptography or reductions. Reuse `FreeM`, handlers, classical scheme code, game organization, and numerical advantage reasoning where their hypotheses remain valid. Introduce quantum-specific interfaces for private memory, coherent oracle access, contextual replacement, extraction, and computational realizability.

This is an umbrella tracking issue. The architecture is a proposal for review; unchecked items do not claim implementation or upstream agreement. Source findings are pinned to the September 11–12, 2026 baseline. Establish a fresh dependency/build/axiom baseline when implementation begins.

- [ ] Specify heterogeneous `SubInstrument A B α` with quantum input A, quantum output B, and arbitrary finitely supported classical outcomes α; prove indexed composition/tensor/frame laws. Keep `QComp H α` as its fixed-memory specialization.
- [ ] Specify a register-operation signature: coherent queries/local operations return `Unit`; measurement returns a classical outcome. Use ordinary `FreeM` for the first fixed-context pilot, with PolyFun's indexed interfaces available when needed.
- [ ] Specify a runner and per-port access policy with explicit setup quantifiers: one fixed adversary family `A : Public → Strategy` is selected outside hidden-table sampling. Local operations act only on owned systems; allowed public input/advice correlations are explicit. Lean `private`/`opaque` declarations are not an information-flow proof.
- [ ] Select a computational basis/response encoding and reversible action for each quantum port. Do not assume arbitrary dependent `OracleSpec` values have a canonical coherent interpretation.
- [ ] Pin one compatible dependency graph. VCVio's baseline is Lean/mathlib 4.33.1; Physlib/Algolean use the 4.33 generation, while inspected Lean-QIT and public CatCrypt-core use 4.30.
- [ ] Specify quantum-message stages and party-local control of both quantum registers and classical histories. Local tensor framing alone must not permit a global continuation to send one separated party’s answer to another.
- [ ] Specify stateful private oracle runtimes with distinct public and simulator ports; support coherent programming registers where required. General setup supplies an allowed joint database/adversary/reference state, including only the correlations/advice granted by the notion.
- [ ] Separate forward channel invocation from supplied unitary/dilation/circuit implementation access, including inverses, controlled calls, private environments, and reduction costs.
- [ ] State resource and coverage contracts for batches/depth, copies, preprocessing/advice, phase-specific efficiency, continuous outer setup, bounded truncation, and expected/coherent runtime.

## Milestones

### 1. Physical semantics and classical conservativity

- [ ] Provide subnormalized states and finite-support subinstruments with CP branches and TNI totals; define losslessness by TP of the total. Sum raw linear maps or CP maps, and prove the total trace bound separately: CP-TNI maps are not closed under unrestricted addition. Prove extensional equality and the required composition/tensor laws.
- [ ] Prove `QComp` unit/bind laws, finite-support closure, trace bounds, and losslessness preservation.
- [ ] Interpret the new operation syntax through the existing free-monad handler machinery.
- [ ] Prove a quantum-message baseline such as QOTP decryption and Pauli twirling with an arbitrary reference; distinguish new quantum honest-algorithm interfaces from reused classical scheme routines.
- [ ] Observe a closed execution by fixing its initial state and taking branch traces through `MeasureSemanticsVia`. New probability interfaces use `Measure`/`Kernel`; existing discrete APIs remain compatibility surfaces.
- [ ] Embed the supported finite classical fragment and prove equality with existing classical output measures, including correlated classical state and residual quantum memory.
- [ ] Prove typed local-operation framing, disjoint-operation laws, and an entangled-reference/Bell-pair example. Ensure state descriptions are not exposed as inspectable adversary data.

**Acceptance:** the physical core and its adequacy laws have no project-specific physical axioms, `sorry`s, or equivalent placeholders in their transitive dependencies. Audit inherited substrate assumptions explicitly. Finite support does not claim coverage of arbitrary countable sampling or unbounded loops.

### 2. Reference QROM and adversary boundary

- [ ] Define the canonical oracle `U_h |x,y⟩ = |x,y XOR h(x)⟩` for bitstring responses, or a separately witnessed reversible response action.
- [ ] Sample one hidden function for the entire experiment; share it between honest classical queries and coherent adversarial queries.
- [ ] Prove unitarity, basis-state agreement, reference framing, and two-query restoration for XOR queries.
- [ ] Prove zero-query equality of the output channel/state for fixed public input and initial state, hence equality under a common observation. Include hidden-table-capture and oracle-dependent-win counterexamples; count relevant challenger verification queries in game bounds.
- [ ] Give distinguishers against transparent query-content logging and independently resampling the function at each call.
- [ ] Prove agreement of the classical-access adapter with the supported classical random-oracle semantics.
- [ ] Provide a stateful runtime interface for compressed/purified implementations and privileged extraction/programming, with refinement statements over the exact permitted interacting contexts. These operations are not transparent query logs.
- [ ] Specify access modes independently for hash, signing, decryption, and challenge interfaces. Preserve coherent dispatch where domain-separation tags are part of one hash input.
- [ ] State finite input-length bounds/encodings, query count versus depth, and the permissions/costs of inverse or controlled access.

**Acceptance:** every allowed strategy has only the declared access to the hidden oracle; quantum memory persists across stages; counters come from actual query slots rather than unrelated annotations.

### 3. One shared game and contextual replacement

- [ ] Adapt one small game so its honest computation and win predicate are shared by classical and quantum adversary interfaces, with a proved classical-agreement theorem.
- [ ] Prove distance contraction and finite hybrid reasoning under arbitrary permitted quantum references and continuations. Direct contextual bounds may precede a numeric diamond-distance API.
- [ ] Fix missing-mass/abort semantics for subnormalized outputs.
- [ ] Bridge the pinned `lean-unclonable-enc-paulis` splitting channel and local POVMs to the shared physical interface; prove equality of its cloning score, including continuous outer key averaging. Audit the imported statement/dependency/trust boundary separately.
- [ ] Distinguish full-state/statistical replacement, computational contextual indistinguishability, winning-value repair, and terminal-POVM agreement. State preservation is always relative to the same access interface; channel equality alone does not preserve extra coherent implementation access.
- [ ] Prove an elementary oracle-difference bound in terms of query-subspace weight.

### 4. First foundational QROM theorem

- [ ] Implement semi-classical membership and punctured oracles, preserving coherence within marked/unmarked subspaces.
- [ ] Prove AHU Lemma 1: equality of `Pr[E ∧ ¬Find]` under the two punctured oracles for every classical event `E`, with the exact joint-distribution hypotheses.
- [ ] Prove one explicitly chosen O2H variant; the proposed first target is final AHU Theorem 1 specialized to sequential depth `d = q`, with bound `2√((q+1) Pfind)` and explicit terminating/backend hypotheses.
- [ ] Either prove the instrument-to-unitary dilation/deferred-measurement bridge with query preservation or explicitly restrict the first theorem to the proved backend.
- [ ] Add the separate selected-query measurement extractor and regular-oracle O2H bound when needed. Handle zero queries separately and distinguish continuing versus stopped-at-first-hit executions.

**Acceptance:** the quantitative QROM bound follows from the physical semantics. A theorem assuming its own desired bound through a certificate, distance lemma, or imported axiom does not discharge this milestone. Exact AHU and AFP variants/constants are documented in Reference D.

### 5. Efficient realizations and a cryptographic consumer

- [ ] Define a realizable circuit/program family with explicit gate, qubit, measurement, classical-computation, approximation, uniformity/advice, and oracle resources.
- [ ] Prove that the interpreter realizes the claimed physical operation and that reductions preserve realizability with stated overhead.
- [ ] Derive a computational security corollary for a small consumer with explicit oracle access modes.

**Acceptance:** a bound for every physical q-query strategy already covers QPT strategies in that class. When a computational reduction is claimed, prove that the constructed reduction satisfies the resource class required by its assumption. Start with a small consumer before full GPV, FO, or ML-KEM.

### 6. Follow-on QROM techniques

- [ ] Prove sampled-table/purified-table equivalence and the relevant standard/phase oracle bridge.
- [ ] Prove a measure-and-reprogram theorem with explicit measurement, reprogramming, output predicates, and reduction costs.
- [ ] Prove compressed-oracle equivalence to the reference QRO, then a preimage/collision bound.
- [ ] Add named consumers for coherent reprogramming, online extraction, collapsing/state-preserving extraction, and parallel query bounds; preserve each source’s exact access, state and cost contract.
- [ ] Specify a split-game/certified-deletion lane with quantum ciphertexts/certificates, independently local strategies, correlated copy ensembles, allowed late leakage, and distinct pre-/post-certificate resource classes.
- [ ] Treat exact unbounded execution and coherent-runtime efficiency separately; begin with source-specific bounded approximants/truncation guarantees. Exact optical continuous-variable semantics remains outside the finite pilot unless a cutoff/discretization theorem is supplied.
- [ ] Expand to selected signature/KEM proofs. Track quantum rewinding, UC, parallel-query depth, dynamic contexts, and unbounded recursion as separate scoped workstreams when required.
