## Project Understanding
You need assistance with: 
**Multithreaded iterator with the hybrid kernels drops the OpenCASCADE-only items of a mixed representation (and duplicates the CGAL part single-threaded)**

*Project description:*
### Bug Description

With `hybrid-cgal-simple-opencascade` (and `hybrid-cgal-opencascade`), when a product's Body has some items CGAL can build and some it can't (here a curved `IfcAdvancedBrep`), `ifcopenshell.geom.iterator` returns different geometry depending on the thread count:

- **2 or more threads:** only the CGAL-built item comes back. The curved item is missing, and nothing is logged. The result is the same as `cgal-simple` on its own.
- **1 thread:** the full shape comes back, but the CGAL-built item is in it **twice** (its triangles appear once from each kernel).

`create_shape` with the same library gives the 1-thread result (duplicated part). `opencascade` gives the correct shape at any thread count. A product whose only item is the curved brep is fine under both, because the whole representation goes to OpenCASCADE.

The result is the same on every run (5 runs per setting), so this is not the nondeterminism in #8050. It looks related to #8052, where the hybrid was changed to defer to OpenCASCADE when cgal-simple only partly succeeds: under multithreading that fallback doesn't seem to happen, and single-threaded the partial CGAL result is kept alongside the fallback. #10049 (fixed in #10052) was a different hybrid-iterator fault, on mapped bodies with openings.

I found this on a Revit 2026 export, where the body of each affected element is one `IfcMappedItem` over 11 `IfcAdvancedBrep`s: two flat-faced ones and nine with cylindrical faces or faces of revolution. With the multithreaded iterator, only the two flat-faced breps are returned, so the element appears moved by about 0.55 m (its centroid) and loses most of its shape. The mapped item isn't needed to trigger it, as the reproduction shows.

### Minimal reproduction

`make_repro.py` writes `hybrid_repro.ifc` from scratch (IFC4, millimetres, four `IfcBuildingElementProxy`s 1 m apart). Each has a 200 × 100 × 100 mm box on top of a cylinder 50 mm in radius and 600 mm tall:

| Product | Body |
|---|---|
| `mapped-mixed` | `IfcMappedItem` (identity origin and target) of [box `IfcAdvancedBrep` with `IfcPlane` faces, cylinder `IfcAdvancedBrep`] |
| `direct-mixed` | the same two `IfcAdvancedBrep`s directly in the representation |
| `extrusion-mix` | box as `IfcExtrudedAreaSolid` + the cylinder `IfcAdvancedBrep` |
| `cyl-only` | the cylinder `IfcAdvancedBrep` alone (control) |

The cylinder brep has one `IfcCylindricalSurface` face with a seam edge and two `IfcPlane` caps bounded by `IfcCircle` edges.

`check_repro.py` meshes the file with default settings (`ifcopenshell.geom.settings()`, local coordinates) using `opencascade` and `hybrid-cgal-simple-opencascade`, with 1 and 4 iterator threads, and prints each product's vertex count, Z range and enclosed volume:

```
python make_repro.py hybrid_repro.ifc
python check_repro.py hybrid_repro.ifc 4
```

"""Write a minimal IFC4 file, from scratch, with a few proxies whose Body mixes a planar-only solid with a curved
IfcAdvancedBrep (a cylinder: IfcCylindricalSurface side, IfcPlane caps bounded by IfcCircle edges).

  python -I make_repro.py <out.ifc>

Products (millimetres, the file's length unit; near the origin, 1000 mm apart along X):
  mapped-mixed   IfcMappedItem (identity origin and target) of [planar box IfcAdvancedBrep, cylinder IfcAdvancedBrep]
  direct-mixed   the same two IfcAdvancedBreps directly in the Body representation, no mapping
  extrusion-mix  an IfcExtrudedAreaSolid box + the cylinder IfcAdvancedBrep, directly
  cyl-only       the cylinder IfcAdvancedBrep alone
"""
import sys
import ifcopenshell
import ifcopenshell.api.aggregate, ifcopenshell.api.context, ifcopenshell.api.project
import ifcopenshell.api.root, ifcopenshell.api.spatial, ifcopenshell.api.unit

f = ifcopenshell.api.project.create_file(version='IFC4')
project = ifcopenshell.api.root.create_entity(f, ifc_class='IfcProject', name='Hybrid kernel repro')
ifcopenshell.api.unit.assign_unit(f)                                   # its default: millimetres
model = ifcopenshell.api.context.add_context(f, context_type='Model')
body = ifcopenshell.api.context.add_context(f, context_type='Model', context_identifier='Body',
                                            target_view='MODEL_VIEW', parent=model)
site = ifcopenshell.api.root.create_entity(f, ifc_class='IfcSite', name='Site')
ifcopenshell.api.aggregate.assign_object(f, products=[site], relating_object=project)

P = lambda *c: f.createIfcCartesianPoint([float(x) for x in c])
D = lambda *c: f.createIfcDirection([float(x) for x in c])
A3 = lambda o, z=None, x=None: f.createIfcAxis2Placement3D(P(*o), D(*z) if z else None, D(*x) if x else None)


def vertex(*c):
    return f.createIfcVertexPoint(P(*c))


def edge(v0, v1, curve):
    return f.createIfcEdgeCurve(v0, v1, curve, True)


def loop(*oriented):
    return f.createIfcEdgeLoop([f.createIfcOrientedEdge(None, None, e, s) for e, s in oriented])


def face(surface, bound, same_sense=True):
    return f.createIfcAdvancedFace([f.createIfcFaceOuterBound(bound, True)], surface, same_sense)


def box_brep(x0, y0, z0, dx, dy, dz):
    """Axis-aligned box as an IfcAdvancedBrep of six IfcPlane faces bounded by IfcPolyline edges."""
    c = [(x0 + i * dx, y0 + j * dy, z0 + k * dz) for k in (0, 1) for j in (0, 1) for i in (0, 1)]
    v = [vertex(*p) for p in c]
    E = {}

    def e(a, b):
        if (b, a) in E:
            return E[(b, a)], False
        if (a, b) not in E:
            E[(a, b)] = edge(v[a], v[b], f.createIfcPolyline([P(*c[a]), P(*c[b])]))
        return E[(a, b)], True

    # vertex index = i + 2j + 4k; each quad listed counter-clockwise seen from outside
    quads = {(0, 0, -1): (0, 2, 3, 1), (0, 0, 1): (4, 5, 7, 6), (0, -1, 0): (0, 1, 5, 4),
             (0, 1, 0): (2, 6, 7, 3), (-1, 0, 0): (0, 4, 6, 2), (1, 0, 0): (1, 3, 7, 5)}
    faces = []
    for n, q in quads.items():
        o = c[q[0]]
        ref = [c[q[1]][i] - o[i] for i in range(3)]
        plane = f.createIfcPlane(A3(o, n, [r / max(abs(x) for x in ref) for r in ref]))
        faces.append(face(plane, loop(*[e(q[i], q[(i + 1) % 4]) for i in range(4)])))
    return f.createIfcAdvancedBrep(f.createIfcClosedShell(faces))


def cylinder_brep(cx, cy, z0, r, h):
    """Vertical cylinder as an IfcAdvancedBrep: one IfcCylindricalSurface face with a seam, two IfcPlane caps."""
    vb, vt = vertex(cx + r, cy, z0), vertex(cx + r, cy, z0 + h)
    cb = edge(vb, vb, f.createIfcCircle(A3((cx, cy, z0), (0, 0, 1), (1, 0, 0)), r))
    ct = edge(vt, vt, f.createIfcCircle(A3((cx, cy, z0 + h), (0, 0, 1), (1, 0, 0)), r))
    seam = edge(vb, vt, f.createIfcPolyline([P(cx + r, cy, z0), P(cx + r, cy, z0 + h)]))
    side = face(f.createIfcCylindricalSurface(A3((cx, cy, z0), (0, 0, 1), (1, 0, 0)), r),
                loop((cb, True), (seam, True), (ct, False), (seam, False)))
    bottom = face(f.createIfcPlane(A3((cx, cy, z0), (0, 0, 1), (1, 0, 0))), loop((cb, True)), False)
    top = face(f.createIfcPlane(A3((cx, cy, z0 + h), (0, 0, 1), (1, 0, 0))), loop((ct, True)), True)
    return f.createIfcAdvancedBrep(f.createIfcClosedShell([side, bottom, top]))


def extruded_box(x0, y0, z0, dx, dy, dz):
    prof = f.createIfcRectangleProfileDef('AREA', None, f.createIfcAxis2Placement2D(
        f.createIfcCartesianPoint([x0 + dx / 2, y0 + dy / 2]), None), dx, dy)
    return f.createIfcExtrudedAreaSolid(prof, A3((0, 0, z0)), D(0, 0, 1), dz)


def shape(items, rep_type):
    return f.createIfcProductDefinitionShape(None, None, [f.createIfcShapeRepresentation(body, 'Body', rep_type, items)])


def proxy(name, x, product_shape):
    p = ifcopenshell.api.root.create_entity(f, ifc_class='IfcBuildingElementProxy', name=name)
    p.ObjectPlacement = f.createIfcLocalPlacement(None, A3((x, 0, 0)))
    p.Representation = product_shape
    ifcopenshell.api.spatial.assign_container(f, products=[p], relating_structure=site)
    return p


# the parts: a 200 x 100 x 100 mm box sitting on top of a 50 mm radius, 600 mm tall cylinder
BOX = (-100.0, -50.0, 600.0, 200.0, 100.0, 100.0)
CYL = (0.0, 0.0, 0.0, 50.0, 600.0)

source = f.createIfcRepresentationMap(A3((0, 0, 0)), f.createIfcShapeRepresentation(
    body, 'Body', 'AdvancedBrep', [box_brep(*BOX), cylinder_brep(*CYL)]))
target = f.createIfcCartesianTransformationOperator3D(None, None, P(0, 0, 0), 1.0, None)
proxy('mapped-mixed', 0.0, shape([f.createIfcMappedItem(source, target)], 'MappedRepresentation'))
proxy('direct-mixed', 1000.0, shape([box_brep(*BOX), cylinder_brep(*CYL)], 'AdvancedBrep'))
proxy('extrusion-mix', 2000.0, shape([extruded_box(*BOX), cylinder_brep(*CYL)], 'SolidModel'))
proxy('cyl-only', 3000.0, shape([cylinder_brep(*CYL)], 'AdvancedBrep'))

f.write(sys.argv[1])
print('wrote', sys.argv[1])
```

"""Mesh a file with the default and the hybrid kernel, with 1 and N iterator threads, and print each product's
vertex count, bounding box (local coordinates) and enclosed volume.

  python -I check_repro.py <file.ifc> [N=4]
"""
import sys
import numpy as np
import ifcopenshell, ifcopenshell.geom

path = sys.argv[1]
n_threads = int(sys.argv[2]) if len(sys.argv) > 2 else 4
f = ifcopenshell.open(path)
print('IfcOpenShell', ifcopenshell.version, '| python', sys.version.split()[0])


def volume(v, t):
    a, b, c = v[t[:, 0]], v[t[:, 1]], v[t[:, 2]]
    return float(np.einsum('ij,ij->i', a, np.cross(b, c)).sum() / 6)


def run(lib, threads):
    s = ifcopenshell.geom.settings()                   # defaults, local coordinates
    it = ifcopenshell.geom.iterator(s, f, threads, geometry_library=lib)
    assert it.initialize()
    out = {}
    while True:
        sh = it.get()
        v = np.asarray(sh.geometry.verts).reshape(-1, 3)
        t = np.asarray(sh.geometry.faces).reshape(-1, 3)
        out[f.by_id(sh.id).Name] = (len(v), v.min(0), v.max(0), volume(v, t))
        if not it.next():
            break
    return out


for lib in ('opencascade', 'hybrid-cgal-simple-opencascade'):
    for threads in (1, n_threads):
        print('\n%s, %d thread(s)' % (lib, threads))
        for name, (nv, lo, hi, vol) in sorted(run(lib, threads).items()):
            print('  %-14s verts %5d  z %.3f..%.3f  volume %.6f m3' % (name, nv, lo[2], hi[2], vol))
```

### Expected

Every mixed product: the box and the cylinder, Z from 0.000 to 0.700 m and a volume of about 0.00667 m³ (box 0.002 m³ + cylinder ≈ 0.00467 m³ as tessellated), whatever the thread count, as with `opencascade`.

Counting triangles with every vertex at z ≥ 0.6 m (the box plus the cylinder's top cap): `opencascade` gives 36 (24 cap + 12 box). The hybrid gives 48 at 1 thread (the box's 12 triangles twice), and 12 at 4 threads (the box only).

Other observations:

- `hybrid-cgal-opencascade` gives exactly the same numbers as `hybrid-cgal-simple-opencascade`.
- `cgal-simple` and `cgal` give the 8-vertex box for the mixed products at any thread count, and no shape for `cyl-only`.
- An `include=[one product]` iterator gives the same result (124 triangles at 1 thread, 12 at 2 and 8 threads), so one product and two threads are enough.
- `create_shape(settings, product, geometry_library="hybrid-cgal-simple-opencascade")` gives 124 triangles (the duplicated box). `opencascade` gives 112.
