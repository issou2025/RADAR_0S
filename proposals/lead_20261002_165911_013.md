## Top priorities
1. **W1** — the tray's messages go to a window that drops them. This is very likely the real cause of BACKLOG 7, and it explains why a hand-posted message works and a real click does not. Together with **W3** (no single-instance guard) and **W4** (no `TaskbarCreated`, ghost icon), users can end up with no UI, no Quit, or two daemons.
2. **W8** — without the Japanese OCR pack (the most likely first-run mistake), chibipop exits right after the first dictionary build with no message; startup errors only reach a hidden console.
3. **W2** — the mouse hook swallows a button release over the popup even when the press went to another app, so drags in browsers and other windows get stuck.
4. **S1** — opening the CSS editor twice is a use-after-free.
5. **R1** — on mixed-DPI setups (laptop + external monitor) the popup is drawn and hit-tested at the wrong scale until restart.
6. **D1** — disabled and out-of-language dictionaries still take the 10 result slots before filtering, so popups come up short or empty.
7. **P1** — an Anki add is silently lost when the popup hides during the add-time sentence probe (for example "press Add, release the hold key").
8. **W12 + I1** — the self-updater installs an unverified exe on a click labelled "Check", replaces only the exe, and its TLS stack (rustls 0.23.43) has a published advisory.
9. **C1** — one non-UTF-8 stderr line (Japanese Windows, accented user names) kills the meikiocr plugin for the session.
10. **D2** — every default Anki card gets a run-on glossary (`\n` in an HTML field), and sentence text goes in unescaped.
11. **W6 + W7** — wake-ups are lost during menus and dialogs (Apply can stay stuck), and the app wakes the CPU roughly 180–300 times a second while idle.
12. **I7** — AUR and Nix installs never find the IPADIC model.

## Quick wins (small, low-risk changes)
- `cargo update -p rustls` (I1).
- Pass a button-up through unless its press was swallowed (W2).
- `drop(tray)` before `std::process::exit(0)` (W4).
- Start with the existing `UnavailableOcr` plus a visible notice when the built-in engine cannot be created, instead of exiting (W8).
- Focus an open CSS editor instead of opening a second one, and give `CssEditor` a `Drop` (S1).
- Make `parse_hex_color` check `is_ascii_hexdigit` before slicing (R4).
- Use `EnabledDictionary` on the hover and drill-down paths (D1).
- Escape Anki text and join plain glossary lines with `<br>` (D2).
- Read plugin stderr with `from_utf8_lossy` and never stop draining (C1).
- `AcquireNextFrame(0)` for warm grabs (C4).
- Break on `GetMessageW` `<= 0` in `settings_only` (BACKLOG 21, still at `crates/chibipop-windows/src/app.rs:391`).
- `contents: read` at the top of `release.yml`; `set +e` in clippy pass 1 (I3, I6).
- Rename `background-on-close` to snake_case before the next tag, if it is still unreleased (I13).
- Make the Linux font test use the production Japanese-family check (L1).
