## 5 — Math and deterministic animation specification
Let `u ∈ [0,1]` be authoritative normalized native scroll phase for this section, not wall-clock time.

**Segment-local phase:** for boundaries `b_i, b_{i+1}`, `t_i = clamp((u - b_i)/(b_{i+1}-b_i),0,1)`.

**C² stop-to-stop easing:** `S(t)=6t^5-15t^4+10t^3`; use for gate aperture, light state, fades and designed camera holds. For flowing movement, use a monotonic continuous speed profile rather than forcing every little segment to stop.

**Path geometry:** cubic Bézier
`B(t)=(1-t)^3 P0 + 3(1-t)^2 t P1 + 3(1-t)t² P2 + t³ P3`.
For consistent world-space speed, precompute an arc-length LUT `L(t)=∫₀ᵗ ||B'(v)||dv`, then invert `L` for path progress. The work item must occupy **one** deterministic position for every `u`. For pause at gate, use a piecewise monotonic progress function with a constant interval; do not use an uncontrolled physics timer.

**Gate state:** `g(u) ∈ [0,1]`; held during B/C, releases via `S(t_D)` during D only after the human review state is visually resolved. An amber pending state is different from a success/completed state.

**Flow illumination:** `I(d)=I_base + I_peak exp(-k d)`, where `d` is distance along a route to the active work item / trace front; keep inactive/secondary paths dim and validate screen-space contrast.

**Camera:** use Blender curve/camera rig keyframes and interpolated aim target `P(u), T(u)`; ease anchor transitions, manage orientation by quaternion slerp or smooth tracked target, preserve up vector and avoid camera clipping into objects. Desktop and mobile can share the world/logic but require **separately art-directed camera framing**; no naive center crop.

**Reversibility requirement:** final visual state = `F(u)` only. No uncontrolled random seeds, elapsed-time-only physics, asynchronous independent clocks or one-way state mutations. For any `u0→u1→u0`, expected camera, object transforms, gate state and active light state at `u0` must match within rendering tolerance.

**Frame export:** current site uses 72 desktop/36 mobile frames. Treat this as an integration baseline, **not a quality-imposed frame count**. Define rendered sample `u_n=n/(N-1)`; propose increased `N` only after motion/size/performance evidence. Include exact-phase posters, reversible frame numbering, frame manifests, and sensible transitions to next chapter. Frame-index quantization and adjacent-frame visual displacement must be checked at mobile scrolling rates.

## 6 — Blender authoring / art techniques (NOT code-first geometry)
The first production discipline is **art direction and compositional proof**; Blender is a digital-content-creation tool, not just a Python API.

Preferred authoring:
- coherent modular hard-surface station kit with distinct readable silhouettes, bevels/weighted normals, real material hierarchy and restrained micro-details;
- curves and Geometry Nodes for reusable paths/ribbons/couplings, physically small in world and screen scale;
- a single master rig for the hero work item; keyframed ownership, pause and release;
- custom animation attributes for path activation / state-based emission, deterministically derived from `u`;
- one art-directed camera rail with controlled focus, lenses/ortho scale and composition guide overlays;
- studio/environment lighting with key/fill/rim, local practical lighting, ambient occlusion/contact separation and modest compositor glare;
- material families: graphite/gunmetal, satin silver/titanium, restrained emerald/cyan translucent or painted highlights, minimal amber checkpoint;
- Eevee for iteration where practical; controlled color management and compression. Avoid massive geometry/particles/texture budgets on Intel Iris Xe;
- organized Blender collections: `ENV`, `STATIONS`, `ROUTES`, `WORK_ITEM`, `REVIEW_GATE`, `LIGHTS`, `CAMERA_DESKTOP`, `CAMERA_MOBILE`, `EXPORT`.

A procedural Blender script MAY accelerate repeatable geometry/render/export after the art is validated; **script generation alone is not a creative-quality acceptance test**. No mass-render of dozens of frames from an unapproved scene.
