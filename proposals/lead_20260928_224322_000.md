# Project Proposal — Bim Modeling

## Project Understanding
You need assistance with: 
**OkPy Agent stops with HTTP 401 “API key is invalid” when continuing an interrupted task**

*Project description:*
### Environment
- OkPy for Revit, running in Revit 2025.4
- An existing, saved multi-file tool opens normally in the OkPy editor.
- I am using the free OkPy Agent allowance.

### What happened
1. The Agent was working on a code change. The test step reported “Test completed successfully – analyzing results,” but the Agent remained in “thinking” for more than seven hours and never produced its final report.
2. I saved the tool and reopened OkPy. I then asked the Agent to continue the interrupted task from the saved code.
3. The Agent stopped after approximately three seconds with:
   `API Error 401: {"type":"error","error":{"type":"authenticationError","message":"API key is invalid."},"requestid":null}`
4. The chat also displayed `[LIMIT] Agent reached maximum operations.` The free-prompt message and reset countdown were visible.
5. The tool itself still opens, and I can view its code. The Agent does not process the continuation request. OkPy Preferences shows settings for Inputs and Templates, but no visible Agent account, provider, or API-key setting.

### Expected behavior
The Agent should either continue from the saved code when free prompts are available or show a clear, actionable account/quota message.

### Questions
- Is free OkPy Agent access still active for my account, and when will the next prompts become available?
- Is the HTTP 401 caused by my account session, an Agent service credential, or another configuration? How can I resolve it when OkPy exposes no Agent API-key setting?
- Does a request that fails immediately with HTTP 401 consume one of the four free prompts?
- Can the interrupted Agent task be resumed after authentication is fixed, or should I start a new Agent chat with the saved tool?

I can provide additional diagnostic details privately if needed. I have not included any API keys or project model data in this public issue.
