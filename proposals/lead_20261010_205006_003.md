## Decided

- The header becomes a strip of tabs, one per open Project. "roundup" leaves the header.
- A tab shows only the Project's name and one circle. The name is the folder name until the user renames it.
- No tab boxes, borders or underline: space alone separates tabs. The open tab is in full ink and the others are in `--grey`. A quiet `+` at the end opens a folder.
- The circle shows the most urgent Agent in that Project, `error` over `needs-you`, and nothing otherwise:
  - `●` in amber: an Agent needs you. This is the Rail's own needs-you Glyph.
  - `◉` in red: an Agent is in error. The ring adds a shape, so colour is never the only cue.
  - A plain ring is never used, because `○` already means working in the Rail.
- Counts stay off the tab. Hovering the tab shows `<n> need you · <m> error`, and the Dock badge (U10) counts all open Projects.
- Clicking the name switches to that Project. Clicking the circle selects that Project's most urgent Agent, as `⌘J` does (U30).
- Double-clicking the name edits it in place: `⏎` saves and `esc` cancels.
- The tab's `✕` shows only on hover. Closing a tab with running Agents asks once, naming them, then stops that Project's Daemon and its Agents.

## Facts the spec must handle

- **One Project per App today.** The App starts one Daemon for one Project, and a second `open_project` is `CONFLICT` (`scenarios/app.md` S1, S5). A Rail holds one Project and ids are per Project (`scenarios/worktrees.md` G7), and `GLOSSARY.md` says "in one Project". Tabs mean the App holds several Daemons, so the App seam and the Daemon's lifetime change, not only the header. This is a contract change (AGENTS.md rule 4).
- **Native macOS window tabs cannot carry the circle.** Tauri 2.12.1 can group windows into native tabs, but it does not expose AppKit's `NSWindowTab.accessoryView`, so the strip belongs in the webview.
- **Header text in other scenarios changes**: U30 (`<n> need you` after the Project name), U25 and U37 (`roundup   <Project name>`), and U2 (first run, with no Project open).
- **Keys collide**: `⌘1`/`⌘2` move focus (U41) and `⌥1..9` pick an Agent (U107), while `⌘1..9` is the macOS tab convention. Pick one owner. Decide whether `⌘J` crosses tabs. Switching from the keyboard does not animate.
- **Overflow**: a tab that needs you stays visible when the strip overflows. Solo's `+N` hides its marks, which is the failure to avoid, and the Rail's `● 1 below` is the model.
- **Order is stable**: tabs never reorder by attention, as the Rail never reorders (wireframes decision 3).
- **The name** is new stored state: it belongs per Project path, beside `recent_projects` (S6), unless the spec finds a better owner.
- No snooze or dismiss: the circle clears when the Agent's need is answered (P3).
