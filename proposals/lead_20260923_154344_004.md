# Project Proposal — Dwg To Revit

## Project Understanding
You need assistance with: 
**Export a pile plan to CAD or BIM software**

*Project description:*
## Goal

Export the selected pile plan in a form that can be used directly in a CAD or BIM workflow, rather than only as the current CSV/XLSX schedule or IFCPP project file.

## Candidate paths

- Drawing exchange: DXF and/or DWG.
- Model exchange: IFC and/or a Revit-compatible workflow.

These are alternatives to evaluate, **not** a commitment that all four formats must be implemented together. Choose the first useful path and, if needed, split the remaining formats into follow-up issues.

## Desired outcome

- Export the active pile plan with stable load-point/pile identifiers, project coordinates and units, assigned pile configuration (including size and tip level), and any other data needed for an unambiguous handoff.
- Define how unassigned points, grouped points, locks, and plan-specific state should appear or be omitted.
- Preserve the distinction between drawing geometry and semantic BIM objects/parameters.
- Make the output straightforward to import into at least one representative target application and document any information that cannot be carried across.
- Keep browser and desktop export behavior aligned where feasible.

## Acceptance direction

After selecting a target format and scope, a user can export the active plan, open/import it in the intended CAD or BIM application, and verify coordinates, units, identifiers, and pile assignments against the original project. The export identifies its source plan and does not silently turn unassigned points into designed piles.

## Design questions for implementation

- Which target workflow should be supported first: DXF/DWG drawing or IFC/Revit model exchange?
- Which pile geometry, labels, layers, and metadata must be included for a useful handoff?
- What coordinate reference and unit conventions should the export use?
- For BIM exchange, which objects and properties best represent the actual pile design without pretending that absent engineering data exists?
