### Talk title

Building the Future of Mobile Apps with AI: Architecture, On-Device SLMs, and Python Backends

### Short talk description

Artificial Intelligence is shifting from cloud-heavy APIs to lightweight, on-device models and reactive backends. In this talk, we explore how modern mobile architectures leverage Python services alongside edge intelligence to create responsive, context-aware mobile applications. Attendees will discover how to integrate Small Language Models (SLMs) into mobile workflows, design resilient FastAPI backends, and optimize latency, battery consumption, and user privacy. Whether you build full-stack mobile systems or design Python APIs, this session delivers actionable engineering patterns to prepare your apps for the next era of AI.

### Long talk description

As AI shifts from cloud endpoints into user devices, mobile development is undergoing a fundamental architectural rethink. Building intelligent client applications requires bridging high-performance mobile frontends with robust Python ecosystems powering orchestration, data pipelines, and offline-capable inference.

In this talk, we break down end-to-end architectures connecting mobile interfaces to intelligent Python runtimes. We begin by examining modern on-device AI patterns: running quantized Small Language Models (SLMs) locally via ONNX Runtime and LiteRT to maintain privacy and sub-100ms response times. We then cover hybrid orchestration—deciding when to process prompts locally versus offloading heavy reasoning tasks to cloud-hosted Python microservices (built with FastAPI and async worker pools).

Additionally, we tackle practical production trade-offs: balancing memory footprints, handling offline fallbacks gracefully, managing state synchronization between mobile runtimes and Python servers, and preventing battery drain during sustained inference workloads. Attendees will leave with practical blueprints for deploying production-grade, AI-driven mobile solutions.

Introduction & Current Landscape (4 mins): The paradigm shift from cloud wrappers to hybrid edge-cloud mobile architectures.

Production Best Practices & Pitfalls (4 mins): Battery optimization, thermal throttling, memory budgets, and graceful offline fallback.

Interactive Q&A (5-8 mins): Open discussion on mobile AI deployment challenges and tools.

### Key takeaways

Clear architectural blueprints for integrating on-device SLMs with Python-driven cloud services.

Practical knowledge of converting, quantizing, and deploying lightweight AI models on mobile hardware.

Best practices for designing async Python microservices tailored for mobile streaming responses.

Strategies to avoid common pitfalls like memory leaks, battery drain, and poor offline handling.
