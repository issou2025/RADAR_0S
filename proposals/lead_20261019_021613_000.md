# Project Proposal — Bim Modeling

## Project Understanding
You need assistance with: 
**BIM4LCA office doors: Revit's OverallWidth is the door's own extent, 10 mm over its type's Width; 0 of 268 written as Revit's**

*Project description:*
On the BIM4LCA office, rvt-rs writes no door with Revit's `OverallWidth` and `OverallHeight`: 0 of 268 on each file, 198 differing and 70 with none (`door_window_sizes_vs_ifc`, Measure run 39178084272). Core Interior has 132 of 132 and RE1 Architecture 4 of 5 (RE-187).

The RE-187 probe with its scorer on the as-built file (run 39180583664, `-f probe=probe_re187_door_window_sizes -f probe_scorer=door_window_sizes_vs_ifc`) shows why. No candidate the type holds equals Revit's size on any of the 268 doors:

| candidate | equal | differs | not read |
|---|---:|---:|---:|
| width/height (-1001301 / -1001300) | 0 | 198 | 70 |
| rough width/height (-1001305 / -1001304) | 0 | 142 | 126 |
| family Width / Height | 0 | 0 | 268 |

Revit's width is the type's Width plus 10 mm on these Finnish doors. Door 1382481, type 2393450, has a type Width of 3.9370 ft (1,200 mm) and Revit's 3.9698 ft (1,210 mm). Doors 1383546 (800 → 810 mm) and 1409058 (1,800 → 1,810 mm) are the same. Heights equal the type's Height.

Revit's two sizes are the door's own extents:

- In the doors listed, one extent of the element record's box equals Revit's `OverallWidth` and the vertical extent its `OverallHeight`. That holds where the type has a Width (1409058: box 5.9383, Revit 5.9383; 1421116: 3.9698 and 3.9698) and where it has none (703256: box 7.8412 × 6.7093, Revit 7.8412 × 6.7093).
- On Core Interior the type's Width is the door's extent, so the two readings agree there.

Windows: rvt-rs writes no `OverallWidth` or `OverallHeight` on any of the office's 269 windows, and every type candidate differs from Revit's.

To do:

- Measure the door's own extent on all 268 doors. A box in model axes only serves doors along the axes; turned doors need their own frame, as RE-87's instance transform gives.
- Decide between the extent and the type's Width by which agrees with Revit on Core Interior, RE1 and both office files.
- The same for windows.

The rough-width candidate reads a hundredth of the Width on these files, so it is not that parameter here.
