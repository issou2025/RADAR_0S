## Repository problem / structural analogy
README/ROADMAP emphasize rich-model intent, bounded local continuation, fresh-evidence invalidation and YIELD. A human watching a shared desktop may know the task goal yet not know whether the agent is currently allowed to keep moving, typing, retrying, or acting after the planner is silent. A positive-looking screenshot, a completed receipt, or an earlier plan does not reveal the *current* lease, target scope, expiry, revocation, or safe-stop boundary. If the person incorrectly predicts the next possible action, a well-formed runtime can still produce an automation surprise or a late/needless takeover.

Flight deck: mode-dependent behavior with a human supervisor and imperfect feedback. Agent Interface: authority/evidence generation, permitted action class, active hold/cover, expiry, and cancellation can change while a human sees little surface change. Both require the observer to infer what the system may do next and when intervention is needed. The analogy fails because desktop tasks differ in stakes, many agent actions are subsecond and unobservable, and a display cannot make untrusted authority valid.

## Proposed idea: human-predictable autonomy envelope
Investigate an **observation-only, source-bound envelope display** for a declared disposable task, distinct from a plan preview or an authority grant. At each visible checkpoint it reports:
1. current state: MODEL_DECIDING, LOCAL_ACTION_ACTIVE, WAITING_FOR_EVIDENCE, YIELDING, RELEASE_VERIFYING, or TERMINAL/UNKNOWN;
2. narrowly permitted next action *classes* and target/effect footprint, if known;
3. lease/evidence generation and expiry window, with stale or unavailable fields marked UNKNOWN;
4. the event that will stop/revoke local continuation and what physical release has or has not been verified;
5. a separately authenticated takeover/cancel affordance where one actually exists.

The display consumes runtime receipts; it must not synthesize confidence or imply that a currently permitted action will happen, that it succeeded, or that the human consented. A stale display is worse than no display and must visibly expire. Keep agent-facing cues separate from human-facing shared UI. No new actuation path or policy is proposed.

## H / T / D / C / U
- **H:** In a frozen set of low-risk delegated GUI episodes with lease changes and interruptions, a source-bound, expiry-aware autonomy-envelope display improves human prediction of the agent's permissible next action class and correct stop/takeover timing versus goal-only, outcome-only, or static-plan displays, without increasing false confidence that unauthorized or completed effects occurred.
- **T0 (no participants):** Finite no-model state-machine fixture with an independent authority/evidence oracle. Freeze true action set and physical-release state at each checkpoint. Include model wait with valid local cover, revoked target after focus loss, late evidence, lease expiry, active cancel before verified release, harmless re-observation, and unknown actor/effect footprint. Compare envelope display, static plan, last-result receipt and no display. Independently audit that every displayed claim is entailed by current receipts, stale displays expire, and UNKNOWN/release-in-progress is not rendered as “safe/finished.” Mutate generation, expiry and release receipt to test fail-closed presentation. T0 proves only display fidelity, not human comprehension.
- **T1 (conditional):** Separately approved voluntary vignette study using disposable recorded GUI episodes. Randomize/counterbalance display condition and episode order, hold video/task truth fixed, and ask participants at frozen checkpoints to select which actions the agent *may* take next, which effects are already verified, and whether cancel/takeover is currently necessary and effective. Include a seeded unauthorized-action alarm control and a benign continued-work control. Measure set-prediction accuracy, false “agent finished/safe” belief, correct intervention timing, unnecessary interventions, workload and accessibility. Do not recruit or observe real users under this Idea Issue.
- **D:** METHOD_PASS_SCOPED only if T0 matches the independent oracle at every checkpoint, visibly expires stale claims, does not claim physical release before receipt, and rejects all planted corruptions. FAIL_METHOD for any false permission/terminal claim. H_PASS_SCOPED requires preregistered T1 improvement against the strongest eligible simple display at bounded false reassurance and intervention burden; H_FAIL_SCOPED if the display is no better, slower to interpret, or promotes false confidence. HOLD if exact authority/release truth, current receipt delivery, participant consent, or display accessibility is unavailable.
- **C:** The runtime's hard safety gates may be sufficient and humans may rarely monitor local action; a simple explicit “working / stopped” indicator or direct takeover button may dominate richer scope visualization. A detailed display may overload users, creating more mode confusion.
- **U:** Correct prediction in vignettes does not prove live supervision or task benefit. Authority sets may be too dynamic to render at human time scale; network/display lag can make a truthful snapshot misleading. Participants differ in expertise, language and accessibility. A displayed permission is not an action commitment, consent, or effect proof.

## Expected value / cost / handoff
A positive result would add human *mode awareness* as a criterion alongside #57's effect correctness and ROADMAP's human-tempo goals, possibly revealing a cost of opaque local continuation even when it is mechanically safe. A negative result would favor simpler state/stop cues. T0 is a small CPU-only fixture suitable for an exclusive WSLc lane after ownership checks; T1 is higher-cost voluntary human research. T0 result recorded 2026-10-02: the synthetic display-fidelity fixture passed `PASS_METHOD_SCOPED` on PR #6421 (merged to main). This does not validate human comprehension or operational benefit. No T1 participants were recruited and no runtime change was made. Preserve historical outcomes; publish any later evidence additively through reviewed PR.
