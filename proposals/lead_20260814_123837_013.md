# Project Proposal — Flutter App

## Project Understanding
You need assistance with: 
**[Windows] Random crash 0xC0000005 in Dart VM profiler (ProfilerNativeStackWalker) during debug/profile runs**

*Project description:*
### Steps to reproduce

1. `flutter create test` (default counter app, no code changes — any Windows desktop app works)
2. `flutter run -d windows` (debug mode, or `--profile`)
3. Interact with the app (click the counter button repeatedly). Crash happens at random time from a few seconds up to ~1 minute of activity — app silently exits (no error message) or freezes. Passive waiting alone rarely triggers it. No DevTools needed, happens with and without Impeller.

Minimal repro without the flutter tool (confirmed the trigger is the profiler switch):

```powershell
$env:FLUTTER_ENGINE_SWITCHES = "1"
$env:FLUTTER_ENGINE_SWITCH_1 = "enable-dart-profiling=true"
# then launch any debug-built Windows exe directly
# -> access violation 0xC0000005 within ~15-30 s while the UI is actively used
```


### Expected results

Debug and profile runs stay alive; the app can be developed and profiled on Windows.


### Actual results

Random silent crash (0xC0000005 access violation) or UI freeze, ~1 s to ~1 minute after launch, in every debug/profile session. Release mode never crashes. Bisected: the crash is in the Dart VM sampling profiler native stack walker, racing with lazy deopt.


### Code sample

Any `flutter create` default app reproduces it — the crash is in the engine, not app code (reproduced with 2 unrelated projects; identical crash offsets across different exes)
