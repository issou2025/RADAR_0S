# Project Proposal — Flutter App

## Project Understanding
You need assistance with: 
**[BUG] Package cryptography_flutter_plus forces built-in Kotlin after changing to AGP 9**

*Project description:*
### The issues

Flutter created the flag `android.builtInKotlin=false` so developers can migrate to AGP 9 without using Built-in Kotlin. This is to allow projects to migrate to AGP 9 even if some plugins did not yet migrate to support Built-in Kotlin.

However, this plugin does not support the flag `builtInKotlin`. If I upgrade my AGP to version 9, it forces me to use builtInKotlin=true, which means that all my other plugins should already support builtInKotlin, otherwise it won't build. So I'm basically stuck from upgrading to AGP 9 right now.

### The reason why this is happening

The plugin contains this line:
```
if (agpMajor < 9) {
    apply plugin: 'kotlin-android'
}
```

What flutter does is adding the kotlin-android pluging to every package during build time in case builtInKotlin=false, using this check:
```
if (!isBuiltInKotlinEnabled(project, agpVersion) && !pluginState.hasKgpPlugin) {
    pluginManager.apply("kotlin-android")
}
```

And the real issue is how flutter checks if `hasKgpPlugin`, which is by doing a simple regex checking if `apply plugin: 'kotlin-android'` is already there. And in your file it is :D. Unfortunatelly flutter does a very simple text analysis instead of real state check.

So what happens with this plugin, is that KGP is not added, so the `kotlin { ... }` lines below fail to execute. The build fails

### Solution

Just remove this completely
```
if (agpMajor < 9) {
    apply plugin: 'kotlin-android'
}
```
and push the minimum version of flutter to be 3.44, since this is the version where flutter will start applying the KGP when needed

For reference: https://docs.flutter.dev/release/breaking-changes/migrate-to-built-in-kotlin/for-plugin-authors
