# Project Proposal — Bim Modeling

## Project Understanding
You need assistance with: 
**Read key schedule parameters with correct ownership and unset-value semantics**

*Project description:*
### Problem

Key schedule row parameters and key assignments are not fully exposed. A row containing stored values is not enough to determine which parameters belong in the public list, and empty values must not be confused with an unset element reference.

### Expected behavior

Recover the applicable row parameters and assignments through their actual ownership and binding relationships, with the correct value and missing-value semantics.

Use the door key schedules and their row parameters to investigate key assignment and value ownership. A smaller fixture isolating the affected schedule definitions and unset-reference behavior is still needed.

### Acceptance criteria

- [ ] Decode the relationships between key schedules, rows, parameter definitions and assigned elements.
- [ ] Add reduced fixtures for text, boolean and element-reference values.
- [ ] Distinguish an empty string, an unset reference and an unavailable value.
- [ ] Exclude stored fields that are not applicable parameters for the row or assigned element.
- [ ] Add coverage for unassigned keys.
