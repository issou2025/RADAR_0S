**[Phase 1] Parse and validate AAIGrid with explicit NODATA handling**

*Project description:*
## Outcome

Turn an Arc/Info ASCII Grid response into a validated in-memory elevation grid without ever treating a NODATA sentinel as terrain.

## Scope

- Parse the plain-text header and numeric rows using invariant culture.
- Support the valid corner/center origin forms needed by the source and compute cell-center coordinates correctly.
- Preserve north-to-south row orientation explicitly and reject malformed dimensions or sample counts.
- Commit only small, inspected, deterministic fixtures.

## Acceptance criteria

- [ ] Valid grids produce the expected dimensions, coordinates, cell size, and elevations.
- [ ] NODATA cells are represented as missing before statistics or later processing.
- [ ] Malformed headers, missing values, extra values, and inconsistent row/column counts fail clearly.
- [ ] Tests cover coordinate orientation, NODATA holes, numeric parsing, and fixture secret inspection.
- [ ] The repository restore, build, and offline tests pass.
