# Project Proposal — Bim Modeling

## Project Understanding
You need assistance with: 
**Hosted opening quantities use the generic box when the family cut loop is not decoded**

*Project description:*
For some Revit 2021 samples (the rac basic and rac advanced sample projects) and the Revit 2023 build of the rme basic sample project, the opening of a door or window is written as the generic box of the hosted opening, because the family cut loop is not decoded. A window that is 1.5 wide and 2.7 high gets Height 3.0 and Width 6.0. About 950 quantity slots in 7 samples differ from the reference.

Using the size of the door or window as a default was tried and rejected: it fixes 444 slots but makes 68 slots worse where the box carries a decoded cut that is larger than the nominal size.

Needed: record on each opening whether its box comes from a decoded cut or from a bounding box, and use the size of the door or window only for the second kind, so that nothing that is already correct gets worse.
