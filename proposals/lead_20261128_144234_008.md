## Project Understanding
You need assistance with: 
**Add configurable screen-edge spacing and a built-in iOS-style action bar**

*Project description:*
Hi! Thanks for maintaining this package.

It would be helpful to have an option for configuring the action bar’s horizontal distance from the screen edges. Currently, `padding` only affects the bar content, while `keyboardGap` controls the vertical distance from the keyboard. There appears to be no way to set an outer horizontal margin.

More generally, it would be great if the package provided a ready-to-use, native-looking iOS action bar that did not require additional styling. I am not referring to the glass effect, but at least the native shape, spacing, and icons could be provided out of the box.

Keyboard actions are especially useful on iOS, since Android keyboards usually already provide buttons for the necessary actions.

Ideally, developers could use a pre-styled iOS widget with sensible defaults while still being able to customize it when needed.
