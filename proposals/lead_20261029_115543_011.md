# Project Proposal — Flutter App

## Project Understanding
You need assistance with: 
**SelectionArea: rebuilding a Text.rich with WidgetSpans while a selection is active corrupts MultiSelectableSelectionContainerDelegate (_flushAdditions → ensureChildUpdated → _initSelection on a half-built selectables list)**

*Project description:*
### Steps to reproduce

1. Put a `Text.rich` inside a `SelectionArea`. The span contains at least three `WidgetSpan`s whose children are `Text` widgets, with plain text before the first one (for example markdown bullets or inline "pills" in a chat message).
2. Select the text so that the selection starts in the first plain-text fragment. Select all and a mouse drag both work.
3. Change the text of the span while the selection is active, for example by appending streamed text. Any change with `RenderComparison.layout` is enough; a new `WidgetSpan` is not needed.
4. (Follow-up) Remove the `Text.rich` from the tree.

The widget test below reproduces the problem deterministically with `flutter test`. No device is needed.

### Expected results

There are no exceptions. The selection is either kept or cleared consistently.

### Analysis

All of this happens in the `_SelectableTextContainerDelegate` (`StaticSelectionContainerDelegate`) of the outer `Text.rich`. Its selectables are `[f0, W0, f1, W1, f2, W2, f3]`: the paragraph fragments `fN` and the nested `Text` containers `WN`.

1. The selection runs from `f0` to `W2`, so `currentSelectionStartIndex == 0` and `currentSelectionEndIndex == 5`. `_lastStartEdgeUpdateGlobalPosition` and `_lastEndEdgeUpdateGlobalPosition` are set.
2. The text changes, so `RenderParagraph` removes all fragments and re-adds new ones. `_removeSelectable(f0)` decrements `currentSelectionStartIndex` to **-1**. The end index ends up at 2, pointing at `W2` in `[W0, W1, W2]`. The new fragments go into `_additions`.
3. `_flushAdditions` sets `selectables = []` and merges the two lists. Some new fragments fall between `min(start, end) = -1` and `max = 2`, and for each of them it calls `ensureChildUpdated(mergingSelectable)` **while `selectables` is only partly rebuilt**.
4. `StaticSelectionContainerDelegate.ensureChildUpdated` sees `currentSelectionStartIndex == -1` and calls `handleSelectionEdgeUpdate(forStart)` → `_initSelection`. That starts at `oppositeEdgeIndex = currentSelectionEndIndex`, an index into the *old* list, but it runs against the *partial* list. In debug this fails `assert(selectables.isEmpty)`. In release it either returns silently or walks and rewrites indices on the partial list, which leads to the out-of-range reads above. The final `currentSelectionStartIndex/EndIndex = selectionStart/EndIndex` assignment then mixes indices from both lists.

The root cause seems related to #183331: the cached edge positions survive a removal at or before the edge index, and `ensureChildUpdated` replays them. The new part is that `ensureChildUpdated` can call `handleSelectionEdgeUpdate` on the delegate itself during `_flushAdditions`, while `selectables` is in an inconsistent state.

Possible directions:
- Defer the `ensureChildUpdated` calls in `_flushAdditions` until the merge has finished and the indices are final.
- Or clear or invalidate the cached edge state when a removal turns an edge index into -1 (as #183332 tried for #183331).

Related: #184400 (same `_flushAdditions`/`_compareScreenOrder` crash, closed for lack of a repro), #183331, #179527, #151536.

```dart
import 'package:flutter/gestures.dart';
import 'package:flutter/material.dart';
import 'package:flutter_test/flutter_test.dart';

/// Text interleaved with WidgetSpans whose children are themselves `Text`
/// widgets (e.g. markdown bullets or inline "pills" in a chat message).
InlineSpan message(String streamed) => TextSpan(
      children: <InlineSpan>[
        const TextSpan(text: 'Start '),
        const WidgetSpan(child: Text('pill0')),
        const TextSpan(text: ' a '),
        const WidgetSpan(child: Text('pill1')),
        const TextSpan(text: ' b '),
        const WidgetSpan(child: Text('pill2')),
        TextSpan(text: ' end$streamed'),
      ],
    );

Future<List<FlutterErrorDetails>> run(
  WidgetTester tester,
  Future<void> Function() select,
) async {
  final errors = <FlutterErrorDetails>[];
  final originalOnError = FlutterError.onError;
  FlutterError.onError = errors.add;

  var streamed = '';
  var showMessage = true;
  late StateSetter setState;
  await tester.pumpWidget(
    MaterialApp(
      home: Scaffold(
        body: SelectionArea(
          child: StatefulBuilder(
            builder: (BuildContext context, StateSetter s) {
              setState = s;
              return Column(
                children: <Widget>[if (showMessage) Text.rich(message(streamed))],
              );
            },
          ),
        ),
      ),
    ),
  );

  // 1. Select the whole message (selection starts in the first text fragment).
  await select();
  await tester.pump(const Duration(seconds: 1));

  // 2. The message text changes while the selection is active (streaming).
  setState(() => streamed = ' more');
  await tester.pump();

  // 3. The message is removed (e.g. chat cleared / navigated away).
  setState(() => showMessage = false);
  await tester.pump();
  FlutterError.onError = originalOnError;

  for (final FlutterErrorDetails e in errors) {
    final String frames = e.stack
        .toString()
        .split('\n')
        .where((String l) => l.contains('package:flutter/'))
        .take(5)
        .join('\n  ');
    // ignore: avoid_print
    print('${e.exceptionAsString().split('\n').first}\n  $frames\n');
  }
  return errors;
}

void main() {
  testWidgets('select all, then rebuild Text.rich with WidgetSpans', (
    WidgetTester tester,
  ) async {
    final errors = await run(tester, () async {
      tester
          .state<SelectableRegionState>(find.byType(SelectableRegion))
          .selectAll(SelectionChangedCause.keyboard);
    });
    expect(errors, isEmpty);
  });

  testWidgets('mouse drag selection, then rebuild Text.rich with WidgetSpans', (
    WidgetTester tester,
  ) async {
    final errors = await run(tester, () async {
      final Rect rect = tester.getRect(find.byType(RichText).first);
      final TestGesture gesture = await tester.startGesture(
        rect.topLeft + const Offset(1, 5),
        kind: PointerDeviceKind.mouse,
      );
      await tester.pump();
      await gesture.moveTo(tester.getCenter(find.text('pill2')));
      await tester.pump();
      await gesture.up();
    });
    expect(errors, isEmpty);
  });
}
```
