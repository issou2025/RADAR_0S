# Project Proposal — Bim Modeling

## Project Understanding
You need assistance with: 
**Color fill scheme usage report: views, templates, legends per area scheme; safe cleanup of unused schemes**

*Project description:*
## Context

In a live session, a user asked "what is using these?" about 3 color fill scheme names in the Edit Color Scheme dialog: a plain name, the same name + TRUE, and the same name + ARCHIVE. No skill covers color scheme usage, so the agent wrote the query by hand.

## What happened

- Each name occurred 5 times, once for each area scheme. A color scheme for Areas belongs to one area scheme, so the dialog list hides the duplicates.
- Usage came from `View.GetColorFillSchemeId(categoryId)` on every view and view template (Areas, Rooms, Spaces), and from `ColorFillLegend` elements through their owner view. The report also needed each view's template and sheet number.
- Result: only the TRUE schemes were used (69 views, 5 templates, 16 legends). The 10 plain and ARCHIVE schemes had no users, and the user deleted them. The delete guarded that each area scheme kept at least one scheme. Then the user removed "TRUE" from the remaining names.
- Trap: a view template showed one area scheme's color scheme in its settings, but its 12 views belonged to other area schemes, and each one used its own area scheme's color scheme. A report that lists only the template's setting gives the wrong answer for those views.
- Side note: all 5 schemes kept the default legend title "Schema 1 Legend".

## Proposed change

Add a color scheme section to `am-model-health`, or a small read-only skill:

- Per scheme: name, category, area scheme, entry count, legend title, the views that use it (with template and sheet), the templates, and the legends.
- Flags: unused schemes, the same name on several area schemes, default legend titles, and schemes that templates use but no view does.
- Cleanup through `am-safe-change`: delete unused schemes after a recheck, and never delete the last scheme of an area scheme.

## Acceptance ideas

- On a model with 2 area schemes, each with one used and one unused scheme of the same name, the report lists 4 schemes, marks 2 as unused, and shows the area scheme for each.
- Template trap: a view under a template whose scheme belongs to another area scheme is reported with the scheme that the view really uses.

Environment: Windows 11, Revit 2026, pyRevit 7.0.0, Claude Code desktop.
