# Project Proposal — Pdf To Revit

## Project Understanding
You need assistance with: 
**Expose sheets, placed views and 2D presentation data**

*Project description:*
### Goal

Provide the sheet and view presentation data needed to generate printable drawings without a Revit installation.

### Current behavior

The supported public API exposes document elements and model geometry, but does not provide a complete sheet presentation model for drawing export.

### Scope and milestones

- Expose sheet identity, page dimensions, title blocks and placed views.
- Recover viewport position, rotation, scale, crop and view-specific visibility information.
- Expose applicable 2D linework, text, dimensions, tags, images and schedule placement. Distinguish stored presentation data from data that must be generated.
- Start with a documented set of supported views and annotations, then extend coverage.

### Acceptance criteria

- [ ] Add public API access to sheets and placed-view layout with explicit units and coordinate frames.
- [ ] Cover plan, section and elevation placement using reduced or public sample fixtures.
- [ ] Verify scale, rotation, crop boundaries and annotation placement independently of the PDF backend.
- [ ] Report unsupported view or annotation content so downstream exporters can identify incomplete pages.
