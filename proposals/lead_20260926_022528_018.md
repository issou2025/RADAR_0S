## 3. Module Scope & Operational Guides

### 🟢 Module 01: VMware vSAN Deep Dive
* Focuses on next-generation NVMe memory tiering and end-to-end storage policy assignments within VMware Cloud Foundation.

### 🟢 Module 02: Enhanced vSphere Replication
* Focuses on upgrading existing workloads to vSphere Replication 9.0.3+. 
* Guides users through the critical migration steps required to convert older baseline virtual machine replications into the **Enhanced vSphere Replication** engine topology.

### 🟢 Module 03: VMware Data Protection (DR Case Study)

* Covers disaster recovery testing scenarios, running migration workflows, and automating failovers with minimum system disruption.

* Demonstrates infrastructure as code (IaC) drift correction.
* Automates validation controls against industry standard hardening security benchmarks (**CIS** and **DISA STIG**) and manages immediate CVE vulnerability remediations at scale across 10,000+ nodes.
