# Project Proposal — Flutter App

## Project Understanding
You need assistance with: 
**dart:ui Canvas / PictureRecorder / Picture.toImage cannot be used off the root isolate, so batch offscreen rendering blocks the UI thread**

*Project description:*
### Use case

We ship a Flutter-based Android launcher. Every app icon goes through an offscreen composition pipeline before it is shown:

1. Parse the icon's vector drawable into plain data (pure Dart).
2. Record the vector into a `Canvas` (`Path`, `Gradient`, transforms) and rasterize it with `Picture.toImage` at 2x supersampling.
3. Read back pixels with `toByteData` to find the content bounds.
4. Draw a white backing (`drawRect` + `drawImage`), then `toImage` again.
5. Downscale and clip to the theme mask (`clipRSuperellipse` / path with `BlendMode.dstIn`), then `toImage` again.
6. Read back pixels with `toByteData` to compute a background tint.

Opening a folder, switching the theme or first boot loads dozens to hundreds of icons at once. A complex icon takes ~30 ms in this pipeline.

Step 1 moves to `Isolate.run` without problems. Steps 2–6 cannot: `PictureRecorder()`, `Canvas()`, `Path()`, `Gradient.*` etc. all throw `UI actions are only available on root isolate.` when called on a background isolate. So all of this work, plus the `await` round trips for each `toImage` / `toByteData`, runs on the UI isolate and competes with frame building.

### Steps to reproduce

1. `flutter create` an app and replace `lib/main.dart` with the code sample below (no extra dependencies).
2. `flutter run --profile` on a physical Android device.
3. Tap **Try on background isolate**: it throws `UI actions are only available on root isolate.`
4. Drag both sliders to the maximum (120 icons, complexity 4) and tap **Load icons (root isolate)**. Watch the spinner, then read the stats.
5. Switch to **sequential** and tap **Load icons** again.

### Expected results

There is a supported way to record and rasterize a `Picture` off the UI isolate (e.g. `PictureRecorder`/`Canvas`/`Path`/shaders + `Picture.toImage`/`toImageSync` usable from a background isolate, or a dedicated "offscreen rendering" isolate/API). The resulting `ui.Image` (or its GPU texture) can be sent back to the UI isolate. Heavy, non-interactive offscreen work then no longer drops frames.

### Actual results

Measured on a Snapdragon 8 Elite (SM8750) phone, Android, 120 Hz, Impeller/Vulkan, profile mode, Flutter 3.44.4 stable.
120 icons × 80 paths × 120 cubic segments; 360 `toImage` + 240 `toByteData` calls in total:

| Schedule | Wall time (steps 2–6) | UI-thread sync work | Frames / expected | Dropped | Longest UI event-loop stall |
|---|---|---|---|---|---|
| `Future.wait` (all icons concurrently) | 893 ms | 176 ms | 42 / 143 | **101** | **142 ms** |
| Sequential `await` | 3695 ms | 371 ms | 443 / 480 | 37 | 13 ms |

How to read this table:

- **Test setup**: 120 Hz means a frame is due every 8.3 ms. Profile mode performs close to release.
- **Schedules**: `Future.wait` starts all 120 icons together; sequential `await` does one icon at a time.
- **Columns** (lower is better, except frames drawn):
  - *Wall time*: from start until all 120 icons are done.
  - *UI-thread sync work*: time the UI thread spent recording commands and scanning pixels, not counting the waits for `toImage` / `toByteData`.
  - *Frames / expected*: frames actually drawn vs. frames that should have been drawn in that time (a spinner animates every vsync, so every vsync should produce a frame).
  - *Dropped*: expected minus drawn.
  - *Longest UI event-loop stall*: the longest stretch in which the UI isolate could not run even a 1 ms timer.
- **Reading the rows**: concurrent loading finishes in 0.9 s but drops 101 of 143 frames, and the longest stall (142 ms) is about 17 missed frames in a row. Sequential loading keeps the stall at 13 ms, but takes 3.7 s (4× longer) and still drops 37 frames.

- Background isolate: `UI actions are only available on root isolate.`
- Concurrent loading finishes sooner but freezes the UI for ~1 s (70% of frames dropped).
- Sequential loading keeps most frames, but icons take 4× longer to appear and still drop frames.
- Step 1 (parsing, 130–150 ms for 120 icons) already runs on a background isolate, so the remaining cost really is the dart:ui part.

The app has no way out of this trade-off, because the only isolate allowed to record and rasterize is the one that also builds frames.

Root cause in the engine: `UIDartState::ThrowIfUIOperationsProhibited()` (`lib/ui/ui_dart_state.cc`) rejects non-root isolates. `PictureRecorder::Create`, `Canvas::Create`, `Path`, gradients, image/color filters, `Vertices` and `ParagraphBuilder` all call it. Also, `Picture::RasterizeToImage` posts to the single raster task runner and replies on the UI task runner, so batches of `toImage` share one queue with frame rasterization.

// Repro: dart:ui recording (PictureRecorder / Canvas / Path / Gradient) and
// Picture.toImage are only usable on the root isolate, so a batch of
// vector-icon compositions monopolizes the UI thread and drops frames.
//
// The pipeline below mirrors a real launcher theme-icon pipeline:
//   1. parse vector data (pure Dart, CAN run on a background isolate)
//   2. record vector -> Canvas, toImage at 2x supersampling   (root isolate only)
//   3. toByteData readback + content-bounds detection          (root isolate only)
//   4. white backing: drawRect + drawImage -> toImage          (root isolate only)
//   5. mask: superellipse clip / path dstIn -> toImage         (root isolate only)
//   6. toByteData readback for background tint                  (root isolate only)
// Opening a folder or switching theme runs this for dozens of icons at once.

import 'dart:async';
import 'dart:isolate';
import 'dart:math' as math;
import 'dart:typed_data';
import 'dart:ui' as ui;

import 'package:flutter/material.dart';
import 'package:flutter/scheduler.dart';

void main() => runApp(const ReproApp());

class ReproApp extends StatelessWidget {
  const ReproApp({super.key});

  @override
  Widget build(BuildContext context) => const MaterialApp(
        debugShowCheckedModeBanner: false,
        home: ReproPage(),
      );
}

// ---------------------------------------------------------------------------
// Step 1: vector data. Plain data, so it can be built on any isolate.
// ---------------------------------------------------------------------------

/// One path of a parsed vector drawable: cubic segments + fill/stroke style.
class VectorPath {
  VectorPath(this.points, this.colors, this.stroke, this.rotation);

  /// moveTo(x, y) followed by groups of 6 values for cubicTo, in 0..100 space.
  final Float64List points;

  /// Two ARGB colors for a linear gradient.
  final List<int> colors;

  /// 0 means fill, >0 means stroke width.
  final double stroke;

  /// Group rotation in radians, applied around the icon center.
  final double rotation;
}

/// Builds a deterministic "complex icon" (similar in cost to heavily detailed
/// brand icons). Pure Dart: works inside Isolate.run.
List<VectorPath> parseVector(int seed, int pathCount, int segments) {
  final rnd = math.Random(seed);
  return List.generate(pathCount, (_) {
    final pts = Float64List(2 + segments * 6);
    for (var i = 0; i < pts.length; i++) {
      pts[i] = 10 + rnd.nextDouble() * 80;
    }
    return VectorPath(
      pts,
      [0xFF000000 | rnd.nextInt(0xFFFFFF), 0xFF000000 | rnd.nextInt(0xFFFFFF)],
      rnd.nextBool() ? 0 : 0.5 + rnd.nextDouble() * 2,
      rnd.nextDouble() * math.pi,
    );
  });
}

/// Top-level so the closure sent to the isolate captures only these ints.
Future<List<List<VectorPath>>> parseOnBackgroundIsolate(
        int count, int pathCount, int segments) =>
    Isolate.run(() => [
          for (var i = 0; i < count; i++) parseVector(i, pathCount, segments)
        ]);

// ---------------------------------------------------------------------------
// Steps 2-6: drawing and compositing. Every dart:ui call here throws
// "UI actions are only available on root isolate." off the root isolate.
// ---------------------------------------------------------------------------

/// Per-icon timings. `uiSyncUs` is time the UI thread spent in synchronous
/// work (recording, pixel scanning); `awaitUs` is time spent awaiting
/// toImage / toByteData round trips to the raster thread.
class IconStats {
  int uiSyncUs = 0;
  int awaitUs = 0;
  int toImageCalls = 0;
  int readbacks = 0;
}

const int kIconSide = 136; // launcher icon size in px
const int kSupersample = 2;

Future<T> _timedAwait<T>(IconStats s, Future<T> f) async {
  final sw = Stopwatch()..start();
  final r = await f;
  s.awaitUs += sw.elapsedMicroseconds;
  return r;
}

T _timedSync<T>(IconStats s, T Function() body) {
  final sw = Stopwatch()..start();
  final r = body();
  s.uiSyncUs += sw.elapsedMicroseconds;
  return r;
}

Future<ui.Image> composeIcon(List<VectorPath> vector, IconStats s) async {
  final side = kIconSide * kSupersample;

  // Step 2: record vector commands, rasterize at 2x.
  final vectorPicture = _timedSync(s, () {
    final recorder = ui.PictureRecorder();
    final canvas = ui.Canvas(recorder);
    final scale = side / 100.0;
    canvas.scale(scale);
    for (final p in vector) {
      final path = ui.Path()..moveTo(p.points[0], p.points[1]);
      for (var i = 2; i + 5 < p.points.length; i += 6) {
        path.cubicTo(p.points[i], p.points[i + 1], p.points[i + 2],
            p.points[i + 3], p.points[i + 4], p.points[i + 5]);
      }
      path.close();
      final paint = ui.Paint()
        ..isAntiAlias = true
        ..shader = ui.Gradient.linear(
          const ui.Offset(0, 0),
          const ui.Offset(100, 100),
          [ui.Color(p.colors[0]), ui.Color(p.colors[1])],
        );
      if (p.stroke > 0) {
        paint
          ..style = ui.PaintingStyle.stroke
          ..strokeWidth = p.stroke;
      }
      canvas
        ..save()
        ..translate(50, 50)
        ..rotate(p.rotation)
        ..translate(-50, -50)
        ..drawPath(path, paint)
        ..restore();
    }
    return recorder.endRecording();
  });
  final vectorImage =
      await _timedAwait(s, vectorPicture.toImage(side, side));
  vectorPicture.dispose();
  s.toImageCalls++;

  // Step 3: readback + content bounds detection.
  final bytes = await _timedAwait(
      s, vectorImage.toByteData(format: ui.ImageByteFormat.rawRgba));
  s.readbacks++;
  final bounds = _timedSync(s, () => _contentBounds(bytes!, side, side));

  // Step 4: white backing, centered on the detected content.
  final backingPicture = _timedSync(s, () {
    final recorder = ui.PictureRecorder();
    final canvas = ui.Canvas(recorder);
    canvas.drawRect(ui.Rect.fromLTWH(0, 0, side.toDouble(), side.toDouble()),
        ui.Paint()..color = const ui.Color(0xFFFFFFFF));
    canvas.drawImage(
        vectorImage,
        ui.Offset(side / 2 - bounds.center.dx, side / 2 - bounds.center.dy),
        ui.Paint());
    return recorder.endRecording();
  });
  final backed = await _timedAwait(s, backingPicture.toImage(side, side));
  backingPicture.dispose();
  vectorImage.dispose();
  s.toImageCalls++;

  // Step 5: downscale + superellipse mask + coverage-AA path mask.
  final maskPicture = _timedSync(s, () {
    final recorder = ui.PictureRecorder();
    final canvas = ui.Canvas(recorder);
    final dst = ui.Rect.fromLTWH(0, 0, kIconSide.toDouble(), kIconSide.toDouble());
    final r = kIconSide * 16 / 60;
    canvas.saveLayer(dst, ui.Paint());
    canvas.clipRSuperellipse(ui.RSuperellipse.fromRectXY(dst, r, r));
    canvas.drawImageRect(
        backed,
        ui.Rect.fromLTWH(0, 0, side.toDouble(), side.toDouble()),
        dst,
        ui.Paint()..filterQuality = ui.FilterQuality.high);
    canvas.drawPath(
        ui.Path()..addOval(dst.deflate(1)),
        ui.Paint()
          ..isAntiAlias = true
          ..blendMode = ui.BlendMode.dstIn);
    canvas.restore();
    return recorder.endRecording();
  });
  final result =
      await _timedAwait(s, maskPicture.toImage(kIconSide, kIconSide));
  maskPicture.dispose();
  backed.dispose();
  s.toImageCalls++;

  // Step 6: readback for background tint calculation.
  final finalBytes = await _timedAwait(
      s, result.toByteData(format: ui.ImageByteFormat.rawRgba));
  s.readbacks++;
  _timedSync(s, () => _averageColor(finalBytes!));

  return result;
}

ui.Rect _contentBounds(ByteData bytes, int w, int h) {
  var left = w, top = h, right = 0, bottom = 0;
  for (var y = 0; y < h; y++) {
    for (var x = 0; x < w; x++) {
      if (bytes.getUint8((y * w + x) * 4 + 3) > 8) {
        if (x < left) left = x;
        if (x > right) right = x;
        if (y < top) top = y;
        if (y > bottom) bottom = y;
      }
    }
  }
  if (right < left) return ui.Rect.fromLTWH(0, 0, w.toDouble(), h.toDouble());
  return ui.Rect.fromLTRB(left.toDouble(), top.toDouble(), right + 1.0, bottom + 1.0);
}

int _averageColor(ByteData bytes) {
  var r = 0, g = 0, b = 0, n = 0;
  for (var i = 0; i < bytes.lengthInBytes; i += 4) {
    if (bytes.getUint8(i + 3) == 0) continue;
    r += bytes.getUint8(i);
    g += bytes.getUint8(i + 1);
    b += bytes.getUint8(i + 2);
    n++;
  }
  if (n == 0) return 0;
  return 0xFF000000 | (r ~/ n) << 16 | (g ~/ n) << 8 | (b ~/ n);
}

// ---------------------------------------------------------------------------
// What we would like to do: move steps 2-6 to a background isolate.
// ---------------------------------------------------------------------------

/// Tries the smallest possible recording on a background isolate and returns
/// the error text (or "OK" if it ever becomes supported).
Future<String> tryRecordOnBackgroundIsolate() async {
  try {
    final bytes = await Isolate.run(() async {
      final recorder = ui.PictureRecorder(); // throws today
      final canvas = ui.Canvas(recorder);
      canvas.drawCircle(const ui.Offset(8, 8), 8,
          ui.Paint()..color = const ui.Color(0xFF2196F3));
      final image = await recorder.endRecording().toImage(16, 16);
      final data = await image.toByteData(format: ui.ImageByteFormat.png);
      return data!.lengthInBytes;
    });
    return 'OK: background isolate produced a $bytes-byte PNG';
  } catch (e) {
    return 'Background isolate failed:\n$e';
  }
}

// UI: a continuously animating indicator + frame statistics.

enum Schedule { sequential, concurrent }

class ReproPage extends StatefulWidget {
  const ReproPage({super.key});

  @override
  State<ReproPage> createState() => _ReproPageState();
}

class _ReproPageState extends State<ReproPage>
    with SingleTickerProviderStateMixin {
  late final AnimationController _spin =
      AnimationController(vsync: this, duration: const Duration(seconds: 1))
        ..repeat();

  final List<ui.Image> _icons = [];
  int _iconCount = 40;
  int _complexity = 2; // 1..4
  Schedule _schedule = Schedule.concurrent;
  bool _running = false;
  String _report = 'Tap "Load icons" while watching the spinner.';
  String _isolateResult = '';

  // Frame statistics collected while a batch runs.
  bool _collecting = false;
  final List<ui.FrameTiming> _timings = [];

  // Longest stretch the UI event loop could not run a 1 ms timer.
  Timer? _ticker;
  final Stopwatch _tickClock = Stopwatch();
  int _lastTickUs = 0;
  int _maxStallUs = 0;

  @override
  void initState() {
    super.initState();
    SchedulerBinding.instance.addTimingsCallback(_onTimings);
  }

  @override
  void dispose() {
    SchedulerBinding.instance.removeTimingsCallback(_onTimings);
    _ticker?.cancel();
    _spin.dispose();
    for (final i in _icons) {
      i.dispose();
    }
    super.dispose();
  }

  void _onTimings(List<ui.FrameTiming> t) {
    if (_collecting) _timings.addAll(t);
  }

  void _startStallProbe() {
    _maxStallUs = 0;
    _tickClock
      ..reset()
      ..start();
    _lastTickUs = 0;
    _ticker = Timer.periodic(const Duration(milliseconds: 1), (_) {
      final now = _tickClock.elapsedMicroseconds;
      _maxStallUs = math.max(_maxStallUs, now - _lastTickUs);
      _lastTickUs = now;
    });
  }

  Future<void> _loadIcons() async {
    if (_running) return;
    for (final i in _icons) {
      i.dispose();
    }
    setState(() {
      _icons.clear();
      _running = true;
      _report = 'Loading...';
    });
    // Let the cleared grid render before measuring.
    await Future<void>.delayed(const Duration(milliseconds: 100));

    final pathCount = 20 * _complexity;
    final segments = 30 * _complexity;

    // Step 1 is pure data, so it can already go to a background isolate.
    final parseSw = Stopwatch()..start();
    final vectors = await parseOnBackgroundIsolate(_iconCount, pathCount, segments);
    parseSw.stop();

    _timings.clear();
    _collecting = true;
    _startStallProbe();
    final total = Stopwatch()..start();
    final stats = List.generate(_iconCount, (_) => IconStats());

    Future<void> one(int i) async {
      final img = await composeIcon(vectors[i], stats[i]);
      if (!mounted) {
        img.dispose();
        return;
      }
      setState(() => _icons.add(img));
    }

    if (_schedule == Schedule.sequential) {
      for (var i = 0; i < _iconCount; i++) {
        await one(i);
      }
    } else {
      await Future.wait([for (var i = 0; i < _iconCount; i++) one(i)]);
    }
    total.stop();

    // Collect the trailing frames too.
    await Future<void>.delayed(const Duration(milliseconds: 300));
    _collecting = false;
    _ticker?.cancel();
    final windowUs = _tickClock.elapsedMicroseconds;

    // The spinner animates every vsync, so any missing frame was dropped
    // because the UI thread was busy, not because nothing needed painting.
    final refreshRate =
        ui.PlatformDispatcher.instance.views.first.display.refreshRate;
    final expectedFrames = (windowUs * refreshRate / 1e6).round();
    final dropped = math.max(0, expectedFrames - _timings.length);
    final builds = _timings.map((t) => t.buildDuration.inMicroseconds).toList();
    final uiSync = stats.fold<int>(0, (a, s) => a + s.uiSyncUs);
    final toImages = stats.fold<int>(0, (a, s) => a + s.toImageCalls);
    final readbacks = stats.fold<int>(0, (a, s) => a + s.readbacks);
    final perIcon = stats.map((s) => s.uiSyncUs + s.awaitUs).toList()..sort();

    setState(() {
      _running = false;
      _report = [
        'icons: $_iconCount  paths/icon: $pathCount  segments/path: $segments  '
            'schedule: ${_schedule.name}',
        'step 1 parse on background isolate: ${parseSw.elapsedMilliseconds} ms (off UI thread)',
        'steps 2-6 on root isolate: wall ${total.elapsedMilliseconds} ms, '
            'UI-thread sync work ${uiSync ~/ 1000} ms',
        'toImage calls: $toImages   toByteData readbacks: $readbacks',
        'per-icon latency p50/max: ${perIcon[perIcon.length ~/ 2] ~/ 1000} / '
            '${perIcon.last ~/ 1000} ms',
        'frames: ${_timings.length} / expected $expectedFrames '
            '@${refreshRate.round()} Hz -> dropped $dropped',
        'max frame build: ${builds.isEmpty ? 0 : builds.reduce(math.max) ~/ 1000} ms',
        'longest UI event-loop stall: ${_maxStallUs ~/ 1000} ms',
      ].join('\n');
    });
  }

  Future<void> _tryIsolate() async {
    setState(() => _isolateResult = 'Running...');
    final r = await tryRecordOnBackgroundIsolate();
    setState(() => _isolateResult = r);
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('dart:ui on background isolate')),
      body: Padding(
        padding: const EdgeInsets.all(12),
        child: Column(
          crossAxisAlignment: CrossAxisAlignment.stretch,
          children: [
            Row(children: [
              RotationTransition(
                turns: _spin,
                child: const Icon(Icons.autorenew, size: 48, color: Colors.blue),
              ),
              const SizedBox(width: 12),
              const Expanded(child: LinearProgressIndicator()),
            ]),
            const SizedBox(height: 8),
            Row(children: [
              const Text('icons'),
              Expanded(
                child: Slider(
                  value: _iconCount.toDouble(),
                  min: 8,
                  max: 120,
                  divisions: 14,
                  label: '$_iconCount',
                  onChanged: _running
                      ? null
                      : (v) => setState(() => _iconCount = v.round()),
                ),
              ),
              const Text('complexity'),
              Expanded(
                child: Slider(
                  value: _complexity.toDouble(),
                  min: 1,
                  max: 4,
                  divisions: 3,
                  label: '$_complexity',
                  onChanged: _running
                      ? null
                      : (v) => setState(() => _complexity = v.round()),
                ),
              ),
            ]),
            SegmentedButton<Schedule>(
              segments: const [
                ButtonSegment(value: Schedule.sequential, label: Text('sequential')),
                ButtonSegment(value: Schedule.concurrent, label: Text('Future.wait')),
              ],
              selected: {_schedule},
              onSelectionChanged:
                  _running ? null : (s) => setState(() => _schedule = s.first),
            ),
            const SizedBox(height: 8),
            Row(children: [
              Expanded(
                child: FilledButton(
                  key: const Key('load'),
                  onPressed: _running ? null : _loadIcons,
                  child: const Text('Load icons (root isolate)'),
                ),
              ),
              const SizedBox(width: 8),
              Expanded(
                child: OutlinedButton(
                  key: const Key('isolate'),
                  onPressed: _tryIsolate,
                  child: const Text('Try on background isolate'),
                ),
              ),
            ]),
            const SizedBox(height: 8),
            Text(_report, style: const TextStyle(fontFamily: 'monospace', fontSize: 12)),
            if (_isolateResult.isNotEmpty)
              Text(_isolateResult,
                  style: const TextStyle(
                      fontFamily: 'monospace', fontSize: 12, color: Colors.red)),
            const SizedBox(height: 8),
            Expanded(
              child: GridView.count(
                crossAxisCount: 6,
                mainAxisSpacing: 6,
                crossAxisSpacing: 6,
                children: [for (final i in _icons) RawImage(image: i)],
              ),
            ),
          ],
        ),
      ),
    );
  }
}
