## 1. Ecosystem Overview

The generative UI ecosystem is transitioning from experimental demos to production infrastructure. Three of the four tracked projects show heavy 24-hour activity — a2ui (67 items touched), CopilotKit (32), OpenUI (13) — while vercel-labs/json-render recorded none, underscoring the divide between full framework ecosystems and single-purpose spec libraries. - **Most deliberate: OpenUI.** Zero merges but tightly sequenced stacked PRs gated on backend deployments — intentional, not stagnant. Community energy is inbound ecosystem expansion (renderers, plugins) rather than support load, a healthy pattern for a UI framework, though both community issues await a maintainer response.
- **Maturity ranking (operational):** CopilotKit (release cadence, security process — albeit with a 12-day lag — major-version planning) > OpenUI (product coherence, small bus factor) > a2ui (pre-1.0, spec governance ahead of operational hygiene) > json-render (indeterminate today).

## 6. Trend Signals

1. **MCP Apps is consolidating as the standard surface for agent UIs.** Two independent projects built for it in the same 24h window. Treat MCP Apps compatibility as a near-term requirement, not an option.
2. **Security is the gating factor for production adoption.** The recurring failure modes are unauthenticated endpoints in reference/showcase deployments (CopilotKit #8269) and sandbox/privilege escapes via nesting (a2ui #3774). Action: audit embed surfaces and treat sample code as production code.
3. **Auditability is becoming a purchase criterion.** Provenance (#1544), telemetry (v1.90.0), and structured errors (#4019) are being built by every active project — budget for these features when designing generative UI stacks.
4. **The renderer ecosystem is escaping the web.** .NET/Blazor, SwiftUI, Flutter, and React Native are all in play; spec-based formats (OpenUI Lang, A2UI catalogs) are attracting third-party renderer authors. Format-over-framework strategies are being validated.
5. **Generation is shifting from prompt-driven to data-grounded and multi-agent.** Agents must inspect data/tools before designing (OpenUI #1686/#1678); chat agent + specialist UI agent pipelines are the emerging architecture.
6. **Expect API churn.** OpenUI's `@openuidev/intelligent-ui-library` packaging migration (#1681/#1682) and CopilotKit 2.0 will both force migrations in the next quarter; lock versions and plan migration overhead.

**Reference value for technology selection:** choose **a2ui** if you need a renderer-agnostic protocol spanning web and native; **OpenUI** if AI-generated dashboards/data artifacts are the product; **CopilotKit** if embedding agents into existing multi-framework applications with a commercial support path. All three warrant a security review before production deployment today.
