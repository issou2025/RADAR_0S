**Optimize Geometry.Spatial.Query.Difference(Mesh3D, IEnumerable<PolygonalFace2D>) for large polygon sets via spatial partitioning / chunking**

*Project description:*
## Problem Description

In GIS, architectural, and urban modeling workflows (e.g. `DiGi.GIS.WebAPI.UI` and `DiGi.CityGML`), terrain ground meshes (`Mesh3D`) spanning several square kilometers ($10,000\text{--}50,000$ triangles) are subtracted against collections of 2D/3D building footprints (`IEnumerable<PolygonalFace2D>`) to cut out ground surfaces beneath building foundations.

When processing large numbers of dense buildings ($N > 250\text{--}500$ footprint polygons):
1. **Delaunay Constraint Enforcement Failure:** Feeding all polygons globally into NetTopologySuite's `ConformingDelaunayTriangulationBuilder` triggers an excessive recursion / constraint-splitting loop, throwing:
   ```
   NetTopologySuite.Triangulate.ConstraintEnforcementException: Too many splitting iterations while enforcing constraints.
      at NetTopologySuite.Triangulate.ConformingDelaunayTriangulator.EnforceConstraints()
      at NetTopologySuite.Triangulate.ConformingDelaunayTriangulationBuilder.Create()
      at DiGi.Geometry.Planar.Query.Triangulate(Polygon polygon, Double tolerance)
      at DiGi.Geometry.Spatial.Query.Difference(Mesh3D mesh3D, IEnumerable`1 polygonalFace2Ds, Double tolerance)
   ```
2. **Computational Scaling & High Latency:** Without spatial pruning, computing global intersections of thousands of polygon constraints against thousands of mesh triangles takes $15\text{--}60+\,\text{seconds}$, creating latency bottlenecks in interactive and WebAPI pipelines.
3. **Cascading Failure:** If a single degenerate or touching polygon sliver causes a triangulation failure, the entire global difference operation fails.

---

## Proposed Solution & Architecture

### 1. Spatial Partitioning & Localized Chunk Difference (QuadTree / STRtree)
- Instead of feeding all $N$ polygons and $M$ triangles into a single global Delaunay triangulation:
  - Subdivide the `Mesh3D` into a regular spatial grid (or index mesh faces into an R-Tree / STRtree).
  - Index the input `PolygonalFace2D` bounding boxes.
  - For each local spatial tile/chunk ($50\text{--}100\,\text{m}$ cell), collect only the intersecting polygons ($N_{\text{local}} \le 20$).
  - Execute `Difference` on each isolated local tile.
  - Stitch the resulting cut mesh tiles into the final output `Mesh3D`.

### 2. Polygon Pre-Union & Simplification
- Detect touching or overlapping footprint polygons within each local cell and compute `UnaryUnion` / `Union` to eliminate micro-gap slivers and duplicate collinear segment constraints that trigger NTS splitting loops.

### 3. Per-Chunk Fault Tolerance & Resilient Fallback
- Isolate triangulation operations per local tile inside `try/catch` guards.
- If a specific local polygon cluster encounters a `ConstraintEnforcementException`, retain the uncut local mesh tile while successfully cutting all surrounding valid tiles.
