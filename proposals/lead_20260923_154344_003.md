# Project Proposal — Dwg To Revit

## Project Understanding
You need assistance with: 
**Update load-point and CPT geometry from CAD/BIM deliverables**

*Project description:*
## Goal

Use a CAD/BIM deliverable as a source of **precise locations** for load points and/or CPTs. In particular, update the coordinates of load points that already have design loads from a calculation source.

## Source responsibilities

- CAD/BIM provides geometry, positions, and identifiers needed to match objects. It is **not** the source of FEd.
- FEd comes from a calculation program such as the existing RFEM import. Other calculation-source options, for example Open Calculations Studio, may be supported later and should remain separate from the geometry import.
- Foundation advice and pile resistances remain separate sources as well.

## Desired behavior

- Import a supported CAD/BIM deliverable directly, preview recognized load-point/CPT objects and their mapped coordinates, then match them to project objects using stable identifiers or an explicit reviewed mapping.
- For matched load points, update precise coordinates without replacing FEd or other calculation-derived values. Keep existing project identity and explain any downstream recalculation caused by moved points (for example CPT selection or grouping).
- For matched CPTs, update their locations without silently breaking their identifiers, foundation-advice links, or manual selection references.
- Show unmatched, duplicate, ambiguous, and moved objects before applying the import. Do not silently create duplicate load points or overwrite loads.
- Preserve coordinate reference, units, transformations, and source provenance so a later refresh is reproducible.
- Treat an applied geometry update as a project change with undo/redo and persistence. Keep existing spreadsheet/RFEM imports available.

## Acceptance direction

For one selected and documented deliverable format, a user can match existing calculation-sourced load points to CAD/BIM objects and update their coordinates. Their FEd values remain unchanged, and the preview makes moved/unmatched points visible. CPT coordinates can be imported or updated when the deliverable contains identifiable CPTs. Reimporting the same source does not silently duplicate objects.

## Design questions for implementation

- Which real-world deliverable and format should be supported first (for example IFC, DXF/DWG, or a Revit-origin export)? Obtain representative files before choosing an importer.
- Which object identifiers, layers, blocks, or properties reliably match CAD/BIM objects to RFEM load points and project CPTs?
- How should model coordinates, project origin, units, and rotations be transformed into project coordinates?
- Should geometry-only objects be staged when no matching calculation-sourced load point exists, or should the import only update existing points?
- Which recalculations and warnings are needed after load points or CPTs move?
- Which additional calculation-source profiles, potentially including Open Calculations Studio, should provide FEd in a separate workflow?
