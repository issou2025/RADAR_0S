# Project Proposal — Bim Modeling

## Project Understanding
You need assistance with: 
**ExecuteRevitCode crowds out the specialized commands, so they go untested**

*Project description:*
Not a defect — an observation from the 1.5 field test (#96) that explains one, and predicts the next.

## What was observed

With C# execution switched on, the agent reached for `ExecuteRevitCode` by default. It can do everything the specialized read commands do, plus arbitrary logic, in one call and with no schema to learn. The session log bears this out: roughly **twenty** `ExecuteRevitCode` invocations against a handful of calls to everything else.

That is rational behaviour from the agent's side. The consequence is not.

## The consequence

`GetElements` was completely broken for the entire session (#98) and the agent worked around it rather than being blocked by it. The command reached a release candidate broken because the one tool that would have exercised it had a strictly more capable alternative sitting next to it.

Generalised: **the specialized commands are the ones that carry the schemas, the descriptions, the validation and the safety flags — and they are the ones an agent skips when a general-purpose escape hatch is available.** So the surface that is most carefully designed is the surface that gets least exercise, and its breakage surfaces late.

## Things that would help, roughly in order of cost

- **A test that calls each MCP command for real.** The cheapest fix and the one that would have caught #98. It does not need Revit for all of them, but the ones that do need a machine with it.
- **Say something in the tool descriptions.** `ExecuteRevitCode` could state that a specialized command should be preferred where one exists — a nudge, not a rule, and it costs one sentence.
- **Consider what "on" should mean.** Code execution is off by default and only a person can enable it, which is right. But once enabled it is enabled for everything, and there is no notion of "prefer the safe path". Not obviously worth solving; noted so the decision is deliberate rather than accidental.

Related: #98 (the command that this hid), #84 (MCP ergonomics).
