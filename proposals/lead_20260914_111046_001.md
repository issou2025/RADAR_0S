# Project Proposal — Bim Modeling

## Project Understanding
You need assistance with: 
**install.ps1: rollback across Revit years on failure**

*Project description:*
## Context

`install.ps1` installs the add-in for several Revit years in one run. If a later year fails (file locked, missing asset), earlier years stay installed and the script exits with an error: the machine ends up half-updated with no way to return to the previous state.

## Proposal

- Stage all years first, then commit; on any failure, restore the previous `RevitModelMcp` folders and manifests from a backup taken before the first copy.
- Print a summary table at the end: year, previous version, new version, status.
- `-WhatIf` support that lists what would change.

## Acceptance criteria

- Pester tests (or a scripted check in CI on windows-latest) for: success across two years; failure on the second year restores the first.
- `docs/` installation section mentions rollback.

## Pointers

- `install.ps1`
- The MSI installers are unaffected; this is about the script path only.

Good first issue for PowerShell contributors; no Revit needed for the test, the script only copies files.
