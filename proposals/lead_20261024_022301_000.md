# Project Proposal — Bim Modeling

## Project Understanding
You need assistance with: 
**Domain gap: transforms and groups — mirror, array, create/ungroup/place groups, move whole groups**

*Project description:*
## Goal

Round out the element-editing group. Move, copy, rotate, align and elevation exist; mirror and array do not, and groups are only a blocker (`MoveElementsService` reports `InGroup`, `CopyElementsService` copies one member and notes it). Add:

| Tool | Permission | Purpose |
|---|---|---|
| `revit_preview_mirror_elements` / `revit_mirror_elements` | ReadOnly / RequiresApproval | Mirror across a plane given by two points in a view (or an axis + point), copy or move |
| `revit_preview_array_elements` / `revit_array_elements` | ReadOnly / RequiresApproval | Linear or radial array as plain copies (default) or as a Revit array group |
| `revit_list_groups` | ReadOnly | Model and detail group types with instance counts, members, and whether instances are mixed (edited) |
| `revit_preview_create_group` / `revit_create_group` | ReadOnly / RequiresApproval | `doc.Create.NewGroup(ids)` with a name; refuses mixed model/detail sets and explains |
| `revit_ungroup` | RequiresApproval | `Group.UngroupMembers()` for instances or every instance of a type (`deleteType` optional, destructive branch) |
| `revit_place_group_instances` | RequiresApproval | `doc.Create.PlaceGroup(point, groupType)` at points, with rotation |
| (change) `revit_move_elements`, `revit_rotate_elements`, `revit_copy_elements` | — | Accept a **group instance** id and move/rotate/copy the whole group instead of reporting `InGroup` |

## Why

Symmetric rooms, repeated luminaire rows and sockets per workstation are everyday patterns; today the agent emits dozens of absolute coordinates for `revit_place_family_instances` instead. Groups are how the company reuses a classroom's EN layout, and the connector cannot create or place one.

## Design

### Mirror

Arguments: `elementIds[]` (≤ 2 000), plane: `{viewId?, fromMm {x,y}, toMm {x,y}}` (a line in the view's plane → vertical mirror plane through the line, the common case) or `{axis: x|y|z, throughMm {x,y,z}}` or `{pointMm, normal}`; `copy` (default true — Revit's mirror-copy; `false` moves), `atomic` (default true), `skipPinned` (default true). Plane math in `MirrorMath` (pure): plane from two points in a view (`View.RightDirection/UpDirection` frame via `MoveElementsService.FrameOf`), from axis+point, or explicit; mirrored position preview of each element's tracking point (`MoveElementsService.TrackingPoint`) so the preview can list where things land. Execution: `ElementTransformUtils.CanMirrorElements(doc, ids)` first; `ElementTransformUtils.MirrorElements(doc, ids, Plane.CreateByNormalAndOrigin(normal, origin), copy)` returns the new ids (2024+ signature returns `IList<ElementId>`), one transaction via `RevitTransactionRunner.Run`. View-specific elements: the view must be the owner view; model elements with a vertical plane only unless `allowHorizontalPlane=true` (flipping a device upside down is almost always a mistake). Families that are not mirrorable (`FamilyInstance.CanFlipFacing`? no — `Mirrored` state becomes true; some families forbid mirroring via `family.CanMirror`? not in API; rely on `CanMirrorElements` and per-element try/catch) are reported. Result: `{mirrored|moved, newIds[], pairs[] {sourceId, newId, fromMm, toMm}, skipped[]}`.

### Array

Arguments: `elementIds[]`, `kind` = `linear` | `radial`, linear: `count` (2–200), `spacingMm {x,y,z}` or `totalMm` (spread between first and last) in model axes or `deltaRightMm/deltaUpMm` in a view (`FrameOf`); radial: `centerMm`, `axis` (default z), `count`, `angleDeg` per step or `totalAngleDeg`, `rotateElements` (default true); `asGroup` (default **false**: plain copies with `CopyElementsService` so every copy is independent — the agent's normal need; `true`: `LinearArray.Create(doc, view?, ids, count, ArrayAnchorMember.Second, ...)` / `RadialArray.Create(...)` producing a Revit array with its parameter), `includeOriginal` (default true: count includes the source), `atomic`. Pure `ArrayMath` computes the N transforms (translation, or rotation about the axis + optional element rotation). Execution: plain copies through `CopyElementsService.CopySet` per transform (model or view path chosen as that service does), rotation per copy via `ElementTransformUtils.RotateElements` about the array axis; result lists copies per step. Array groups via `LinearArray`/`RadialArray` static creators with the view when all elements are view-specific. Collision with existing elements is not checked (say so).

### Groups

- `revit_list_groups`: `GroupType` collector (`OST_IOSModelGroups`, `OST_IOSDetailGroups`, attached detail groups) → `{groupTypeId, name, kind: model|detail|attachedDetail, instanceCount, memberCount (from the first instance), memberCategories, hasMixedInstances}`; `nameContains`, `kind` filters. Optional `includeMembers` for one named type (member ids and categories of the first instance).
- `revit_create_group`: `elementIds[]`, `name` (unique against existing `GroupType` names via a `ResolveUniqueName`-style helper), `kind` auto-detected: all model elements → model group; all view-specific in one view → detail group; mixed → `validation_failed` naming the offenders (Revit would create an attached detail group only through the UI). `doc.Create.NewGroup(ICollection<ElementId>)` then `group.GroupType.Name = name`. Pinned or already-grouped members block (`element.GroupId`). Preview lists members per category, the kind, the resulting name, blockers.
- `revit_ungroup`: `groupIds[]` (instances) or `groupType` (name/id → every instance), `deleteTypeWhenEmpty` (default false). `Group.UngroupMembers()` returns member ids per instance; one transaction. Approval summary states instance count and member count. Deleting the type is the destructive branch: route it through `revit_delete target=elements` semantics (manual approval) by making `revit_ungroup` with `deleteTypeWhenEmpty=true` a `DestructiveRequiresManualApproval` sibling tool `revit_ungroup_and_delete_type`; keep the default tool `RequiresApproval`.
- `revit_place_group_instances`: `groupType` (name/id), `placements[] {pointMm, rotationDeg?, viewId? (detail groups), levelOverride?}` ≤ 500; `doc.Create.PlaceGroup(XYZ, GroupType)`, rotate with `RotateElement` about Z at the point; detail groups need the view: `PlaceGroup` is model-only, so for detail groups use `doc.Create.PlaceGroup(point, groupType)` after setting the active view? Not possible from the API thread — implement detail-group placement by **copying an existing instance** with `CopyElementsService` (view path) and translating; the result says which path was used. Preview resolves the type, kind, and the host level per point (`PlacementHelpers.NearestLevel`).

### Whole-group moves (change to existing tools)

`MoveElementsService.BuildPlans`: when `elementId` is a `Group` instance, plan the move on the group (location point = `Group.Location`), status `Ready`; when it is a **member**, keep `InGroup` but add the group id and the hint "pass the group id to move the whole group". Same in `RotatePlanner` and `CopyElementsService` (copy a group instance → `CopyElements` on the group id, which Revit supports). Add `MoveStatus.GroupMoved` for clarity in results. Tests for `MoveElementsMath` keep passing; new cases cover the group path.

### Status codes

`mirror_not_allowed` (data: ids `CanMirrorElements` rejected), `group_members_mixed`, `group_type_not_found`, `array_count_out_of_range`.

## Acceptance criteria

- Mirror produces the same result as Revit's Mirror – Pick Axis along the given line; non-mirrorable elements are listed, not silently dropped; horizontal planes need an explicit flag.
- Arrays as copies create exactly `count` elements including or excluding the original as asked, each independent; `asGroup` creates a Revit array whose count parameter equals `count`.
- Group creation refuses mixed sets with the offending ids; placement of a model group lands at the point with the given rotation on the nearest level.
- Passing a group instance id to move/rotate/copy acts on the whole group; passing a member still reports `InGroup` with the group id.
- Unit tests green, both targets build, benchmark report committed.
