## 3. Reseed — needs the prod host

`POST /api/intake/activity` returns **401** from outside; the auth middleware sits on the edge and `scripts/batch.py` has no way to present a credential. Run it from inside the host so it reaches the backend directly:

```bash
python scripts/batch.py --api http://localhost:8001 --limit 40 --max-dispatch 3 --yes
```

`--max-dispatch` is a hard stop on live Auto dispatches; `require_review` and `block` never dispatch and are free. Needs `SUPABASE_DB_PROJECT_URL` / `SUPABASE_URL` and the key in the environment — it pulls the activity rows back through the live integration rather than off disk.

Please do not reimplement the posting loop elsewhere. It joins the source tables and computes `icp_score` from the seeded scoring config; a hand-rolled version would post different facts, which is the one thing this build must not do.
