## 7. 开发者痛点

- **CI 不稳定：** 托管代理门禁、E2E 测试和 SDK Java 通道出现多起"未识别到测试"失败（issues #14724、#15173、#14104、#13009）。本地测试通过但 CI 失败，暗示存在环境相关的 flaky 问题。
- **发布流水线阻塞：** 发布后扇出等待 GitHub runner 耗时 37-50 分钟（#15465）。SDK 发布因集成超时被阻塞（#15498）。
- **上下文压缩缺陷：** 自动压缩导致待处理工具结果重复计算（#15486），导致请求以 `max_tokens: 1` 发送。
- **内存钩子回归：** PR #14129 在追加目录快照后引入了去重功能破坏（#15552）。
- **提供商兼容性问题：** Anthropic Claude 5.5 模型不支持 `tool_choice: any`，导致 JSON 侧查询失败（#15542）。
- **Maven 速率限制：** ecs-qwen 池上的 SDK Java 通道遭遇 Maven Central 速率限制，任务在测试运行前就已失败（#15546）。
- **模型列表陈旧：** 百炼 Token Plan 模型与 `/auth` 显示不同步，导致图像/视频生成失败（#8432）。
