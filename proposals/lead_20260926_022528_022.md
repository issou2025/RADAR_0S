## ExecSurface is looking for early adopters

A source diff can show that code or a dependency changed. It does not by itself show which new external runtime effects appeared.

ExecSurface learns an accepted runtime execution surface, runs the same workflow later, and reports observed drift such as:

```text
+ EXEC     /usr/bin/curl
+ NETWORK  telemetry.example.com:443
+ READ     $HOME/.ssh/config
```

It then applies an explicit policy and returns:

`PASS / REVIEW / BLOCK / ERROR`

## Good first integrations

- dependency-update CI;
- build/test pipelines;
- developer tools;
- Rust/Python/Node test workflows on Linux x86_64;
- AI tooling that launches subprocesses;
- security-sensitive automation where new process/file/network behavior should be reviewed.

## Boundary

It does not prove that software is safe, malicious, or vulnerability-free.
