# Project Proposal — Bim Modeling

## Project Understanding
You need assistance with: 
**Feature Request: Native Metric System Support**

*Project description:*
Dear @Swichllc,

First of all, thank you for creating and maintaining the Wood Framing extension for pyRevit. It's an incredibly useful tool, and I've been using it extensively in my daily workflow.

The Issue
I'm writing to request official support for the metric system (millimeters/centimeters) in the Wall Framing tool. Currently, the extension appears to be hard-coded for the imperial system (inches/feet), which creates several challenges for users outside the US:

Incorrect calculations – When setting stud spacing to 400mm or 600mm, the resulting spacing is incorrect (the tool still calculates in inches)

Wrong blocking sizes – Blocking pieces come out as 561.9mm instead of the expected 550mm

User confusion – The interface shows metric labels (400mm, 600mm) but the internal calculations remain in imperial units

Proposed Solution
I would like to suggest adding a unit toggle that would allow users to switch between Imperial and Metric systems. This could be implemented as:

A global setting in the extension's configuration

A dropdown selector in the Wall Framing dialog

Detection of the project's base units (if possible)

What I've Already Tried
As a temporary workaround, I've been manually converting values and making local edits to the source code. However, this is not sustainable, and I believe other users would greatly benefit from official metric support.

My Experience
I've already successfully adapted the script for metric use by:

Converting spacing values (400mm, 600mm)

Adjusting blocking calculations

Updating the mid-plate interval to 2400mm

I'd be happy to share my modifications and testing results if that would be helpful.

Why This Matters
With the growing international user base of pyRevit, supporting both measurement systems would make this excellent extension accessible to a much wider audience.

Would you consider adding native metric system support in a future update? I'm willing to help with testing or even contribute code if needed.

Thank you for your time and consideration!

Best regards,
