## Defect ledger

1. `Packages/HermesKit/Package.swift:21` processes a nonexistent `Fixtures` resource.
2. `Packages/HermesKit/Sources/HermesKit/JSONRPC.swift` calls `KnownKeys.allCases` twice, but both `KnownKeys` enums omit `CaseIterable`: a definite compile error.
3. `App/TalariaWatchWidgets/WatchWidgetsBundle.swift:52` uses nonexistent `.accessoriesCircular`; the correct case already appears earlier in the file.
4. `Tests/TalariaUITests/LaunchPerformanceUITests.swift:28` applies `try` to a nonthrowing `clock.measure` closure, violating zero-warnings under Tier B.
5. Swift language/tool settings disagree: the package and SwiftFormat use 5.10, XcodeGen uses 6.0, and the intended toolchain is 6.3.
6. `protocol/methods.json` is not regeneration-identical to the available Hermes source: 58 source-location arrays drift, although names/routes and other metadata remain identical. The catalog records no source SHA.
7. `scripts/derive_protocol.py` claims `hermes_cli/web_server.py` as an input but never reads it, does not require all declared inputs, and deduplicates REST routes by path rather than `(method, path)`.
8. Generated event tests encode event names as bare JSON-RPC methods instead of the derived wire shape `method: "event"` plus `params.type`.
9. Generator/checker collapse request and event namespaces. `session.title` and `session.usage` occur in both, so 224 catalog entries produce only 222 tests and omit both event-shaped cases.
10. Generator writes omit explicit UTF-8; normal regeneration on Windows fails on a generated Unicode character.
11. G3 passes vacuously with zero fixture files or frames; the fixture directory does not exist.
12. G3's Python checker accepts any canonical JSON value rather than requiring a valid JSON-RPC envelope.
13. G3's determinism check rewrites the real generated Swift file and does not restore it on drift.
14. `scripts/capture_golden.py` fails on its first request ID because the walrus-assignment lambda raises `UnboundLocalError`.
15. The capture harness promises sanitization but contains no sanitizer and never emits fixtures consumable by G3.
16. The capture harness does not prove ownership of its endpoint or spawned child before driving it, and forwards the full ambient environment into the child.
17. `docs/PROTOCOL.md` and `docs/GOVERNANCE.md` are missing despite citations; `docs/BRIEF.md` required by the operating contract is also absent. `qa/` is cited but absent.
18. Fixture documentation and code disagree: README names root `Tests/Fixtures/`; Package.swift/checker expect `Packages/HermesKit/Tests/HermesKitTests/Fixtures`; neither exists.
19. Generated `scripts/__pycache__/check_conformance.cpython-311.pyc` is tracked, and `.gitignore` lacks `__pycache__/`/`*.pyc` coverage.
20. The extracted working tree reports a mode-only `scripts/gauntlet.sh` regression `100755 -> 100644`. The archive and Git index retain `100755`; this is a staging hazard, not archive corruption.
21. G6 is ineffective: `.gitignore` excludes `*.xcodeproj`, no Xcode project is tracked, and `git diff -- Talaria.xcodeproj` cannot detect ignored/untracked generated output.
22. Tier B writes many `.gauntlet/*` files in fresh checkouts without creating `.gauntlet/`, so jobs fail independently of build correctness.
23. G13 requires a watch app embedded in the iOS archive, but `project.yml` does not attach `TalariaWatch` to the `Talaria` target.
24. At audit time the remote exposed no intended `main` base. Post-audit, local `main` at `a4b0581` was published, made default, and draft PR #1 was opened from `codex/phase-0-handoff`.
