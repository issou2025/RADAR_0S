## Goal
Collect the smaller post-MVP improvements that the design already leaves room for ([contract section 11](https://github.com/urdaraluca/friends/blob/main/docs/api/contract.md)). Split any item into its own issue when it gets picked up.

## Items
- [ ] **Web auth hardening:**
  - an HttpOnly, Secure, SameSite=Strict **cookie mode** for the refresh token on web, now possible thanks to same-origin hosting;
  - a strict **Content-Security-Policy** header from the backend (the build already uses `--no-web-resources-cdn`, so CanvasKit is self-hosted).
  - Today the web app keeps the refresh token in `flutter_secure_storage`, which only obfuscates it on web.
- [ ] **iOS**, once a Mac and a paid Apple Developer account exist:
  - run on devices and TestFlight;
  - Universal Links (`apple-app-site-association` served like `assetlinks.json`, plus the Associated Domains entitlement);
  - check that `flutter_secure_storage` keychain accessibility is `first_unlock` (for future background notifications).
- [ ] **Movie auto-fill:** search TMDB or OMDb from the activity form and fill in `title`, `description` and the Movie night attributes (genre, IMDb rating, IMDb link, year, runtime). Needs an API key, kept only on the server. Add a backend proxy endpoint and rate-limit it.
- [ ] **Filter by custom attributes** in the backlog and the wheel, e.g. "movies rated ≥ 7.5" or "genre = Comedy". SQLite `json_extract`, or generated columns + indexes.
- [ ] **Group activity feed:** `GET /groups/{id}/feed` over `group_log` (cursor-paged), plus a feed UI.
- [ ] **Personal calendar UI** over `GET /me/calendar` (the endpoint exists after {{be-calendar}}): all my groups in one view.
- [ ] **Edit a single occurrence** of a recurring event: `override_*` columns on `event_exceptions`.
- [ ] **Email:** SMTP for verification, password reset by email (today there's the `reset-password` CLI), and invite by email.
- [ ] **Localization:** Romanian alongside English (`intl`, ARB files); the currency default per locale.
- [ ] **Drag-to-reorder** categories (the `position` column already exists).
- [ ] **Postgres** migration path, if ever needed: UUIDs, UTC instants and plain SQL keep it cheap; NOCASE becomes `citext` or `lower()` indexes.
- [ ] **Observability:** a Prometheus `/metrics` endpoint or a simple uptime ping, plus alerts when backups fail.
- [ ] **Off-site backups:** rclone to cloud storage, in addition to USB/NAS.
