## Project Understanding
You need assistance with: 
**M1.6 — Establish Environment & Configuration Management**

*Project description:*
## Description

Create a consistent mechanism for managing development configuration and environment-specific values across the mobile application and backend.

## Objective

Prevent environment-specific values and secrets from being hardcoded while establishing a reproducible development setup.

## Technical requirements

Handle configuration needed for:

* Backend server configuration
* Database connection
* API base URL
* Flutter development configuration
* Environment-specific settings required by the foundation

### Security requirements

* Do not commit secrets to Git.
* Provide appropriate example configuration files.
* Clearly distinguish example configuration from actual secrets.
* Document required environment variables/configuration.

This aligns with the brief's requirement for secure authentication/token handling later and its recognition that several infrastructure providers remain undecided.

## Acceptance criteria

* A new developer can determine which configuration values are required.
* Backend can be configured without modifying source code.
* Flutter can target the appropriate development API.
* Secrets are not committed to the repository.
* Example configuration is available.
* Configuration works in the development environment.
