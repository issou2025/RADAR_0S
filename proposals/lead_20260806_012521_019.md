Across 6 audited runs (`checkpointr.com`, `woodworkersarchive.com`, `isitsafe.tv`, `make-a-beat.com` + 2 partials), **only one completed** — and it completed by the producer node emitting a final answer, never reaching `Validate and deliver` or `Finish Node`. Three were cancelled by the user at the same place: the QC → produce repair bounce, **while a technically-passing master already existed on disk**.

Representative failures, all verbatim:

- `Changing video frame properties on the fly is not supported by all filters` → **`EXIT=-1073741819` (0xC0000005, ffmpeg access violation)** from `-reinit_filter 0` over a PNG sequence that was `290 RGBA + 610 RGB24`

- `[AVFilterGraph] No option name near 'UsersMoeDocumentsGitHubFLUJO...'` — Windows path eaten by the filter-option parser in `metadata=print:file=`

**Zero `xfade` in any successful pipeline.** Every scene boundary is a hard cut via `concat -c copy`; the one hand-phased crossfade produced *"during each 0.34 s transition the incoming scene was still empty, producing dark dips at every cut"* and was abandoned. The missing primitive is already distorting creative output.

## 3. Architecture — three layers, only the bottom two generic

### Layer 1 — Executor (thin, boring, non-negotiable)

Typed wrappers over ffmpeg/ffprobe/patchright. No creative concepts.

`probe` · `probe_loudness` · `verify_decode` · `check_faststart` · `hash_asset` · `normalize_video` · `encode_deliverable(preset)` · `extract_frames_at` · `make_contact_sheet` · `render_html_frames`

**Hard rule: if any tool parameter is named `filtergraph`, the design has failed.** Exactly one escape hatch — `raw_ffmpeg`, documented as *"for when the abstraction fails; file an issue when you use it."* Every mutating tool returns `{ output_path, duration, frames, sha256, ffmpeg_command }`.

### Layer 2 — Timeline document (the actual framework)

One `project.json` with a `revision`. Agents call `set_scene` / `set_transition` / `set_audio_track` / `set_text`. **Everything else is derived**: frame counts, the concat list, `-t`, `-frames:v`, the SRT, and the xfade offset math.

Today that arithmetic is duplicated in **four** places (`scene-manifest.json`, `render-manifest.ffconcat`, `EDIT-TIMING-AND-MIX-PLAN.md`, hardcoded `-t 30 -frames:v 900`) with nothing deriving one from another.

Required fields that are **absent from every existing in-house model**: seconds/frames positioning (not steps/bars), `trimIn`/`trimOut` as authored source offsets, `speed`, `fadeIn`/`fadeOut`, `transition {type, duration}`, `fps`, `raster`, codec + loudness targets, per-scene `source` (`html` | `still` | `generated_clip`), and `pronunciation` distinct from `script` and `caption`.

This also collapses the production folder to four things:

```
project.json      # the only authored artifact
assets/           # content-addressed by sha256 (dedupes TTS/music/inserts across retries)
renders/          # evictable cache, keyed by hash of the timeline slice that produced it
out/              # the deliverable
```

`SHA256SUMS.txt`, `reproducibility-manifest.json`, `FILE-PATHS-WORKED-WITH-FINAL.md` (26 KB in one run), `bundle-audit.json`, `production-state.json`, `evidence-lock.json` all become derived. They are currently hand-maintained by an LLM and **already drifting at delivery** — `bundle-audit.json` recorded stale byte counts for three files it had just audited.

### Layer 3 — Presets, deliberately closed

A generic keyframe engine hands an LLM infinite parameters and no taste, which is how you get technically-compliant, cold, explainer-shaped output. Instead: a **closed vocabulary of named, parameterised motion presets**.

```
push_in · pull_out · ken_burns · whip_pan · match_cut
text_pop · text_wipe · lower_third · kinetic_line
mask_wipe · light_sweep · bloom_pulse · grain · speed_ramp
easing: ease_out_expo | ease_in_out_cubic | overshoot | linear
```

Plus **style profiles**, so "make it feel like an ad, not an explainer" is enforced and QC-verifiable rather than requested in prose:

| | `ad` | `explainer` |
|---|---|---|
| avg shot length | 1.8–2.5 s | 4–6 s |
| cut alignment | music beat grid | narration boundaries |
| motion per scene | required | optional |
| music bed | −18 LUFS, duck 8 dB | −22 LUFS, duck 12 dB |
| transitions | whip / sweep / mask | dissolve / cut |
| narration | 150–170 wpm, 55–70 words | 130–145 wpm |

Swing is mostly three mechanical things — shorter shots, cuts on the beat, a hotter and less-ducked bed. All three are timeline-document properties.

## 4. Harvest, don't rebuild — and what not to copy

Audited: `C:\Users\Moe\Documents\GitHub\flujoshort` (~9,700 lines, **not under version control** — `git remote -v` → `fatal: not a git repository`) and `C:\Users\Moe\Documents\GitHub\mcp-audio-studio-mcpapp` (v0.2.0).

**Neither contains an editing engine.** Of 18 editing operations, `flujoshort/studio` supports 5 (narration text, caption cues, per-scene regeneration, audio-section replacement, voice/language management). Cut, split, move, drag, speed, volume, effects, transitions, scene trim, reorder, undo/redo, multi-track timeline, waveform — **all absent**. It cannot even trigger the MP4 render; that lives in a standalone `tools/render-film.js` with no button in the UI. Scene `start`/`end`/`duration` are read-only display fields. `studio.js` is a form over `project.json`: `state.project = payload.project`, mutated in place, `JSON.stringify`'d back — no diff, no document model, and no `draggable`/drag listener in 926 lines.

`mcp-audio-studio` is fully editable but its schema cannot express a video edit: `startStep`/`lengthSteps` are `z.number().int()`, `secondsPerStep = 60 / tempo / stepsPerBeat`, drag snaps to `Math.round(dx / pixelsPerStep)`, "trim" is a side effect of window intersection (`sourceOffsetSeconds = (overlapStart - clip.startStep) * secondsPerStep`), and there is no fade, no crossfade (overlapping clips sum additively with a hard edge) and no time-stretch.

Take:

| From | What |
|---|---|
| `mcp-audio-studio/src/shared/automation.ts` | **verbatim** — lane/point/curve + binary search + smoothstep is generic numeric automation; drives `opacity`/`scale`/`position` unchanged once "step" is reinterpreted as frame. The only module both its engines share. |
| `mcp-audio-studio/scripts/build.mjs` | esbuild bundle → inline into HTML → virtual module (`virtual:studio-html`) → single self-contained string, no CDN |
| `mcp-audio-studio/src/web/bridge.ts` | dual-mode transport: App SDK `callServerTool` when embedded, HTTP `fetch` when standalone |
| `mcp-audio-studio/src/server/actions.ts` | the `define()` / `ActionDefinition` / `ToolResult` registration pattern |
| `mcp-audio-studio/src/web/studio.tsx` | optimistic-local-mutate → commit → revision-gated reconcile (currently a 1.8 s poll; upgrade to push) |
| `flujoshort/tools/video-studio.py` | `atempo_filter()` + `render_voice_track()` — chained `atempo` time-fit to an exact scene slot, `anullsrc` gaps, concat demuxer, `loudnorm=I=-16:TP=-1.5:LRA=7`. **The one correct primitive in either repo**, and exactly what the promo flows spent 4 remix rounds rediscovering. |
| `flujoshort/app.js` | 6 extractable motion presets: `reveal()` (already generic, covers ~70 % of element motion), staggered list entrance, SVG path draw-on, polyline travelling dot, orbit rotation, deterministic index-seeded particle field. **Zero `Math.random` in the file** — deterministic by construction. |
| `checkpointr-com-.../build/capture.mjs` | deterministic frame-stepping (`page.evaluate(renderFrame(i, fps))` → PNG → FFV1 → exact 900 frames at native 1920×1080) |

Do **not** copy:

- `flujoshort/tools/render-film.js`'s **`recordVideo` screencast at 1600×900**, upscaled with `scale=1920:1080:flags=lanczos`, VFR resampled to CFR 30, frame alignment recovered after the fact by `trimStart = rawDuration - duration`, and a hard failure mode (`throw new Error('Playback stopped early at ${t} seconds')`) that can kill a 148 s render at second 140
- **Two independently written render engines with no shared core and no parity test.** `mcp-audio-studio` runs a `ConvolverNode` with a `Math.random()` noise impulse live vs. a deterministic 4-tap comb offline; the browser's `DynamicsCompressorNode` live vs. a hand-rolled envelope follower offline. `audio-engine.test.ts` and `audio-renderer.test.ts` treat them as unrelated subjects — nothing asserts they produce the same output. Share the transform/compositing math or inherit this.
- **`revision` as a bare counter.** No tool in `actions.ts` accepts `expectedRevision`/`ifMatch`; every mutating action calls `store.mutate()` unconditionally, so it is last-write-wins with a version number attached. Make it a precondition that returns a conflict.
- **Non-atomic persistence** — `writeFile` straight to the target path, no temp+rename; a crash mid-write corrupts the project and `open()` silently falls back to a fresh default with only a `console.error`.
- **Binary assets inline in the document** (`AudioClip.dataUrl`, base64, no `.max()` on the schema). One to two orders of magnitude worse for video.
- **Renders in an in-memory `Map` capped at 8**, lost on process restart.
- **Whole document returned on every mutation** (`projectResult()` embeds the full project) — an O(project size) response for toggling one step.
- Manim / any codegen-based renderer: generating Python is the same failure mode as generating filtergraphs, in a different language. `mcp-manimgl` is in an **error** state anyway. HTML/CSS/JS is already the proven renderer on this machine.

## 5. Non-goals

- A Clipchamp clone with full direct-manipulation editing. **The agent will never use drag handles**; ~80 % of that effort buys affordances nothing in the pipeline consumes. The UI's job is **scrub-and-approve over the same `project.json` the agent is mutating** — timeline with scene boundaries, contact sheet, waveform with the duck envelope drawn on it, per-scene approve/reject. That turns "is this 30 s MP4 any good?" from a 149-message forensic QC subflow into ~20 s of looking at it. Editing affordances come later, and only the ones actually missed.
- A generic keyframe/property-animation engine (see Layer 3).
- Owning music composition. Video-editor owns a simple mix bus (`normalize_loudness`, `duck`, `mix`, `mux`) because 90 % of promos are VO + bed. `mcp-audio-studio` stays an *optional* upstream for genuinely composed, section-timed beds — cross-server project handoff is a lot of complexity for a narrow win.
- Retiring `flujoshort`'s studio. It is a good narration/caption/localisation console; keep it as that.

## 6. Implementation constraints (from the FLUJO codebase)

`mcp-servers\video-editor\` as an npm workspace beside `bash` / `browser` / `filesystem` / `flujo`, following those verbatim: TypeScript ESM, **low-level SDK** (`new Server(...)` + `setRequestHandler(ListToolsRequestSchema|CallToolRequestSchema)` + `StdioServerTransport`, **raw JSON Schema, no zod, no `McpServer`/`server.tool()`**), convention `src/index.ts` (wiring) + `src/tools.ts` (`<name>ToolDefinitions(): Tool[]` + `<name>CallTool()` switch). Vendored third-party dirs under `mcp-servers/` use `McpServer`+zod — do **not** follow those.

Registration: `package.json` (version pinned to the monorepo's, `build: "tsc -p tsconfig.json && node ../embed-shared.mjs video-editor"`), shared `tsconfig.json` verbatim, root `workspaces` + `dependencies` + `build:mcp`, a descriptor row in `scripts/validate-mcp-release.mjs`, and a `ShippedMcpServerDescriptor` in `shippedServers.ts` (`command:'node'`, `args:[<appRoot>/mcp-servers/<dir>/dist/index.js]`) merged by `shippedServerMigration.ts`.

Two hard constraints specific to this server:

1. **stdio servers do not inherit `process.env`** — only ~12 default Windows vars plus `config.env`. `FFMPEG_PATH`, `FFPROBE_PATH`, `FONTCONFIG_FILE` and the scratch dir must be declared explicitly, not assumed from PATH.
2. **stdout carries MCP frames only** — all ffmpeg stderr/progress goes to stderr or a log file, never stdout.

Plus: never invoke tools through PowerShell (see #364); the renderer must accept `file://`/local paths natively (the QA agent's terminal blocker was `NAVIGATION_BLOCKED: Only HTTP and HTTPS URLs are allowed`, then `Private and local network destinations are blocked` for `localhost`); **derive, never duplicate**. Point scratch at **G: (120.9 GB free)**, not C: (20.0 GB).
