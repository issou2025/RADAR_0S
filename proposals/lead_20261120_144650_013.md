*Project description:*
An agent shell inherits its own CLAUDE_CONFIG_DIR. A fixture run without an explicit fixture home therefore writes into the live account: a fake Claude, run from an agent shell during a local test, wrote session and transcript files into that agent's real Claude config dir. A few have ad-hoc guards, such as fixture-codex.sh login and seed-refusal-registry.py; most have none.

Require all offline provider stand-ins and provider/app state writers to resolve their effective config directory and find a `.cagents-fixture-root` file on that directory or an ancestor before starting. Use one shared helper per shell, Python, and JavaScript, propagate markers through fixture creators and test harnesses, and preserve stricter existing checks. Add refusal, unchanged-state snapshot, marked-startup, symlink, and fixture inventory contracts. Native scenes that only write through the evidence command channel are exempt; direct writers are guarded.
