## 7. Trend Signals

**1. Delivery guarantees are becoming an SLA**
- Evidence: OpenClaw silent drops, NanoClaw queue starvation, NanoBot WebSocket recovery, Hermes gateway loops.
- **For developers:** Build retry, dead-letter, and user-visible failure states into any channel or transport layer from day one.

**2. Context economy is the next competitive battleground**
- Evidence: IronClaw’s measured 49 KiB MIME-blob inference cost and cache-hit collapse; CoPaw’s prompt-cache observability request; OpenClaw compaction work; ZeroClaw persistent prompt attachments.
- **For developers:** Instrument context size, cache-hit rates, and per-payload token cost; avoid injecting unrequested tool output.

**3. Multi-agent orchestration is moving from power-user to enterprise requirement**
- Evidence: OpenClaw multi-agent instability, CoPaw multi-tenant Hub, IronClaw bot-group epics, ZeroClaw session-persistence ownership.
- **For developers:** Design session ownership, per-group isolation, and RBAC before multi-agent features ship.

**4. MCP is growing, but integration quality lags**
- Evidence: Hermes stdio liveness inversion, Moltis Fastmail OAuth scope bug, ZeroClaw triple-spawn and payload duplication, CoPaw hung-RPC recovery.
- **For developers:** Treat MCP transport liveness, OAuth scope correctness, and egress control as first-class engineering problems.

**5. Upgrade trust is a moat**
- Evidence: OpenClaw docs-ahead-of-release, Windows installer issues across Hermes/CoPaw/NanoClaw/LobsterAI, migration regressions in several projects.
- **For developers:** Invest in upgrade-path tests, migration fixtures, and release/docs parity; user trust is eroded by regression cycles.

**6. Security is becoming baseline, not differentiator**
- Evidence: IronClaw TOCTOU fixes, ZeroClaw SSRF/webhook-auth hardening, NanoClaw injection fix, OpenClaw install-policy warnings.
- **For developers:** Build approval gates, egress control, and sandbox escape prevention into agent frameworks proactively rather than reactively.
