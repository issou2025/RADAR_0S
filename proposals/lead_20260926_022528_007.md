# Project Proposal — Unknown

## Project Understanding
You need assistance with: 
**Rebuild as a standalone App Store app that connects to Mentra Live directly over Bluetooth**

*Project description:*
## Problem
The project is currently a MentraOS miniapp (`@mentra/miniapp`, PR #2, and PR #4 for the spoken welcome), which runs inside Mentra's phone app. Andrew wants Mentra X Joby to be its own iPhone app that talks to the glasses directly through Mentra's Bluetooth SDK, without the MentraOS app, miniapp runtime, or store in between. Mentra recommends this route for Mentra Live.

Reference: https://docs.mentraglass.com/bluetooth-sdk/overview

Target hardware is **Mentra Live**, which has no display, so everything is audio: spoken output and voice input.

## User-visible outcome
A user installs "Mentra X Joby" from the Apple App Store on their iPhone, opens it, pairs their Mentra Live glasses from inside the app, and hears a spoken welcome through the glasses. No MentraOS app is needed.

## Acceptance criteria
- [ ] A standalone iOS app project exists in this repo and builds and runs on a physical iPhone.
- [ ] The app discovers and connects to Mentra Live using Mentra's Bluetooth SDK, with no dependency on the MentraOS app, miniapp runtime, or store.
- [ ] The app shows a clear connection state on the phone (searching, connected, disconnected) and can reconnect after the glasses drop.
- [ ] Once connected, the app plays one spoken welcome through the glasses' speaker (same idea as #3: something like "Welcome to the Mentra X Joby tour"). Audio reaches the glasses through the phone's Bluetooth media route.
- [ ] No text is sent to a glasses display.
- [ ] The app meets App Store submission basics: Bluetooth and microphone permission prompts with plain-language reasons, an app icon and name, and a build that can be uploaded to TestFlight.
- [ ] The README explains how to build, run on an iPhone, pair the glasses, and produce a TestFlight build.
- [ ] The plan says which parts of the current miniapp code are kept, moved, or removed.
- [ ] No secrets, signing keys, or API keys are committed.
