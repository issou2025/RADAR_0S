# Project Proposal — Bim Modeling

## Project Understanding
You need assistance with: 
**Leave out of the export the properties that carry no value in Revit**

*Project description:*
Split out of #35, which is closed: its acceptance criteria (the export phase filter) were met by #55, but its goal also named data that Revit itself would not write, and that part was not covered.

Properties that carry no value in Revit can still appear in the export. Revit leaves such a parameter out of its own IFC export, while RvtIO can write it with an empty, zero or default value.

Needed: find, per parameter storage kind, how the file marks a parameter as having no value, leave those parameters out of the IFC property sets (and decide whether the JSON output keeps them, with the decision documented), and list the properties that change against the reference export on the public samples. The phase filter of a view, also not covered by #55, is out of scope here.

Acceptance:
- A parameter without a value in Revit is not written to an IFC property set.
- Parameters that hold a real zero or empty string keep being written.
- The number of properties that change is recorded per sample, with any that move away from the reference.
